## 摘要
LoRA 等参数高效微调方法已成为适配大型基础模型的标准方法。将微调应用于分布式场景面临若干挑战。现有的大多数分布式 LoRA 方法依赖集中式聚合，而基于 gossip 的去中心化 LoRA 则需要在多个模型副本之间进行重复同步。这两类方法均会带来显著的通信开销，并因同时聚合多个模型更新而引入误差。本文从不同视角出发，提出了一种基于随机游走的 LoRA 微调方案。该方案不再维护多个模型副本，而是让单个模型令牌在网络中遍历，并依据本地微调目标进行顺序更新。这一设计无需全局同步，显著降低了通信与计算成本，并避免了聚合误差。我们在标准假设下，为非凸目标提供了严格的收敛性保证。通过在多个自然语言处理任务和图拓扑上的实验结果，我们表明，所提出的方法以远低于基于 gossip 的 LoRA 的通信与计算开销，实现了具有竞争力的任务性能。

## Abstract
Parameter-efficient fine-tuning methods such as LoRA have become a standard approach for adapting large foundation models. Adopting fine-tuning to distributed settings faces several challenges. Most existing distributed LoRA methods rely on centralized aggregation, and gossip-based decentralized LoRA requires repeated synchronization among multiple model copies. Both methods incur significant communication overhead and introduce errors due to simultaneous aggregation of multiple model updates. In this paper, we take a different perspective and propose a random-walk-based LoRA fine-tuning scheme. Instead of maintaining multiple model replicas, a single model token traverses the network and is updated sequentially using local fine-tuning objectives. This design eliminates the need for global synchronization, substantially reduces communication and computation costs, and avoids aggregation errors. We provide rigorous convergence guarantees for non-convex objectives under standard assumptions. Through empirical results on multiple NLP tasks and graph topologies, we show that the proposed method achieves competitive task performance with substantially less communication and computation than gossip-based LoRA.

  即**因子平均与完整更新矩阵平均不一致**。
- 如果先恢复完整矩阵、再进行平均并通过 SVD 压缩回低秩形式，则会引入：
  - 额外的矩阵计算；
  - SVD 成本；
  - 低秩截断误差；
  - 更高的通信和存储开销。

# 2. 论文提出的方法论

## 2.1 LoRA 参数化

对于预训练模型中的某个权重矩阵 \(W_0\)，LoRA 不直接更新完整矩阵，而是使用低秩增量：

\[
W = W_0 + BA,
\]

其中：

- \(W_0 \in \mathbb{R}^{d_1 \times d_2}\) 为冻结的预训练权重；
- \(A \in \mathbb{R}^{r \times d_2}\)；
- \(B \in \mathbb{R}^{d_1 \times r}\)；
- \(r \ll \min(d_1,d_2)\) 为 LoRA rank。

可训练参数量由原本的 \(d_1d_2\) 降低为：

\[
r(d_1+d_2).
\]

论文中的 RW-LoRA 训练对象就是各层的 \(A\) 和 \(B\)，而不是完整模型权重。

## 2.2 随机游走式模型令牌

论文将通信网络建模为一个有限无向图：

\[
G=(V,E),
\]

其中：

- \(V=[N]\) 表示节点集合；
- \(E\) 表示节点之间允许通信的边；
- 每个节点保存自己的本地训练数据；
- 一个模型令牌携带当前的 LoRA 参数 \((A^{(t)},B^{(t)})\)。

在第 \(t\) 个通信时刻：

1. 令牌位于节点 \(v_t\)；
2. 当前节点使用本地数据对 LoRA 参数进行更新；
3. 根据转移矩阵 \(P\) 随机选择下一个节点 \(v_{t+1}\)；
4. 将更新后的令牌传递给下一个节点；
5. 重复上述过程。

与 Gossip 方法不同，网络中始终只有一个模型状态在传播，而不是每个节点都维护并同步一个模型副本。

## 2.3 目标函数

论文将全局微调目标定义为节点局部目标的加权平均：

\[
f(W)=\mathbb{E}_{v\sim \pi}[f_v(W)],
\]

其中：

- \(f_v(W)\) 是节点 \(v\) 的局部微调目标；
- \(\pi\) 是目标节点采样分布；
- 在实验中，\(\pi\) 被设置为均匀分布。

随机游走的转移矩阵需要具有 \(\pi\) 作为平稳分布。论文采用 Metropolis–Hastings 方法构造相应的转移矩阵，以便在任意给定通信图上实现目标采样分布。

## 2.4 本地 LoRA 更新

在节点 \(v_t\) 上，令牌执行 \(K\) 个本地训练步骤。初始化为：

\[
A^{(t,0)}=A^{(t)}, \qquad B^{(t,0)}=B^{(t)}.
\]

对 \(k=0,\ldots,K-1\)，依次执行：

\[
A^{(t,k+1)}
=
A^{(t,k)}
-
\eta \nabla_A \tilde f_{v_t}(W^{(t,k)}),
\]

\[
B^{(t,k+1)}
=
B^{(t,k)}
-
\eta \nabla_B \tilde f_{v_t}(W^{(t,k)}),
\]

其中：

- \(\eta\) 是学习率；
- \(\tilde f_{v_t}\) 是基于节点本地随机数据批次的随机目标；
- 当前模型权重为：
  \[
  W^{(t,k)}=W_0+B^{(t,k)}A^{(t,k)}.
  \]

完成 \(K\) 个本地步骤后，令：

\[
A^{(t+1)}=A^{(t,K)}, \qquad B^{(t+1)}=B^{(t,K)}.
\]

随后令牌按照：

\[
v_{t+1}\sim P_{v_t,\cdot}
\]

随机移动到下一节点。

## 2.5 算法初始化与整体流程

论文采用如下初始化方式：

- \(A^{(0)}\) 的元素独立采样自高斯分布：
  \[
  [A^{(0)}]_{ij}\sim \mathcal{N}(0,\sigma^2);
  \]
- \(B^{(0)}=0\)。

因此初始时：

\[
W^{(0)}=W_0+B^{(0)}A^{(0)}=W_0.
\]

整体流程可以概括为：

1. 初始化 LoRA 因子和随机游走起点；
2. 在当前节点计算当前模型；
3. 使用该节点的本地数据执行 \(K\) 步 LoRA 优化；
4. 按照通信图上的随机游走转移矩阵选择下一节点；
5. 传输 \((A,B)\)；
6. 直至达到预设迭代次数；
7. 输出最终 LoRA 适配器和模型。

## 2.6 理论收敛结果

论文在非凸目标下给出了收敛保证。其主要结论是：在光滑性、有界梯度、有界方差、矩阵范数次乘性以及 LoRA 因子有界等假设下，算法的平均一阶驻点指标满足近似形式：

\[
\frac{1}{T}\sum_{t=1}^{T}
\left(
\mathbb{E}\|\nabla_A f(W^{(t)})\|^2
+
\mathbb{E}\|\nabla_B f(W^{(t)})\|^2
\right)
\leq
\widetilde O
\left(
\epsilon^2+
\frac{L\tau}{\sqrt T}
+
\frac{L\tau}{T}
\right),
\]

其中：

- \(T\) 是随机游走训练步数；
- \(L\) 是光滑性常数；
- \(\tau\) 与随机游走的混合时间有关；
- \(\epsilon\) 控制随机游走分布接近平稳分布的误差；
- \(\widetilde O\) 隐藏了对数因子。

论文特别指出，随机游走的混合时间会影响收敛速度。网络拓扑越不利、混合时间越长，模型需要更多步骤才能充分访问不同节点的数据分布。

此外，由于 LoRA 的优化变量是矩阵因子 \(A\) 和 \(B\)，而更新矩阵为 \(BA\)，其理论分析比普通向量参数的 Markov 链随机采样优化更复杂，收敛界中对混合时间的依赖也可能更强。

总体而言，实验能够支持论文关于“在 i.i.d. NLP 场景下通信效率较高”的核心结论，但还不足以证明其在更广泛分布式学习环境中的普适优势。

---

# 6. 主要结论与发现

## 6.1 性能方面

- 在完全图和环图上，RW-LoRA 在 MRPC、QNLI、MNLI、QQP 和 SST-2 上总体能够取得与 Gossip LoRA 相当的结果。
- 部分任务上，RW-LoRA 的最终或最佳得分高于 Gossip baseline。
- 在完全图中，RW-LoRA 的代表性结果包括：
  - MRPC Final：91.32；
  - SST-2 Final：93.28；
  - QNLI Final：91.35；
  - MNLI Final：84.50；
  - QQP Final：87.61。
- 在环图中，RW-LoRA 仍然保持了较有竞争力的性能，但 QQP 的最终结果方差较大，说明随机游走轨迹可能导致一定不稳定性。

## 6.2 通信和计算方面

- RW-LoRA 每轮只需要在两个相邻节点之间传输一次模型令牌。
- Gossip LoRA 每轮需要多个节点与邻居反复交换模型更新，网络级通信量随节点度数增长。
- 在完全图中，RW-LoRA 相对于 Gossip 的通信优势尤其明显。
- RW-LoRA 的本地更新总数也低于 Gossip baseline：
  - 约 25,000 次；
  - Gossip 约 54,000 次。
- 因此，RW-LoRA 在论文设置下实现了：
  - 更低的通信成本；
  - 更低的计算量；
  - 避免多副本聚合和 LoRA 因子平均误差。

## 6.3 理论方面

- 论文为随机游走 LoRA 在非凸目标下提供了收敛分析。
- 收敛速度受到 Markov 链混合时间影响。
- 这说明网络拓扑不仅决定通信成本，也会影响模型访问各节点数据的充分程度和优化收敛速度。

# 7. 优点

## 7.1 方法设计上的亮点

- **通信机制简单**：每次只传输一个模型令牌，不需要全网同步。
- **无需参数服务器**：适合没有中心协调节点或不希望依赖中心服务器的场景。
- **避免多副本维护**：网络中只维护一条模型轨迹，降低节点端存储和计算压力。
- **避免 LoRA 因子聚合失配**：不需要直接平均多个 \((A_i,B_i)\)，从根源上规避：
  \[
  \sum_iB_iA_i\neq(\sum_iB_i)(\sum_iA_i)
  \]
  的问题。
- **适合稠密网络**：在完全图等高连接度网络中，Gossip 通信成本会快速增加，而随机游走每轮仍只需一次传输。
- **具有理论可解释性**：通过平稳分布和混合时间分析随机访问各节点数据的影响。
- **兼容 LoRA 低秩训练**：能够保留 LoRA 的参数高效特性。

## 7.2 实验设计上的亮点

- 同时测试环图和完全图，体现了不同网络连接度下的行为；
- 覆盖多个 GLUE 任务，而非仅在单一数据集上验证；
- 同时报告最终性能、最佳性能、通信量和计算量；
- 对 LoRA rank 进行消融，结果显示在 \(r=4,8,16,32\) 范围内性能总体较稳定；
- 使用多条随机游走轨迹进行重复实验，具有一定的随机性控制意识。

# 8. 不足与局限

## 8.1 方法本身的局限

- **顺序更新导致潜在的收敛速度问题**：一次只有一个节点参与训练，天然缺乏并行性。在需要快速完成训练的场景中，可能不如 Gossip 或联邦并行方法。
- **混合时间依赖**：如果通信图连通性较差或混合时间较长，令牌可能长时间集中访问部分节点，导致数据覆盖不充分和收敛变慢。
- **单令牌存在串行瓶颈**：整个训练过程依赖一条模型轨迹，令牌丢失、节点离线或通信中断都可能影响训练连续性。
- **节点异构适应性尚未解决**：论文默认节点使用相同的 LoRA rank，未来才计划研究异构 rank 网络。
- **对节点故障和恶意攻击的处理有限**：虽然论文引用了随机游走鲁棒性和隐私相关工作，但当前 RW-LoRA 实验没有系统评估节点失效、恶意更新或数据投毒。
- **隐私保护不是本文重点**：模型令牌会在多个节点之间传播，尽管不直接传输原始数据，但模型更新可能泄露信息，论文没有给出差分隐私、安全聚合或攻击评估。

## 8.2 理论分析的限制

- 理论依赖较强的标准化假设，包括：
  - 局部目标函数光滑；
  - 随机梯度有界；
  - 随机梯度方差有界；
  - LoRA 因子 \(A,B\) 始终有界。
- 特别是 \(A\) 和 \(B\) 的有界性在实际深度神经网络训练中并非自动成立，通常需要额外的正则化、投影或经验验证。
- 理论结果主要刻画一阶驻点收敛，并不保证：
  - 收敛到全局最优；
  - 达到更高任务准确率；
  - 在实际 wall-clock 时间上优于并行方法。
- 收敛界对混合时间的依赖表明，理论优势会受到具体网络拓扑和转移矩阵的显著影响。

## 8.3 实验覆盖不足

- 仅使用 RoBERTa-base，模型规模和架构覆盖有限；
- 只测试分类类 GLUE 任务，没有评估：
  - 文本生成；
  - 指令微调；
  - 对话任务；
  - 长文本任务；
  - 多模态任务。
- 节点数据均为 i.i.d.，与医疗、企业和跨机构场景中的非独立同分布数据存在差距。
- 只使用 30 个节点，尚不清楚在数百或数千节点网络中的表现。
- 拓扑只有环图和完全图，缺少真实网络实验。
- 仅与 Gossip LoRA 比较，缺少更全面的基线体系。
- 没有报告 GPU、训练时长、实际网络带宽和端到端运行时间，因此“通信效率”和“计算效率”主要是理论或代理指标，而不是完整系统层面的测量。

## 8.4 公平性与偏差风险

- RW-LoRA 和 Gossip LoRA 的收敛轮数差异较大，若仅比较各自“运行到收敛”的结果，可能存在训练预算不完全一致的问题。
- Gossip baseline 的统计方差报告不够完整，而 RW-LoRA 报告了多次运行的均值和标准差，可能影响结果的可比性。
- 论文主要展示 QNLI 的通信—准确率曲线，其他数据集虽然声称趋势相似，但缺少完整曲线和详细资源数据。
- i.i.d. 数据划分有利于随机游走方法快速获得近似全局分布，不能直接推断其在强非 i.i.d. 场景下仍具有同等优势。
- 论文的实验结论更准确地说是：
  > 在 RoBERTa-base、30 节点、i.i.d. GLUE 分类任务和两种固定拓扑下，RW-LoRA 相比 Gossip LoRA 展现出较好的通信—性能权衡。
  
  不宜泛化为其在所有分布式微调场景中都优于联邦或 Gossip 方法。
