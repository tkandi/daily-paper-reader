## 摘要
时序图神经网络 (TGNs) 在动态图任务上取得了最先进的性能，然而现有系统仅专注于加速训练——在推理阶段，尽管只有一小部分节点受到影响，但每条新边都会触发 $O(|V|)$ 次嵌入更新。我们提出了 StreamTGN，这是首个利用时序图更新固有局部性的流式 TGN 推理系统：在 $L$ 层 TGN 中，一条新边仅影响端点 $L$ 跳范围内的节点，在百万级节点图中，这一比例通常低于 0.2%。StreamTGN 维护持久化的 GPU 驻留节点内存，并使用脏标记传播（dirty-flag propagation）来识别受影响集合 $\mathcal{A}$，在零精度损失的情况下，将每批次的复杂度从 $O(|V|)$ 降低到 $O(|\mathcal{A}|)$。漂移感知的自适应重建调度和具有松弛排序的批处理流进一步最大化了吞吐量。在八个时序图（2K 至 2.6M 节点）上的实验表明，在精度相同的情况下，TGN 的加速比达到 4.5$\times$ 至 739$\times$，TGAT 的加速比高达 4,207$\times$。StreamTGN 与训练优化是正交的：将 SWIFT 与 StreamTGN 结合，在三种架构（TGN、TGAT、DySAT）上实现了 24$\times$ 的端到端加速。

## Abstract
Temporal Graph Neural Networks (TGNs) achieve state-of-the-art performance on dynamic graph tasks, yet existing systems focus exclusively on accelerating training -- at inference time, every new edge triggers $O(|V|)$ embedding updates even though only a small fraction of nodes are affected. We present \textbf{StreamTGN}, the first streaming TGN inference system exploiting the inherent locality of temporal graph updates: in an $L$-layer TGN, a new edge affects only nodes within $L$ hops of the endpoints, typically less than 0.2\% on million-node graphs. StreamTGN maintains persistent GPU-resident node memory and uses dirty-flag propagation to identify the affected set $\mathcal{A}$, reducing per-batch complexity from $O(|V|)$ to $O(|\mathcal{A}|)$ with zero accuracy loss. Drift-aware adaptive rebuild scheduling and batched streaming with relaxed ordering further maximize throughput. Experiments on eight temporal graphs (2K--2.6M nodes) show 4.5$\times$--739$\times$ speedup for TGN and up to 4,207$\times$ for TGAT, with identical accuracy. StreamTGN is orthogonal to training optimizations: combining SWIFT with StreamTGN yields 24$\times$ end-to-end speedup across three architectures (TGN, TGAT, DySAT).

#### 1. 核心问题与整体含义（研究动机和背景）
时序图神经网络（TGNs）在动态图任务（如欺诈检测、推荐系统）中表现卓越。然而，现有的系统（如 TGL、SWIFT 等）主要关注**训练加速**，而在**在线推理（Serving）**阶段存在严重效率瓶颈：
*   **计算冗余**：现有系统采用批处理模式，每当新边到达时，即使只有极少数节点受影响，也会重新计算全图 $O(|V|)$ 个节点的嵌入。
*   **推理主导**：在生产环境中，推理占总计算预算的约 96%，而训练仅占 4%。即使是毫秒级的推理延迟降低，在大规模查询下也能节省巨大的算力成本。
*   **局部性观察**：论文指出，在 $L$ 层 TGN 中，新边仅影响其端点 $L$ 跳范围内的节点（受影响集 $\mathcal{A}$）。在百万级节点图中，这一比例通常低于 0.2%。

#### 2. 论文提出的方法论
StreamTGN 是首个利用时序局部性实现**增量更新**的流式推理系统，核心技术包括：
*   **持久化 GPU 驻留内存与脏标记追踪**：在 GPU 上维护持久的节点内存、邻接表和嵌入缓存。通过轻量级的“脏标记”传播机制，识别受影响的节点集 $\mathcal{A}$，将复杂度从 $O(|V|)$ 降至 $O(|\mathcal{A}|)$。
*   **增量计算流水线**：
    *   **增量采样与读取**：仅针对受影响节点更新邻居缓存和特征检索。
    *   **Delta 嵌入生成**：利用邻居的稳定性，仅计算新增、过期或更新邻居带来的嵌入增量（Delta），大幅减少注意力机制的计算量。
*   **漂移感知自适应重建调度**：监控增量更新产生的近似误差（漂移），当误差超过阈值时触发局部或全局重建，确保精度。
*   **松弛排序的批处理流**：允许同一批次内的边共享逻辑时间戳并并行处理，在保证误差可控的前提下极大提升吞吐量。

*   **内存限制**：由于所有状态（内存、嵌入、邻接表）均驻留在 GPU，对于超大规模图（如数十亿节点），单块 GPU 的显存可能成为瓶颈（实验中 DySAT 在 Stack-Overflow 上出现 OOM）。
