## 摘要
上下文稀疏性是降低大语言模型（LLM）推理过程中计算复杂度的方法之一。现有的基于上下文稀疏性且精度损失极小的 LLM 推理加速技术通常需要训练稀疏模式预测器。本文提出了一种用于加速 LLM 中基于 ReGLU 的前馈网络（FFN）推理的框架。该框架提供了一种快速、无需训练的方法，通过对门控投影矩阵进行截断感知的奇异值分解（SVD）来构建稀疏模式预测器，并结合了阈值校准算法，以及支持在 CUDA 和 CANN 设备上进行条件计算的推理执行器。在三个 FFN 平均激活稀疏度为 90% 的稀疏 LLM 上进行的实验表明，在涉及复杂数学和代码生成的任务中，端到端解码时间缩短了高达 1.8 倍，同时基准测试分数下降不到 1%。这项工作推进了 LLM 在边缘设备上的部署。

## Abstract
Contextual sparsity is one of the approaches used to reduce computational complexity in the inference process of large language models (LLMs). Existing techniques for efficient LLM inference acceleration based on contextual sparsity with minimal accuracy degradation require training sparse pattern predictors. This paper presents a framework for accelerating inference of ReGLU-based feed-forward networks (FFNs) within LLMs. The proposed framework provides a fast, training-free method for building sparse pattern predictors using truncation-aware singular value decomposition (SVD) of the gate projection matrix, along with a threshold calibration algorithm, and inference executors supporting conditional computation on CUDA and CANN devices. Experiments on three sparse LLMs with an average activation sparsity level of 90% in the FFNs demonstrate up to a 1.8x reduction in end-to-end decoding time while maintaining less than 1% degradation in benchmark scores on tasks involving complex math and code generation. This work advances the deployment of LLMs on edge devices.

### 1. 核心问题与整体含义（研究动机和背景）
大语言模型（LLM）在边缘设备部署时面临巨大的计算和内存带宽挑战。研究发现，基于 ReGLU 激活函数的模型存在**上下文稀疏性**（Contextual Sparsity），即在推理过程中，FFN 层中只有约 10% 的神经元会被激活。
*   **现有问题**：目前的加速方案通常需要训练额外的轻量级预测器（如 Deja Vu），这增加了模型转换的复杂度和训练成本。
*   **核心目标**：提出一种**免训练（Training-free）**的框架，通过数学分解手段快速构建稀疏预测器，在保证精度的前提下显著提升推理速度。

### 2. 方法论：核心思想与关键技术
该框架分为离线校准和在线推理两个阶段，核心思想是利用低秩分解来近似神经元的激活行为。

*   **数据感知 SVD 分解（Data-aware SVD）**：
    *   对 FFN 的门控投影矩阵 $W_{gate}$ 进行奇异值分解（SVD）。
    *   引入**数据白化（Data Whitening）**技术：利用少量校准数据的协方差矩阵进行 Cholesky 分解，调整 SVD 过程，使其更关注实际输入分布中的高频特征，从而降低 Frobenius 范数误差。
*   **贪心偏置校准算法（Greedy Bias Calibration）**：
    *   SVD 近似会带来分布偏移，导致预测器出现假阴性（误删有效神经元）。
    *   论文设计了一个贪心算法，为每个神经元计算一个特定的偏置项（阈值）。该算法在给定的稀疏度预算下，优先保留对输出精度贡献最大的神经元。
*   **顺序执行流水线（Sequential Pipeline）**：
    *   不同于传统的并行计算 Gate 和 Up 投影，该方法先计算 Gate 投影，利用其结果进一步过滤掉预测器未能识别的“假阳性”神经元，从而在 Up 和 Down 投影阶段实现更高的实际稀疏度。
*   **硬件执行器优化**：
    *   针对 NVIDIA GPU（CUDA）编写了自定义内核，避免原子加法以保证确定性。
    *   针对华为昇腾（CANN）利用高阶 PyTorch API 实现了高效的矩阵切片计算。

### 6. 主要结论与发现
*   **加速效果**：在保持 90% 稀疏度的情况下，端到端（E2E）解码速度提升高达 **1.8 倍**。
*   **精度保持**：在数学和代码等高敏感任务中，精度下降控制在 **1% 以内**，表现优于现有的免训练方法（如 GRIFFIN）。
*   **预测质量**：SVD 预测器的 ROC-AUC 分数显著高于 Deja Vu 等学习型预测器，说明直接利用权重结构的分解能更本质地捕捉神经元激活规律。

### 7. 优点：亮点总结
*   **免训练部署**：无需复杂的梯度下降训练，仅靠线性代数分解和简单校准即可完成，极大降低了 LLM 压缩加速的门槛。
*   **理论支撑**：论文在附录中提供了 SVD 预测器误差界的确定性数学证明，这在同类经验性研究中较为少见。
*   **跨平台适配**：同时支持 CUDA 和国产昇腾 CANN 架构，具有很强的工业实用价值。

### 8. 不足与局限
*   **架构限制**：该方法高度依赖 ReGLU/ReLU 等具有天然稀疏特性的激活函数。对于使用 SiLU（如原始 Llama 3）的模型，直接应用会导致精度大幅下降，需先进行“ReLU 化”微调。
*   **Batch Size 限制**：目前主要针对 **Batch Size = 1** 的边缘推理场景。在高性能服务器的大 Batch 场景下，由于不同序列的稀疏模式不重合，加速效果会显著减弱。
*   **Prefill 阶段无效**：由于 Prefill（预填充）阶段通常是计算密集型而非访存密集型，且难以应用动态稀疏性，该方法目前仅加速 Decoding（解码）阶段。
