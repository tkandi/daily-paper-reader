## 摘要
扩展自回归大语言模型（LLMs）推动了前所未有的进步，但也带来了巨大的计算成本。在这项工作中，我们通过利用 LLM 前馈层中的非结构化稀疏性来解决这些成本问题，前馈层是占据模型大部分参数和执行 FLOPs 的主要组件。为了实现这一目标，我们引入了一种新的稀疏打包格式和一组 CUDA 内核，旨在与现代 GPU 的优化执行流水线无缝集成，从而在 LLM 推理和训练期间实现高效的稀疏计算。为了证实我们的收益，我们对 LLM 稀疏性进行了定量研究，证明简单的 L1 正则化可以诱导超过 99% 的稀疏性，且对下游性能的影响微乎其微。当与我们的内核结合使用时，我们展示了这些稀疏水平可以转化为显著的吞吐量、能效和内存使用优势，且这些优势随模型规模的扩大而增加。我们将以开源许可证发布所有代码和内核，以促进采用并加速研究，从而将稀疏性确立为提高现代基础模型效率和可扩展性的实用维度。

## Abstract
Scaling autoregressive large language models (LLMs) has driven unprecedented progress but comes with vast computational costs. In this work, we tackle these costs by leveraging unstructured sparsity within an LLM's feedforward layers, the components accounting for most of the model parameters and execution FLOPs. To achieve this, we introduce a new sparse packing format and a set of CUDA kernels designed to seamlessly integrate with the optimized execution pipelines of modern GPUs, enabling efficient sparse computation during LLM inference and training. To substantiate our gains, we provide a quantitative study of LLM sparsity, demonstrating that simple L1 regularization can induce over 99% sparsity with negligible impact on downstream performance. When paired with our kernels, we show that these sparsity levels translate into substantial throughput, energy efficiency, and memory usage benefits that increase with model scale. We will release all code and kernels under an open-source license to promote adoption and accelerate research toward establishing sparsity as a practical axis for improving the efficiency and scalability of modern foundation models.

### 论文总结：Sparser, Faster, Lighter Transformer Language Models

#### 1. 核心问题与整体含义
论文针对大语言模型（LLM）在扩展过程中面临的巨大计算开销、高能耗及内存占用挑战，探讨了如何利用**非结构化稀疏性（Unstructured Sparsity）**来提升效率。尽管稀疏性在理论上能减少计算量，但由于现代 GPU 硬件和软件栈高度优化了稠密矩阵运算，传统的稀疏算子在实际运行中往往比稠密算子更慢。本研究旨在打破这一“稀疏性悖论”，通过设计新型稀疏格式和高效 CUDA 内核，使稀疏 LLM 在现代 GPU 上实现真正的端到端加速。

#### 2. 方法论
核心思想是利用 L1 正则化在模型的前馈网络（FFN）层诱导极高水平的激活稀疏性，并配合定制化的硬件加速方案。
*   **稀疏诱导：** 采用 ReLU 激活函数，并在标准交叉熵损失基础上增加 L1 正则化项，强制模型在推理时仅激活极少数神经元。
*   **TwELL 格式（Tile-wise ELLPACK）：** 论文提出的一种新型稀疏数据打包格式。它将矩阵划分为水平 Tile，在 Tile 内部进行局部 ELL 编码。其关键优势在于可以无缝集成到现代 Tiled Matmul 内核的 Epilogue（收尾阶段）中，避免了昂贵的全局同步和格式转换开销。
*   **推理内核融合：** 针对推理阶段，设计了将 Gate、Up 和 Down 投影融合的单内核流水线，通过 TwELL 格式跳过零值计算，大幅减少 DRAM 访问。
*   **训练混合格式（Hybrid Format）：** 针对训练中稀疏分布不均的问题，将行划分为“紧凑 ELL 存储”和“稠密备份（Dense Backup）”。大部分稀疏行通过 CUDA Core 处理，而少数溢出的稠密行则利用 Tensor Core 处理，从而在保证内存节省的同时维持高吞吐量。

#### 3. 实验设计
*   **模型架构：** 基于 Transformer++（类似 Llama/Qwen 架构），包含 0.5B、1B、1.5B 和 2B 四种参数规模。
*   **数据集：** 使用 FineWeb 数据集（FineWeb-Edu 子集）进行预训练。
*   **Benchmark：** 评估了 7 个下游任务，包括 ARC (Easy/Hard)、HellaSwag、OpenBookQA、PIQA、WinoGrande 和 CommonsenseQA。
*   **对比方法：** 主要对比对象是标准的稠密（Dense）模型基准，以及在不同 L1 正则化强度下的稀疏模型变体。此外还对比了 ReLU 与 SiLU 激活函数的效果。

*   **硬件型号：** 主要实验在一台配备 8 张 **NVIDIA H100 PCIe GPU** 的节点上完成。

论文进行了多维度的实验：

*   **消融实验：** 包括激活函数对比、有无 Gated 机制的对比、以及针对“死神经元”缓解策略的验证。
*   **特性分析：** 深入分析了稀疏性随模型深度、Token 位置及 Token 语义的变化规律。
*   **充分性评价：** 实验设计非常系统且客观，不仅关注宏观的吞吐量，还深入到了能效比、内存占用以及下游任务的准确率保持情况，论证较为充分。

#### 6. 主要结论与发现
*   **极高稀疏度：** 简单的 L1 正则化可诱导超过 **99%** 的稀疏度，且对下游任务性能的影响微乎其微（交叉熵损失增加在 2% 以内）。
*   **显著加速：** 在 2B 参数规模下，稀疏内核使推理前向执行速度提升了 **20.5%**，训练步速度提升了 **21.9%**。
*   **能效与内存：** 稀疏模型可降低约 **17%** 的每 Token 能耗，并减少高达 **28%** 的训练峰值内存。
*   **正向扩展性：** 实验发现，模型规模越大，稀疏性带来的效率收益越显著，这表明稀疏性是未来超大规模模型扩展的有效路径。

#### 7. 优点
*   **软硬结合：** 不仅仅停留在算法层面，而是通过底层 CUDA 内核优化解决了稀疏性在 GPU 上的落地难题。
*   **TwELL 格式创新：** 解决了稀疏索引管理带来的高昂开销，实现了与现代 GPU 执行流水线的无缝集成。
*   **全生命周期覆盖：** 同时提供了针对推理和训练的优化方案，具有很强的实用价值。
*   **开源贡献：** 承诺开源所有代码和内核，有助于社区进一步研究。

#### 8. 不足与局限
*   **模型规模上限：** 实验目前最高仅验证到 2B 参数，尚未在 70B 或更大规模的模型上展示实际效果。
*   **激活函数依赖：** 方案高度依赖 ReLU 激活函数，而目前主流 LLM 普遍采用 SiLU 或 SwiGLU，迁移现有模型可能需要重新预训练。
*   **死神经元风险：** 高稀疏度会导致约 30% 的神经元永久失活，虽然论文提出了缓解策略，但这仍可能限制模型的潜在容量。
*   **硬件特定优化：** 内核针对 NVIDIA Hopper 架构（H100）进行了深度优化，在其他厂商（如 AMD）或旧款架构上的表现和适配性尚待验证。
