## 摘要
具身智能体日益需要根据共享的观测结果，在不同的时间约束下并行执行多项任务，例如操作、对话和记忆构建。最近的混合 Transformer (MoT) 视觉-语言-动作模型 (VLAs) 在架构上支持此类异构输出，但现有的推理系统由于冗余计算和资源竞争，无法在设备端部署中实现高效的多任务并行。我们发现孤立的 KV 缓存管理是其根本原因。为了解决这一问题，我们提出了统一 KV 缓存管理，这是一种将 KV 缓存视为跨任务和跨时间的共享资源的推理范式。这种抽象实现了两项关键优化：跨任务 KV 共享消除了共享观测值的冗余预填充，而跨帧连续批处理则在控制周期内将变长语言解码与固定速率的动作生成解耦。我们针对最流行的 MoT VLA 模型 $π_{0.5}$ 实现了该范式，并在代表性的机器人配置下进行了评估。OxyGen 相比于孤立执行实现了高达 3.7 倍的加速，在不降低动作质量的情况下，同时实现了超过 200 tokens/s 的语言吞吐量和 70 Hz 的动作频率。

## Abstract
Embodied AI agents increasingly require parallel execution of multiple tasks, such as manipulation, conversation, and memory construction, from shared observations under distinct time constraints. Recent Mixture-of-Transformers (MoT) Vision-Language-Action Models (VLAs) architecturally support such heterogeneous outputs, yet existing inference systems fail to achieve efficient multi-task parallelism for on-device deployment due to redundant computation and resource contention. We identify isolated KV cache management as the root cause. To address this, we propose unified KV cache management, an inference paradigm that treats KV cache as a first-class shared resource across tasks and over time. This abstraction enables two key optimizations: cross-task KV sharing eliminates redundant prefill of shared observations, while cross-frame continuous batching decouples variable-length language decoding from fixed-rate action generation across control cycles. We implement this paradigm for $π_{0.5}$, the most popular MoT VLA, and evaluate under representative robotic configurations. OxyGen achieves up to 3.7$\times$ speedup over isolated execution, delivering over 200 tokens/s language throughput and 70 Hz action frequency simultaneously without action quality degradation.

### 1. 核心问题与整体含义（研究动机和背景）
*   **研究动机**：具身智能机器人需要同时处理多种任务（如一边操作物体，一边进行对话或构建环境记忆）。虽然最新的 MoT-VLA 模型（如 $\pi_{0.5}$）在架构上支持多模态输出，但现有的推理系统采用“孤立执行”模式。
*   **核心问题**：孤立执行导致了两个主要效率瓶颈：
    1.  **冗余计算**：相同的视觉观测值被多次重复编码，为不同任务生成相同的 KV 缓存。
    2.  **资源竞争**：不同任务（如高频动作生成与长文本语言解码）竞争单一硬件资源，导致动作频率下降或语言吞吐量受限。
*   **整体含义**：论文旨在通过统一管理 KV 缓存，解决多任务并行下的计算冗余和调度冲突，实现实时、高效的机器人多任务推理。

### 2. 方法论：统一 KV 缓存管理
OxyGen 将 KV 缓存抽象为跨任务和跨时间的共享资源，核心技术包括：
*   **跨任务 KV 共享 (Cross-task KV Sharing)**：
    *   在每一帧中，VLM 主干网络仅对观测值进行一次预填充（Prefill），生成的 KV 缓存被动作专家（Action Expert）和语言专家（Language Expert）共同复用，消除了重复编码开销。
*   **跨帧连续批处理 (Cross-frame Continuous Batching)**：
    *   **解耦调度**：将动作生成（硬实时、固定频率）与语言解码（软实时、变长周期）解耦。
    *   **状态持久化**：引入统一 KV 管理器，通过 `Store`、`Retrieve`、`Batch` 等操作维护每个请求的生成状态（包括 KV 缓存、已生成 Token 和终止标志）。
    *   **并行解码**：将当前帧的新语言请求与前几帧尚未完成的在途请求进行批处理，在单个前向传播中完成多个 Token 的解码，提高硬件利用率。
*   **算法流程**：每帧执行：1) 预填充新观测值；2) 运行动作去噪；3) 检索并合并所有活跃请求的 KV 状态；4) 执行批处理语言解码；5) 更新或移除已完成的请求状态。

### 7. 优点
*   **针对性强**：精准捕捉到了具身智能多任务推理中“非对称截止日期”（动作快、语言慢）的特性。
*   **系统级优化**：不改变模型权重，作为调度层具有良好的通用性，可适配不同的 MoT 架构。
*   **实用价值高**：在消费级显卡上实现了极高的推理性能，直接推动了复杂 VLA 模型在机器人上的实时部署。

### 8. 不足与局限
*   **架构依赖**：该方法主要针对 MoT（混合 Transformer）架构，对于完全不共享主干网络的多模型组合，KV 共享的收益会消失。
