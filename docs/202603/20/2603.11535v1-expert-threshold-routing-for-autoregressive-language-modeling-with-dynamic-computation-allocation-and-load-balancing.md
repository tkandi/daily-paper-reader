## 摘要
令牌选择混合专家模型 (TC-MoE) 将每个令牌路由到固定数量的专家，这限制了动态计算分配，并需要辅助损失来维持负载均衡。我们提出了专家阈值 (ET) 路由，其中每个专家维护一个根据全局令牌分布估计的指数移动平均 (EMA) 阈值。在训练和推理阶段，如果令牌的分数超过专家的阈值，则该令牌会被独立地路由到该专家，从而在无需辅助损失的情况下实现动态计算分配并达成负载均衡。这种完全因果机制消除了对批次中其他令牌的依赖，使其非常适合自回归语言建模。在 FineWeb-Edu 上扩展至 24 亿参数的预训练实验中，ET 的交叉熵损失比 TC-MoE 低 0.067，相当于以少 1.6 倍的令牌达到了相同的性能。

## Abstract
Token-choice Mixture-of-Experts (TC-MoE) routes each token to a fixed number of experts, limiting dynamic computation allocation and requiring auxiliary losses to maintain load balance. We propose Expert Threshold (ET) routing, where each expert maintains an exponential moving average (EMA) threshold estimated from the global token distribution. At both training and inference, each token is independently routed to an expert if its score exceeds the expert's threshold, enabling dynamic computation allocation while achieving load balance without auxiliary losses. This fully causal mechanism eliminates dependence on other tokens in the batch, making it well-suited for autoregressive language modeling. In pretraining experiments scaling to 2.4B parameters on FineWeb-Edu, ET achieves 0.067 lower cross-entropy loss than TC-MoE, equivalent to reaching the same performance with 1.6$\times$ fewer tokens.

### 1. 核心问题与整体含义（研究动机和背景）
传统的混合专家模型（MoE）主要采用**令牌选择（Token-choice, TC）**策略，即每个令牌固定选择 $k$ 个专家。这种方式存在两个主要缺陷：
*   **计算分配僵化**：无论令牌的复杂程度如何，分配的计算资源（专家数量）是固定的，无法实现按需分配。
*   **依赖辅助损失**：为了防止“专家塌陷”（所有令牌涌向少数专家），必须引入辅助损失函数（Auxiliary Loss）来强行维持负载均衡，但这往往会损害模型的表征能力。
*   **因果性冲突**：虽然“专家选择（Expert-choice）”等变体能解决负载均衡，但它们通常需要全局信息，破坏了自回归语言模型的因果性（Causality），导致推理困难。

本研究提出了**专家阈值（Expert Threshold, ET）路由**，旨在实现一种既能动态分配计算资源、又能天然维持负载均衡，且完全符合因果律的路由机制。

### 2. 论文提出的方法论
**核心思想**：为每个专家设置一个动态变化的“准入门槛”（阈值）。令牌只有在针对该专家的预测得分超过阈值时，才会被路由到该专家。

**关键技术细节**：
*   **独立路由决策**：每个令牌独立地与所有专家的阈值进行比较，这意味着一个令牌可能被路由到 0 个、1 个或多个专家，实现了动态计算分配。
*   **EMA 阈值更新**：每个专家 $i$ 维护一个阈值 $\tau_i$。在训练过程中，利用**指数移动平均（EMA）**根据当前批次令牌得分的分布动态调整阈值。
    *   如果某个专家过于“拥挤”（得分普遍高于阈值），则调高阈值以提高准入门槛。
    *   如果某个专家被“冷落”，则调低阈值以吸引更多令牌。
*   **天然负载均衡**：通过 EMA 调整，每个专家最终会处理大致相同比例的令牌，从而在不需要辅助损失的情况下实现全局负载均衡。
*   **完全因果性**：路由决策仅依赖于当前令牌的得分和已有的阈值，不依赖于同批次中的其他令牌，完美适配自回归推理。
