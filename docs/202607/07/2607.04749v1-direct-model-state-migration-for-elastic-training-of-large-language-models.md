## 摘要
大语言模型（LLM）训练需适应共享集群中的动态资源，以应对弹性需求，包括被动抢占和主动扩展。当因动态资源而改变混合并行配置时，需要在设备集之间进行状态迁移。现有方案依赖基于检查点的机制，将完整状态持久化到存储，以便利用重新分配的资源进行恢复，但在传输模型状态时，所有GPU都必须停顿。尽管有优化努力，基于检查点的方案由于跨内存层次的数据移动，仍会带来难以接受的延迟。我们提出ETC，一个用于弹性混合并行LLM训练的无检查点状态迁移框架。我们利用状态局部性最小化GPU间的数据移动，以直接点对点通信替代存储持久化。此外，我们通过通信合并消除节点碎片化。与Megatron-LM集成后，ETC在多种并行配置下，相比基于检查点的方案，迁移开销降低了2.33倍到6.37倍。通过实现高效迁移，ETC在生产环境中解锁了实用的弹性训练。

## Abstract
Large language model (LLM) training shall adapt to dynamic resources in shared clusters to tackle the elasticity, including passive preemption and optimistic scaling. State migration across device sets is required when altering the hybrid-parallel configuration due to dynamic resources. Existing solutions rely on checkpoint-based mechanisms, which persist complete states to storage for resuming with re-assigned resources, forcing all GPUs to stall when transferring model states. Despite optimization efforts, checkpoint-based solutions incur prohibitive latency due to data movement across memory hierarchies.   We propose ETC, a checkpoint-free state migration framework for elastic hybrid-parallel LLM training. We exploits the state locality to minimize inter-GPU data movement, replacing storage persistence with direct peer-to-peer communication. Besides, we eliminate node fragmentation through communication coalescing. Integrated with Megatron-LM, ETC reduces migration overhead by 2.33$\times$ to 6.37$\times$ compared to checkpoint-based solutions across diverse parallel configurations. By enabling efficient migration, ETC unlocks practical elastic training in production environments.

## 1. 核心问题与整体含义
- **研究背景**：大语言模型（LLM）训练通常依赖混合并行（数据并行、流水线并行、张量并行），部署在共享大规模集群中。由于集群资源动态波动（作业抢占、主动伸缩、配额回收），训练任务需要频繁更改并行配置并在不同设备集之间迁移模型状态（参数、优化器状态等），即弹性训练。
- **核心问题**：现有状态迁移方案几乎全部基于检查点机制，需要将完整模型状态从GPU内存经主机内存持久化到磁盘，再于新配置下加载并重新分片（reshard）。这一过程导致所有GPU停顿、数据跨内存层次大量搬移，产生数十至上百秒的高延迟，成为弹性训练不可逾越的瓶颈。即使经过优化的检查点方案（异步、内存级缓存），仍然无法避免全量状态移动、忽视GPU原生状态局部性的根本缺陷。
- **整体含义**：本文提出一种无检查点的直接状态迁移框架 ETC，利用GPU间高带宽直连通信取代存储 I/O，通过保持尽可能多的状态原地不动（in‑place）来最小化数据搬移，从而实现秒级甚至毫秒级的混合并行重配置，使生产环境下高频弹性训练变得实际可行。

## 2. 方法论
### 核心思想
ETC 的设计原则是**利用模型状态局部性，消除冗余数据搬移**，完全绕开持久化存储，所有迁移均通过 GPU‑to‑GPU 的点对点（P2P）通信完成。

### 关键技术细节
- **成本矩阵（Cost Matrix）抽象与最优迁移草图**
  - 将旧策略（prev state）和新策略（curr state）中每个进程（rank）的逻辑负载（如某层、某张量片）表示为集合。
  - 定义成本矩阵 $C\in \mathbb{Z}^{M \times N}$，其中元素 $c_{i,j} = \text{len}(curri) - \text{len}(curri \cap prevj)$，含义：将旧进程 $j$ 转换为新进程 $i$ 所需搬移的数据量。
  - 将进程配对建模为指派问题，目标是最小化总数据移动量 $\sum_i \sum_j c_{ij} x_{ij}$，采用带零填充的匈牙利算法求解，生成一系列 $\langle curr, prev \rangle$ 迁移算子，构成**最优迁移草图**。求解成本极低（$k \le 1024$ 时仅数十毫秒）。
  - 扩展至混合并行：对流水线并行（PP）和张量并行（TP）分别计算成本矩阵，再按规则合并为整体成本矩阵，数据并行（DP）维度无需搬移数据，仅复制或丢弃副本，并利用 DP 组间冗余实现容错。

- **执行引擎与迁移指令**
  - 将迁移草图转换为三类细粒度指令：**Send**（负载由旧进程发出）、**Recv**（负载由新进程接收）、**Refer**（负载原地绑定，零搬移）。
  - 通过元模型（meta model）获取张量形状，确定 TP 切片索引。所有进程同时发射指令列表，完成状态块式（chunk）迁移，并即时释放源端GPU内存。

- **虚拟排名分配器与资源去碎片化**
  - **占用级碎片**：弹性缩容后，GPU 负载分散在多个节点上，导致无法释放完整节点。通过重映射虚拟排名与物理排名，将空闲设备的负载集中到少量节点，释放完整节点。
  - **效率级碎片**：因直接复用产生的跨节点 TP 组会降低通信效率。同样通过重映射来保证 TP 组位于同一节点内。去碎片化操作也表示为迁移算子。

- **通信合并（Coalescing）**
  - 将状态迁移指令与去碎片化指令合并。例如，若负载 $w$ 从设备 $i$ 发往 $k$，后又从 $k$ 发往 $j$，则合并为直接从 $i$ 发往 $j$，避免冗余中转。

## 6. 主要结论与发现
- ETC 在下述各类重配置场景中，相较于最快检查点基线 FB，迁移总时间缩短 **2.33 倍至 6.37 倍**；相较于 Tenplex 和 Tenplex‑Central 模式，加速分别达 **4.79 倍和 10.74 倍**。

- 迁移过程中内存峰值仅短暂上升至稳定态的 **1.25 倍**，且迁移前后训练损失曲线平滑衔接，无突跳或收敛异常。

## 7. 优点
- **方法论创新**：首次以完全无检查点、仅依赖 GPU 间直连通信的方式解决混合并行状态迁移，突破了存储 I/O 的根本瓶颈。
- **系统化设计**：成本矩阵 + 匈牙利算法可理论保证数据移动量全局最小；执行引擎、虚拟排名分配、通信合并构成完整实用的系统栈。

## 8. 不足与局限
- **未覆盖超大规模**：实验模型最大为 64B，未验证在 175B、530B 等更大规模下的表现，此时成本矩阵求解和通信合并的复杂度可能上升。

- **网络拓扑假设**：主要实验在有 NVLink/InfiniBand 的高性能连接上进行，未充分探讨异构、低带宽或拓扑不对称网络下的迁移效率。
