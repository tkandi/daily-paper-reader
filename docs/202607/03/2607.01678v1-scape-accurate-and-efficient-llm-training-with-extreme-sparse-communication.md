## 摘要
在大语言模型（LLM）预训练中，通信成本日益占据主导地位，尤其是在数据并行和分片训练方案下，梯度同步和参数重构的开销随模型规模和系统规模而增加。现有的通信缩减方法或对原始梯度进行稀疏化，但在高稀疏度下对于现代Adam风格优化器可能不稳定；或对通信进行量化，其节省效果本质上受比特宽度限制，且通常引入额外运行时开销。我们提出SCAPE，一种面向LLM训练的通信高效分布式优化器，它利用AdamS第一矩的稳定性，在无损LLM质量的前提下实现积极的稀疏化。SCAPE不从原始梯度构建掩码，而是从基于第一矩的统计量中导出掩码，将掩码生成分布到各工作节点以对齐优化器分片，并将掩码使用延迟一步，使得掩码同步可与计算重叠。SCAPE还从单个同步稀疏缓冲区重构二阶矩更新所需的量，避免额外的集合通信。我们在Megatron-LM中实现SCAPE，并使用32块NVIDIA GH200 GPU在TACC Vista上，通过在OpenWebText上预训练GPT-345M和在SlimPajama-6B上预训练Llama-500M评估其收敛性。在两个模型上，SCAPE在90%和99%稀疏度下均保持了训练稳定性、验证损失和下游任务精度。对于Llama-500M，SCAPE将端到端预训练实际耗时减少高达43.3%，同时保持与稠密AdamW和AdamS相当的模型质量。对于Llama-1.8B，SCAPE相比稠密AdamS每步加速高达3.26倍。

## Abstract
Communication increasingly dominates the cost of Large Language Model (LLM) pre-training, especially under data-parallel and sharded training schemes, where gradient synchronization and parameter reconstruction overhead increase with model size and system scale. Existing communication-reduction methods either sparsify raw gradients, which can be unstable for modern Adam-style optimizers at high sparsity, or quantize communication, whose savings are fundamentally bounded by bit width and often incur additional runtime overhead. We present SCAPE, a communication-efficient distributed optimizer for LLM training that exploits the stability of AdamS's first-moment to enable aggressive sparsification without loss of LLM quality. Instead of constructing masks from raw gradients, SCAPE derives them from first-moment-based statistics, partitions mask generation across workers to align with optimizer sharding, and delays mask usage by one step so that mask synchronization can overlap with computation. SCAPE also reconstructs the quantities required for second-moment updates from a single synchronized sparse buffer, avoiding an additional collective. We implement SCAPE in Megatron-LM and evaluate its convergence by pre-training GPT-345M on OpenWebText and Llama-500M on SlimPajama-6B using 32 NVIDIA GH200 GPUs on TACC Vista. In both models, SCAPE preserves training stability, validation loss, and downstream task accuracy under 90\% and 99\% sparsity. For Llama-500M, SCAPE reduces end-to-end pre-training wall-clock time by up to 43.3\% while maintaining model quality comparable to dense AdamW and AdamS. For Llama-1.8B, SCAPE achieves up to 3.26$\times$ speedup per step compared to dense AdamS.

### 1. 论文的核心问题与整体含义（研究动机和背景）
大语言模型（LLM）预训练中，通信开销已成为主要瓶颈，尤其在数据并行及分片数据并行（如 ZeRO、FSDP、Megatron‑LM）框架下，梯度同步与参数重构的通信量随模型规模和 GPU 数量急剧增长。现有降低通信的方法主要分为两类：
- **梯度稀疏化（top‑k）**：直接对原始梯度取绝对值最大的k个元素传输，在高稀疏度下会导致现代 Adam 风格优化器不稳定，收敛变差。
- **量化**：用低比特表示梯度或参数，节约效果受比特宽度限制，且往往需要额外的 all‑to‑all 通信或自定义后端，引入运行时开销。

因此，该工作提出核心问题：能否在极端压缩通信量（如 90% 甚至 99% 稀疏）的前提下，仍保持 LLM 训练质量（训练稳定性、验证损失、下游任务精度）？为此，文章进行了**观察‑分析‑设计**的全链路研究，最终提出 SCAPE——一个基于 AdamS 的通信高效分布式优化器。

### 2. 论文提出的方法论
SCAPE 的核心思想是利用 **AdamS 第一阶动量（first‑moment）的稳定性**，从动量而非原始梯度构建稀疏掩码；并利用掩码在相邻步骤的**时间稳定性**，延迟掩码使用以实现通信与计算重叠。具体关键技术包括：

- **掩码生成与分片对齐**：  
  每个工作节点只在其持有的优化器分片（shard）上计算 top‑k 掩码，避免全局收集导致的“填满效应（fill‑in effect）”。掩码基于 `|β₁ m_{t-1} +(1-β₁)g_t + e_{t-1}|`（含本地误差反馈）计算，保证本地重要梯度值尽早被选中。

- **掩码一步延迟与异步同步**：  
  第 t 步计算出的掩码 M_t 被延迟到第 t+1 步使用。这样可以利用反向传播计算期间异步执行 all‑gather 来收集掩码，将掩码通信重叠在计算中，几乎不增加额外延迟。

- **单一稀疏 buffer 更新二阶矩**：  
  通过只传输一个稀疏的缓冲区 `b_t`（包含被上一时刻掩码 M_{t-1} 选中位置上的 `m_t` 值），利用已同步的全局平均动量 `m̄_t`，反推出位置上的“梯度+残差” `ḡ_t + ē_{t-1} = (b̄_t – β₁ m_{t-1})/(1-β₁)`，从而更新二阶矩 `v_t`，避免额外一次 all‑reduce 通信。

- **分布式优化器兼容优化**：  
  当模型参数被分片时，针对未被掩码选中的参数，权重衰减更新 `θ_{t+1} = (1-ηλ)θ_t` 可直接本地计算，避免进行 all‑gather 通信。同时利用 CPU 卸载（NVLink‑C2C 高带宽）存放完整 FP32 参数副本，通过双向流水线重叠传输与计算，减轻 GPU 内存压力。

整体算法流程可见文中的 Algorithm 1（稀疏更新核心）和 Algorithm 2（优化后的 Megatron‑LM 分布式优化器流程）。

- **创新性方法**：不稀疏化梯度，而利用一阶矩统计特性构建掩码；利用 AdamS 的稳定性突破高稀疏度瓶颈。
- **系统与算法协同设计**：掩码分片对齐分布式优化器、一步延迟实现通信重叠、单一稀疏缓冲区更新二阶矩等系统优化，显著减少通信且不牺牲模型质量。

### 8. 不足与局限
- **依赖 AdamS 优化器**：方法建立在 AdamS 的第一阶矩稳定性和内存节省上，尚不适用于广泛使用的 AdamW 或其他优化器，虽然文中表明未来将探索扩展至 Muon 等。
