## 摘要
向量数据库已成为人工智能应用中高维向量检索的基础组件。近期的研究聚焦于过滤近似最近邻搜索（过滤ANN），其涉及检索满足给定属性过滤器的最近向量。然而，现有过滤器通常局限于数值范围约束或类别存在性检查，这限制了它们在更复杂的实际场景中的适用性。在本文中，我们研究了使用图范围过滤器的过滤ANN，其中检索到的向量必须位于预定义过滤器图中与查询节点的指定距离内。为了解决这个问题，我们提出了DLH，一种带有哈希压缩的距离感知标签索引。DLH创建距离感知的标签集合，通过简化的集合交集操作实现高效的图范围过滤。大型标签集被进一步压缩为布隆过滤器以提高DLH的查询效率。此外，认识到查询节点总是参与图范围过滤器的范围内查询，我们通过记忆查询节点的中间哈希索引来增强DLH，产生一个称为DLH-M的优化版本。在多个数据集上的实验评估表明，DLH和DLH-M将吞吐量提高了多达70.3%，并且能够在有限的额外存储下保持超过98.5%的召回率，验证了所提解决方案的实际可用性。

## Abstract
Vector databases have become a fundamental component for high-dimensional vector retrieval in artificial intelligence applications. Recent research has focused on filtered approximate nearest neighbor search (filtered ANN), which involves retrieving the nearest vectors that satisfy a given attribute-based filter. However, existing filters are generally limited to numerical range constraints or categorical existence checks, which restricts their applicability in more complex, real-world scenarios. In this paper, we investigate filtered ANN using graph range filters, where the retrieved vectors must be within a specified distance from the query node in a predefined filter graph. To address this problem, we propose DLH, a Distance-aware Labeling index with Hashing compression. DLH creates distance-aware labeling sets to enable efficient graph range filters via the simplified set intersection operations. Large labeling sets are further compressed into Bloom filters to improve query efficiency in DLH. Furthermore, recognizing that the query node is always involved in in-range queries of the graph range filters, we enhance DLH by memoizing the intermediate hashing index for the query node, yielding an optimized version called DLH-M. Experimental evaluations on diverse datasets demonstrate that DLH and DLH-M improve throughput by up to 70.3%, and could maintain recall rates over 98.5% with limited extra storage, validating the practical availability of the proposed solution.

### 1. 论文的核心问题与整体含义
本文聚焦于**带图范围过滤器的近似最近邻搜索（ANNGR）**。传统的过滤 ANN 仅支持数值范围约束或类别存在性检查，无法处理现实场景中基于图结构距离的复杂过滤需求。例如，在反洗钱（AML）场景中，需从账户嵌入向量中找出既在交易图上 \(r\) 跳可达、又语义相似的向量。为此，论文首次形式化定义 ANNGR 问题，并指出其两大核心挑战：
- **候选属性空间爆炸**：图中每个节点均可作为属性，传统属性独立索引难以扩展。
- **候选分布不规则且不可预测**：图拓扑的异质性使不同查询的 \(r\)-hop 邻域差异巨大，无法通过预计算利用重叠特性。

整体含义：为向量数据库赋能对**结构化图距离约束**的高效近似检索，拓宽过滤 ANN 的适用范围。

### 2. 论文提出的方法论
论文提出 **DLH（Distance‑aware Labeling index with Hashing compression）** 及其记忆优化版 **DLH‑M**，采用后过滤（post‑filtering）范式。

#### 2.1 核心思想
- 基于最短路径标签索引（PLL）为每个节点构建**距离感知标签集**，仅保留距离不超过 \(r\) 的枢纽节点，并按距离分层（0‑hop, 1‑hop, …, \(r\)-hop）。
- 判断候选节点是否在查询节点 \(r\) 跳内，转化为**分层标签集的交集检查**，同时利用距离信息进行剪枝（\(i+j > r\) 的交集跳过）和**提前终止**（一旦发现公共枢纽即返回 true）。
- 对规模较大的标签集用**布隆过滤器**压缩，以支持近似集合交集（包含查询、基数估计），在可控假阳率下大幅降低时空开销。
- DLH‑M 进一步观察到范围内查询的不对称性：**预计算并记忆查询节点标签集中所有元素的哈希索引**，避免在每次候选验证时重复哈希，从而降低平均查询复杂度。

#### 2.2 关键技术细节与算法流程
- **标签构建**（Algorithm 3）：  
  对于节点 \(v\)，遍历其 PLL 标签 \(L(v)\)，若标记节点 \(u\) 与 \(v\) 的距离 \(dis_G(u,v) \le r\)，则将其加入集合 \(D_{dis_G(u,v)}(v)\)；距离大于 \(r\) 的丢弃。
- **范围内查询**（Algorithm 4）：  
  对查询节点 \(v_q\) 和候选节点 \(v_o\)，遍历所有 \((i,j)\) 满足 \(i+j \le r\)，检查 \(D_i(v_q) \cap D_j(v_o)\) 是否非空。若找到交集则返回 true，否则 false。
- **DLH 的哈希加速**（Algorithm 5）：  
  当 \(D_i(v_q)\) 或 \(D_j(v_o)\) 有对应布隆过滤器时，采用三种方式判断交集：
  - 双方均为布隆过滤器：用 `aic` 估计交集大小，若 ≥1 则视为有交集。
  - 仅一方为布隆过滤器：对另一方集合中每个元素执行包含查询。
  - 双方均为确切集合：直接求交集。
- **DLH‑M 的记忆优化**（Algorithm 6、7）：  
  在搜索开始前，预计算查询节点所有确切标签集元素的哈希位数组 \(P_L\)；在 `lcontain` 中，直接检查候选布隆过滤器在这些预计算位置是否全为 1，从而消除重复哈希。

### 3. 实验设计
#### 3.1 数据集与场景
- **向量数据集**： SIFT（128维）、GIST（960维）、DEEP（96维）、YFCC（192维），各 100 万向量。
- **过滤图**： 80,000 节点的 Erdős–Rényi 随机图，边概率 \(p \in \{0.00025, 0.00027, 0.0003\}\)，向量与节点均匀关联。
- **查询负载**： 每个查询检索 \(k=128\) 近邻，图范围 \(r \in \{3,4,5,6\}\)，默认 \(r=4\)。

#### 3.2 Benchmark 与对比方法
- **Pre‑Filter**：先 BFS 获得 \(r\)-hop 邻居，再暴力检索向量。
- **Post‑Filter (HNSW)**：在 HNSW 图上做 ANN 搜索，再用 BFS 校验图距离。
- **ACORN**：支持任意过滤器的图索引（使用过滤占比的反比作为权重）。
- **Navix**：集成 HNSW 与预过滤策略的通用图索引。
- **DLH** 和 **DLH‑M**：本文提出的方法。

#### 3.3 评价指标
- **吞吐量（QPS）** 与 **召回率** 的权衡曲线（通过变化波束宽度 \(b\) 产生多个工作点）。
