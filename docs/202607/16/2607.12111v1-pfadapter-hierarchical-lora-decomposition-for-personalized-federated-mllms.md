## 摘要
代理型人工智能系统通过在网络边缘部署能够协作学习并保持数据隐私的自主智能体，正在重塑通信与网络。在分布式网络环境中，多模态大语言模型 (MLLMs) 作为边缘设备的认知引擎，然而在异构网络条件下，联邦微调在平衡全局知识聚合与本地适应方面面临巨大挑战。传统的联邦协议通常依赖于统一的参数聚合，将领域不变特征与客户端特定细节混杂在一起，导致个性化效果欠佳且通信开销过大。为解决这些挑战，我们提出了 PFAdapter，一个通信高效的框架，引入分层 LoRA 分解，将适配器参数显式分离为全局共享和本地私有两部分。查询和键投影被分配给全局同步以捕获整个网络中的通用多模态语义，而值和输出投影则保留在本地以进行边缘特定适应。此外，基于 Frobenius 范数的正交正则化强制这些组件严格分离，防止冗余特征学习。选择性聚合协议仅在联邦网络中同步全局共享组件，保留本地专业知识，并将通信成本降低近 50%。在 VQA-RAD、SLAKE、Hateful Memes 和 CrisisMMD 数据集上的大量实验表明，PFAdapter 始终优于最先进的基线方法，在各种边缘智能任务中的准确率提升了 2.4% 到 4.8%。因此，我们的框架为在资源受限的通信网络中部署代理型人工智能提供了一种高效解决方案。

## Abstract
Agentic AI systems are reshaping communications and networking by deploying autonomous intelligent agents capable of collaborative learning while maintaining data privacy at network edges. Within distributed network environments, Multimodal Large Language Models (MLLMs) serve as cognitive engines for edge devices, yet federated fine-tuning faces substantial challenges in balancing global knowledge aggregation with local adaptation under heterogeneous network conditions. Conventional federated protocols typically rely on uniform parameter aggregation, which conflates domain-invariant features with client-specific nuances, thereby resulting in suboptimal personalization and excessive communication overhead. To address these challenges, we propose PFAdapter, a communication-efficient framework introducing hierarchical LoRA decomposition to explicitly separate adapter parameters into global-shared and local-private components. Query and key projections are assigned to global synchronization for capturing universal multimodal semantics across the network, while value and output projections remain localized for edge-specific adaptation. Additionally, orthogonality regularization based on the Frobenius norm enforces strict separation between these components, preventing redundant feature learning. Selective aggregation protocols synchronize only global-shared components across the federated network, preserving local expertise and reducing communication costs by nearly 50%. Extensive experiments on VQA-RAD, SLAKE, Hateful Memes, and CrisisMMD datasets demonstrate that PFAdapter consistently outperforms state-of-the-art baselines, achieving accuracy improvements ranging from 2.4% to 4.8% across diverse edge intelligence tasks. Consequently, our framework establishes an efficient solution for agentic AI deployment in resource-constrained communication networks.

### 2. 论文提出的方法论
- **核心思想**：自注意力机制中不同投影模块具有不同的功能特性——查询（Q）和键（K）投影负责学习跨模态的结构关系（领域泛化性强），而值（V）和输出（O）投影负责生成具体的内容表征（任务特异性强）。据此，将 LoRA 适配器参数显式拆分为全局共享部分（Q、K 投影的低秩更新）和本地私有部分（V、O 投影的低秩更新）。
- **关键技术细节**：
  - **分层 LoRA 分解**：将每一层的适配器参数集合 \(\Theta\) 划分为全局参数集 \(\Theta_G\)（包含所有层的 Q 和 K 的 A、B 矩阵）和本地参数集 \(\Theta_{L}\)（包含所有层的 V 和 O 的 A、B 矩阵）。
  - **正交正则化**：引入基于 Frobenius 范数的正交化损失 \(\lambda_o \|W^{\top}_{l,mg} W_{l,ml}\|_F^2\)，强制全局与本地权重矩阵的列空间相互正交，避免冗余学习，实现知识解耦。
  - **选择性聚合**：联邦通信轮次中，仅上传和聚合全局共享部分 \(\Theta_G\)（使用 FedAvg 加权平均），本地私有部分 \(\Theta_{Lk}\) 始终保留在客户端本地。由此，通信量理论上减少约 50%（因为只传输 4 个投影中的 2 个）。
- **算法流程（Alg.1）**：服务器初始化全局 Q/K 适配器并广播；每轮选定客户端在本地用组合损失（交叉熵 + 正交正则项）进行多轮 SGD 更新；客户端只上传更新后的 Q/K 适配器；服务器聚合后进入下一轮。训练完成后，各客户端保有自己私有的 V/O 适配器。
- **理论支撑**：在标准光滑性、有界方差、客户端异质性等假设下，给出了 \(O(1/\sqrt{T})\) 的非凸收敛率，证明选择性聚合引入的偏差和正交正则化在可控范围内。

### 7. 优点
- **创新性分解视角**：首次从自注意力投影功能的角度划分联邦学习的全局与本地参数，而非传统的按层或按模型部件划分，更贴合 MLLM 的架构特性。
- **双层解耦机制**：同时使用结构分解（Q/K vs. V/O）和数值约束（正交正则化）实现知识解耦，有效防止冗余学习。
- **通信效率与性能兼得**：在不牺牲甚至提升精度的前提下，将通信量减半，对实际边缘部署极具吸引力。
- **实验严谨全面**：覆盖多领域 benchmark、多种联邦优化器、多维鲁棒性测试，包含消融和分解策略分析，统计稳健。
- **理论支撑**：提供了非凸设定下的收敛率分析，增强方法的理论可信度。
- **低资源适应**：仅需单张消费级 GPU 即可复现，具有实际工程价值。

### 8. 不足与局限
- **固定分解比例**：当前对所有层采用统一的 Q/K 全局、V/O 本地的划分，未考虑不同层可能具有不同的跨客户端共享程度，可能导致次优配置。
- **正交约束的局限性**：Frobenius 范数的正交约束可能无法完全捕捉全局与本地组件之间复杂的非线性依赖关系，在极其动态或概念偏移严重的场景下解耦能力可能不足。
- **分解策略的泛化性**：虽然实验证明 Q/K 全局 V/O 本地最优，但这一结论可能依赖于所采用的数据异构模式和 MLLM 骨架，推广到其他模型架构或任务类型时需重新验证。
- **隐私讨论仍为浅层**：论文明确指出 PFAdapter 仅保证原始训练数据不离开本地，不抵御梯度反转、成员推断等更强的攻击，未集成差分隐私或安全多方计算。
- **实验未覆盖极端资源受限场景**：虽然通信量减半，但本地训练仍需要下载完整的全局 Q/K 适配器并进行 LoRA 微调，对存储和计算极其受限的物联网微节点可能仍有压力。
- **客户端数量与规模**：实验采用 10 个客户端，每轮采样 2 个，未验证在大规模客户端（如数百个）下的可扩展性。
