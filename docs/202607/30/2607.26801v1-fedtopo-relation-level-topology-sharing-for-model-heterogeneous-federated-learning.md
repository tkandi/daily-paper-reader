## 摘要
联邦学习能够在不需要集中原始数据的情况下，在去中心化的数据孤岛上进行协作学习。然而，异构的本地架构常常导致不对齐的表示空间，使得跨孤岛传递全局知识变得困难。现有范式将这种知识作为模型参数、蒸馏预测或类别原型进行共享，但所有这些都在一个绝对空间中编码，必须在客户端之间对齐。异构主干打破了这种对齐，因此共享的知识变得不可靠并误导本地训练。我们提出了FedTopo，一个关系级框架，将全局知识编码为类别关系拓扑，捕捉每个客户端内类别之间的关联方式，而不是它们在特征空间中的位置。每个客户端从本地原型构建其关系拓扑，并将其与类别统计信息一起上传。服务器然后以可靠性感知的方式聚合这些关系，对弱支持的关系进行降权，并将全局拓扑广播给客户端。全局拓扑通过强调拓扑相似的负类来指导本地训练。在八个异构主干下的三个数据集上的实验表明，FedTopo在低通信和无推理开销的情况下，持续优于基于参数、蒸馏和原型共享的基线方法。我们的代码可在https://github.com/Zhaoyang-Ma/FedTopo获取。

## Abstract
Federated learning (FL) enables collaborative learning over decentralized data silos without centralizing raw data. However, heterogeneous local architectures often induce non-aligned representation spaces, making it difficult to transfer global knowledge across silos. Existing paradigms share this knowledge as model parameters, distilled predictions, or class prototypes, yet all encode it in an absolute space that must be aligned across clients. Heterogeneous backbones break this alignment, so the shared knowledge becomes unreliable and misleads local training. We propose FedTopo, a relation-level framework that encodes global knowledge as class relation topology, capturing how classes relate within each client rather than where they lie in feature space. Each client builds its relation topology from local prototypes and uploads it with class statistics. The server then aggregates these relations in a reliability-aware manner that down-weights weakly supported ones, and broadcasts the global topology to clients. The global topology guides local training by emphasizing topology-similar negative classes. Experiments on three datasets under eight heterogeneous backbones show that FedTopo consistently outperforms parameter-, distillation-, and prototype-sharing baselines, with low communication and no inference overhead. Our code is available at https://github.com/Zhaoyang-Ma/FedTopo.

### 2. 论文提出的方法论

FedTopo框架的核心思想是从“坐标级”知识共享转向“关系级”拓扑共享，其流程分为三个阶段：

*   **核心思想**：编码并共享类别间的相对关系（哪些类别彼此相似），而非它们在特征空间中的绝对位置。

*   **关键技术细节与流程**：
    *   **阶段一：关系级拓扑构建 (Client-side)**
        1.  **计算本地原型**：每个客户端 \(k\) 在其本地数据上，对每个存在的类别 \(c\)，用其样本的均值特征作为原型 \(p_{k,c}\)。
        2.  **构建关系矩阵**：计算客户端 \(k\) 内所有类别原型对之间的余弦相似度，并将其缩放到 \([0, 1]\) 区间，得到一个对称的关系矩阵 \(R_k\)。该矩阵捕获了客户端内部的类间关系。
        3.  **记录类别统计**：同步记录每个类别的样本数量 \(n_k\)，用于衡量关系的统计支持度。
        4.  **上传**：仅将关系矩阵 \(R_k\) 和统计信息 \(n_k\) 上传至服务器，**绝不泄露本地原型或原始数据**。

    *   **阶段二：可靠性感知的全局拓扑聚合 (Server-side)**
        1.  **二元掩码**：为每个客户端生成一个掩码 \(M_k\)，标记出该客户端上同时存在的类别对。不存在的类别对不参与聚合。
        2.  **可靠性权重**：为每个有效的类别对计算一个可靠性权重 \(w_k(c, c')\)。该权重与两类别样本数的**调和平均数**成正比，意味着只有当两个类别都有充足样本时，其关系才被视为可靠。
        3.  **加权聚合**：使用可靠性权重，对所有客户端上传的 \(R_k\) 进行加权平均，得到本轮的全局关系矩阵 \(\tilde{R}^t_g\)。
        4.  **计算可靠性矩阵**：基于所有客户端对该类别对的累积支持度，计算全局可靠性矩阵 \(S_g\)，衡量每个全局关系的可信程度。
        5.  **指数移动平均 (EMA)**：对全局关系矩阵进行EMA平滑，得到稳定的最终全局关系矩阵 \(R^t_g\)，以减少训练波动。
        6.  **广播**：将 \((R^t_g, S^t_g)\) 作为全局拓扑广播给各客户端。

    *   **阶段三：拓扑引导的本地训练 (Client-side)**
        1.  **选择引导信号**：对于标签为 \(y\) 的训练样本，从全局拓扑中提取 \(y\) 与其他所有类的关系向量，并与可靠性矩阵点乘，得到增强的引导信号 \(A_y\)。
        2.  **本地掩码与Top-q选择**：屏蔽本地不存在的类别，并从中选出与 \(y\) 关系最紧密（且可靠）的 \(q\) 个负类，生成一个稀疏的引导向量 \(B_y\)。
        3.  **调整Logits**：在模型的原始输出logits上，将这 \(q\) 个拓扑相似的负类的logits值加上一个调制强度 \(\gamma\)，生成调整后的logits \(o'_k\)。
        4.  **计算联合损失**：最终的损失函数是标准交叉熵损失与基于调整后logits的交叉熵损失之加权和。通过增加相似负类的竞争压力，迫使模型学习更具判别力的决策边界。
        5.  **推理阶段**：推理时移除所有拓扑相关组件，仅使用原始logits，**无额外推理开销**。
