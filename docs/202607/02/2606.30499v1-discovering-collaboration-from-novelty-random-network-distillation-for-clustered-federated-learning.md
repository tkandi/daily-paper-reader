## 摘要
联邦学习经常受到非独立同分布数据的影响，其中单一的全局模型可能无法代表客户端分布的多样性。聚类联邦学习通过为相似客户端组训练专门的模型来缓解这个问题，但现有方法通常将聚类分配与主训练循环耦合，增加了计算和通信成本。我们提出了一种基于随机网络蒸馏的轻量级聚类方法。每个客户端在其本地数据上训练一个紧凑的随机网络蒸馏预测器，并使用其预测误差作为新颖性信号来估计与其他客户端的相似性。这使得在联邦训练之前能够发现有意义的客户端组，而无需共享原始数据或反复评估主模型。至关重要的是，由此产生的联邦在运行时从局部新颖性估计中涌现，使得该方法适用于自主的大规模分布式系统，在这些系统中，聚类的数量和协作结构都无法预先指定。总体而言，通过将聚类与学习解耦，该方法为非独立同分布数据下的自主协作提供了一种任务无关的高效机制。

## Abstract
Federated Learning often suffers under non-independently and identically distributed data, where a single global model may fail to represent the diversity of client distributions. Clustered Federated Learning mitigates this issue by training specialized models for groups of similar clients, but existing approaches often couple cluster assignment with the main training loop, increasing computational and communication costs. We propose a lightweight clustering approach based on Random Network Distillation. Each client trains a compact Random Network Distillation predictor on its local data and uses its prediction error as a novelty signal to estimate similarity with other clients. This enables the discovery of meaningful client groups before federated training, without sharing raw data or repeatedly evaluating the main model. Crucially, the resulting federations emerge from local novelty estimates at runtime, making the method suitable for autonomous large-scale distributed systems where neither the number of clusters nor the collaboration structure can be specified a priori. Overall, by decoupling clustering from learning, the method provides a task-agnostic and efficient mechanism for autonomous collaboration under non-independently and identically distributed data.

### 2. 方法论
- **核心思想**：每个客户端在其本地数据上训练一个紧凑的 RND 预测器 `̂f(·;θ)` 来近似一个共享的、随机初始化的固定目标网络 `f`。预测器的优化目标是使均方误差最小化。训练完成后，预测误差可作为数据新颖性度量：在分布相似的数据上误差低，在分布相异的数据上误差高。
- **关键流程**（参见 Algorithms 1–2）：
  1. **本地训练**：客户端 `d_i` 在自身数据 `B_i` 上训练 RND 预测器，得到 `̂f_i`。
  2. **预测器交换**：所有客户端广播各自的预测器（而非原始数据），并接收其他客户端的预测器。
  3. **新颖性评分**：客户端 `d_i` 用其他客户端 `d_j` 的预测器 `̂f_j` 评估自己的本地数据，得到交叉新颖性分 `s_{ij}`。自身预测器的自评分为 `s_{ii}`。
  4. **相似性矩阵**：各客户端上报评分行，服务器构建完整的相似性矩阵 `S`。
  5. **自适应联邦发现**：根据兼容性准则 `s_{ij} ≤ s_{ii} + ε·σ_i` 判断客户端 `j` 是否与 `i` 兼容（其中 `σ_i` 为评分标准差，`ε` 为容差超参数）。联邦分组从兼容关系自然涌现，簇的数量无需预定义。
  6. **学习阶段**：各联邦独立运行标准 FL（如 FedAvg）。
  7. **再聚类频率**：对于平稳环境可以只聚类一次；对于变化环境可按 `τ` 轮周期重新聚类。
  8. **去中心化扩展**：可通过领导者选举、八卦协议或仅与邻居交换预测器实现完全去中心化聚类。

### 6. 主要结论与发现
- **RND 残差能够清晰区分同组与异组客户端**：热图中同组设备的自新颖性与交叉新颖性差异趋近于零，异组差异明显更大，证实 RND 可以捕获特征偏斜带来的分布分歧。
- **聚类开销显著降低**：无论采用何种再聚类频率，RND 方法的累积时间均远低于 IFCA。即使每轮都重聚类，开销也比 IFCA 低一个数量级；若仅聚类一次或周期进行，优势更明显。
- **联邦数量可以自适应涌现**：不需要像 IFCA 那样预先固定簇数，而是通过阈值兼容性从相似性矩阵中自动形成分组。

### 7. 优点
- **轻量且解耦**：用小型辅助网络代替完整任务模型做聚类，避免在训练循环中反复评估重模型，降低计算与通信负载。
- **隐私保护**：仅交换预测器参数，不共享原始数据。
- **自主性与无参数预设**：无需事先知道簇的数量，联邦结构从局部新颖性估计中动态形成，适合自主大规模系统。
- **灵活的再聚类策略**：可根据环境变化周期性重新聚类，适应非平稳场景。
- **具备去中心化潜力**：方法可自然扩展到完全去中心化、仅与邻居交互的模式。

### 8. 不足与局限
- **实验规模有限**：仅在 CIFAR‑10 上的小型人工特征偏斜场景下验证，缺少对其他非 IID 类型（标签偏斜、异质性更强场景）和大规模客户端的评估。
- **可扩展性瓶颈**：集中式方案要求每个客户端评估所有其它客户端的预测器，当客户端数量巨大时可能抵消轻量优势（虽然论文提出去中心化受限交换可缓解，但缺乏实验支撑）。
- **对动态变化的敏感度未深入测试**：虽然提到底层环境缓慢变化时可周期性重聚类，但未实验验证在真实概念漂移或剧烈分布变化下的鲁棒性。
- **缺少最终模型性能对比**：实验仅评估聚类开销与分组正确性，并未对比 RND 导出的分组在最终 FL 任务上的精度、收敛速度等学习性能指标。
- **再聚类超参数 `ε` 和 `τ` 的敏感性分析缺失**：未讨论容差阈值或再聚类周期对分组效果的影响。
