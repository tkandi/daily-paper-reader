## 摘要
仅解码器语言模型将长期记忆和推理纠缠在单个参数集中，使得独立扩展记忆容量变得困难。记忆解码器引入了一个参数化长期记忆模块，但仅在相对较小的规模上进行了研究。在这项工作中，我们提出了大规模记忆解码器，将记忆模型扩展到69亿参数，并在3000亿词元上进行预训练。在这种数据规模下，索引和搜索的联合成本使得标准的Faiss流程不可行。我们通过一个用于Faiss索引和检索的分布式管道，以及kNN分布的稀疏、批次加载来解决这一瓶颈。在不同模型规模下，我们发现分配更多参数给记忆模块相比仅扩展基础模型能获得更好的参数-性能权衡。在17个基准测试中，将一个69亿参数的通用记忆模块与Pythia-410M配对，将其平均得分从29.86提高到37.34，以总参数减少39%超越了Pythia-12B（37.24）。对于参数范围从0.6B到14B的Qwen3基础模型，17亿参数的领域记忆在每个规模下都将三个领域的平均得分提高了9分以上。总体而言，我们的结果表明，独立扩展预训练记忆为提高语言模型性能提供了一条参数效率更高的途径。

## Abstract
Decoder-only language models entangle long-term memory and reasoning in a single parameter set, making it difficult to scale memory capacity independently. Memory Decoder introduces a parametric long-term memory module but only studies it at a relatively small scale. In this work, we present Memory Decoder at Scale, scaling memory models up to 6.9B parameters and pretraining them on 300B tokens. At this data scale, the combined cost of indexing and search makes a standard Faiss pipeline infeasible. We address this bottleneck with a distributed pipeline for Faiss indexing and retrieval, together with sparse, batch-wise loading of kNN distributions. Across model scales, we find that allocating more parameters to memory yields a better parameter-performance tradeoff than scaling the base model alone. On 17 benchmarks, pairing a 6.9B general memory with Pythia-410M raises its average score from 29.86 to 37.34, surpassing Pythia-12B (37.24) with 39% fewer total parameters. For Qwen3 Base models ranging from 0.6B to 14B, 1.7B domain memories improve the average score across the three domains by more than 9 points at every scale. Overall, our results demonstrate that independently scaling pretrained memory offers a more parameter efficient path to improving language model performance.

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **核心问题**：当前主流的仅解码器语言模型将“知识（长期记忆）”与“推理能力”耦合在同一个参数集中。这带来了三个关键限制：1）**无法独立扩展**：想提升记忆容量就必须整体增大模型，参数效率低下；2）**领域适配成本高**：对新领域的知识进行持续预训练或微调，需要优化全部参数，不仅昂贵，还可能导致灾难性遗忘；3）**缺乏模块化**：知识无法像插件一样在不同模型或任务间“即插即用”和共享。
*   **研究动机**：受神经科学中人脑记忆和推理系统分区的启发，旨在探索一种能独立于基础推理模型进行预训练、扩展和部署的**参数化长期记忆模块**。这为知识存储、更新和跨模型复用提供了模块化的解决方案。
*   **整体目标**：验证将这一参数化记忆思想从小规模实验扩展到工业级预训练规模的可行性，并系统性地研究其扩展规律和参数效率优势。

### 2. 论文提出的方法论

核心思想是将非参数检索器的行为“蒸馏”到一个独立的、可插拔的参数化Transformer模块中，称为“记忆解码器”。

*   **核心思想**：训练一个独立模型来模仿k-最近邻语言模型在训练语料库上的下一个词概率分布，从而将语料库知识内化到记忆模块的参数中。推理时，此模块与一个冻结的基础模型并行运行，其输出分布再进行插值。
*   **关键技术流程**:
    1.  **构建检索数据存储**
        *   使用冻结的基础语言模型，将训练语料库中每个位置的上下文表示为高维向量作为“键”，对应的下一个词作为“值”。
    2.  **大规模kNN分布构建**
        *   **核心瓶颈**：面对207B词元的Pile数据集，标准的Faiss流程因索引构建和搜索的二次成本而不可行。
        *   **分布式Faiss流水线**: 提出以下三步来解决此瓶颈：
            1.  **嵌入降维 (OPQ256)**：使用优化乘积量化将4096维的隐藏状态压缩为256维的搜索向量，大幅减少存储和距离计算成本。
            2.  **索引分片**：利用IVF+HNSW算法将索引分区，并为每个分区创建独立的IndexIVFPQ分片。
            3.  **大规模并行检索**：查询向量先通过HNSW路由到相关分片，然后各分片在独立GPU上进行本地检索，最后合并结果。
    3.  **记忆预训练与损失函数**：
        *   记忆解码器模型 \( M\_\psi \) 以原始上下文为输入，直接预测下一个词的分布 \( p\_\psi \)。
        *   训练目标是拟合由检索器构造的kNN分布 \( p\_{ret} \) 和原始的下一个词预测损失。损失函数为：
            \[
            L\_{mem} = \beta D\_{KL}(p\_{ret}(\cdot | c\_t) \| p\_\psi(\cdot | c\_t)) + (1 - \beta) (-\log p\_\psi(x\_t | c\_t))
            \]
            其中，KL散度项用于记忆检索知识，语言模型项用于保持语料库分布。
    4.  **训练优化**：
        *   **稀疏kNN分布存储与加载**：由于kNN分布在整个词表上是稀疏的（平均仅65个非零概率），只存储非零概率的词和值，使存储量减少约250倍，并通过分布式流式传输高效加载。
    5.  **推理**：
        *   冻结的基础模型 \( M\_\theta \) 和记忆解码器 \( M\_\psi \) 处理相同的上下文，输出分布进行线性插值得到最终预测：
            \[
            p\_{final}(y | c\_t) = (1 - \alpha)p\_\theta(y | c\_t) + \alpha p\_\psi(y | c\_t)
            \]

*   **主实验**:
    *   通用记忆扩展实验：测试了3种规模（1.4B, 2.8B, 6.9B）的通用记忆与同规模以及不同规模（410M）Backbone的组合。
    *   领域记忆实验：测试了1.7B参数的领域记忆在5种尺度Qwen3 Backbone (0.6B-14B)上的效果，并与3个强基线（CPT, LoRA, RAG）对比。
    *   跨词表迁移实验：验证了领域记忆从Qwen3词表迁移到OLMo-2和OLMo-3模型上的效果。
*   **分析性实验**:
    *   **Few-shot鲁棒性**: 在0-shot, 3-shot, 5-shot设定下评估.
    *   **记忆大小与训练预算消融**: 探究记忆参数量和训练步数对性能的影响。
    *   **训练目标消融**: 对比了使用记忆损失函数与使用标准继续预训练损失训练的模块的效果。
    *   **可提取记忆评估**: 量化了记忆模型相对CPT模型在训练数据上的可提取性。
    *   **记忆保真度评估**: 分析了记忆模型的输出分布与kNN监督信号的一致性。
    *   **案例分析与参数敏感性分析**: 可视化单词级别的记忆贡献，并研究了插值系数α的影响。

### 6. 论文的主要结论与发现

1.  **扩展记忆比扩展基础模型更参数高效**: 将参数预算分配给一个独立的记忆模块，其性能提升远超将同等参数直接加到基础模型上。例如，Pythia-410M + 6.9B记忆的组合以**减少39%的总参数超越了Pythia-12B**。
2.  **记忆模块具有“即插即用”和可迁移性**: 一个预训练好的记忆模块可以无需重新训练，直接与不同大小甚至不同词表的Backbone模型结合并带来一致提升。
3.  **领域知识可以通过模块化记忆有效注入**: 小型领域记忆模块（1.7B）在生物学、法律、金融等专业领域为各种尺度的Base模型带来了显著且一致的大幅提升（平均>9个点），优于继续预训练和LoRA。
4.  **方法在Few-shot场景下仍然有效**: 记忆模块提供的增益与上下文示例是互补的，即使有5个示例，增益依然存在。
5.  **增益主要来自知识密集型任务**: 记忆模块极大地改善了模型在需要事实知识的问题上的表现，如同一个外部知识库。

### 7. 优点：方法或实验设计上的亮点

*   **思想新颖，架构清晰**: “推理与记忆分离”的模块化架构设计干净、优雅，具有很强的解释性。
*   **工程贡献扎实**: 成功解决了在超大规模数据上构建kNN分布这一核心工程瓶颈，提出的分布式Faiss管道具有很强的实际价值。
*   **实验设计全面、对比公平**:
    *   严格控制了“总参数量”和“总训练预算”进行对比，使得“参数效率更高”的结论非常坚实。
    *   对比方法多样，包含了继续预训练、LoRA和RAG等具有代表性的知识注入或利用方法。
    *   从通用到领域，从单一模型到跨模型系列、跨词表迁移，验证维度非常全面。
*   **分析深入**: 不仅展示了性能提升，还通过分析揭示了记忆模块工作的内在机理，如事实证据的加强、对训练数据保真度等。

### 8. 不足与局限

*   **离线构造kNN分布成本高昂**: 尽管提出了分布式管道，但在记忆模块预训练阶段仍需进行一次昂贵的全量语料库索引和检索操作，这仍然是预处理阶段的巨大开销。
*   **插值系数α为静态固定**: 推断时，α是一个全局或按任务固定的超参数。理想情况下，模型应能根据上下文的不确定性或自身知识的置信度动态决定是否需要以及多大程度上依赖记忆模块。
*   **联合训练潜力未探索**: 基础模型和记忆模块是独立训练的。未来或可探索联合或分阶段的训练方式，虽然这会增加训练成本和复杂性，但可能进一步提升两者的协同效果。
*   **模型架构的局限性**: 方法验证主要基于Pythia和Qwen系列模型，其在更多样化的模型架构（如GQA、MoE等）上的表现有待检验。
*   **依赖特定基础模型构建索引**: kNN分布的构建依赖于一个特定的、预训练好的基础模型，这意味着记忆模块的质量受限于该基础模型。
