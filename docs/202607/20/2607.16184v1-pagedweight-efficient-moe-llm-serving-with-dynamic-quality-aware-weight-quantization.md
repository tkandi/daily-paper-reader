## 摘要
专家混合（Mixture-of-Experts，MoE）是一类流行的大型语言模型（LLM），具有较高的效率和准确性。然而，在KV缓存密集型的服务场景中，MoE模型往往在模型权重的GPU内存需求与不断增长的KV缓存之间出现紧张关系。我们提出PagedWeight，一种用于MoE LLM服务的新型管理方法，它在运行时动态量化MoE模型的权重，并平衡专家权重精度与KV缓存大小。PagedWeight揭示并有效应对了模型任务准确性、内存消耗以及吞吐量/延迟之间的复杂权衡。在多个内存敏感的MoE服务场景中，PagedWeight相对于多种现有量化基线方法改善了质量与内存的权衡。PagedWeight在实现FP16等效准确性的同时，最多节省72.0%的GPU内存，并将吞吐量提升1.94倍；在相似的内存预算下，与量化方法相比，质量最高可提升39.3%，且吞吐量损失最多仅为4.1%。

## Abstract
Mixture-of-Experts (MoE) is a popular class of large language models (LLMs), offering high efficiency and accuracy. However, in KV-cache-intensive serving scenarios, MoEs often exhibit a tension between the GPU memory requirements of the model weights and the growing KV cache. We propose PagedWeight, a novel management method for MoE LLM serving that dynamically quantizes MoE model's weights at runtime and balances expert-weight precision with the KV cache sizes. PagedWeight exposes and effectively navigates the complex tradeoff between the model's task accuracy, memory consumption, and throughput/latency. Across several memory-sensitive MoE serving scenarios, PagedWeight improves the quality-memory tradeoff over several existing quantization baselines. PagedWeight achieves FP16-equivalent accuracy with up to 72.0% GPU memory savings and 1.94$\times$ throughput improvement, and improves quality over quantization methods by up to 39.3% at a similar memory budget with at most 4.1% throughput loss.

- **核心问题**：在 MoE（Mixture-of-Experts）大模型的服务场景中，GPU 显存需要同时容纳模型权重和不断增长的 KV 缓存（尤其是长文本推理时），二者争抢有限显存，导致内存瓶颈和性能下降。传统的静态量化方法在服务前一次性确定位宽，无法在运行时灵活释放权重占用的显存来满足 KV 缓存的突发需求。
- **整体含义**：提出 **PagedWeight**，一种面向 MoE 大模型服务的动态质量感知权重量化系统，它借鉴了 KV 缓存的分页管理思想，在运行时按需调整专家权重的位宽，从而精细地权衡任务精度、显存占用与推理吞吐，突破静态量化的刚性限制。

### 2. 论文提出的方法论
- **核心思想**：将 MoE 专家的权重视为可动态调整精度、可在 CPU 与 GPU 之间移动的“权重页”（weight pages），通过一个质量感知的运行时规划器，根据 KV 缓存压力自适应地降低或恢复线性块（linear-block）的位宽，从而释放或回收 GPU 内存。
- **关键技术细节**：
  - **分页权重表示**：每个专家线性块（`gate_up`、`down`）的权重以 Any-Precision 位平面（bit-plane）和查找表（LUT）形式存储，每个位平面和对应 LUT 构成一个**权重页**。权重页表记录各线性块的已提交位宽 `q`、期望位宽 `d`、页状态（GPU驻留/CPU驻留/传输中）及不同位宽的内存占用。
  - **质量感知运行时规划器**（Algorithm 1）：
    - **离线全局敏感性**：基于 Hessian 加权的量化误差，为每个线性块和位宽转换计算全局损伤 `g^{b→b’}_i`，作为先验知识。
    - **在线路由统计**：实时收集专家激活频率与路由权重，将专家按热度分桶，给热门专家施加更高的损伤乘数和位宽下限，保护关键专家不被过度量化。
    - **提示残差**：从路由加权的输入范数特征中提取三维向量，通过离线训练的线性回归头预测当前输入对位宽转换的额外敏感性，以乘性因子 `η` 修正全局损伤估计。
    - **规划过程**：将 KV 缓存压力转化为需释放的字节目标 `D`，对所有候选降位宽动作计算 **单位释放字节的预测损伤**（`bd / Δ`），贪心地选择代价最小的动作序列，直至满足内存释放目标或达到允许的最大降位范围。
  - **异步页面移动**：加载/卸载权重页与推理流水线解耦，在安全边界提交位宽变更，利用重叠传输隐藏 PCIe 延迟。
  - **融合混合精度 MoE 内核**：一个 CUDA 内核直接读取 Any-Precision 位平面和 LUT，支持同一线性块的不同位宽，减少逐专家分散执行的额外开销。
