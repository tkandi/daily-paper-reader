## 摘要
单轮联邦学习（OSFL）通过将训练限制为单轮通信来解决联邦学习的通信开销问题，但在不牺牲模型质量的前提下做到这一点并非易事，尤其当客户端数据分布存在差异时。近期研究通过在服务器上构建可迁移的合成数据集或蒸馏物来聚合客户端知识，从而应对这一挑战。然而，这些方法大多缺乏正式的隐私保障，在同时实现低通信、对异构性的鲁棒性以及严格隐私方面存在空白。我们提出 FedKT-CSD（通过协作合成数据实现联邦知识迁移），这是一个受神经图像压缩启发的框架，通过利用公开预训练的自编码器作为共享潜在空间来填补这一空白。每个客户端只需一次前向传递即可对其私有数据进行编码，计算类别条件下的潜在统计量，并将其传输至服务器。服务器通过安全聚合汇集这些统计量，添加校准的差分隐私噪声，并解码出一个合成数据集，用于训练全局模型以及进一步的下游任务。该设计从构造上提供了正式的 $(\varepsilon,δ)$-差分隐私保证，同时保持客户端计算和通信的轻量级。尽管在隐私约束下运行，FedKT-CSD 在多种数据集和异构设置中与无隐私基线方法相比具有竞争力，甚至表现更优，并且能够扩展到大量客户端。我们的代码可在以下链接获取：https://github.com/an7123/FedKT-CSD

## Abstract
One-shot federated learning (OSFL) addresses the communication overhead of federated learning by limiting training to a single round, but doing so without sacrificing model quality is non-trivial, particularly when client data distributions diverge. Recent work has addressed this challenge by aggregating client knowledge on the server through the construction of transferable synthetic datasets or distillates. However, most of these methods lack formal privacy guarantees, leaving a gap in jointly achieving low communication, robustness to heterogeneity, and rigorous privacy. We propose FedKT-CSD (Federated Knowledge Transfer via Collaborative Synthetic Data), a framework inspired by neural image compression that closes this gap by leveraging publicly pretrained autoencoders as a shared latent space. Each client encodes its private data in a single forward pass, computes class-conditional latent statistics, and transmits these to the server. The server aggregates these statistics via secure aggregation, adds calibrated differential privacy noise, and decodes a synthetic dataset for training a global model and further downstream tasks. This design provides formal $(\varepsilon,δ)$-differential privacy by construction, while keeping client-side computation and communication lightweight. Despite operating under privacy constraints, FedKT-CSD is competitive with and even outperforms non-private baselines across diverse datasets and heterogeneity settings, and scales to a large number of clients. Our code is available at: https://github.com/an7123/FedKT-CSD

### 2. 方法论
- **核心思想**：将预训练的自编码器（编码器 $E$、解码器 $D$）冻结并分发至各客户端。客户端对本地私有图像进行单次前向编码，计算类别条件下的潜在向量和、外积和与样本计数，上传这些可加的统计量。服务器安全聚合后添加校准的差分隐私噪声，恢复带噪声的类条件均值与协方差，再从对应高斯分布中采样并解码，生成可供多种下游任务使用的合成图像数据集 $\mathcal{X}^*$。
- **关键技术细节**：
  - **客户端计算（无训练）**：
    1. 对图像 $x_{i,j}$ 编码得到潜在向量 $z_{i,j}=E(x_{i,j})$，并裁剪到 $\ell_2$ 范数不超过 $R$（根据编码器先验独立设定）。
    2. 对每个类别 $c$ 计算三个可加统计量：潜向量和 $\mathbf{m}_i^c$、外积和 $\mathbf{M}_i^c$、样本数 $n_i^c$。
  - **服务端聚合与加噪**：
    1. 通过安全聚合得到全局各类别总和 $\mathbf{S}_{\mu,c}, \mathbf{S}_{\Sigma,c}, n_c$。
    2. 分别向均值总和与协方差总和中添加校准的高斯噪声（使用解析高斯机制），满足 $(\varepsilon,\delta)$-DP。噪声尺度根据灵敏度（$\Delta_\mu=2R$, $\Delta_\Sigma=2R^2$）和预算分配确定。
  - **后处理与生成**：
    1. 从带噪声的总量恢复类别均值 $\boldsymbol{\mu}_c^{\text{DP}}$ 和协方差估计 $\hat{\boldsymbol{\Sigma}}_c$。
    2. 偏差校正（补偿均值噪声引入的偏差）和半正定投影（将协方差矩阵修正为半正定）。
    3. 从高斯分布 $\mathcal{N}(\boldsymbol{\mu}_c^{\text{DP}}, \boldsymbol{\Sigma}_c^{\text{DP}})$ 中采样潜在向量并解码为图像，构成合成数据集 $\mathcal{X}^*$。
  - **隐私分析**：采用类内替换邻接定义，对每个类别仅发布两个（或三个，若隐藏计数）聚合统计量，利用解析高斯机制和并行/顺序组合严格满足记录级 $(\varepsilon,\delta)$-DP。

### 6. 主要结论与发现
- 在 $(\varepsilon=10,\delta=10^{-5})$ 的差分隐私约束下，FedKT-CSD **在所有数据集和异质性设置下均超越全部无隐私 OSFL 基线**，且性能几乎不受数据划分方式或客户端数量的影响。
- 方法具有**固有的异构性不变性**和**客户端数量不变性**，根源在于可加统计量的聚合等价于集中式计算。
- 生成的像素级合成数据集可灵活用于下游个性化 FL，仅需一轮通信即可达到或超越多轮 pFL 方法。
- 通信负载极低（约 327.5 KB/客户端），客户端无需训练，适合带宽与算力受限场景。

### 7. 优点
- **隐私与效用的优雅平衡**：利用预训练自编码器的低维潜在空间，使 DP 噪声仅加在紧凑的统计量上，避免了高维模型参数的灵敏度膨胀。
- **设计精练且计算友好**：客户端仅需一次编码传递，不上传任何模型参数或梯度，无在设备训练，真正实现轻量联邦学习。
- **鲁棒性突出**：聚合模式天然免疫于数据标签的异质性和参与客户端数量变化，这在 OSFL 方法中尤为难得。
- **合成数据通用性强**：输出为标准图像数据集，可与任意下游架构和任务配合，不受制于特定的特征提取器。
- **实验严谨全面**：与众多无隐私和隐私基线对比，消融覆盖广，隐私评估包含正式分析和实证攻击，结论可信度高。

### 8. 不足与局限
- **任务依赖标签**：当前方法仅适用于有监督分类任务，且类条件统计依赖于已知标签，无法直接用于无监督或自监督场景。
- **分布假设简单**：每个类别仅用单一高斯建模，当类内分布复杂、类别严重重叠或存在噪声标签时，生成质量可能受限。
- **小样本类别脆弱**：样本数极少的类别的统计量受 DP 噪声影响相对更大，恢复质量可能下降。
- **隐私模型设定**：主要隐私分析假设标签是公开信息，保护的是记录的特征值而非类别存在性（虽附录给出了扩展方案）；并且需要预训练自编码器的权重公开。
- **域外数据泛化**：自编码器在自然图像上预训练，迁移到卫星、医疗等域外图像时虽仍可用，但合成图像视觉质量可能较差，依赖下游任务对纹理特征的利用。
