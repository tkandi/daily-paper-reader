## 摘要
现代分布式训练的调试、调优和分析成本高昂，因为忠实的分析通常需要在目标规模下反复执行。我们观察到，许多分析任务依赖于原始的分布式执行路径，但并不需要所有 rank 的完整执行。我们提出 RankLens，这是一种单 rank 模拟系统，可在单个 GPU 上运行一个保留 rank，同时保持目标任务的分布式语义。该保留 rank 执行原始训练程序并进行真实的本地计算。在通信边界处，系统以依赖于任务的语义替代真实的多 rank 通信，在保留分析所需异步依赖关系的同时，选择性地恢复记录的通信结果以及记录或估计的完成时序。这使得系统能够基于真实执行进行回放，并借助现有调试器和性能分析工具支持分析、调试和调优。我们在采用 8 至 64 个 GPU 的目标配置上，针对 DeepSpeed 和 Megatron-LM 对该系统进行了评估。RankLens 实现了训练张量通信结构的 100% 匹配，将模拟时序误差控制在 5% 以下，支持本地异常复现与执行分析，并将这些分析的资源需求从目标规模集群降低至单个 GPU。

## Abstract
Modern distributed training is costly to debug, tune, and analyze because faithful analysis often requires repeated target-scale executions. We observe that many analysis tasks depend on the original distributed execution path, but not on full all-rank execution. We present RankLens, a single-rank emulation system that runs one survivor rank on a single GPU while preserving the target job's distributed semantics. The survivor rank executes the original training program and performs real local computation. At communication boundaries, the system replaces real multi-rank communication with task-dependent semantics, selectively restoring recorded communication results and recorded or estimated completion timing while preserving the asynchronous dependencies required for analysis. This enables replay from real executions and supports analysis, debugging, and tuning with existing debuggers and performance analysis tools.   We evaluate the system on DeepSpeed and Megatron-LM across 8-64-GPU target configurations. RankLens achieves 100% training-tensor communication-structure match, keeps emulation timing error below 5%, supports local anomaly reproduction and execution analysis, and reduces the resource requirement of these analyses from target-scale clusters to a single GPU.
