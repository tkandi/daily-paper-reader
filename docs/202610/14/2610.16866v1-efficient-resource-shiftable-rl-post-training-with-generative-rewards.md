## 摘要
采用生成式奖励模型（GenRM）的强化学习（RL）后训练已成为提升大语言模型（LLM）的核心方法，同时其资源消耗也日益增加：策略轨迹生成、基于 GenRM 的奖励评估以及策略训练均会竞争 GPU 资源。然而，现有的共置式和解耦式系统对这些角色采用静态资源分配。这种分配方式无法适应各角色在 RL 过程中不断变化的工作负载，因而会导致某些角色的资源未被充分利用。我们提出 PivotRL，一种可根据不同角色的运行时需求在其间动态迁移资源的 RL 后训练系统。PivotRL 引入了一种基于全局参数存储（Global Parameter Storage）的资源可迁移运行时，并配备了可高效迁移角色特定上下文的统一机制。其具备迁移感知能力的调度器可在资源迁移时实现序列迁移；规划器则综合考虑总体吞吐量收益与迁移开销，以决定迁移的时机和方式。我们在一个包含 128 块 GPU 的集群上，使用涵盖稠密模型和混合专家模型的四组模型对 PivotRL 进行了评估。PivotRL 可在数秒内完成资源迁移；在保持 RL 收敛性的同时，相较于共置式部署将端到端吞吐量提升 1.81–2.05 倍，相较于解耦式部署提升 1.50–1.95 倍。

## Abstract
Reinforcement learning (RL) post-training with generative reward models (GenRM) has become a central recipe for improving large language models (LLMs), and it is also increasingly resource-intensive: policy rollout, GenRM-based reward evaluation, and policy training all compete for GPU resources. However, existing colocated and disaggregated systems rely on static resource allocation for these roles. Such allocation cannot adapt as each role's workload changes during RL and therefore leaves a role's resources underutilized.   We present PivotRL, an RL post-training system that dynamically shifts resources among different roles according to their runtime demands. PivotRL introduces a resource-shiftable runtime built on a Global Parameter Storage, together with a unified mechanism that efficiently shifts role-specific context. A shift-aware scheduler enables sequence migration upon a shift, while a planner considers the aggregate throughput benefit and the shift overhead to determine when and how to shift. We evaluate PivotRL on a 128-GPU cluster using four model groups spanning dense and mixture-of-experts models. PivotRL enables resource shifting within seconds and improves end-to-end throughput by 1.81-2.05 times over colocated deployment and 1.50-1.95 times over disaggregated deployment, while preserving RL convergence.
