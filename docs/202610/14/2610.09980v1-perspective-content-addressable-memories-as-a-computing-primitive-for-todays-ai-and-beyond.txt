Abstract 

Modern artificial intelligence is predominantly executed on computing architectures optimized for dense linear algebra. While this has enabled the success of contemporary neural networks and motivated compute-in-memory (CIM) architectures, a growing class of artificial intelligence (AI) workloads depends on associative retrieval, identifying stored information by content or similarity rather than by explicit memory addresses. Such operations are central to transformer attention, tree-based inference, genomic search, and other retrieval-intensive applications, yet remain inefficiently supported by conventional memory systems. In this Perspective, we argue that content-addressable memories (CAMs) provide a complementary hardware primitive for associative processing in AI. We review their ability to perform massively parallel in-memory matching, discuss how emerging memory technologies can improve density and energy efficiency, and identify hierarchical search, application-specific architectures, hardware-aware learning, and heterogeneous integration with CIM as key directions for scalable associative computing. Together, these developments suggest that associative retrieval should complement linear algebra as a foundational computing primitive for future AI systems. 

# 1 Introduction 

Traditional computer memories operate according to the random-access memory (RAM) paradigm, where an input address directly connects to a stored digital value. Content-addressable memories (CAM) invert this relationship: a query pattern is presented to memory and compared against a collection of stored keys, as illustrated in Fig. 1(a,b), with the output being a measure of association, such as a similarity score or an exact match, that can be translated into an address [1]. This fundamentally changes the nature of memory operations: retrieval itself becomes a computation, and information can be recalled from data that is incomplete, noisy, or partially corrupted by identifying the closest matching stored pattern [2, 3]. As we discuss in this Perspective, these properties align closely with many computing applications, including today’s AI where the central operations are often not numerical computation alone, but the retrieval of stored patterns by association. Despite the diversity of implementations, all content-addressable memory (CAM) hardware shares the same underlying computational principle, illustrated in Fig. 1(c). At its core, every CAM consists of two fundamental building blocks: a CAM cell that stores a key and evaluates its relationship to an input query, and a match line that combines the resulting cell responses mi,j

Beyond just hardware, associative memories have a long history in both computer engineering and neuroscience, although the two fields developed largely independently for many decades. Modern AI increasingly highlights associative retrieval as a central computational principle. This creates a natural bridge between associative memory concepts in neuroscience and content-addressable memory architectures in computer engineering. Recent CAM-based implementations of transformer attention further illustrate this convergence [37, 38]. The memory bottleneck of conventional von Neumann architectures built around RAM, together with the rapidly rising computational and energy demands of AI, expose the limits of existing computing systems and the need for more performant, specialized hardware innovations [39]. This provides a central motivation for reconsidering CAMs as a missing computational primitive, particularly for workloads in which stored representations must be repeatedly searched, compared, or filtered. Transformer attention is a prominent example, since large volumes of stored key-value representations must be accessed and compared during inference [40]. Finally, we examine CAM-based architectures and system-level design considerations, outlining the engineering challenges and opportunities associated with deploying CAMs across diverse application domains. 4Box 2: Associative Memory in the Brain An addressable and directly programmable RAM-like memory has certainly not been found in the brain. Instead, a multitude of memory types (episodic, semantic, procedural) are described by psychologists and neuroscientists, where memory “fetching" is instead a dynamic process triggered by context and association (e.g., Proust’s madeleine), and memory “programming" is instead a learning procedure (e.g., learning to ride a bike). Thus, the view of the brain as an associative memory system has deep roots. In hippocampal indexing theory, the hippocampus stores indices to distributed neocortical activity patterns, linking episodic memories to the cortical areas in which their semantic contents are represented, as shown in Fig. 1(d) [29, 30]. Importantly, this does not imply that long-term memory resides only in the hippocampus: cortical networks are thought to support long-lasting semantic memories over years, whereas hippocampal memories are more episodic and gradually consolidated into cortical representations. Recent models extend this idea toward key-value memory, where sparse hippocampal “keys” retrieve distributed neocortical “values” containing sensory and semantic information [31, 32]. Retrieval is likely not an exhaustive global search, but instead relies on sparse and hierarchical hippocampal-cortical dynamics that organize memories into nested subspaces for efficient access to spatial, episodic, and linguistic associations [33, 34]. Beyond hippocampal indexing, cortico-thalamic circuits may support attention-like key–value retrieval, where cortical activity maintains short-term memory traces while thalamic pathways contribute to routing, gating, and sustaining these representations [35]. This connects biological associative memory to query-key-value mechanisms in transformer architectures and motivates CAM-based attention hardware, as discussed in Section 3.3. 

# 2 Memory and Device Technology for CAM Systems 

2.1 Technology Landscape of Associative Memories 

CMOS SRAM-based TCAMs are the established industrial standard, providing high-speed, reli-able search with mature fabrication [10] making them well suited for latency-critical applications such as networking, packet classification, and routing. However, their large cell area highly limits capacity. Although both SRAM- and DRAM-based CAMs store only one bit per memory cell, DRAM-based CAMs partly address the area limitation through more compact dynamic storage, at the cost of reduced robustness, retention, or circuit simplicity [14]. Flash- and floating-gate-based CAMs form a dense class of non-volatile associative memories, from early multi-level Si-based floating-gate MOS CAMs [13], to recent 3D-stackable concepts based on thin-film oxide transistor-based such as IGZO and on low-dimensional materials such as MoS 2 [21, 47, 48]. FeFETs instead store the state in the polarization of a ferroelectric gate rather than as charge on a floating gate, avoiding the charge injection or tunneling required for Flash programming and thereby enabling substantially faster, lower-voltage state updates. This gives the same non-volatile, multi-level threshold shift while switching at a few volts in nanoseconds rather than at the tens of volts and microseconds required for tunneling [6, 17, 19, 49, 50]. In both FeFET and floating-gate CAMs, programmable analog thresholds can directly define the matching bounds of an analog CAM cell, avoiding additional thresholding circuitry. Their main limitation is that the matching boundaries inherit the finite switching slope and variability of the transistor, which can soften thresholds and limit the number of reliable states or the achievable inference precision, depending on the application. Memristive technologies, including phase-change and filamentary resistive switching devices, are attractive CAM candidates due to their high density, non-volatility, and analog programmabil-5ity. Early hybrid memristor-CMOS CAMs demonstrated integration with CMOS search circuitry, followed by many memristive BCAM and TCAM architectures [15, 16, 51–54]. The field later expanded to analog CAMs, particularly 6T2M cells that store continuous matching boundaries instead of binary states [5]. Since memristors are passive two-terminal devices, CMOS support is typically needed for thresholding and gain, creating a density–discrimination trade-off: additional circuitry sharpens search boundaries but increases cell area and reduces storage density. Gain-cell-based aCAMs combine compact dynamic storage with analog associative search and storage functionality [55]. Their high-speed write operation and effective unlimited write endurance make them attractive for associative cache hierarchies, while oxide-semiconductor platforms such as IGZO could enable monolithic 3D integration of dense vertical CAM arrays [56–61]. Additional non-volatile CAM concepts based on magnetic tunnel junctions (MTJs) [62] and, more recently, ferroelectric memcapacitors [63], further broaden the device landscape, although they are currently less developed than FeFET-, Flash-, and memristor-based implementations. Optical and opto-electronic CAMs exploit optical parallelism and wavelength-division multi-plexing to address electrical bandwidth and interconnect limits [64, 65]. They may offer high search throughput for specialized workloads, but large-scale deployment remains limited by fabrication, thermal stability, and opto-electronic integration challenges. 

2.2 Associative Memory Hierarchy 

Conventional memory is organized as a hierarchy because no single technology simultaneously optimizes density, latency, bandwidth, energy efficiency, and retention, so each level is implemented in a different technology, as shown in Fig. 3(a) [66]. CAM systems will likely follow the same principle. The radar plots of Fig. 3(b) compare candidate technologies (left) with the requirements of representative applications (right) along three axes: density, retention, and programmability, where the latter combines write speed, energy, and endurance. Programmability and density are largely in tension: fast-to-write charge-based cells are either large, as in SRAM, or volatile, as in DRAM and gain cells, whereas the non-volatile mechanisms that provide density and retention require slower, endurance-limited programming. Applications separate along the same axis, since frequently updated associative state favors programmable memories, whereas large but rarely updated search databases prioritize density and retention. Both plots therefore order along a common spectrum, drawn in the center panel. For the remainder of this paper we reduce it to its two endpoints [67]: a write-heavy dynamic 

CAM tier for frequently updated state, and a larger-capacity static CAM tier for search-intensive workloads. This two-tier picture is a deliberate simplification, and intermediate tiers are both conceivable and likely. 

Tier-1 Dynamic / Write-intensive CAMs Dynamic CAMs are high-speed associative memories optimized for frequently updated representations such as embeddings, descriptors or sensory states. Operating close to AI accelerators or sensory front-ends, they can continuously compare transient runtime information to identify temporal correlations, recurring patterns, or previously observed states. Visual place recognition (VPR) is a representative example, where feature matching corresponds to nearest-neighbor search in Hamming space and, together with feature extraction, can account for approximately 60–70% of execution time [68]. Similar requirements arise in transformer attention and token reuse mechanisms [37, 38], CAM-based learning hardware with continuously updated weights or prototypes (Sec. 3.4), and the second stage of two-stage genomic search, where candidate locations returned by a ShiftCAM filter differ for every query and, therefore, must be written before each fine-grained alignment (Sec. 4.2). The ShiftCAM filter that stores the reference database itself belongs to the static tier below. This application class is currently the most established domain for CAM-based acceleration, with numerous reported demonstrations across both classical and emerging workloads. Classical examples include routing and packet-classification tables, where CAMs have long been used for fast lookup operations [11, 12]. Static search memories have also been explored for database search and large-scale nearest-neighbor retrieval [2, 10]. More recent application directions include tree-based search accelerators, discussed in Sec. 3.1, and genomics workloads, discussed in Sec. 3.2 [3, 18, 69]. 

2.3 Scaling CAMs Arrays with New Materials and Vertical Integration 

Scaling CAMs to larger capacities exposes a central device–circuit trade-off between sensing margin and storage density. Robust CAMs require clear match–mismatch discrimination to tolerate device variability, noise, and non-ideal search dynamics, but larger sensing margins typically demand additional transistors, stronger isolation, or peripheral gain stages, all of which increase cell area. Highly compact cells instead operate with smaller margins and fewer states per cell, making them more sensitive to variability and array-level parasitics [70, 71]. The trade-off becomes more severe in large arrays, where sensing margin, interconnect loading, match-line capacitance, and search bandwidth turn into coupled system-level constraints rather than isolated cell-level metrics. Relaxing this trade-off requires devices and integration schemes beyond planar silicon, and two-dimensional materials are the clearest example at the device level. The appeal of 2D semiconductors starts at the device level. Their atomically thin body improves electrostatic control, suppresses short-channel leakage, and reduces parasitic capacitance, which sharpens the electrical contrast between matching and mismatching states during search while limiting unwanted current paths [72–74]. The most direct benefit for CAMs is the drain capacitance that every cell attaches to the match line and that is charged and discharged on every search: a thin body on an insulator has no bulk junction to deplete, lowering both the CV 2

search energy and the match-line RC delay, although the delay benefit requires the read current to be maintained. Recent ultrafast 2D flash studies show that this read current depends more 7strongly on contacts and interfaces than on the channel material itself, and that the bottleneck can be relaxed through semimetal and edge-contact strategies that reduce contact resistance and weaken Fermi-level pinning [45, 75–80]. Semimetal-contacted MoS 2 flash aCAMs illustrate the direction, combining high read current with a large ON/OFF ratio for low-latency analog search [21]. These device properties translate into a system-level opportunity, since back-end-of-line (BEOL) compatibility, shared by 2D channels and by thin-film oxide semiconductors, permits stacking memory and search layers directly above CMOS logic. Vertical integration shortens the wiring between storage and peripherals and thereby reduces interconnect parasitics, but it does not eliminate the underlying compromises between density, retention, programmability, and sensing robustness. It is therefore most valuable wherever capacity, bandwidth, and energy are limited by footprint and wiring rather than by the memory cell alone [73, 74, 81]. Both tiers of the associative hierarchy introduced in Sec. 2.2 can benefit from this, but they call for different stacked platforms. For the static tier, the 2D flash devices discussed above are the natural candidate, since retention and density dominate and their dual-gate structure already suggests vertically stacked complementary cells that form a compact aCAM without an external analog inverter [21]. The dynamic tier instead requires fast and endurance-tolerant writes, which points to the gain-cell aCAMs of Sec. 2.1 implemented in oxide-semiconductor platforms such as IGZO. Here the low off-current of the oxide access transistor extends the retention time of the dynamically stored key and thereby relaxes the refresh overhead, while BEOL-compatible processing allows multiple such layers to be stacked above a shared CMOS search periphery, reducing the effective area per stored bit relative to a planar cell. This combination could therefore enable monolithic 3D integration of dense vertical dynamic CAM arrays [56–61]. The open question is therefore not whether these materials can demonstrate CAM behavior, but whether they can be manufactured as scalable 3D associative systems. This requires stable analog programmability, a controllable memory window, adequate retention and endurance, and low device-to-device variation so that stored match ranges remain predictable across large arrays [21, 45, 46, 76]. Equally important are wafer-scale synthesis, layer-to-layer alignment, thermal-budget management, and the co-integration of selectors, sense amplifiers, and digital control [46, 73, 82]. If these hurdles can be reduced, new materials may matter less as standalone device novelties than as enabling platforms for dense monolithic 3D CAM systems. 

# 3 Applications 

Associative retrieval is a fundamental operation that appears across many computational work-loads. In this section, we survey how CAMs can accelerate applications ranging from thresholding and tree-based inference to genomic sequence alignment and transformer attention. We further discuss emerging directions in trainable and differentiable CAMs, highlighting both the opportu-nities and challenges of learning directly within associative memories. Together, these examples illustrate the growing role of CAMs as a general-purpose substrate for associative computation. 

3.1 Tree Model Inference with CAMs 

Beyond database-style lookups, inference of tree models (Fig. 4) is one of the clearest examples of a workload mapping naturally onto CAM hardware. Decision trees, random forests, and related rule-based learners are composed of repeated inequality tests and threshold comparisons rather than dense linear algebra. However, their inference remains inefficient on conventional processors because tree traversal induces irregular memory accesses, branch divergence, and sequential data dependencies. Unlike approaches that require differentiable memory access during end-to-end optimization, tree models can be trained with standard algorithms and only mapped to hardware after training. In a tree model, each internal node tests whether a specific input feature falls above or below a learned threshold, and each root-to-leaf path defines a decision rule as the conjunction of these inequalities, as illustrated in Fig. 4(a). The learned inequalities or decision boundaries can then be translated almost one-to-one into stored CAM ranges [18, 83]. This makes CAM-based tree inference compatible with conventional offline training, while retaining the interpretability of rule-based models and shifting the main hardware challenge to accurate programming and verification of the search boundaries to mitigate non-idealities [87, 88] A particularly promising direction is to move beyond hard trees. Recent work maps soft decision trees to analog CAM hardware by exploiting the intrinsic soft boundaries of threshold-tunable devices, turning a device limitation into a probabilistic compute primitive that improves robustness to variation and perturbation [89]. More broadly, CAM-based tree inference should co-design model classes with analog device physics rather than forcing analog comparisons to emulate abrupt digital thresholds.

Furthermore, mapping Levenshtein automata directly into TCAM arrays[98] can be a highly accurate approach to compute edit distances for approximate matching, but this process needs some iterations and would sacrifice speed efficiency. For targeted sequencing, real-time control makes speed the top priority. To achieve this, researchers proposed an LSH-TCAM system to extract binary features from nanopore raw signals and search them in CAM directly instead of conventional base pair[94]. Although this is the fastest method, it sacrifices some accuracy. 

3.3 Transformer Attention with CAMs 

Today’s large language models (LLM) depend on Transformer attention [36], which can be understood as a form of associative memory. This has conceptual roots in Kohonen’s correlation matrix memory [99], where key–datum pairs are stored as outer products and recalled by multiplying the resulting memory matrix with a retrieval key. In modern terminology, this resembles an unnormalized key–value retrieval operation. This connection has been further 10 developed in modern Hopfield networks, which interpret the query–key interaction in transformers as associative retrieval over stored patterns [20]. More broadly, several works have shown that neural networks and attention layers can be viewed as complementary forms of associative memory, linking representation learning, pattern retrieval, and transformer computation within a common conceptual framework [100–102]. While transformer attention relies almost exclusively on scaled dot-product similarity, recent studies suggest that alternative similarity measures–such as Manhattan and Euclidean distance– can offer improved retrieval robustness and practical memory capacity in associative memory systems [41]. The dominance of scaled dot-product attention may therefore partly reflect its efficient mapping onto GPU-based linear algebra, rather than an inherent optimality for associative retrieval. This observation motivates the exploration of CAM-based architectures, which naturally support distance-based matching and can implement highly selective similarity metrics directly in memory. Recent works have demonstrated that transformer attention mechanisms can be implemented efficiently using CAM-based architectures [37, 38]. In these approaches, the generation of attention scores, corresponding to the query-key (QK) lookup operation, is implemented directly within a CAM structure. This enables content-based similarity search to be performed in-memory, avoiding the explicit computation of large matrix multiplications and softmax operations typically required in conventional dot-product attention, thereby significantly simplifying the underlying compute-in-memory hardware architecture. Existing pre-trained transformer models cannot be directly transferred to CAM-based atten-tion architectures, but instead require some retraining. A central challenge is that gradient-based optimization requires differentiable memory access and backward signal propagation whereas most CAM operations are inherently non-differentiable and provide no natural backward path. Existing approaches therefore rely on surrogate models or approximate gradients, as discussed in Section 3.4, but these methods can reduce training stability, scalability, and accuracy compared with standard dot-product attention [36, 37, 103]. A promising alternative is non-differentiable retrieval-based attention, where associative lookup is decoupled from gradient propagation, as in k-NN-based Memorizing Transformers and recent sparse-attention methods that selec-tively retrieve relevant KV-cache entries [104–106]. This paradigm is particularly well suited to CAM-based hardware. Another challenge is that CAM-based search can become increasingly energy-intensive as the KV cache grows with the transformer context length. Sparse attention reduces this cost by evaluating only selected tokens, while CAMs can act as a preselector or sorting engine to identify relevant KV entries before subsequent computation [107–109]. However, these approaches typically retain a flat, globally accessible search space. Hierarchical associative structures could instead progressively route each query toward increasingly selective memory subsets, thereby reducing unnecessary array activation and improving scalability. The corresponding CAM architectures and energy–latency trade-offs are discussed in Section 4.4. 

3.4 Machine Learning with CAMs 

Many CAM applications discussed in this perspective require training methodologies compatible with gradient-based optimization. Depending on the deployment scenario, this may involve differentiable software models of the CAM hardware for offline training, or training and fine-tuning directly on the hardware itself. In such systems, the memory operation itself must often be differentiable such that gradients can propagate through the associative memory during backpropagation [103]. The required degree of differentiability depends on the application. Tree models can be trained using conventional algorithms and subsequently mapped directly onto analog content-addressable memory (aCAM) ranges without backpropagating through a hardware model, as discussed in Section 3.1 [18, 83]. Hardware non-idealities can then be mitigated during deployment through decision-boundary-aware programming and verification. One approach is to approximate the inherently sharp decision boundaries with smooth functions, as implemented in TorchCAM, where shallow sigmoid functions model the boundaries and are progressively sharpened during training, thereby providing surrogate gradients for backpropagation, as shown in Fig. 6(a) [111]. Similarly, the L2S algorithm presented in [4] optimizes memristor conductances using gradients computed from a differentiable surrogate circuit model, enabling compensation of hardware non-idealities such as match-line crosstalk during training [71]. If device-specific variations and non-idealities are to be compensated directly, actual in-hardware learning or fine-tuning becomes necessary. Training directly on CAM hardware remains a major challenge because most CAM architec-tures provide little or no usable gradient information for backpropagation. Differentiable CAMs offer a potential route to overcoming this limitation by employing smooth, shallow decision boundaries that support gradient-based optimization [4]. However, this increased differentia-bility typically comes at the cost of reduced storage capacity and selectivity [71]. Figure 6(b) compares sharp and smooth CAM decision landscapes, highlighting the improved gradient prop-agation enabled by the smoother landscape. Another major challenge is that all CAM hardware does not provide a natural backward path for gradient propagation. Enabling in-hardware backpropagation therefore requires substantial circuit modifications at the CAM cell level to support transposed CAM operations, dramatically increasing the area footprint. One possible alternative to full in-hardware backpropagation is to employ local or forward-only learning rules, such as Hebbian-style updates [112], frequency-multiplexed gradient descent [113, 114], or node-perturbation-based training [115]. By reducing or eliminating the need for dedicated backward-propagation paths, these approaches may be particularly attractive for CAM-based hardware. Although such approaches have received little attention in the context of CAMs, they may provide a more hardware-compatible learning paradigm for future CAM-based architectures. From a broader perspective, several challenges must be addressed to enable CAM-based AI 12 systems. First, accurate and computationally efficient software models are required to support standard gradient-based optimization and backpropagation. Second, specialized CAM circuits capable of supporting in-hardware learning and backward signal propagation will likely be necessary, although such approaches are expected to incur additional area overhead and require dynamically programmable memory structures. Finally, alternative local learning rules should be further explored to compensate hardware non-idealities and alleviate the need for full global backpropagation in CAM-based architectures. 

# 4 From CAM Arrays to Associative Computing Architectures 

Individual CAM arrays provide the fundamental operation of content-based search, but practical systems require scalable architectures. This includes architectural decisions on where CAMs are placed, how they interact with surrounding compute and memory blocks, how data movement is organized, and which memory technologies are assigned to different levels of the memory hierarchy. At the same time, the increasing diversity of associative hardware requires correspondingly flexible software tools capable of designing, evaluating and optimizing these heterogeneous systems. Together, these architectural and software considerations connect the device, circuit, and application perspectives introduced above. They also demonstrate that CAMs are not restricted to a single integration strategy, but can serve as standalone retrieval engines, associative memory tiers, near-memory accelerators, or tightly integrated components within broader CIM systems. In the next section, we discuss how CAMs can be designed, integrated and scaled as building blocks of future associative computing architectures. 

4.1 Design Automation for Large-Scale Associative Computing Architectures 

The growing diversity of CAM technologies, search modalities, and system architectures creates an increasingly large design space spanning devices, circuits, architectures, and applications. Exploring this space manually is becoming impractical, particularly as different memory tech-nologies exhibit distinct latency, energy, area, precision, and endurance trade-offs. Consequently, future associative computing systems will require mature design automation frameworks capable of circuit- and architecture-level evaluation, rapid design-space exploration, hardware-aware mapping, and compiler support. Recent efforts already point in this direction. Eva-CAM [116] enables technology-aware evaluation of heterogeneous CAM architectures across multiple abstraction levels, facilitating rapid exploration of architectural trade-offs. At the application level, X-TIME [83] demonstrates hardware-aware mapping and optimization of tree-based machine-learning models onto analog CAM architectures, while compiler frameworks such as C4CAM [117] further generalize this concept by translating high-level programs into optimized implementations for heterogeneous CAM accelerators. Together, these efforts represent important first steps toward a complete hardware–software ecosystem for associative computing, analogous to the role that compiler and programming frameworks have played in enabling modern GPU computing. 

4.2 Application Specific CAM Architectures 

Many applications require broader operations than matching between queries and stored CAM entries. Depending on the workload, associative search may need to support approximate simi-larity, shifted alignment, programmable precision, winner-take-all selection, or direct retrieval of associated values. These functions require application-specific peripheral circuitry and archi-tectural organization beyond the CAM array itself. The following examples illustrate how such specialization extends basic lookup into more capable associative computing systems. 13 ShiftCAM for Genomic Matching Unlike conventional similarity search, there are frequent insertion and deletion (“indel") errors in sequencing data, which will decrease conventional CAM performance. This is because conventional CAMs search according to Hamming distance. However, even a single indel error can lead to a large Hamming distance, making it fail to represent sequence similarity. As discussed in Sec. 3.2, ShiftCAM uses additional time-domain shift logic circuits to tolerate indel errors, which is efficient but not accurate enough for many practical applications. To further improve search accuracy, additional architectural support is required. A promising direction is to use ShiftCAM as a first-stage filter to quickly identify rough candidate locations in the reference database, and then use a TCAM-based second stage to perform fine-grained edit distance matching through Levenshtein automata. This second stage can evaluate sequence similarity more accurately, but the candidate locations generated by ShiftCAM differ across input queries, thus additional dynamic memory is needed to store and update the input-dependent candidate DNA fragments and automaton states for Levenshtein automata. By implementing this dynamic memory with BEOL compatible materials such as IGZO or 2D materials[81], this potential architecture could be realized through high density 3D integration, further improving efficiency. 

Soft CAM Architecture A second application-specific direction is to use CAMs for probabilis-tic inference, where preserving graded match information is more important than collapsing every comparison into a binary decision. As discussed in Sec. 3.1, soft decision tree models are a natural example because inference operates by accumulating probabilities across multiple candidate paths rather than selecting a single hard branch [89]. In these workloads, application-specific architectures are needed because conventional CAM optimized for exact or thresholded matching does not preserve the analog information required by the model. A Soft CAM therefore maps candidate paths to rows, uses the cell responses to evaluate soft node conditions, and accumulates the resulting analog signals on the match line so that each row carries a probability-like confidence score. After calibrated sensing, the most likely outcome can be selected through winner-take-all readout. Since this winner-take-all operation can be implemented directly in hardware as part of the CAM architecture, it can avoid additional digital post-processing and improve overall efficiency [118]. A key architectural requirement is to preserve the relative ordering of row-level probabilities, even under device variations and finite-slope readout, rather than only maximiz-ing binary match discrimination. This Soft CAM example illustrates the benefits for future associative systems to be tailored for workload-specific organization, beyond justbasic CAM primitives. 

4.3 Integrating CAMs into CIM Architectures 

CAMs can be viewed as the missing associative primitive in future compute-in-memory (CIM) systems. Crossbar arrays efficiently accelerate linear algebra, but they do not natively provide content-based retrieval. CAMs fill this gap, enabling associative recall directly in memory. This is particularly relevant because many analog CIM architectures are dominated by data-conversion overhead, with analog-to-digital converters (ADCs) and digital-to-analog converter (DAC) reported to contribute roughly 60–90% of the energy consumption and up to ∼80% of the area [119–121]. By accepting analog inputs and producing digital match outputs, analog CAMs could reduce repeated conversions while adding search as a native compute operation. We next discuss two architectures that move toward this tighter integration of associative search and crossbar-based CIM.

By tightly integrating both arrays, the analog output of the match-line sense amplifier (MLSA) or transimpedance amplifier (TIA) can directly drive the CIM array, eliminating intermediate ADCs and preserving an end-to-end analog signal path. Given the wide range of existing implementations and its conceptual generality, this structure emerges as a fundamental building block for future CAM-enhanced CIM architectures. Applications of this principle have already emerged across multiple domains. In finite-state machines, CAMs detect the current state while CIM arrays encode the corresponding state-transition [122]. Another prominent example is the Attention Mechanism, which can itself be interpreted as a hetero-associative unit linking queries to values through coupled CAM and CIM arrays [37, 38], discussed further in Sec. 3.3. For example, in decision tree (tree model) implementations, the CAM evaluates decision rules performing a classification, while a crossbar array retrieves the class label associated with the selected leaf node [18]. A recent work applied this concept to Kolmogorov-Arnold Networks (KANs), where CAM-based LUTs are used to encode nonlinear activation functions within the network [123]. Extending this concept further, networks of hetero-associative units or LUTs can, in principle, realize arbitrary computations. Modern FPGAs represent the closest practical realization of this paradigm, employing large arrays of configurable LUTs and programmable interconnects to implement digital logic rather than relying solely on fixed-function processors [124]. A potential system-level realization is shown in Fig. 7(b), where heterogeneous processing elements (PEs), including conventional crossbar-based CIM units, standalone CAMs, and hybrid hetero-associative CAM–CIM units, are integrated on-chip and interconnected through a network-on-chip. 

Non-Linear DPE for ADC-Light Crossbar Readout In classical mixed-signal CIM accelerators, as shown in Fig. 7(c), the bottleneck is not only the matrix-vector multiplication itself, but also the analog-to-digital conversion of the accumulated output [119–121] and the subsequent nonlinear mapping in the digital domain. A second integration pattern for CAMs and 15 crossbar arrays therefore operates in the reverse direction: the crossbar array first performs the analog dot product, while the CAM replaces the conventional ADC and digital post-processing pipeline. This forms a non-linear dot-product engine (NL-DPE) [125–127], as illustrated in Fig. 7(d). CAMs provide a natural way to embed this readout stage in memory. Instead of fully digitizing the crossbar output, the analog signal can be compared directly against stored thresholds or intervals. The CAM then produces a binary code indicating the region of the programmed nonlinearity in which the input signal falls, which can be passed to subsequent processing stages. This architecture is conceptually related to a flash ADC, but replaces fixed comparator levels with programmable, memory-resident thresholds that can be adapted to the target nonlinear activation function, the signal statistics, or even the calibration of the dot-product engine (DPE) [128, 129]. From this perspective, NL-DPE can merge analog-to-digital conversion and nonlinear activation into a tighter analog front end, potentially reducing ADC overhead while enabling application-specific post-processing directly in memory. Whether this approach is beneficial depends on the required resolution, the number of stored ranges, sensing cost, variation tolerance, and whether associative thresholding scales more favorably than a conventional ADC followed by digital logic [5, 125, 128]. 

4.4 Reducing Search Energy Through Hierarchical CAM Architectures 

Recent work has shown that large-scale associative retrieval can benefit substantially from hierarchical memory organization. Flat retrieval architectures scale poorly with increasing memory size, suggesting that future (larger) memory systems will require structured memory navigation mechanisms beyond dense global search, further evidenced in the example of retrieval augmented generation (RAG) [130]. This can also be attractive for the implementation of KV cache within the attention mechanism of transformers (Section 3.3), which has been demonstrated theoretically in [131]. As introduced in Box 2, sparse hierarchical retrieval may explain how the brain accesses relevant associations within vast stored memory spaces without requiring exhaustive and energy-hungry search. Tree-based inference, discussed in Section 3.1, is typically implemented using parallel associative search. However, the underlying tree structure can also be exploited to enable hierarchical and sparse search, reducing the number of candidate paths that must be evaluated. Early CAM works identified the large energy consumption associated with fully parallel search operations where all highly capacitive search-lines and match-lines switch during every query [27]. To mitigate this problem, segmented and hierarchical CAM architectures were proposed, where search operations can terminate early once any mismatch is detected, reducing unnecessary switching activity and lowering overall power consumption by up to 60% [27]. This principle of progressive pruning has been extended directly to search-lines, where data-aware gating nodes actively halt signal propagation upon encountering "don’t care" bits in IP routing tables to cut energy consumption by nearly half [132]. Similar ideas were recently validated in application-driven associative computing, where sequential feature-wise search with early termination reduced Random Forest inference energy by approximately 50% across multiple datasets while requiring only three to four sequential feature evaluations per search in most cases [71]. While aCAMs enable highly parallel Random Forest inference, sequentially evaluating decision paths from root to leaf allows mismatching candidates to be discarded early, substantially reducing switching activity and search energy. More generally, the above results highlight that pipe-lined or sequential associative search strategies can effectively trade-off search latency for energy efficiency. This may become particu-larly important for transformer attention mechanisms, where associative search operations poten-tially scale with the entire context window and therefore incur rapidly increasing search energy and bandwidth requirements. Nevertheless, hierarchical associative search from a hardware-centric CAM perspective remains largely unexplored, despite multiple works already demonstrating the 16 strong potential of hierarchical and staged CAM architectures for reducing search energy and improving scalability. We advocate for hierarchical search to be treated as a core architectural design target in future CAM hardware. Rather than activating the full array for every query, future systems should support sparse search directly in hardware, for example through row-wise or block-wise activation schemes in which only candidate regions are enabled after an earlier search stage reports a match. 

# 5 Conclusions and Future Directions 

In this perspective, we propose CAMs as a foundational hardware primitive for advanced AI systems and broader applications, not just as specialized lookup circuits in networking or database systems. We showcase recent advancements across emerging memory technologies, algorithmic workloads, and novel architectures for broad application spaces. We have examined this paradigm shift across many levels: underlying device technologies, which determine density, robustness, and sensing limits; the application perspective, which highlights emerging CAM workloads such as attention, tree-based inference, and genomics; and the architectural perspective, which positions CAMs as a natural complement to modern AI computing infrastructure. Realizing associative computing as a general-purpose computing paradigm requires progress across multiple levels of the technology stack, from emerging memory devices, circuits, and architectures to learning methods, neuroscience-inspired memory organization, and application-driven system design. The figure highlights key research opportunities, including hierarchical search, monolithic 3D integration, hardware-aware and online learning, application-specific CAM architectures, and emerging domains such as probabilistic computing and low-latency scientific instrumentation. Transitioning CAMs from specialized lookup tables to foundational computing primitives opens the door to high-performance and paradigm-shifting capabilities. To realize this potential, we propose here directions for future work for researchers across many disciplines, summarized in Fig. 8. 1. Device-Level: Future CAM systems must be co-designed with memory devices that balance density, endurance, retention, analog programmability, and read energy. Unlike 17 conventional RAM or CIM, many CAM workloads can benefit from high-resistance states, since massively parallel search favors low-current readout and reduced static power. Emerg-ing non-volatile devices with high endurance and precise analog programmability therefore offering a promising substrate for energy-efficient associative arrays. To overcome the area penalty of CAMs, monolithic 3D integration is a key frontier, with comparison logic in the silicon substrate and dense reference weights, defining the stored keys embedded in 3D stacked layers. 2. Architectural: Future CAM research should first aim to invent novel circuit and cell designs that maximize sensing gain while minimizing component count, area, and peripheral overhead. Second, large-scale sparse associative search for databases can be explored more deeply, motivated by the overlap between CAM-based retrieval, sparse attention, and hierarchical memory access in the brain. Third, future systems should increasingly develop application-specific CAM architectures, as prior work shows that tailoring the associative array to the workload can yield substantial gains in area, latency, energy, and reliability, exemplified in this perspective with the CAM and crossbar integration. 3. Emerging Application Primitives: Future research should expand CAM deployments beyond static retrieval toward dynamic, probabilistic, and real-time workloads. One promising direction is to use analog associative search as a transition engine for probabilistic or non-deterministic computing, where state transitions are selected not by exact lookup, but by similarity, uncertainty, or learned matching boundaries. This could provide a hardware-native route toward probabilistic CAM-based computing. Another important direction is the use of ultra-fast associative lookup in high-rate scientific workloads, such as real-time particle-track triggering in nuclear physics, where relevant patterns must be identified under strict latency and energy constraints. 4. Machine Learning with CAMs: Machine learning with CAMs remains a niche topic, partly because AI researchers rarely view CAMs as trainable hardware primitives. Future research should investigate efficient surrogate models and online learning methods that make CAMs easier to integrate into existing machine-learning pipelines. In parallel, in-hardware learning should be explored more deeply, especially forward-only or local learning algorithms that reduce the need for full backpropagation through associative memory arrays. 5. Translating Neuroscience into CAM Hardware Primitives: An open and long-term challenge is to translate the brain’s ability to retrieve, reorganize, consolidate, and forget information into practical associative hardware. Rather than mimicking biological wetware directly, future CAM research should abstract high-level principles such as sparse and hierarchical memory organization, context-dependent recall, surprise-triggered writes, and offline memory consolidation. This points toward dynamic, self-organizing CAM arrays that cluster related memories, prune rarely accessed data, store only novel inputs, and replay important patterns during idle phases to migrate information across an associative memory hierarchy.
