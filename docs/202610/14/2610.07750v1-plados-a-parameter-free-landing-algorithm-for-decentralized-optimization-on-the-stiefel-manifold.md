## 摘要
Stiefel 流形上的去中心化优化在机器学习和信号处理领域具有广泛应用。我们提出 PLADOS，一种用于 Stiefel 流形上去中心化优化的无参数着陆算法。每次迭代将局部随机梯度更新与通信图上的一次无回缩通信步骤相结合。我们通过针对纯惩罚方案的受限割线不等式，刻画了非凸 Stiefel 流形与一致性约束交集的一个关键类凸性质，从而保证流形一致性误差的局部收缩，且无需引入额外的待调参数。对于使用大小为 b 的独立局部批次的 n 个节点，我们证明，经过 K 次迭代后，PLADOS 相对于节点数实现了线性加速，其渐近收敛率为 O(σ/\sqrt{nbK}+(nξ^2)^{1/3}/K^{2/3})，其中 σ^2>0 为采样方差，ξ^2 用于量化梯度异质性。实验表明，该方法在所测试的步长和网络条件下均具有稳定性、时间效率，并且相对于节点数实现线性加速。

## Abstract
Decentralized optimization on the Stiefel manifold has broad applications in machine learning and signal processing. We propose PLADOS, a parameter-free landing algorithm for decentralized optimization on the Stiefel manifold. Each iteration combines local stochastic gradient updates with a single retraction-free communication step over the communication graph. A key convex-like property of the intersection of the nonconvex Stiefel manifold and consensus constraints is characterized through a restricted secant inequality for the penalty-only scheme, ensuring local contraction of the manifold consensus error without introducing additional parameters that require tuning. For $n$ nodes using independent local batches of size $b$, we prove that PLADOS achieves linear speedup with respect to the number of nodes with an asymptotic convergence rate of $O(σ/\sqrt{nbK}+(nξ^2)^{1/3}/K^{2/3})$ after $K$ iterations, where $σ^2>0$ is the sampling variance and $ξ^2$ quantifies gradient heterogeneity. Experiments demonstrate stability across tested stepsizes and networks, time efficiency, and linear speedup with respect to the number of nodes.
