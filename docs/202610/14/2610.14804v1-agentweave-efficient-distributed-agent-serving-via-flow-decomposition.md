## 摘要
智能体应用正演变为由大语言模型（LLM）调用和工具调用构成的工作流，这些调用被称为模块。现有的分布式智能体系统通常采用解耦式架构，将不同模块部署在不同设备上。尽管这种方式能够实现流水线并行，但模块间的延迟不均衡会引入严重的流水线气泡，从而限制吞吐量。一种自然的替代方案是聚合式架构，即在所有设备上共同部署全部模块，通过使每个设备持续处于活跃状态来消除流水线气泡。然而，这会带来请求阻塞问题：短请求被迫与同一批次中的长请求同步推进，而新到达的请求则必须等待当前整个批次完成完整工作流。为解决这一问题，我们提出了AgentWeave，一种基于聚合式架构的高效分布式智能体应用服务系统。其核心机制——流分解——在保持智能体语义的同时，将长智能体请求分解为细粒度执行单元，使短请求和新到达的请求能够避免被长时间运行的请求阻塞。作为补充，流自适应调度器能够动态权衡分解带来的吞吐量增益与其调度开销。在四个具有代表性的智能体应用上的实验表明，相较于最先进的基线方法，AgentWeave将吞吐量提升了1.81倍，将平均延迟降低了2.45倍，并将P90延迟降低了2.04倍。

## Abstract
Agent applications are evolving into workflows composed of large language model (LLM) calls and tool invocations, termed modules. Existing distributed agent systems typically adopt a disaggregated architecture, deploying different modules on separate devices. While this enables pipeline parallelism, imbalanced module latencies introduce severe pipeline bubbles that limit throughput. A natural alternative is an aggregated architecture that co-deploys all modules across all devices, eliminating bubbles by keeping every device continuously active. However, this introduces request blocking: short requests are forced to progress in lockstep with longer ones in the same batch, and newly arriving requests must wait until the entire ongoing batch completes the full workflow. To address this, we propose AgentWeave, an efficient distributed serving system for agent applications built on the aggregated architecture. Its core mechanism, flow decomposition, decomposes long agent requests into fine-grained execution units while preserving agent semantics, allowing short and newly arriving requests to proceed without being stalled by long-running ones. Complementing this, a flow-adaptive scheduler dynamically balances the throughput gains of decomposition against its scheduling overhead. Experiments across four representative agent applications demonstrate that AgentWeave improves throughput by 1.81x, reduces average latency by 2.45x, and reduces P90 latency by 2.04x over state-of-the-art baselines.
