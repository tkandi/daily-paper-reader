ABSTRACT 

In real-world scenarios, industrial processes can span multiple factories and goods are often produced at multiple sites, leading to a shared yet non-identical distribution of data across locations. To address this, we propose two fed-erated approaches for i) combining existing coresets ( Double Subsampling ) and ii) creating new coresets ( Federated Sub-sampling ) in a distributed anomaly detection setting. In particular, we adapt the memory bank based PatchCore algo-rithm to a federated setting, resulting in increased cold-start performance, resilience to domain- and sensor-shift, and re-silience to unreliable actor participation, a common problem in classical, network based federated learning strategies. 

Index Terms — Anomaly Detection, Federated Learning, Memory Bank, Coreset, Subsampling 

1. INTRODUCTION 

Distributed and small-lot production settings (e.g., molds production, aerospace components, contract electronics) gen-erally require few-shot capable methods for anomaly detec-tion due to the limited amount of available training samples as well as the cost and effort of data distribution between sites. Small-lot production suffers from poor cold-start per-formance, while in distributed settings a consistent detection model is a requirement at all sites to ensure product quality. While zero-shot models are gaining interest in anomaly de-tection and could potentially be used in such settings, they currently lack the depth and accuracy of detection systems utilizing a smaller but non-zero corpus of nominal training images. Combining data from federated production facilities offers access to a richer training corpus, potentially increasing model accuracy. This motivates the contributions of this paper as follows: We extend PatchCore [1] to harness the strengths of few-shot capable memory bank based approaches in a fed-erated setting by introducing two distinct approaches. We introduce i) Double Subsampling , a hierarchical approach to combining federated memory banks, which can utilize multi-ple existing local models to create a global anomaly detection model, and ii) Federated Subsampling , a federated approach for creating memory banks. Both approaches leverage the few-shot capability of PatchCore, improving cold-start per-formance, implicitly correcting for domain- and sensor-shift over multiple production sites. 

2. RELATED WORK Federated Learning leverages data across multiple actors to train a shared model. As each actor’s local data distribu-tion can differ from the aggregated global distribution, aver-aging locally trained model updates does not guarantee con-vergence towards the same optimum as centralized training [2–4]. This non-IID setting is particularly important in an in-dustrial anomaly detection context. The memory bank paradigm is inherently well suited to sidestep this aggregation problem, since it does not rely on gradient-based training and instead directly uses features from pre-trained extractors based on nominal training sam-ples. Roth et al. [1] proposed PatchCore, a state-of-the-art memory bank approach for practical industrial anomaly de-tection. The strengths of this approach are the few-shot possi-bility, the small inference model size, and the ability for rapid re-training. While other approaches [5–8] show competi-tive results, they utilize neural networks for inference, need extensive training times, or rely on a rich corpus of nom-inal training samples to achieve competitive performance. Chen et al. [9] first proposed the concept of employing fed-erated memory banks (FedDyMem). A global memory bank for inference is constructed by training a local network to project local features towards a global distribution. While FedDyMem combines the memory bank for easy inference with known federation strategies, the approach still utilizes training of a neural network as the core component for creat-ing the memory bank, leaving room for longer training runs and non-IID data drifts. To close this gap, we propose Feder-ated Subsampling and Double Subsampling for constructing federated memory banks based on few-shot capable methods, enabling multiple actors to jointly construct a shared coreset of nominal features under the few-shot cold-start constraint. The algorithm is feature-agnostic and only assumes the existence of a meaningful met-ric between feature vectors. 4. METHODS 

The proposed methods in this work, Double Subsampling and 

Federated Subsampling , depart from the traditional federated parametric training regime. Instead, they leverage the non-parametric memory bank paradigm. 

Double Subsampling In contrast to a traditional iterative approach, the proposed Double Subsampling method uses a hierarchical coreset subsampling process to combine exist-ing coresets. We assume that each actor owns a local coreset 

MC,i (see section 3). In practice, this is a reasonable assump-tion, as the feature extraction and inference steps are usually performed actor-side. For each actor, the local coreset MC,i 

is propagated to the server and aggregated into a single global memory bank MS = S MC,i . Each MC,i contains a distri-bution of the most informative and representative local fea-tures. The resulting union over all coresets MS can be seen as a global representation of the entire distributed data cor-pus. As a regularization step, and to improve computational performance, we perform coreset subsampling on MS at the server again, resulting in a final global coreset M ∗, which is propagated to all actors Ci.

Federated Subsampling More in line with existing fed-erated learning strategies, the proposed Federated Subsam-pling employs an iterative approach, where in each iteration, all actors calculate a potential candidate for the best vector to add to the global coreset M∗. The number of iterations performed in this approach equals the final number of vec-tors in the global memory bank, which is a problem-specific figure that can range from a percentage of the total amount of features to a fixed value. As a greedy iterative approxima-tion is used to select the next feature for the memory bank, we utilize the iterative properties of the coreset reduction pro-cess and established federated learning frameworks to con-struct a strategy to add features iteratively to a global coreset 

M∗. The candidate proposal for each actor works similarly to the coreset reduction process, where each actor proposes the vector with the largest distance to its nearest neighbor in 

MC,i . The proposed vectors vi (see Equation 1) and the cor-responding distances di = min y∈M C,i ∥vi − y∥2 to the near-est neighbors in MC,i are aggregated on the server per actor as V = {(v1, d 1), . . . , (vi, d i)}.On the server, the distances in each tuple are used to select the winning candidate, following the last step of the coreset reduction process. The feature part of the tuple is used for the coreset and is the object that is added to the global coreset 

M∗ as well as propagated to each actor’s coreset MC,i . This candidate-proposal and -selection process is repeated until no more feature vectors need to be added to the memory bank. As this approach is a distributed version of the greedy coreset subsampling process of PatchCore, we show (section 5) that the resulting M ∗ is equal to a locally created memory bank, created by the PatchCore algorithm. A strength of the proposed methodology is its compati-bility to the standard non-federated PatchCore method and memory bank based methods in general. Both proposed approaches act merely on the coreset subsampling part, effec-tively enabling the use of the standard inference and feature-extraction process. Inference is performed actor-side on the coresets propagated from the server but can theoretically be performed server-side, propagating only the anomaly-score back to the actor. Server-side inference could prove useful in scenarios with untrusted or potentially malicious actors contributing to a shared memory bank. 

5. EXPERIMENTS 

All experiments are conducted using the standard bench-mark dataset for structural anomalies, MVTec AD [12]. This dataset is comprised of 15 categories, covering 5,354 high-resolution images, with 73 different defect types. The meth-ods and experiments were implemented using PyTorch . ray 

was used for simulating multiple actors. The feature-extractor backbone used in the experiments is a WideResNet50 using 

layer-2 and layer-3 with adaptive average pooling, resulting in a 1000-dimensional locally aware patch feature. Following the idea of [10] and [13], we performed the coreset selec-tion process as explained in section 3 using dimensionality-reduced feature vectors of 100 dimensions. This dimension-ality reduction was performed with a randomly initialized linear projection. 

AUROC compared to Baseline PatchCore As our two proposed methods, Federated Subsampling and Double Sub-sampling , are extensions of the PatchCore algorithm, we com-pared the pixel- and image-level Area Under the Receiver Operating Characteristic (AUROC) score to validate the ac-curacy of the distributed extension compared to the original localized algorithm. As seen in Table 1, constructing core-sets from scratch using the Federated Subsampling approach results in equal scores across all categories compared to the original algorithm, indicating equally constructed coresets be-tween our approach and the baseline. However, the Dou-ble Subsampling approach yields similar, yet different perfor-mance, deviating slightly from the baseline depending on the category. This is likely an effect caused by the local subsam-pling step, rejecting local candidates that could improve the global memory bank and vice versa. We consequently focus the follow-up experiments on the Federated Subsampling .

Cold-start performance We setup a cold-start scenario to illustrate the performance increase gained through Federated Subsampling by participating as an actor towards constructing a shared coreset. Leveraging the larger available training cor-pus AUROC scores are increased, as shown in Figure 1. The fewer samples that are available locally, the more the data fed-eration benefits the quality of the global coreset. While in a single-sample training corpus per actor the image-level AU-ROC improves from 84 .2 to 89 .2, the improvement with 64 available samples per actor is marginal, going from 97 .1 to 

97 .4. This is an expected behavior as the quality of the global-and local-memory banks converge with larger training corpi. The results suggest that the Federated Subsampling approach is beneficial for cold-start problems, such as pilot series pro-duction or small-lot production. 

Non-IID adaptation Federated Subsampling can be use-ful when dealing with domain- and sensor-shifts in data. As-suming a distribution over domains and sensors exists across actors, the created global memory banks are robust against such effects. This is in contrast to traditional localized mem-ory bank based methods, which require re-buildling a stale memory bank with the new data distribution to avoid degra-dation in accuracy. We analyze whether using non-IID data from other actors aids an actor in recovering performance with fewer new im-

To investigate this effect, a set of parametrizable photometric transforms (Col-orJitter, brightness, contrast, saturation, hue, gaussian blur) is introduced, simulating differences in lighting and image cap-turing. The distribution shift and difference to other actors is achieved by assigning each actor its own randomly chosen transforms, while verifying that the mean embedding distance between two distributions is sufficiently large. The actor’s performance is then evaluated on the domain-shifted full test set with the new transforms applied. Five different memory banks are considered: (1) the stale bank, (2) the stale bank + K samples from the new distribution, (3) the stale bank + peers only, (4) the stale bank + K samples from the new distribution + peers, and (5) an oracle built from the actor’s full new-domain data. At image-level, using data from peers alone closes roughly half (extreme) to three quarters (severe) of the stale-to-oracle gap without the actor using any new samples. Federating on top of local adaptation improves per-formance most when the actor has little data and the benefit decreases as K grows. At pixel-level, federating only bene-fits the actor at K = 0 , indicating that peer embeddings aid detection but dilute localization. 

Unreliable actor participation Actors might join the construction process at any point in time or be unavailable for certain periods. We investigate the implications on Federated Subsampling under the unreliable availability of all actors in each round. We establish four scenarios: (baseline) - all actors are always available, unrealistic best-case; (random) - a random feature across all actors is selected per round, simulating actors joining and leaving randomly; (skewed) - a 

20% probability of failure per actor is assumed in each round, resulting in a skewed distribution, depicting a more realistic scenario; (worst) - only the worst feature is selected. While the baseline scenario is not always yielding the best result due to the greedy nature of the approach, its performance stays consistent across the increase of actors in the system. Meanwhile, scenarios with more exploration are more un-stable towards the number of actors in a system. Regardless of the strategy, the results indicate a more resilient behavior compared to other federated learning approaches.

6. CONCLUSION 

We propose two novel approaches for construction of mem-ory banks in federated settings. Double Subsampling allows for a federated usage of memory banks, consolidating multi-ple localized memory banks, providing similar results com-pared to a fully local model by assuming the contents of a memory bank are similar to features extracted from a dataset. While this approach can be applied on top of existing meth-ods, Federated Subsampling introduces a strategy to federate the construction process of a memory bank model, allowing for a guaranteed consistent global model. Experiments show the resilience to non-IID distribution and improved cold-start performance. Finally, the method proves resilient to non-deterministic actor behavior due to availability and timing. 7. ACKNOWLEDGEMENTS
