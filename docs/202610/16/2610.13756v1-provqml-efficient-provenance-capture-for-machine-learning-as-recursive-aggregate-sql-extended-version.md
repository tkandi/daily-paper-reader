## 摘要
将机器学习算法表示为分布式系统上的递归聚合 SQL 查询，能够实现大规模声明式数据分析；然而，现有系统均不支持可扩展的溯源捕获，而这对于机器学习的可解释性至关重要。我们提出 ProvQML，一个具备溯源感知能力的递归聚合 SQL 引擎，可在将机器学习算法作为递归聚合查询执行时，高效捕获细粒度溯源信息。我们捕获两类溯源信息：（i）局部溯源，记录在特定模型状态下每个训练实例对梯度计算的贡献；（ii）全局溯源，编码跨迭代过程中的模型参数更新序列。在广泛使用的机器学习数据集上进行的大量实验表明，我们的方法能够针对多种机器学习模型，高效捕获这两类溯源信息。

## Abstract
Expressing ML algorithms as recursive aggregate SQL queries over distributed systems enables large-scale declarative data analytics, yet no existing system supports scalable provenance capture, necessary for ML explainability. We present ProvQML, a provenance-aware recursive aggregate SQL engine that efficiently captures fine-grained provenance while evaluating ML algorithms as recursive aggregate queries. We capture two types of provenance: (i) local provenance that records the contribution of each training instance to gradient computation at a specific model state, and (ii) global provenance that encodes the sequence of model parameter updates across the iterations. Extensive experiments on widely used ML datasets demonstrate that our approach efficiently captures both provenance for various ML models over widely used ML datasets.
