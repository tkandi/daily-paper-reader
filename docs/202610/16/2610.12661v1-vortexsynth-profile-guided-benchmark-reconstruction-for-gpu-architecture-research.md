## 摘要
GPU 架构研究需要能够在新型设计上运行的代表性基准测试。然而，许多针对特定厂商优化的工作负载和库内核无法直接在研究型架构上运行，因为其实现为闭源，或依赖于目标架构不支持的编程模型。迁移现有内核需要人工投入，以调整其实现并验证其行为。这使得自动将工作负载迁移至目标平台成为一种需求。我们提出 VortexSynth，一个利用基于性能剖析引导的基准测试重建方法、从参考工作负载构建 GPU 基准测试的框架。该工作流通过性能剖析选择热点内核，在目标编程语言中合成实现，验证输出等价性，并利用转换后的代理实现测量性能剖析差异。所得的性能剖析特征差距被提供给智能体，以进行迭代优化。我们以机器人技术为应用领域，在开放指令集架构的通用 GPU Vortex 上评估了该方法。所有活跃内核对均通过了输出等价性检查，案例研究表明，迭代优化能够缩小性能剖析距离。

## Abstract
GPU architecture research requires representative benchmarks that can execute on new designs. However, many vendor-tailored workloads and library kernels cannot run directly on research architectures because their implementations are closed-source or rely on programming models unsupported by the target architecture. Migrating existing kernels requires manual effort to adapt their implementations and validate their behavior. This creates a need to automate workload migration to target platforms.   We present VortexSynth, a framework that uses profile-guided benchmark reconstruction to construct GPU benchmarks from reference workloads. Our workflow selects hot kernels through profiling, synthesizes implementations in the target programming language, verifies output equivalence, and measures profile differences using a translated proxy implementation. The resulting profile signature gap is supplied to an agent for iterative refinement. We evaluate the method on Vortex, an open-ISA GPGPU, using robotics as the application domain. All active kernel pairs pass both output-equivalence checks, and the case studies show that iterative refinement can reduce profile distance.
