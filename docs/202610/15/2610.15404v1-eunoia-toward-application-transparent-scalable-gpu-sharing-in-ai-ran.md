## 摘要
AI-RAN 范式通过在同一通用硬件上共置 AI 和 RAN 工作负载，使下一代蜂窝网络更具多功能性。尽管 GPU 是实现 AI-RAN 的一种很有前景的平台，但通用的并发 AI 应用会在 GPU 计算资源上干扰对时延敏感的 RAN。本文提出 Eunoia，一种动态实时 AI-RAN GPU 调度器，该调度器对 AI 应用和 RAN 工作负载均透明，并以 RAN 时隙为粒度运行。我们将 Eunoia 部署于 NVIDIA Aerial AI-RAN，并在空口 5G 专用网络和仿真的多小区网络上对其进行评估。结果表明，在包含 27 个小区的 AI-RAN 中，Eunoia 能够将 RAN 上行链路的 P99 时延保持在 3 ms 以下，同时相比其他对 RAN 安全的静态分区方法提供更高的 AI 性能。

## Abstract
The AI-RAN paradigm makes the next-generation cellular network more versatile by co-locating AI and RAN workloads on the same commodity hardware. While the GPU is a promising platform for AI-RAN realization, a generic concurrent AI application interferes with the latency-sensitive RAN on GPU compute resources. In this paper, we propose Eunoia, a dynamic real-time AI-RAN GPU scheduler that is transparent to both AI applications and the RAN workload and operates at the granularity level of the RAN slot. We deploy Eunoia onto NVIDIA Aerial AI-RAN and evaluate Eunoia on both an over-the-air 5G private network and an emulated multi-cell network. We demonstrate that in a 27-cell AI-RAN, Eunoia keeps the RAN uplink P99 latency under 3 ms while delivering higher AI performance than other RAN-safe static partitioning methods.
