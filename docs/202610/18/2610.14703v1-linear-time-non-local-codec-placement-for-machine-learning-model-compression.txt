# Linear-Time Non-Local Codec Placement for Machine Learning Model Compression 

Matteo Spallanzani Axelera AI Zürich, Switzerland 

matteo.spallanzani@axelera.ai 

## Abstract 

On-device inference imposes constraints on model storage and operand traffic and thus benefits from compressed operand representations, which mandate the use of encoding and decoding operators. However, naïve placement of codec opera-tors can cancel the operand traffic gains sought from compression. In this work, I present an algorithm to place codec operators into a source computational graph to make it compatible with target hardware. The edges of the graph are colored so that each induced subgraph is weakly connected and has a maximal node that both postdominates all subgraph inputs and dominates all subgraph outputs; this unique node —dubbed the absolute dominator —is the natural location to observe the traffic flowing through the subgraph and learn parametric codec operators. The algorithm’s time complexity is linear in the source graph’s size. With respect to naïve local codec placement, the algorithm reduces modeled operand traffic by 

24% –44% across four models, including 24% on SigLIP and 34% on SmolLM2. 

## 1 Rationale 

Machine learning (ML) model compression increases efficiency by representing operands (weights and features) with low-bitwidth data types. Compressing source models developed for general-purpose hardware for deployment on target hardware featuring one or more accelerators requires using data-type-changing operators. An example is the quantization of GPU-native models —where operands are represented as 32- or 16-bit floating-point (FP) numbers —into low-bitwidth data types —such as 8- or 4-bit integers (INT). The data-type-changing operators are usually lossy encoder-decoder ( codec ) operators. In regular programs, these new operators would break correctness. ML models are different in that they can use parametric lossy codecs and statistical algorithms to mitigate application accuracy degradations. These algorithms include distribution transformations [Xiao et al., 2023, Ashkboos et al., 2024], post-training quantization (PTQ) [Nagel et al., 2021], and quantization-aware training (QAT) [Nagel et al., 2021]. This codec abstraction encompasses the established case of element-wise linear quan-tization [Bengio et al., 2013, Esser et al., 2020], element-wise non-linear quantization [Zhou et al., 2017], block-wise quantization [Rouhani et al., 2023], and vector quantization [Zandieh et al., 2026]. Codec placement can range in complexity from local to non-local. The difference between local and non-local placement is best illustrated by an example. Consider a two-branch residual block with a matrix-matrix multiplication on each branch: a local rule quantizes the weight and feature inputs of each operator independently; a non-local rule quantizes the shared block input only once while still quantizing the weights independently. This example shows that to achieve operand traffic savings one must decide not only which operators use compressed representations, but also where encodings and decodings occur across operator boundaries. The decision whether to perform local or non-local placement informs the choice of the underlying representation:

Non-local placement requires that eager representations be traced into graph representations. Existing ML model compression frameworks [Roesch et al., 2019, Xilinx, 2019, Lattner et al., 2021, Or et al., 2025, NVIDIA, 2026, Nachin et al., 2026] implement a variety of placement strategies. Naïve strategies use local rules to achieve local placement. More advanced strategies —such as TensorRT’s Q/DQ propagation —use local commutation rules to grow low-precision subgraphs after learning; these strategies can reconcile codecs across operator boundaries only when they have equal parameters, and thus rely on codec parameter sharing specifications (i.e., non-local rules) defined ahead of learning to prevent learning-time parameter divergence. Other advanced strategies use hardware-specific subgraph patterns (i.e., non-local rules) to achieve non-local placement. This work presents an algorithm that 1) derives non-local codec placement ahead of learning from per-operator local commutation rules, 2) guarantees structural correctness, and 3) has linear-time complexity. The non-local rules in codec parameter sharing specifications or pattern catalogs specify codec intent by context, which might depend on both the model to be compressed and target hardware. In contrast, the local commutation rules consumed by this algorithm specify codec intent per operator —for each operator, a commutation rule declares which of its ports a codec can commute through —and they can be reused across every context in which an operator appears. The local commutation rules are specific to the codec class and parametrization; this constraint is shared by existing non-local rules. The linear-time complexity makes this algorithm particularly suited to deployment toolchains, where graphs might be adapted repeatedly under different compression policies.

The third step creates the subgraphs spanned by same-color edges and identifies their absolute dom-inators. To identify a subgraph’s absolute dominator, the step traverses its nodes in topological order while keeping track of each path’s last edges in a frontier; whenever a node is traversed whose set of in-edges is a superset of the frontier, that node is added to a set of candidates; the last element of this set is the absolute dominator . The search does not need a dominator tree. Same-color subgraphs are best interpreted as subprograms in which, if a codec were materialized on each edge, the function realized by the subgraph would be preserved due to codec idempotence:

Assume that each path in the bundle passes through a non-empty set of shared “bottleneck” nodes: sitting at any such node allows one to observe all the traffic passing through every input and output. The last node is preferred because the data layout and distribution at that point in the subgraph are closer to those expected by consumer operators. The fourth step merges adjacent subgraphs when they have compatible colors and the merge preserves the absolute dominance property.

## 3 Evaluation 

The measurements are taken with respect to the following cost model: storage sums the size of all weights; traffic sums the size of every weight and feature operand read by every operator —an object read by multiple operators is counted once per consumer; codec items count the array items cross-ing materialized codecs. The cost model does not account for device-specific memory-hierarchy (caching) or datapath (fusion) optimizations. The cost model is also independent of the codec-learning algorithm and application accuracy, which lie outside this work’s scope. I evaluate the algorithm assuming element-wise linear quantization on four models —ShuffleNetV2, U-Net, SigLIP, and SmolLM2 [Ronneberger et al., 2015, Ma et al., 2018, Zhai et al., 2023, Ben Allal et al., 2025] —and under four compression policies: Z is the 32-bit floating-point baseline; Y uses 8-bit integer matrix-matrix multiplications; X also routes data (concatenate, split) as 8-bit integers; W uses 8-bit integers whenever allowed by the hardware. Table 1 shows that storage savings are not affected by the aggressiveness of the compression policy: compressing the weight inputs of matrix-matrix multiplications yields a 75% saving that is consistent across all compression policies. As a simple decomposition, subtracting the storage reduction once from Z suggests that feature compression reduces modeled traffic by approximately 18% on ShuffleNetV2, 11% on U-Net, and 2% on SmolLM2, while increasing it by approximately 13% on SigLIP. ## 4 Discussion 

This work presents a linear-time algorithm that achieves non-local placement of codec operators from local, per-operator commutation rules and edge-partitions the graph into weakly connected subgraphs, each with an absolute dominator. The algorithm provides correctness guarantees assum-ing the correctness of the supplied local codec commutation rules; it does not verify these rules. The coalescence step greedily attempts to merge adjacent subgraphs while preserving the absolute dominance property; it reduces the number of subgraphs but is not claimed to minimize it. The evaluation shows that non-local placement reduces operand traffic across all four architectures, even though the policy comparison shows that feature compression itself is not beneficial for ev-ery model. Latency measurements for ShuffleNetV2 align with the predictions of the cost model —with the caveat that these figures are exploratory and not part of a broad measurement campaign. The learning of parametric codecs at absolute dominators (calibration, fine-tuning) and application accuracy evaluations are downstream steps, outside this work’s scope. A reflection on the nature of codec commutation rules provides insight into the trade-offs between local and non-local rules for non-local codec placement. In its simplest form, the semantics attached to each edge is a triple of a unique identifier, a source data type, and a target data type; this definition does not capture whether the parameters of a codec are derived from the parameters of other codecs —e.g., a dequantization scale obtained as the product of a weight quantization scale and a feature quantization scale, or the block structure of a block-quantized tensor obtained by concatenating two block-quantized tensors. The simplicity of the algorithm is not inherent, but follows directly from the simplicity of the commutation rules: because a commutation rule simply declares that certain ports share a semantics, assignment reduces to enforcing an equivalence relation over edges, and it is this equivalence that makes non-local placement derivable from local rules in linear time. Enriching the semantics to include codec parameter transformations would change the assignment problem from locally enforcing an equivalence relationship to non-locally composing transformation rules, poten-tially reintroducing the reconciliation cost that parameter sharing specifications and pattern catalogs pay through enumeration and arbitration. Determining which classes of transformation preserve the weak connectedness, absolute dominance, and linear-time guarantees is an open question.
