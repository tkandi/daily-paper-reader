## 摘要
设备端推理对模型存储和操作数传输提出了约束，因此可受益于压缩的操作数表示；而这要求使用编码与解码算子。然而，朴素的编解码器算子放置方式可能会抵消压缩旨在实现的操作数传输收益。本文提出了一种算法，用于将编解码器算子置入源计算图中，使其与目标硬件兼容。该算法对图的边进行着色，使得每个导出子图均为弱连通图，并具有一个极大节点：该节点后支配所有子图输入，且支配所有子图输出。这个唯一节点被称为“绝对支配节点”（absolute dominator），是观测流经子图的传输流量并学习参数化编解码器算子的自然位置。该算法的时间复杂度与源图规模呈线性关系。相较于朴素的局部编解码器放置方法，该算法在四个模型上将建模的操作数传输量降低了24%至44%，其中在 SigLIP 上降低24%，在 SmolLM2 上降低34%。

## Abstract
On-device inference imposes constraints on model storage and operand traffic and thus benefits from compressed operand representations, which mandate the use of encoding and decoding operators. However, naïve placement of codec operators can cancel the operand traffic gains sought from compression. In this work, I present an algorithm to place codec operators into a source computational graph to make it compatible with target hardware. The edges of the graph are colored so that each induced subgraph is weakly connected and has a maximal node that both postdominates all subgraph inputs and dominates all subgraph outputs; this unique node - dubbed the $\textit{absolute dominator}$ - is the natural location to observe the traffic flowing through the subgraph and learn parametric codec operators. The algorithm's time complexity is linear in the source graph's size. With respect to naïve local codec placement, the algorithm reduces modeled operand traffic by $24\%$-$44\%$ across four models, including $24\%$ on SigLIP and $34\%$ on SmolLM2.
