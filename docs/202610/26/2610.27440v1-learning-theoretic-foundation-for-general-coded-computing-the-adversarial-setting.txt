# Learning-Theoretic Foundation for General Coded Computing: The Adversarial Setting 

Parsa Moradi, Hanzaleh Akbarinodehi, and Mohammad Ali Maddah-Ali 

Abstract 

Adversarial workers pose a severe challenge in distributed computing systems by returning corrupted outputs that can substantially distort the recovered computations. Coded computing addresses this threat by introducing redundancy across worker assignments. Existing exact and approximate coded-computing methods typically handle adversarial outputs by explicitly locating and correcting or removing erroneous evaluations, which adds significant computational overhead at the master node. Moreover, existing analyses do not characterize how the recovery error scales with the number of workers and the adversarial budget. In this paper, we develop an adversarially robust extension of general coded computing ( GCC ), a learning-theoretic approximate coded-computing framework that designs the encoder and decoder by minimizing an upper bound on the end-to-end recovery error. Rather than identifying corrupted workers, the proposed method uses smoothness regularization to limit the influence of their outputs. The resulting encoder and decoder can be implemented using smoothing splines with linear master-side complexity. We derive a non-asymptotic bound on the worst-case end-to-end approximation error by decomposing it into three components: (1) the encoder approximation error, (2) the decoder reconstruction error under fully honest results, and (3) the adversarial perturbation error. For maximum of q ≥ 1

adversarial workers among N workers results in a worst-case error of order O(( q/N )6/5) with appropriate selection of smoothness parameter, demonstrating that the approximation error vanishes asymptotically whenever the number of adversaries grows sublinearly with the network size. Experiments on scalar computation and neural-network inference are consistent with the predicted convergence behavior. 

Index Terms 

Adversarial workers, approximate coded computing, distributed computing, general coded computing, reproducing kernel Hilbert space, smoothing spline. 

I. I NTRODUCTION 

The growing scale of data-intensive applications and computationally demanding machine-learning (ML) models has made distributed computation central to modern computing systems [1]. Such systems commonly operate under a master–worker architecture , in which a central master node assigns computational tasks to a collection of worker nodes . Each worker node performs its assigned computation and returns the result to the master node, which

aggregates the worker outputs to recover the desired function evaluations. By executing these tasks in parallel, the system can substantially reduce the computation time incurred at the master node. This benefit, however, comes with a reliability challenge: some workers may fail to return their results (known as straggler worker), while others may return incorrect values because of faults or malicious behavior (known as adversarial worker). These two forms of unreliability are fundamentally different. A straggler removes an observation, whereas an adversarial worker introduces a corrupted observation that may be coordinated with other corruptions and deliberately chosen to distort the final estimate. The master node must therefore reconstruct the desired function values without knowing which worker outputs, if any, are corrupted. Coded computing addresses worker unreliability by introducing redundancy across the assigned computations. The master node encodes the original inputs into some coded inputs and send each coded inputs to one worker nodes. Next, each worker node apply the target function on its assigned coded input and return the results to the master node. Finally, the master node reconstructs the desired computations from the worker outputs [2]–[8] even though some of them are missing or incorrect. For polynomial computations, Lagrange Coded Computing (LCC) achieves exact recovery while simultaneously providing resilience against stragglers and robustness against adversarial workers whenever the number of worker nodes exceeds a prescribed recovery threshold [4]. This threshold is determined by the degree of the target polynomial computation as well as the maximum numbers of straggling and adversarial nodes. However, LCC is originally formulated over finite fields and does not scale well with the input batch size due to numerical overflow and the severe ill-conditioning of high-degree polynomial interpolation [9], [10]. To address this limitation, Analog Lagrange Coded Computing (ALCC) extends LCC to infinite fields (the analog domain), preserving straggler resilience and dataset privacy [11]. Approximate coded computing extends coded computation to a broader class of functions by allowing approximate recovery. Berrut approximated coded computing ( BACC ) uses barycentric rational interpolation to approximate general nonlinear computations from the non-straggler worker outputs [9]. More recently, the learning-theoretic general coded computing ( GCC ) framework designs the encoder and decoder by deriving and minimizing an upper bound on the average end-to-end approximation error [12]. Although GCC provides an efficient scheme that outperforms BACC with a faster convergence rate and provably mitigates the effect of stragglers, its robustness against adversarial workers remains unexplored. Conversely, adversarial robustness has been studied within the Berrut framework. ApproxIFER combines rational interpolation with an algebraic error-location algorithm inspired by Berlekamp–Welch decoding to provide Byzantine-robust distributed inference [13]. However, these approaches address adversarial corruption through explicit error-location and correction procedures prior to reconstructing the desired outputs, which imposes substantial computational overhead at the master node. Furthermore, none of these works investigates how the approximation error behaves as the number of workers increases for a given adversarial budget, nor do they establish fundamental limits on the adversarial budget required for the approximation error to vanish asymptotically. To address these gaps, we investigate the adversarial robustness of the GCC framework from a complementary perspective: rather than explicitly locating and discarding adversarial workers, we mitigate their influence by inducing

smoothness in the encoding and decoding procedures. Building upon the GCC architecture, the proposed method utilizes smooth functions to distribute computations and reconstruct the desired outputs. The decoder aggregates all returned outputs and bounds the impact of corrupted values via smoothness regularization. While the regularization parameters can be calibrated to a known adversarial budget, the framework operates without prior knowledge of either the adversaries’ identities or their specific corruptions. Crucially, we establish that with an appropriately tuned smoothness regularization, the end-to-end approximation error converges to zero as the total number of workers increases, provided the number of adversarial workers grows sub-linearly with the network size. Our main contributions are summarized as follows: 1) Adversarial GCC Framework: We propose an adversarially robust GCC scheme for general high-dimensional computations that operates reliably in the presence of adversarial workers. We derive an upper bound on the end-to-end approximation error and decompose it into three components: (i) the encoder approximation error, (ii) the decoder reconstruction error in a fully honest setting (referred to as the clean approximation error ), and (iii) the perturbation caused by adversarial workers. This decomposition explicitly reveals how the smoothness of the encoder and decoder governs the robustness of the overall scheme. 2) Finite-Sample Guarantees and Convergence Rates: We derive a non-asymptotic upper bound on the worst-case mean-squared approximation error. This bound captures the fundamental trade-off introduced by decoder regularization: stronger smoothing reduces the influence of adversarial outputs but increases the clean approximation error. Balancing these two effects reveals that for a maximum of q ≥ 1 adversarial workers out of N total workers, the decoder smoothing parameter should scale as (q/N )8/5. With this tuning, the proposed scheme achieves an end-to-end error rate of O(( q/N )6/5), demonstrating that the worst-case approximation error converges to zero whenever the number of adversarial workers grows sub-linearly with the total number of workers. 3) Efficient Implementation: We show that both the encoder and decoder can be implemented using vector-valued cubic smoothing splines. Because their coefficients can be computed by solving banded linear systems, the master-side encoding and decoding costs scale linearly with both the input batch size and the total number of workers. Notably, this computational efficiency is achieved without requiring a separate adversarial detection or error-location subroutine. 4) Empirical Evaluation: We evaluate the proposed scheme on both scalar nonlinear computations and high-dimensional neural network inference. The experiments illustrate the predicted convergence behavior under adversarial attacks and confirm that the observed error decay aligns with our theoretical guarantees. The remainder of the paper is organized as follows. Section II introduces the problem formulation. Section III reviews the necessary mathematical preliminaries regarding Sobolev spaces, reproducing kernels, and smoothing splines. Section IV develops the proposed encoding and decoding procedures, establishes their error and convergence guarantees, analyzes the computational complexity. The proofs of the main theorems and corollaries are collected in Section V, and Section VI presents the experiments result.

B. Computational Complexity 

The computational complexity of the encoder and decoder constructions closely follows the analysis developed for the straggler setting in [12]. We therefore summarize the main results and highlight the difference introduced by the adversarial model. For the nonlinear encoder in (48), the finite-dimensional kernel coefficients can be computed using an iterative optimization method such as limited-memory Broyden–Fletcher–Goldfarb–Shanno (L-BFGS) [25]. For L-BFGC solver, If the solver performs I iterations, constructing the encoder and evaluating it at the N decoder design points require 

O IK 2d + N Kd  (56) operations. In contrast, the efficient encoder in (53) is a vector-valued cubic smoothing spline. Using a B-spline implementation with a banded linear system, it can be constructed and evaluated at the decoder design points in 

O (K + N )d (57) operations. The decoder in (39) has the same smoothing-spline structure. Unlike the straggler setting, all N worker nodes return their results, and hence the decoder is constructed using all N received outputs. Constructing the decoder and evaluating it at the K encoder design points require 

O (N + K)m (58) operations. Consequently, with the efficient encoder, the total master-side computational complexity of the adversarial 

GCC scheme is 

O (K + N )d + O (N + K)m. (59) In the common regime N ≥ K, this reduces to O N (d + m).

1) Comparison with Existing Schemes: We compare the computational complexity of different coded computing schemes at the master node, excluding worker-side evaluations of the target function. Lagrange Coded Computing (LCC) relies on polynomial interpolation and fast multipoint evaluation [4], [26], yielding encoding and decoding complexities of O(N log 2 K log log K · d) and O(N log 2 N log log N · m),respectively. In the presence of adversarial workers, LCC requires an explicit error-localization step to identify corrupted outputs. By leveraging sub-quadratic decoding routines for Reed–Solomon codes [27], [28], locating these errors incurs an additional complexity of O(q log 2 q log log q · m). Consequently, in addition to the overhead of error localization, LCC exhibits superlinear computational complexity with respect to the number of worker nodes N .Overall, for an input batch size K and at most q ≤ N adversaries, the total computational complexity at the master node is 

O N log 2 K log log K · d + O N log 2 N log log N · m + O q log 2 q log log q · m

= O N log 2 K log log K · d + N log 2 N log log N · m . (60)

Berrut Approximated Coded Computing (BACC) relies on barycentric rational interpolation [9], where direct evaluation yields encoding and decoding complexities of O(KN d ) and O(KN m ), respectively. Because BACC alone cannot identify corrupted worker outputs, ApproxIFER [13] extends it to the adversarial setting by adapting the Berlekamp–Welch approach [28] to rational interpolation. Specifically, before performing the final rational reconstruction, ApproxIFER constructs candidate error-locator functions by solving linear systems of size O(N )

across the m output coordinates and combining the coordinatewise estimates to filter out suspected adversarial reports. Although [13] does not explicitly analyze the asymptotic cost of this error-localization step, solving these 

O(N )-dimensional linear systems requires O(mN 3) operations under standard dense solvers. In contrast, our proposed GCC framework requires only O(( K + N )d) and O(( K + N )m) arithmetic operations for encoding and decoding, respectively, yielding a total master-node complexity of 

O(( K + N )( d + m)) . (61) Compared with BACC-based schemes, GCC reduces the multiplicative O(KN ) dependence on the input batch size K and worker count N to a purely additive O(K + N ) scaling. Furthermore, unlike LCC, Robust ALCC, ApproxIFER, and RBACC, GCC mitigates corrupted worker reports inherently through spline regularization at the decoder, completely eliminating the need for dedicated error-detection or error-localization stages. Consequently, the computational complexity of GCC remains strictly linear in K + N and is entirely independent of the adversarial budget q.

Under the scaling in (121), Corollary 2 gives Jadv = O(N − 65 (1 −θ)). Therefore, the predicted slope in a log-log plot of the approximation error versus N is − 65 (1 − θ). As expected, increasing θ slows the convergence because the adversarial population grows more rapidly with N .VII. C ONCLUSION AND FUTURE DIRECTIONS 

In this paper, we introduced an adversarially robust framework for general coded computing ( GCC ) that mitigates the impact of malicious worker nodes through smoothness regularization rather than explicit error localization. By distributing computations via a smooth encoder and aggregating all returned outputs with a regularized decoder, we established a non-asymptotic worst-case error bound. This theoretical analysis proves that our proposed spline-based scheme achieves linear master-side complexity and guarantees a vanishing approximation error whenever the adversarial population grows sublinearly with the total number of workers. Several open questions and directions remain for future investigation. First, our current design assumes the adversarial budget is known a priori in order to tune the optimal smoothing parameters. Developing adaptive procedures capable of estimating the effective corruption level directly from the received outputs would significantly  

> October 21, 2026 DRAFT 27

enhance the framework’s practical applicability. Second, future work should address the simultaneous presence of stragglers and adversarial workers, as missing observations and corrupted outputs distort the regularized decoder via fundamentally different mechanisms. Finally, establishing a matching minimax lower bound for the O(( q/N )6/5)

convergence rate would clarify whether our achievable exponent is strictly optimal, or if exploring higher-order regularization penalties and alternative reproducing kernels could yield sharper convergence rates. ACKNOWLEDGMENT
