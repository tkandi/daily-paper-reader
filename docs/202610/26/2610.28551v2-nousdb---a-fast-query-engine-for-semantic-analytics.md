## 摘要
语义数据分析系统将由人工智能驱动的算子集成到查询管道中，从而支持对结构化和非结构化数据进行声明式查询。然而，现有系统依赖逐元组的模型调用、临时性的算子设计，并且缺乏系统化的成本模型，导致其可扩展性较差且优化能力有限。我们提出了 NousDB：一个构建于 Apache DataFusion[22] 之上的高性能语义分析引擎。通过 NousDB，我们提出了一种扩展关系代数，其中包含三个语义算子及其形式化代数性质，从而支持系统化的查询重写和跨算子优化。我们进一步提出了一种基于词元的成本模型，该模型利用等深度词元直方图，在上下文窗口约束下优化批处理大小，并为安全批处理提供统计保证。实验表明，NousDB 在本地和企业级大语言模型上均可实现最高 86 倍的加速，同时在词元效率和准确性方面领先于主要竞争系统。这些优势还可扩展至由语义算子增强的复杂 JOB 和 Stack 工作负载，同时支持传统分析与语义分析。

## Abstract
Semantic data analytics systems integrate AI-powered operators into query pipelines, enabling declarative queries over structured and unstructured data. However, existing systems rely on per-tuple model invocations, ad hoc operator designs, and lack principled cost models, resulting in poor scalability and limited optimization. We present NousDB, a high-performance semantic analytics engine built on Apache DataFusion[22]. Through NousDB we propose an extended relational algebra with three semantic operators and formal algebraic properties that enable principled query rewriting and cross-operator optimization. We further propose a token-based cost model using equi-depth token histograms to optimize batch sizing under context-window constraints and provide statistical guarantees for safe batching. Experiments show that NousDB achieves up to x86 speedups with both local and enterprise LLMs, while leading competitors in token efficiency and accuracy. These gains extend to complex JOB and Stack workloads augmented with semantic operators, supporting both traditional and semantic analytics.
