## 摘要
本文研究一种分布式估计系统，其中边缘节点将平均特征传输至中心节点以进行参数估计。当中心节点拥有辅助侧信息时，会出现一个关键挑战：如何设计局部提取器，使其能够对任意下游任务均具有通用最优性，同时避免与侧信息冗余。为解决该问题，我们对联合函数空间进行正交分解，并证明在弱依赖情形下，典型依赖核的条件加性分量的模态分解能够产生最优的、与任务无关的特征。我们构建了一种分布式嵌套 H-score 来学习该分解，并表明，在特征预算受限时，相对于最佳任务特定特征的均方误差（MSE）差距仅由任务与被舍弃的、信息量最少的模态之间的对齐程度决定；一旦预算充足，对于每个平方可积任务，该差距在主导阶上均趋于零。

## Abstract
This paper considers a distributed estimation system where edge nodes transmit averaged features to a center node for parameter estimation. A key challenge arises when the center node possesses auxiliary side information: how to design local extractors that are universally optimal for any downstream task, while avoiding redundancy with the side information. To tackle this problem, we orthogonally decompose the joint function space and demonstrate in the weak-dependence regime that the modal decomposition of the canonical dependence kernel's conditional-additive component yields optimal, task-independent features. We construct a distributed nested H-score to learn this decomposition and show that, under a limited feature budget, the mean-squared error (MSE) gap to the best task-specific features is determined solely by the task's alignment with the discarded, least informative modes, and vanishes to leading order for every square-integrable task once the budget is sufficient.
