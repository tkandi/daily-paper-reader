ABSTRACT
Local learning algorithms can reshape resource requirements of artificial intelli-
gence. The memory bottleneck of standard end-to-end backpropagation lies in the
need to store all network activations until the loss gradient has been propagated
back through. Local learning avoids this, but typically at a cost in accuracy. We
study how to achieve accurate and memory efficient local learning in transform-
ers. For each transformer block, we train a local proxy network to predict the
global network output via distillation. Gradients can be independently propagated
through this local proxy while estimating well the backpropagation gradients. In
theory, this approach is exact for deep linear networks; in non-linear residual
models, the gradient error can be bounded when using the appropriate residual
proxy. We verify this numerically and demonstrate that optimizing the distillation
loss improves gradient estimation. Evaluating the performance of proxy prop-
agation on CIFAR-100 in vision transformers, we find that it achieves a better
accuracy/memory trade-off compared to other local algorithms. Finally, we show
that the method is further relevant for fine-tuning large language models on a small
memory budget. Our method trains faster and achieves higher performance than
memory-efficient zeroth-order learning algorithms with comparable memory cost.

INTRODUCTION
Conventionally, intelligence emerges in neural network models from end-to-end training with back-
propagation (Rumelhart et al., 1986). By design, backpropagation induces a backward locking prob-
lem (Jaderberg et al., 2017). A forward pass first computes the network activations from inputs to
outputs and then the backward pass propagates gradients in reverse order. In the meantime, network
activations need to be stored, increasing memory requirements with network depth. The large mem-
ory consumption is a major manufacturing cost and increases the energy consumption of training
datacenters (Gholami et al., 2024). When training large language models (LLMs) under a limited
memory budget, the network depth and sequence length that fit in memory therefore constrain the
range of tasks and the reasoning capability of the model.
Historically inspired by neuroscience research (Hebb, 1949; Markram et al., 2011; Gerstner et al.,
2018), local learning is one way of avoiding the backward locking problem. Since the brain ap-
pears to be a distributed network without a precise backward gradient communication pathway, it
is natural to suppose that biological sub-networks mainly learn from their immediate inputs and in-
ternal representations (Lillicrap et al., 2020). Yet few local learning algorithms have been scaled to
transformers, and attempts so far have had limited success (Filipovich et al., 2022). Most of these
algorithms were not designed to approximate the backpropagated gradient, so they struggle in deep
architectures; on top of this, those designed for biological plausibility often come with an increase
in training time. Within the scope of local learning, we seek an alternative to backpropagation that
is mathematically grounded and memory efficient without compromising training time.
Towards this goal, we define locality by partitioning a large transformer into blocks, with the gradient
computation in each block decoupled in the sense of Jaderberg et al. (2017): block parameters are

updates are fully independent, we say that the training algorithm is “unlocked”, making possible an
efficient form of model parallelism (Belilovsky et al., 2020). Here, we follow a principled approach
to estimate global gradients locally. To each block we equip a local proxy network with the objective
of predicting the global network output via distillation. Gradients of each block are then computed
with local backpropagation through the proxy instead of the downstream blocks. This way, proxy
propagation (ProxyProp) offers theoretical insights that translate into a practical algorithm:
• Theory: ProxyProp is an approximation of the global backpropagation. Despite the local-
ity and the simplicity of the prediction objective, a linear proxy implicitly estimates the
expected network Jacobian, and is therefore exact in deep linear networks.
• Theory: For non-linear residual networks, when the proxy follows a residual parameter-
ization, the local gradients are exact at initialization and can achieve a bounded gradient
estimation error when the skip connections of the network are dominating.
• Simulation: For supervised classification in vision transformers (ViT), across various net-
work partitionings, ProxyProp offers a better trade-off between memory and accuracy over
other local algorithms.
• Simulation: ProxyProp enables memory-efficient fine-tuning of LLMs, achieving higher
performance than zeroth-order optimization techniques (MeZO) at comparable memory
cost (even when MeZO uses 8x more compute time).

REVIEW: STATE OF THE ART
The “local learning” terminology has been defined with different aims in different contexts (see
Bredenberg et al. (2023) for a formal review). In bio-inspired computing, it is a constraint for
bio-plausible learning circuitry. This line of research originated from the observation that back-
propagation requires a backward circuit with symmetric feedback weights, for which there is no
anatomical evidence (Lillicrap et al., 2020). Different lines of work have relaxed this requirement
(Lillicrap et al., 2016; Akrout et al., 2019; Max et al., 2024; Nøkland, 2016), or sought compatibility
with Hebbian learning or predictive coding (Whittington & Bogacz, 2017; Scellier & Bengio, 2017;
Halvagal & Zenke, 2023; Illing et al., 2021). All these algorithms formalize how to replace back-
propagation through the network hierarchy in space, which is complementary to the replacement
of the backpropagation of information through time (Bellec et al., 2020; Murray, 2019). Together,

these algorithms were foundational in bringing local learning theory to deep networks and have
inspired circuitry for learning in physical systems (Momeni et al., 2023), photonics (Wang et al.,
2026), analog hardware (Pehle et al., 2022) and digital ASIC technology (Su & Indiveri, 2025).
We focus in particular on decoupling the stack of network layers into L gradient-isolated blocks,
where each block learns locally. This can be achieved by stopping the gradient propagation across
blocks and optimizing each network block with a local loss, either being supervised
(Belilovsky et al., 2019; Nøkland & Eidnes, 2019; Frenkel et al., 2021; Shing et al., 2026) or self-
supervised (L¨owe et al., 2019; Illing et al., 2021; Hinton, 2022; Halvagal & Zenke, 2023; Siddiqui
et al., 2024; Chen et al., 2025). Such methods have also been applied to finetuning pretrained models
(Key et al., 2023; Gelbard et al., 2026). Although local losses work relatively well in practice, it is
not understood how the stack of decoupled blocks builds a hierarchy of representations (see Delrocq
et al. (2026); Korchinski et al. (2026) for some analyses).

compounding errors of the auxiliary networks make it numerically challenging.

ACCURACY/MEMORY TRADE-OFF IN TRANSFORMERS
Studies in vision transformers. To test empirically if the theoretical consistency of the proxy
gradient translates to training transformers, we first implement a 12-layer ViT (Dosovitskiy et al.,
2021) with embedding dimension d = 128 on CIFAR-100. The network is partitioned into L = 3,
6, or 12 blocks, the three cases being denoted 3 × 4, 6 × 2, and 12 × 1 respectively to represent
the number of layers per block. Gradients are computed either with ProxyProp or alternative local
learning algorithms. ProxyProp parameterizes a proxy for each block as a small transformer of
lower dimension d = 64. ProxyProp (3 × 4) achieves performance close to backpropagation while
reducing the VRAM requirements by 62% (Figure 1B).
To justify the design choices of the proxies, we implement ProxyProp variants and compare their
classification performance (Table 1). The simplest variant is when the proxy is reduced to identity
(the error gradient ∂L/∂zL is applied at every layer without transformations). Despite its simplicity,
it outperforms local learning algorithms that use random fixed matrices to train the blocks (see
DFA and DRTP in Table 1). This observation supports the advantage of leveraging the residual
structure when estimating local gradients (Remark 3.3 and Proposition 3.4). Consistent with our
measurements on gradient alignment, non-linear transformer proxies perform better than linear ones.
Then, we examine if the simple proxy distillation objective could be replaced with loss functions that
more explicitly target the gradient. We consider the DNI gradient bootstrapping loss from Jaderberg
et al. (2017). Following their method, we train an auxiliary MLP to estimate a gradient bootstrapped
recursively from the auxiliary network of the next layer: with our ViT architecture this method is
not stable. Instead, we use ProxyProp but replace the distillation loss (Equation 2) with the DNI
loss that explicitly estimates the global gradient. Despite the increase in memory from the second-
order derivatives, it does not bring any significant improvement over our simpler distillation loss
(see Table 1). This empirical finding supports, along with Proposition 3.1 and Corollary3.2, that
proxy distillation is a simple and efficient way to align the local gradients with the global gradients.
We measured for all methods the VRAM occupied in the GPU for the various training algorithms.
Given a relatively large batch size, the memory consumption is dominated by the storage of the
network activations to illustrate the benefits of the algorithm. By choosing the number of layers for
each block in the network, we can navigate the trade-off between network performance and memory
consumption (either 3, 6, or 12 blocks). While ProxyProp pays a small storage to propagate gradients
through the proxy, it sits on the Pareto front of the accuracy/memory trade-off (Figure 1B).

A popular method to almost entirely eliminate the storage of the activations is to estimate gradients
with repeated forward passes. These methods are often referred to as zeroth-order optimization
techniques (e.g. MeZO, Malladi et al. (2023); Tan et al. (2025)); they are cheap in memory, but
their noisy gradient estimates can lead to slow convergence and increase the number of required
optimization steps. We show below that ProxyProp offers a practical alternative.
First we demonstrate that ProxyProp is able to fine-tune LLMs. We choose popular datasets and
models with existing reference baselines for MeZO and backpropagation, then we fine-tune language
models OPT-13B (Zhang et al., 2022) and LLaMA-3.2-3B (Dubey et al., 2024) on three datasets
(1000 examples each): SST2, WIC, and SQuAD (Socher et al., 2013; Wang et al., 2019; Rajpurkar
et al., 2016). We split the entire model into either 7 or 8 blocks and use proxies of dimension 64
or 80 depending on the model (details in Appendix C). ProxyProp approaches the performance of
backpropagation across the 3 tasks and 2 architectures, and also achieves higher performance than
the MeZO results reported by Malladi et al. (2023); Tan et al. (2025) (Figure 4A, 4C). We also
confirm that alternative local algorithms struggle to achieve a comparable performance on these
fine-tuning benchmarks (we tested ProxyProp without the residual parameterization and a block-
wise local-loss baseline).
Our experiments show that ProxyProp uses resources efficiently. The backpropagation baseline is
implemented with the standard HuggingFace Trainer. Towards a fairer comparison, we inherit the
trainer, swapping out PyTorch backpropagation with ProxyProp’s computation of the gradients. For
OPT-13B, we use LoRA to reduce the memory consumption of the optimizer. On the same hard-
ware, ProxyProp is roughly as fast as backpropagation (approximately ×1.5 slower). In comparison,
zeroth-order optimization becomes slow because it needs repetitions of parameter perturbations to

We analyzed theoretically how to compute local

Local learning for very deep, looped, or diffu-
sion architectures. The memory benefits of lo-
cal learning are already visible on moderately deep
LLM architectures (dozens of layers), but Prox-
yProp memory consumption is constant with the
number of layers. From the viewpoint of memory,
the benefits increase with deeper networks. Local
learning has the potential to scale to much deeper
architectures which are hard to train with standard
backpropagation.
A case of interest is a looped transformer in which
repeating the recurrence is effectively increasing
the depth of the network. To avoid increasing the
memory storage, the gradients are not propagated
through all of the loops; rather, the gradient is propagated only through the last (or last few) loop
iterations Yang et al. (2024). Local proxy propagation learning would be adapted to this setting, as
it offers theoretical insights and a method to compute gradients which are aware of all the repeated
loops without increasing memory storage. From another perspective, a single block in residual
models is analogous to a diffusion step. Pushing this analogy, Li et al. (2026) and Shing et al. (2026)
train deep residual architectures using diffusion training schemes. Reciprocally, our analyses might
inspire methods to compute global gradients from a single local diffusion step.
Decoupling parameter updates. The potential of local learning is not limited to memory saving.
By solving the backward locking problem, local learning also enables model-parallelism during
training (Jaderberg et al., 2017; Belilovsky et al., 2020). While the computation speed on a single
device is roughly similar between ProxyProp and backpropagation (see Table A1), decoupling be-
comes relevant when training across devices. As described, ProxyProp from Algorithm 1 preserves
a weak coupling. We see at least two directions to solve this issue: firstly, the pre-forward pass
could be computed ahead of time for a large batch without coupling; with mini-batches then being
dispatched in order and iterated. Hence, the algorithm can be applied if one accepts a lag between
the loss gradients and the local block that it is then sent to. Alternatively, we describe in Algorithm

C.2
VIT
C.2.1
SPECIFICATIONS
All CIFAR-100 experiments use a 12-layer vision transformer of width 128, 4 attention heads, patch
size 4 with classification on a final mean token readout. For local methods, the final LayerNorm is
placed in the classifier rather than in the last block so that local methods read raw activations at each
partition boundary. The classifier is zero-initialized, as in the original ViT.
Training uses the AdamW optimizer with batch size 128 at learning rate 5 × 10−4 with 10% linear
warm-up and cosine decay over 100 epochs. ProxyProp uses a single transformer at width 64 and is
trained by the same optimizer as the backbone. We report last-epoch accuracies.
To highlight the savings in memory in Figure 1B, we increase the batch size to 512 and measure
peak memory usage for one epoch.

C.3
FINETUNING
We follow the training setup in MeZO (Malladi et al., 2023) and build our experiments based on their
published repository. All models are finetuned for 10 epochs with batch size 8, and the epoch with
the best validation loss is used for evaluation on the test dataset. For OPT-13B, we use rank-8 LoRA
and split the 40-layer network into 8 blocks. We use the Adam optimizer and swept the learning rate
(3 × 10−5, 5 × 10−5, 10−4, 2 × 10−4) to select the optimal learning rate. The proxies are parame-
terized as: a linear projection down to 80 dimension, a small OPT transformer layer with 80 hidden
dimension and 40 heads, and a linear projection back to network hidden dimension. The second lin-
ear projector is zero-initialized. A residual connection to each proxy is added unless specified. For
LLaMA-3B, we split the 28 layer network into 7 blocks. The proxies are parameterized as a small
LLaMA transformer layer with 64 hidden dimensions and linear projectors mapping to network hid-
den dimension. We use the Adam optimizer and swept the learning rate (5 × 10−6, 10−5, 3 × 10−5)
to select the optimal learning rate. For all experiments, parameters of the proxies are trained with
the same learning rate as the network parameters. For the local loss objective, we use the shared
classification head for all blocks, because separate classification heads would result in a large mem-
ory cost. We use bfloat16 mixed precision training. All other settings remain exactly the same as
in Malladi et al. (2023). Experiments are performed on one 80G Nvidia H100 for SQuAD and one
A100 for SST2 and WIC.
When profiling the memory, we train the network with synthetic random data. To reduce the large
memory requirement of language head, we compute the cross-entropy loss by chunking the final
activation along the sequence dimension into pieces of a length 512.
D
ADDITIONAL ABLATIONS
D.1
VIT EXPERIMENTS
We perform further ablations in Table A2. At convergence, we find no significance between residual
and non-residual parameterization of the proxy in the classification, despite the clear advantage of
residual in fine-tuning tasks. Further, we find that by prepending some transformer layers to the head
(Gelbard et al., 2026) and training the proxies to distill the input into the deep head is advantageous.
In this case, zL would not be the last layer of the network but the last k-th layer with the parameters
of the last k layers as part of θh. We found that it could further improve performance at roughly the
same memory cost.
To make ProxyProp “update unlocked,” we use Minitron (Muralidharan et al., 2024) to prune the
transformer layer above each block into a 64-wide transformer proxy at the beginning of each epoch.
We train this proxy for 20% of the batch, with the backbone frozen. Then, we freeze the proxy, and
train the backbone with the proxy frozen for the entire batch.
Finally, we offer another baseline where we train a single block of the partitioned network with the
proxy attached with end-to-end by backpropagation on the classification loss under the same opti-
mizer. In ProxyProp, the proxy represents the distilled downstream network; this baseline suggests
this distillation is more useful than simply augmenting the block-wise local loss with an additional
proxy.
D.2
FINETUNING
We also study the importance of proxy training in SQuAD fine-tuning tasks. We found that the
identity proxy has already reached a good performance, but a trained proxy further improves the
performance. Consistent with findings on ViT, prepending the last block with the loss head improves
the performance.
