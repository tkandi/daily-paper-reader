## 摘要
异构超级云系统通过在多样化资源间实现可扩展且高效的任务分配，正在变革数据分析。本文提出了面向异构超级云中稠密 Cholesky（CH）分解和基于奇异值分解（SVD）的分析加速的计算模型与性能估计技术。我们的 ReDSEa 工具链可自动完成映射、负载均衡、调度、并行化以及计算重叠。在配备华为鲲鹏 920 ARM CPU 和昇腾 910 AI 加速器的异构系统上实现时，我们的 LLVM 编译器工具链采用了适用于递归、迭代和分块计算的新型性能模型；相较于经过充分优化的 48 核 CPU 实现，CH 的加速比最高可达 17 倍，SVD 的加速比最高可达 88 倍。

## Abstract
Heterogeneous Supercloud systems are transforming data analytics by enabling scalable and efficient task distribution across diverse resources. This paper presents computational models and performance estimation techniques tailored for accelerating Dense Cholesky (CH) Decomposition and Singular Value Decomposition (SVD)-based analytics on Heterogeneous Superclouds. Our ReDSEa tool-chain automates mapping, load balancing, scheduling, parallelism, and computation overlap. Implemented on a heterogeneous system with a Huawei Kunpeng 920 ARM CPU and an Ascend 910 AI accelerator, our LLVM compiler tool-chain employs novel performance models for recursive, iterative, and blocked computations, achieving up to 17x speedup for CH and 88x for SVD over fully optimized 48-core CPU implementations.
