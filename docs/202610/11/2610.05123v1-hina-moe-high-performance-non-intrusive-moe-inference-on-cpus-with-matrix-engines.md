## 摘要
专家混合（MoE）推理正日益部署于本地和本地部署环境中，其中专家参数的规模往往超过 GPU 的内存容量。在对延迟敏感、低并发的场景下，反复将路由后专家的权重从 CPU 内存调度至 GPU 的开销可能高得难以接受，使得路由专家的前馈网络（FFN）成为多插槽 CPU 上的关键路径。现有的 CPU 加速方案通常依赖侵入性的、硬件或拓扑特定的要求，例如 AMX 专用的权重布局或手动的 NUMA 感知放置。这些要求降低了可移植性，并使其难以集成到标准的 CPU-GPU 卸载流水线中。我们提出 HiNa-MoE，这是一个面向搭载 Intel AMX 的 CPU 的高性能、非侵入式 MoE 推理算子库。HiNa-MoE：（1）利用经过优化的微内核发挥 AMX 的性能优势，保持专家权重采用标准布局，转而将轻量级布局变换融合到令牌收集与存储操作中；（2）在无需修改框架内存分配器的简单页面交错策略下，采用 NUMA 感知的任务划分；（3）将解码阶段的内存矩阵-向量运算转换为小型矩阵-矩阵计算，以利用 AMX。在多个 MoE 模型上，相较于最先进的基线方法，HiNa-MoE 的 FFN 内核最高可实现 3.37 倍加速，端到端推理最高可实现 2.09 倍加速，同时仍可与现有框架和部署工作流即插即用地集成。

## Abstract
Mixture-of-Experts (MoE) inference is increasingly deployed in local and on-premise environments, where expert parameters often exceed GPU memory capacity. In latency-sensitive, low-concurrency settings, repeatedly staging routed-expert weights from CPU memory to the GPU can be prohibitive, leaving routed-expert feed-forward networks (FFNs) on the critical path of multi-socket CPUs. Existing CPU accelerations often rely on intrusive, hardware- or topology-specific requirements, such as AMX-specific weight layouts or manual NUMA-aware placement. These requirements reduce portability and complicate integration with standard CPU-GPU offloading pipelines. We present HiNa-MoE, a high-performance, non-intrusive operator library for MoE inference on CPUs with Intel AMX. HiNa-MoE (1) exploits AMX with an optimized micro-kernel that keeps expert weights in standard layouts and instead fuses lightweight layout transforms into token gathering and stores; (2) applies NUMA-aware task partitioning under a simple page-interleaved policy without modifying the framework allocator; and (3) converts decode-phase memory matrix-vector operations into small matrix-matrix execution to utilize AMX. Across multiple MoE models, HiNa-MoE achieves up to 3.37x speedup for FFN kernels and up to 2.09x end-to-end inference speedup over state-of-the-art baselines, while remaining plug-and-play with existing frameworks and deployment workflows.
