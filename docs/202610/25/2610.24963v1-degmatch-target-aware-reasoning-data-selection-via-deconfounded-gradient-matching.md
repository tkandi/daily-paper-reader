## 摘要
在长轨迹上进行推理后训练已显著提升了大语言模型的推理能力，但将此类训练扩展至大规模数据集的成本正日益增加。我们研究目标感知的推理数据选择问题，其中一个小型参考集用于定义目标能力，并引导训练轨迹的选择以实现专门化。我们发现，现有的目标感知方法在长推理轨迹上可能表现出有限的目标辨别能力；同时，候选样本梯度中占主导地位的总体层面结构，可能在梯度匹配过程中掩盖更细粒度的、依赖于目标的变化。为解决这些局限性，我们提出去混杂梯度匹配（Deconfounded Gradient Matching，DeGMatch），该方法首先构建目标相关性门控机制，随后利用模型特定梯度对候选样本进行重排序。DeGMatch 使用候选样本总体均值对梯度进行中心化，并在目标匹配前移除主要主成分方向，从而减少占主导地位的总体层面结构的影响，并提升目标辨别能力。在数学、科学和代码任务上，DeGMatch 均优于强启发式、目标感知及推理专用数据选择基线方法，同时在不同选择预算、模型系列和模型规模下均保持有效。我们的代码已公开发布于 https://github.com/CHLee0801/degmatch。

## Abstract
Reasoning post-training on long trajectories has substantially improved the reasoning capabilities of large language models, but scaling such training to large datasets is increasingly expensive. We study target-aware reasoning data selection, where a small reference set specifies a target capability and guides the selection of training trajectories for specialization. We find that existing target-aware methods can exhibit limited target discrimination on long reasoning trajectories, while dominant population-level structure in candidate gradients can obscure finer target-dependent variation during gradient matching. To address these limitations, we introduce Deconfounded Gradient Matching (DeGMatch), which first constructs a target-relevance gate and then reranks candidates using model-specific gradients. DeGMatch centers gradients using the candidate-population mean and removes leading principal directions before target matching, reducing the influence of dominant population-level structure and improving target discrimination. Across mathematics, science, and code, DeGMatch outperforms strong heuristic, target-aware, and reasoning-specific data selection baselines, while remaining effective across selection budgets, model families, and scales. Our code is publicly available at https://github.com/CHLee0801/degmatch.
