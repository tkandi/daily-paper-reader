## 摘要
混合专家模型（Mixture-of-Experts，MoE）的部署高度依赖专家并行（Expert Parallelism），而后者会产生密集的 GPU 间通信。因此，最先进的推理系统需要数据中心级 GPU 中具备高带宽、支持点对点（P2P）通信的互连方案（如 NVLink），以处理大规模令牌路由，使得部署成本高得难以承受。消费级 GPU 以显著更低的成本提供了相近的计算能力，有望使个人能够普及使用 MoE 推理，并支持保护隐私的本地部署。然而，其带宽受限的互连方式（仅具备较弱的 PCIe 总线带宽）以及经由主机中介的连接机制（不支持 P2P）带来了严重的通信瓶颈。我们提出 CoMoE，一种通信高效的 MoE 推理系统，通过新颖的以主机为中心的路由机制解决这一不匹配问题。我们的核心洞见是，独特的通信拓扑为将主机提升为主动路由枢纽提供了机会，从而能够从根本上减少通信量，并消除由全局同步引起的停顿。具体而言，对于令牌分发，我们引入主机支持的令牌多播机制，将共享令牌仅写入主机一次，从而消除出站传输冗余；对于令牌合并，我们提出一种利用主机暂存缓冲区的细粒度、令牌级聚合机制，以替代僵化的全局同步并缓解慢节点效应。在 RTX 5090 GPU 上的评估表明，CoMoE 可将推理吞吐量最高提升 1.46 倍，并且仅以 A800 GPU 硬件成本的 23.4%，即可接近具备 NVLink 支持的 A800 GPU 的性能。

## Abstract
Deploying Mixture-of-Experts (MoE) models relies heavily on Expert Parallelism, which generates intense inter-GPU communication. Consequently, state-of-the-art inference systems require high-bandwidth, P2P interconnects (e.g., NVLink) in datacenter GPUs to handle massive token routing, making deployment prohibitively expensive. Consumer GPUs offer comparable compute power at significantly lower cost, promising to democratize MoE inference for individuals and enable privacy-preserving local deployments. However, their bandwidth-limited (only weak PCIe bus bandwidth) and host-mediated interconnects (no P2P support) introduce severe communication bottlenecks.   We present CoMoE, a communication-efficient MoE inference system that resolves this mismatch through novel host-centric routing. Our key insight is that the unique communication topology provides the opportunity to elevate the host to an active routing hub, which can fundamentally reduce communication volume and eliminate global synchronization-induced stalls. Specifically, for token dispatch, we introduce host-backed token multicast to write shared tokens to the host exactly once, eliminating outbound transmission redundancy. For token combine, we propose a fine-grained, token-level aggregation mechanism using host staging buffers, which replaces rigid global synchronization and mitigates straggler effects. Evaluation on RTX 5090 GPUs shows that CoMoE improves inference throughput by up to 1.46x, approaching the performance of NVLink-capable A800 GPUs at only 23.4% of the hardware cost.
