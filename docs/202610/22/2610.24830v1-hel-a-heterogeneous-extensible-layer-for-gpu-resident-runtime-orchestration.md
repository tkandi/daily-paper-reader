## 摘要
我们描述了一种 GPU 驻留运行时系统 HEL，该系统构建于在用户应用程序整个生命周期内持续存在的有状态服务之上。HEL 程序员将工作负载表示为一个能够生成类协程任务的应用程序，随后这些任务由 HEL 运行时进行调度和执行。HEL 支持同步和异步任务、具有运行时依赖关系的任务、批量任务提交以及自动重试。应用程序与任务在经空间划分的 GPU 上并行运行。通过生产者—消费者和主机 RPC 基准测试，以及 PFPL 压缩案例研究，我们表明，对于 GPU 利用率不足的情况，以及 HEL 能够隐藏任务延迟的场景，HEL 均展现出性能优势。

## Abstract
We describe a GPU-resident runtime system, HEL, built on stateful services that persist throughout the lifespan of a user application. A HEL programmer expresses a workload as an application that spawns coroutine-like tasks, which are then scheduled and run by the HEL runtime. HEL supports synchronous and asynchronous tasks, tasks with runtime dependencies, batched task submission, and automatic retries. Applications and tasks run alongside each other on the spatially partitioned GPU. Using producer-consumer and host-RPC benchmarks together with a PFPL compression case study, we show that HEL demonstrates a performance advantage for underutilized GPUs and for scenarios where HEL enables hiding task latency.
