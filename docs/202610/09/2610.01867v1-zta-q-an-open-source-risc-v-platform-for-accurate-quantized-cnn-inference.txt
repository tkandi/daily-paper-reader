# ZTA-Q: an Open-source RISC-V Platform for Accurate Quantized CNN Inference 

Yike Li ∗, Ajay Kumar M ∗, Vishnu PS ∗, Dimitrios S. Nikolopoulos ‡,Bo Ji ‡, Hans Vandierendonck §, Deepu John ∗∗University College Dublin, Ireland ‡Virginia Tech, USA §Queen’s University Belfast, UK 

Abstract —Low-precision inference is widely adopted in edge AI to reduce computational cost and memory footprint. However, existing open-source accelerator platforms provide limited end-to-end support for CNNs following the standard TensorFlow Lite integer inference scheme. This paper presents ZTA-Q, an open-source RISC-V-based platform that enables accurate deployment of TensorFlow Lite INT8 models. In addition to extending operator support, ZTA-Q provides a configurable post-processing datapath for studying how circuit-level approximations, including reduced multiplier precision, shared shift scaling, and simplified rounding, affect model accuracy. The proposed system is implemented on a Digilent Arty A7-100T FPGA and operates at 83.3 MHz. Evalua-tions on representative CNN models show that with LUT, register, and DSP overheads of 26.3%, 12.6%, and 150%, respectively, ZTA-Q limits the degradation in both top-1 and top-5 accuracy to within 0.25 percentage points. 

Index Terms —Deep Learning, Hardware accelerators, RISC-V, Quantization, FPGA 

I. I NTRODUCTION 

AI applications at the edge, such as autonomous vehicles and surveillance cameras, must operate under strict constraints on area, power, and memory. To accelerate computation-intensive operators, recent systems increasingly combine RISC-V processors with dedicated neural processing units (NPUs), providing both general-purpose programmability and efficient tensor computation [1]. For open-source RISC-V SoCs, end-to-end model deployment typically involves three stages: a front-end model parser, a domain-specific middle-end compiler, and a target accelerator backend. Table I summarizes the deep learning frameworks, including PyTorch(torch), ONNX, TensorFlow(TF), Keras and Caffe, targeted by recent platforms. Several works [2]–[4] rely on third-party tools, such as ONNX Runtime [5], MLIR [6], or TVM [7], to import models from mainstream deep learning frameworks. Although this approach reduces development effort compared to an in-house parser, their multi-layer abstractions can make low-level hardware specification less explicit, which may complicate architectural exploration and extension. Another limitation lies in the quantization flow, which con-verts wide accumulator values back to low-bitwidth activations after each layer. In [4], TVM-generated C code is executed entirely on the RISC-V cores, without a dedicated hardware implementation for quantization. Through software–hardware co-design, ZTA-Q supports standard TensorFlow Lite integer models and intro-duces a post-MAC quantization datapath with two-stage round-ing, extending the original per-tensor implementation to both per-tensor and per-channel quantization. The main contributions of this work are summarized as follows: 1) We redesign the quantization mapping in the ztachip parser and compiler to provide in-house support for both per-tensor and per-channel quantization. We further introduce a post-MAC datapath with two-stage rounding to implement both schemes directly within the acceleration engine. 2) We provide a per-layer ablation study on how circuit-level approximations in the quantization flow, including reduced scale precision, shared shift scaling, and simplified rounding, affect inference accuracy and hardware cost. We evaluate ZTA-Q on representative quantized CNN mod-els, including LeNet-5, SqueezeNet1.1, MobileNetV1/V2, and ResNet-18/50. The proposed system is implemented on aDigilent Arty A7-100T board at 83.3 MHz. With our extended quantization scheme support, ZTA-Q achieves accuracy compa-rable to TensorFlow Lite, with less than 0.25 percentage points of accuracy degradation. II. P LATFORM ARCHITECTURE

A. Baseline Platform: ztachip 

Ztachip is an open-source RISC-V AI acceleration platform for edge inference, with an in-house parser and compiler targeting quantized TensorFlow Lite models, as shown in Fig. 1(a)-(c). The parser extracts operator options like tensor shapes, strides, padding, activation functions, and quantization parameters from the model graph and converts them into an intermediate representation. The compiler then performs quan-tization preparation and hardware-aware grouping and tiling before generating tensor programs, which are compiled into RISC-V executable code containing the required accelerator register configurations. The hardware consists of a VexRiscv CPU [13], a dataplane controller, and a multicore acceleration engine. Each acceleration core contains four pcores, with eight ALU lanes per pcore for parallel vector computation. The CPU configures and launches operators, while the dataplane controller and stream processor manage tensor transfers be-tween external DDR memory and pcore-local memories. In this work, we retain the original execution and data-movement flow, extend the baseline per-tensor quantization scheme to per-channel quantization, and add a post-MAC requantization datapath to improve inference accuracy. 

B. Per-Channel Quantization Mapping 

The baseline ztachip platform supports only per-tensor quan-tization, in which all output channels of a convolution layer share a single weight scale. In the ex-tended flow, the parser first determines whether the weight scale is scalar or channel-wise according to the number of scale values. If it’s channel-wise, the compiler generates a corresponding multiplier–shift pair (Mc, N c) for every output channel. The multiplier and shift vectors are then packed according to the grouping and tiling configuration used by the convolution kernel. Different SIMD ALU lanes will now be configured to apply different multiplier and shift values to their post-MAC results. To enable end-to-end evaluation on a broader range of CNN models, we additionally introduce support for several previously unsupported operations to improve model compatibility, including padding, max pooling, and mean reduc-tion, and extend existing convolution kernels to cover additional kernel sizes and stride configurations. 

C. Post-MAC Quantization Datapath 

Executing the TensorFlow Lite-equivalent requantization pro-cedure on the RISC-V CPU would preserve the reference arithmetic. However, it would require frequent transfers of inter-mediate accumulator values between the PCORE local memory and external memory, resulting in substantial data-movement overhead. ZTA-Q therefore performs post-MAC requantiza-tion inside the PCORE acceleration engine. The channel-wise multiplier and shift vectors generated by the compiler are loaded into the pcore together with each output-channel tile. After the SIMD ALU lanes complete the multiply–accumulate operations, the 32-bit accumulation result ACC c, stored in the accumulator register xreg , is rescaled using the corresponding multiplier Mc and shift Nc. The resulting value is subsequently passed to the stream processor, where the output zero-point 

Zo, activation function, and any required output remapping are applied.

E XPERIMENTAL RESULTS 

In this section, we first analyze the impact of optional approximation approaches on model accuracy, inference time, and hardware cost. Then, we evaluate the model inference performance on the FPGA board with quantized TensorFlow Lite models. 

A. Ablation study of approximation approaches 

Although quantized inference is widely supported, prior accelerator studies rarely examine how circuit-level approxi-mations in the post-MAC quantization datapath affect end-to-end accuracy and hardware cost. Prior works typically report numerical precision and provide a high-level representation of the quantization module in the hardware architecture, with-out detailing their implementation. We therefore perform an ablation study on all MobileNetV2 convolution layers us-ing five approximations: reduced multiplier ( Mc) precision, shared shifts with rescaled multipliers, removal of multiplier rounding( round m ), removal of shift rounding( round s ), and removal of both rounding stages. Here, shared shifts means 

Nc in Eq. (4) is shared among channels. As Fig. 2 shows, over a balanced subset of 1,000 ImageNet validation images, with one image randomly selected from each class, the exact-match ratios of different schemes become increasingly similar after successive layers, while their numerical deviations re-main distinct. Removing rounding produces substantially larger mean absolute deviation from the TensorFlow Lite reference across convolution (CV), depthwise convolution (DW), and fully connected (FC) layers, whereas INT16 multipliers and shared shifts introduce only minor errors. Notably, the no-shift-rounding curve nearly overlaps with the no-rounding curve, whereas removing only multiplier rounding causes a much smaller deviation. This confirms that shift rounding is the dominant factor in preserving numerical fidelity during post-MAC quantization.

B. End-to-End CNN model inference evaluation 

Following the ablation study, we evaluate our implementation across representative popular CNN models. To cover represen-tative edge-inference workloads with different network depths and operator compositions, we select LeNet-5, SqueezeNet1.1, MobileNetV1/V2, ResNet-18 and ResNet-50 as benchmarks, using full MNIST and ImageNet as their corresponding valida-tion datasets. For post-training quantization, the representative dataset contains 1,000 calibration images, with an equal number of images randomly selected from each class, and the test dataset is the full ImageNet and MNIST validation set. The provided MobileNetV2 model in the ztachip GitHub repository uses unsigned 8-bit activations and per-tensor quantization, whereas the remaining models are quantized using signed INT8 activations and per-channel quantization. The evaluated models and batch evaluation scripts are made publicly available on GitHub 1. As shown in Table IV, the proposed implementation achieves an accuracy difference of less than 0.25 percentage points compared with the corresponding TensorFlow Lite in-ference results across all evaluated models. IV. C ONCLUSION 

In this work, we presented ZTA-Q, an open-source RISC-V-based platform for accurate quantized CNN inference on edge FPGAs. Guided by an ablation study of hardware approxima-tions, we develop a post-MAC quantization flow with two-stage rounding for both per-tensor and per-channel schemes,
