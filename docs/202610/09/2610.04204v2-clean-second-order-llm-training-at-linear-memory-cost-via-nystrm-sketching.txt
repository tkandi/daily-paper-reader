## ABSTRACT 

Training large language models (LLMs) entails a fundamental trade-off: memory-efficient optimizers such as Adam discard cross-parameter curvature, whereas full-curvature methods such as SOAP can accelerate convergence at prohibitive memory costs. We introduce Clean , a memory-efficient and full-curvature opti-mizer designed to resolve this bottleneck. Clean leverages the randomized Nyström method to accurately approximate the left and right preconditioners in SOAP, and to reduce the optimizer’s memory complexity from quadratic to linear in terms of model dimensions. We subsequently reintegrate the off-subspace components to capture curvature information beyond the low-rank approximation, preserving rich curvature at minimal memory cost. We further propose Q-Clean , a low-precision variant that aggressively compresses optimizer states. Q-Clean reduces optimizer memory consumption by over 50% compared to Muon when pre-training a LLaMA-1.3B architecture, all while maintaining strong and competitive predic-tive performance. Notably, Clean operates with a smaller optimizer-state footprint than standard AdamW while reaching AdamW’s final performance 26% faster in wall-clock time. Furthermore, our methods uniquely enable the pre-training of a 13B-parameter model on a single 80GB GPU, providing a scalable, efficient, and accessible approach to large-scale model optimization.

Training large language models (LLMs) forces a trade-off between memory and curvature. Adaptive optimizers store moment statistics that match or exceed the size of the model itself, and second-order methods such as Shampoo (Gupta et al., 2018) and SOAP (Vyas et al., 2024) store even more. The remedies that reduce this foot-print typically discard curvature information, producing poorly conditioned updates and slow-ing convergence (Gupta et al., 2018). Balancing memory efficiency with curvature fidelity has therefore emerged as a central challenge for ef-ficient LLM training. A range of optimizers have been proposed, each making a different trade-off between memory and curvature. First–order methods such as Adam (Kingma & Ba, 2014) and Adafactor (Shazeer & Stern, 2018) are lightweight optimizers that store only diagonal statistics. Shampoo (Gupta et al., 2018) and KFAC (Martens & Grosse, 2015) explicitly capture curvature and can accelerate training, but their quadratic state and computation make them prohibitive at LLMs scale. More recently, SOAP (Vyas et al., 2024) achieved highly stable and full-rank precondition-ing by applying Adam to the gradient projected onto the eigenbasis of Shampoo’s preconditioner; however, it still relies on explicitly accumulating full-rank covariance matrices. Several efficient optimizers have been proposed, but all of them have at least one optimizer memory state that grows quadratically with respect to model dimensions (i.e., O(mn )) (Romashov et al., 2026; Jordan et al., 2024; Gong et al., 2026; Liu et al., 2025), making them difficult to scale. To resolve this, we introduce 

Clean , a curvature-aware optimizer that achieves SOAP-level performance while its memory states scale linearly with respect to model dimensions. Clean replaces explicit gradient covariance accumulations with randomized Nyström approximations, extracting highly accurate, compact estimations for the left and right Shampoo preconditioners. It then splits the update into four orthogonal blocks, Main , A, B, and C, and applies full Adam to Main .Rather than discarding gradients that fall outside the low-rank core, it applies pooled Adam-like updates to the three remaining blocks. Finally, every block is projected back to the parameter space, and Clean recombines all four to produce a rich and full-rank update, as shown in Fig. 2. We also introduce Q-Clean , a quantized variant that aggressively compresses the stored optimizer states. To the best of our knowledge, Clean is the first second-order SOAP-like optimizer whose memory grows only linearly with layer dimensions, requiring O(( m + n)r) instead of O(mn ) for a layer of size m × n. Extensive pre-training evaluations on LLaMA-based architectures demonstrate that our approach successfully retains the benefits of full-rank second-order preconditioning at a fraction of the optimizer memory cost. Clean delivers validation perplexities highly competitive with SOAP, yet operates with a smaller memory footprint than AdamW, while showing significant speedup in comparison to Adam’s convergence rate. Fig. 1 shows that across all the baselines, Clean and Q-Clean are the only optimizers that allow training a 13B model on an H100 GPU with 80GB of memory. In summary, Clean is the first optimizer to perform SOAP-style preconditioning in the eigenbasis of randomized Nyström approximations of both Kronecker factors. The Nyström approximations allow the covariance factors to be updated without ever forming them explicitly, reducing their memory cost from quadratic to linear in the layer dimensions for a fixed rank r. Even when the rank increases with the model dimensions, Clean reduces the per-parameter cost as the model scales. Finally, we present Q-Clean, a low-precision extension that quantizes optimizer states to achieve competitive performance while further reducing optimizer memory requirements.

Most deep learning optimizers can be viewed as preconditioned gradient methods. Consider a weight matrix Wt ∈ Rm×n with vectorization wt = vec( Wt) ∈ Rmn , loss function ϕ(·) and stochastic 2Clean: Second-order LLM Training at Linear Memory Cost via Nyström Sketching gradient gt = ∇ϕt(wt) ∈ Rmn . Different optimizers correspond to different choices of Pt,balancing the accuracy of the curvature with memory and computational costs. We first review several widely used optimizers, and then introduce the technical tools on which our method builds. 2.1 OPTIMIZERS AS PRECONDITIONERS 

Eqn. (1) provides a common lens for comparing optimizers: each corresponds to a particular choice of Pt, which dictates the balance between retained curvature information and memory requirements.

Shampoo (Gupta et al., 2018), a popular second-order optimizer, takes exactly this route and has become the standard Kronecker-factored approximation to full-matrix AdaGrad (Duchi et al., 2011), which computes and stores per-layer Lt and Rt, utilizing fractional powers L−αt , R −αt as left and right preconditioners. The original α = 1 /4 matches AdaGrad in theory, but Anil et al. (2020) found that α = 1 /2 often improves stability. However, fully storing Lt and Rt still incurs quadratic memory in the layer width, which is prohibitive for wide layers. 

SOAP and eigenspace optimization. Rather than explicitly computing the costly inverse fractional powers of Lt and Rt at every step, SOAP (Vyas et al., 2024) periodically computes their eigen decompositions. It then projects the gradients into this slowly changing principal curvature eigenspace, applies a coordinate-wise Adam update, and projects the step back to the original parameter space. Ultimately, this hybrid approach unifies the structural curvature benefits of second-order optimization with the low per-step cost of diagonal methods, empirically reducing both the number of iterations and the wall-clock time compared to standard Shampoo and AdamW. However, SOAP’s memory footprint remains O(m2 + n2), the same as Shampoo’s, since it must still store the full m × m and 

n × n Kronecker factors, Lt and Rt at each step. The SOAP algorithm is provided in Appendix C. 2.2 RANDOMIZED NYSTRÖM PRECONDITIONER 

The randomized Nyström approximation (Gittens & Mahoney, 2016) provides a framework for efficiently representing symmetric PSD matrices using low-rank approximations. > Y=AΩ,B= Ω ⊤AΩ,˜A=Y B †Y⊤≃A, (4)

where ˜A is a rank-r surrogate, requiring only O(nr ) storage instead of O(n2) when r ≪ n. However, a naive implementation based on Eqn. (4) is numerically unstable (Frangella et al., 2023). Alg. 2 in Appendix A presents a numerically stable approach for constructing a Nyström approximation (Tropp et al., 2017). Given the eigenvalue decomposition ˜A = U ΛU ⊤ returned by Alg. 2, where U ∈ Rn×r has orthonormal columns and 

Λ = diag( λ1, . . . , λ r ) with λ1 ≥ · · · ≥ λr ≥ 0, the Nyström preconditioner is obtained by: 

P = ( λr + μ)−1 U (Λ + μI )U ⊤ + ( I − U U ⊤). (5) 

In effect, P −1 scales down each of the top-r eigendirections of A by the factor (λr +μ)/(λi +μ) ≤ 1,so that directions with larger eigenvalues are scaled down more, while acting as the identity on U ⊥.

## 4 Q-C LEAN : L OW -P RECISION SECOND -O RDER OPTIMIZATION 

To further reduce memory overhead, we explore the stability of Clean under quantization, a technique that stores matrices as low-bit integers. In this section, we briefly introduce Q-Clean, which employs quantized optimizer states. More details are included in Appendix B. Following (Dettmers et al., 2021), block-wise quantization partitions a flattened matrix X into contiguous blocks of size B and quantizes each block independently. With an n-bit asymmetric (affine) quantizer, block i uses a scale si and a zero-point zi to represent a value in lower precision. Per-block scaling limits the effect of outliers to a single block rather than coarsening the quantization grid of the entire matrix (Dettmers et al., 2022). However, because optimizer states are continually updated, round-to-nearest scheme discards any update smaller than half a quantization step, so small but consistent updates never accumulate. To remove this bias, the linear quantizer can instead use stochastic rounding (Von Neumann & Goldstine, 1947; Gupta et al., 2015), which is unbiased in expectation, and therefore prevents small updates from vanishing over time. For the first-moment and projection matrices, we apply the block-wise linear asymmetric scheme mentioned above. In contrast, the second-moments are strictly non-negative and exhibit a highly skewed distribution with a large dynamic range (see Appendix B). Because linear quantization is suboptimal for such statistics, we instead adopt the non-linear quantization implementation from 

bitsandbytes (Dettmers et al., 2021), which is also used in the Adam-8bit optimizer. We quantize the first moments of all blocks listed in Table 1, the second moment of the Main , and the projection matrices in INT8. The second moments of blocks A and B are kept in full precision: each is a vector of size r, so its memory footprint is negligible and quantizing it would yield no meaningful savings. 

## 5 RELATED WORK 

Low-rank Projection Methods. A popular approach to reducing optimizer memory is to project gradients onto a low-rank subspace. GaLore (Zhao et al., 2024) introduced this strategy by performing gradient updates within a low-rank subspace defined by the singular value decomposition (SVD) of gradients. A family of works follows this line of optimizers (Chen et al.; Zhu et al., 2025; Liang et al., 2024; He et al., 2024). While effective at saving memory, this one-sided projection can be unstable as the subspace drifts over time. LDAdam (Robert et al., 2024) and Subtrack++ (Rajabi et al., 2025) attempted to mitigate this by incorporating projection-aware updates and more robust subspace tracking mechanisms. However, these methods operate on one-sided approximations and do not capture the row-column geometry of the gradient covariances. 

Second-order Preconditioning. Another line of work focuses on capturing curvature information. K-FAC (Martens & Grosse, 2015) approximates the Fisher information matrix with Kronecker prod-ucts, while Shampoo (Gupta et al., 2018) directly approximates the full-matrix AdaGrad (Duchi et al., 2011) preconditioner by maintaining separate row and column preconditioners. These balanced, two-7Clean: Second-order LLM Training at Linear Memory Cost via Nyström Sketching sided preconditioners are powerful but require storing full-sized covariance matrices, making them memory- and compute-intensive. SOAP (Vyas et al., 2024) combines Shampoo’s preconditioning with first-order updates but still retains the costly full-matrix accumulators. 

Low-rank Second-order Methods. To achieve the benefits of second-order preconditioning with-out the prohibitive memory costs, recent methods have proposed efficient second-order optimizers. Alice (Gong et al., 2026) provides a low-rank extension that converts general full-rank optimizers into memory-efficient approximations by relying on structured Fisher information matrix approximations. Building on this, ALSO (Romashov et al., 2026), extends toward a two-sided approximation of SOAP (Vyas et al., 2024), while compensating for the discarded residual blocks outside the core low-rank projection. Another direction leverages the varying importance of eigensubspaces; for instance, COSMOS (Liu et al., 2025) introduces a hybrid approach that applies memory-intensive SOAP updates exclusively to the leading eigensubspace of the gradient matrix, while utilizing a computationally cheaper, Muon-like update (Jordan et al., 2024) for the residual subspace. 

Low Precision Training with Quantization. Quantization improves memory efficiency by repre-senting data in reduced-precision formats. These techniques broadly fall into Post-Training Quanti-zation (PTQ), where pre-trained models are quantized without additional training (Ashkboos et al., 2025; Dettmers et al., 2023; Ashkboos et al., 2024), and Quantization-Aware Training (QAT), which integrates quantization directly into the training loop. A major challenge in QAT is training instability. Inspired by Izmailov et al. (2018), SWALP (Yang et al., 2019) mitigates this using stochastic weight averaging, though it incurs significant memory overhead when applied to large foundation models. Q-Galore (Zhang et al., 2024) substantially reduces memory consumption by integrating full-model quantization with the low-rank gradient projection of GaLore (Zhao et al., 2024). Similarly, 4-bit Shampoo (Wang et al., 2024) quantizes the left and right eigenvector matrices and applies Björck orthonormalization to restore orthogonality after quantization.

## 7 CONCLUSION 

We introduce Clean, a memory-efficient second-order optimizer that reduces the memory complexity of two-sided preconditioning from quadratic to linear. By leveraging randomized Nyström sketching, Clean accurately approximates left and right preconditioners, while uniquely reintegrating off-subspace residual blocks to preserve essential training signals. We also develop Q-Clean, a low-precision variant that aggressively compresses optimizer states. 9Clean: Second-order LLM Training at Linear Memory Cost via Nyström Sketching Empirically, both Clean and Q-Clean achieve validation perplexities that are highly competitive with full-rank methods like SOAP, yet they operate with a smaller memory footprint than standard AdamW. Crucially, this aggressive memory reduction uniquely enables the pre-training of a 13B parameter architecture on a single 80GB GPU, and increases the convergence speed by 26% compared to AdamW. We are optimistic that these linear-scaling curvature approximations will encourage broader exploration into accessible, memory-efficient optimization frameworks.

## B QUANTIZATION DETAILS 

In this section, we explain the Q-Clean optimizer in more detail. B.1 BLOCK -WISE n-BIT QUANTIZATION 

Block-wise quantization was originally introduced by (Dettmers et al., 2021) for compressing optimizer states during training, and was later adapted by (Dettmers et al., 2023) to frozen base-model weights for memory-efficient LLM fine-tuning. We adopt the same block-wise principle but use a uniform affine quantizer, with an asymmetric formulation (scale and zero-point) for most matrices and a symmetric formulation for the second moment, as detailed below. The block-wise scheme partitions a matrix into contiguous blocks and computes an independent scale s (and, in the asymmetric case, a zero-point z) for each block. The motivation is robustness to outliers: with a single per matrix scale, even one anomalously large value forces every quantization step to be coarse, mapping most typical values to only a handful of integer codes and losing most of the resolution (Dettmers et al., 2022). A per-block scale isolates this effect: only the block containing the outlier loses precision, while every other block keeps a fine-grained scale fitted to its own local data.

The per-matrix view computes a single scalar for an entire matrix, highlighting differences between matrices; this applies when sharing one quantization scale across a matrix. Conversely, the per-block view divides matrices into blocks, computing and pooling statistics for each block individually. Together, these views motivate our quantization strategy. In the per-matrix view, overall matrices (V , L, R, etc.) exhibit extreme distributional probabilities; a global linear scale stretches to cover these heavy tails, wasting resolution and causing high error. Moving to a block-wise approach enhances the tiles by isolating these extreme values, which lightens the tails across all families. For most matrices ( W , G, M , L, R, QL, QR), this shift makes them suitable for asymmetric and linear quantization. However, even after block-wise quantization, the second-moment matrix ( V ) still shows heavy tails, and linear quantization leads to divergence on V , whereas it succeeds for the other matrices. Therefore, we use a symmetric and non-linear quantizer for V and retain linear block-wise codes for the rest in our low-rank proposed method.
