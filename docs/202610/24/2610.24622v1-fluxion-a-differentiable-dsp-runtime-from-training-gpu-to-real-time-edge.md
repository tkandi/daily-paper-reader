## 摘要
原生实时音频引擎能够满足音频时限要求，但难以接入机器学习工作流；而张量框架能够与机器学习集成，却将音频作为离线批次处理，无法提供时序保证；构建于其上的运行时层也会继承宿主系统的调度方式和部署开销。本文提出 Fluxion：一种面向级联二阶节、FIR 滤波器和延迟线效果器的 Rust 音频 DSP 运行时。Fluxion 实现了 DSP 所特有的部分：闭式滤波器设计、前向核、递归的解析伴随以及稳定性检查。它依赖现有库来实现自动微分图、GPU 代码生成（本文在 CUDA 上测试）和数组交换。统一的图代数可被降级为可微训练引擎和免分配的实时引擎；二者之间，训练完成的图会接受稳定性检查，并被冻结为带版本的工件，边缘设备也会在播放前再次进行检查。我们在统一的 float32 协议下，将 Fluxion 与六种基于框架托管及原生实现的基线系统进行比较。在精确计算递归的系统中，当数据保留在设备端时，Fluxion 的 GPU 吞吐量最高，并且在大多数 CPU 工作负载上的吞吐量也最高；但其 CPU 训练步骤慢于 torchaudio 和 GRAFX。其测试套件通过带插桩的分配器检查音频线程中的内存分配，我们还报告了测得的延迟尾部指标。Fluxion 已开源，地址为 \url{https://github.com/matteospanio/fluxion}。

## Abstract
Native real-time audio engines meet audio deadlines but are hard to connect to machine-learning workflows, while tensor frameworks integrate with machine learning but process audio as offline batches without timing guarantees; runtime layers built on them inherit the host's scheduling and deployment footprint. This paper presents Fluxion, a Rust audio DSP runtime for cascaded second-order sections, FIR filters, and delay-line effects. Fluxion implements the parts that are specific to DSP: closed-form filter design, forward kernels, analytic adjoints for the recursion, and stability checks. It relies on existing libraries for the autodiff graph, GPU code generation (tested here on CUDA), and array interchange. One graph algebra is lowered to a differentiable training engine and to an allocation-free real-time engine; between them, a trained graph is checked for stability and frozen into a versioned artifact that an edge device checks again before playback. We compare Fluxion with six framework-hosted and native baselines under one float32 protocol. Among the systems that compute the exact recursion, Fluxion has the highest GPU throughput when data stays on the device and the highest throughput on most CPU workloads, while its CPU training step is slower than those of torchaudio and GRAFX. Its test suite checks the audio thread for allocations with an instrumented allocator, and we report measured latency tails. Fluxion is open source at \url{https://github.com/matteospanio/fluxion}.
