The growing memory demands of artificial neural networks pose a major challenge for energy-efficient comput-ing, particularly for models that rely on large collections of high-dimensional weight and embedding vectors. Conventional memory architectures store these vectors individually, requiring many memory cells per vector and limiting achievable storage density. Here we demonstrate an analog memory architecture that encodes multiple vectors in a distributed superposition within a single memory array. Individual vectors are recovered through in-memory matrix–vector multiplication, allowing the degree of superposition to be tuned to balance storage density against recall fidelity. This approach introduces a new scaling dimension for analog memory, in which effective storage density can be increased without a corresponding increase in the number of physical memory cells. The distributed representation also provides resilience to device-level noise. We implement the architecture on a prototype phase-change memory chip and experimentally evaluate it using embedding tables from deep learning recommendation models and large language models. The results demonstrate inference accuracy comparable to full-precision software baselines, establishing analog superposition as a promising route towards dense, energy-efficient memory for artificial intelligence. 

I. INTRODUCTION 

The rapid progress of deep learning (DL) over the past decade has been driven not only by advances in algorithms, but mainly by advances in computing hardware, particularly specialized accelerators 1–4 . During inference, these artificial intelligence (AI) accelerators repeatedly access large sets of deep neural network (DNN) parameters stored in memory and deliver them to processing units for computation. Because the energy required to access memory often exceeds that required to perform arithmetic operations, the storage and movement of model parameters have emerged as major bottlenecks in AI hardware. As neural networks continue to grow, increasing the amount of model information that can be stored close to the processing units has become increasingly important. Most contemporary AI accelerators rely on a memory hierarchy comprising static random-access memory (SRAM) as high-performance cache memory on the processor chip and off-chip dynamic random-access memory (DRAM) as high-capacity system memory. However, the storage density of SRAM, which typically requires a six-transistor cell, remains limited, and improvements through conventional semiconductor scaling have not kept pace with the rapid growth of modern neural networks. Embedded flash memory has traditionally served as on-chip storage for low-end edge platforms, but it becomes impractical to integrate at advanced technology nodes. Emerging memristive devices such as resistive random-access memory (RRAM) and phase-change memory (PCM) are expected to contribute significantly to integrated on-chip memory because of their compact size 5–8 ; their ability to represent data through binary high-and low-resistance states has already established a niche in edge-AI processors for storing neural-network parameters 9.Nevertheless, conventional approaches to increasing memory capacity, namely, reducing device dimensions, enlarging arrays, or extending them into three dimensions, ultimately depend on the number of physical devices and the number of reliably distinguishable states per device. Moreover, depending on the memory technology, device scaling can increase device resistance, while larger arrays introduce greater interconnect losses, both leading to more demanding sensing conditions. Finally, although emerging non-volatile memory devices are intrinsically analog, their continuous state space is often restricted to a limited number of discrete levels to manage variability and sensing constraints. Here we introduce an analog memory architecture that increases effective storage density through the representation of information rather than through physical device scaling alone. The proposed architecture adds a capacity-scaling dimension that arises from how information is represented, improves the sensing conditions that constrain memory-array scalability, and exploits the analog characteristics of emerging memory devices. Multiple high-dimensional vectors are stored across a fixed set of devices, and the number of vectors can exceed the number of physical rows of the array. This partially decouples effective storage capacity from the number of physical memory units. Increasing

> II. IN-DEPTH LOOK AT THE MEMORY ARCHITECTURE

In conventional memory architectures, the elements of a DNN vector are digitized, stored across individually addressable memory cells, and retrieved through sequential word or row accesses (Fig. 1a). The number of stored vectors is therefore determined by the number of available physical rows and the number of reliably distinguishable states per device. In the proposed architecture, each vector is instead distributed across an entire analog memory array and retrieved by collectively activating its rows according to an associated key (Fig. 1b). This representation allows multiple vectors to be superposed within the same devices, including operation where the number of stored vectors exceeds the number of physical rows. Furthermore, retrieval produces column currents from the collective response of many devices rather than from an individually addressed device, increasing the available current margin.  

> A. Encoding scheme

Prior to being written into the memory array, each D-dimensional vector is mapped to a two-dimensional represen-tation that can be stored in a D×D memory array. To achieve this, we lift the vectors into a matrix representation and combine them into a single superposed composite representation (SCR). To achieve this, we employ tensor-product representations (TPRs) 13 , a mathematical framework which defines the binding of two vectors, a key and a value, using a tensor (outer) product operation. The result is a higher-order representation where information about both components is preserved in a distributed fashion. In our setting, the value corresponds to a DNN vector that we wish to store in memory, while the key is an auxiliary vector that indexes the value within the superposed representation. > B. Physical storage and collective readout

After its creation, the SCR S is mapped directly onto a D × D analog memory array, where each memory cell, comprising one or more analog devices, is programmed to represent the corresponding element of S. Programming can be performed using iterative read-write-verify techniques commonly employed in analog memory devices 16 . In contrast to digital parameter storage, the continuously programmable device conductances are used directly to represent the elements of the composite matrix. In this work, we only investigate the storage of parameters that are static during inference and as such S does not require updating. However, one could incrementally update S by leveraging the crystallization kinetics and the corresponding accumulative behavior of PCM devices 17 .Retrieval of vector ˆvi corresponds physically to an in-memory matrix-vector multiplication (MVM) between the stored matrix S and the key ki (Eq. 3). Keys need only be quasi-orthogonal between them, a condition that can be achieved with bipolar values. Therefore, the inputs to the MVM is bipolar voltages representing the elements of ki

and are applied simultaneously to the array rows, with the resulting column currents being digitized to obtain the elements of ˆvi. This differs from conventional cell-addressed storage, in which the sensing conditions are determined primarily by the current of an individual device. Collective readout provides a larger current margin while preserving the analog information encoded in the array. In the experimental conditions considered here, SCR retrieval produces a median current more than two orders of magnitude larger than single-device readout and reduces the coefficient of variation of the read-current distribution by more than sixfold (Extended Data Fig. 2). This additional margin allows the use of more resistive nanoscale devices, without imposing strict sensing requirements that increase sensing time or the complexity of sensing circuitry as to not pollute a very faint signal.  

> C. Organization of a tiled memory system

Figure 2 illustrates how the proposed architecture can be organized using multiple analog memory tiles. Each tile contains a D × D analog array, row digital-to-analog converters (DACs), column analog-to-digital converters (ADCs), and the programming circuitry required to program a SCR. Vectors whose dimensionality Dvec exceeds the tile dimension D are partitioned across ⌈Dvec /D ⌉ tiles. These tiles form a tile group and are activated in parallel to retrieve the different segments of the same vector. Within each tile group, one SCR stores N = SpD vectors. A collection of parameters containing Nvec vectors therefore requires ⌈Nvec /S pD⌉ tile groups. Increasing Sp reduces the required number of tile groups without changing the physical dimensions of the individual arrays, at the cost of the gradual retrieval-fidelity reduction introduced by superposition. The same set of keys is reused across tile groups because the key identifies the position of a vector within a group, while the group address identifies the physical tiles containing that vector. Consequently, the key-generation circuitry does not need to be replicated for every analog tile. Instead, a shared generator supplies the selected bipolar key to the row-driving circuits of all tiles activated for a read operation. Its hardware cost is therefore amortized across many arrays and across all vector segments participating in the retrieval. Finally, the fact that the keys need only be quasi-orthogonal bipolar vectors further simplifies the key generator circuit significantly. While a detailed design-space exploration of the key generator circuit falls out of scope for this work, for our simulations we adopt a hardware-inexpensive solution of keys that are generated sequentially via binary 4operations of an internal state, thus not requiring the storage of a separate key matrix. In this work, we use a cellular automata (CA) based on Rule 30 to generate pseudo-random bipolar sequences (see related Methods section).  

> III. NEURAL NETWORK ADAPTATION

The memory architecture described in Section II stores vectors approximately due to the interference term ϵtpr 

introduced by the SCR. Therefore, it is essential to adapt the parameters of the DNN model to tolerate this inter-ference. We achieve this by introducing the TPR-based encoding during model retraining by injecting the retrieval error caused by superposition into the model parameters during the forward pass. Backpropagation then updates the parameters such that they become robust to the errors introduced by the SCR transformation, allowing the model to converge to parameters amenable to noisy storage in superposition. A detailed description of the training procedure is provided in Methods and in Extended Data Fig. 3. To assess downstream performance when model parameters are stored in S, we consider two representative applica-tion scenarios where storage capacity is critical and where the inherent superposition capability of the transformation becomes advantageous. First, we evaluate a DLRM 18 , which contains large embedding tables that are repeatedly accessed during inference. Second, we apply the method to store the embedding table of a LLM, specifically GPT2-large 19 . Details on the selected networks and datasets are provided in Methods, while the hyperparameters used during training are listed in Extended Data Table I. We first analyze the impact of storing the embedding tables of the DLRM using SCR, evaluated in the Criteo Kaggle Display Advertising dataset 20 and measured in area under the curve (AUC) (Fig. 3a). When the embeddings are stored in memory arrays with superposition factor equal to one ( N = D), the resulting AUC matches the software baseline, indicating that the encoding does not affect downstream performance. However, since embedding tables in DLRMs are known to be highly compressible 21 , we further investigate the behavior of the model as the number of stored vectors N increases way beyond D. Figure 3a shows that performance remains close to the software baseline even at superposition ratios as high as 1024 ×, with the model remaining within 0.01 AUC of both the baseline and the state-of-the-art embedding compression method ROBE 22 . Notably, our approach introduces no decompression overhead, as retrieval from the SCR results to the target vector naturally. We perform a similar analysis for GPT2-large by storing its embedding tables in S and measuring perplexity on WikiText 23 . Here, on a network much more sensitive to interference, we observe that we need to employ the delta rule variant of SCR to achieve baseline perplexity when we store N = D vectors. As superposition increases, perplexity degrades gracefully, reflecting the interference introduced by superposition and the tradeoff of storage density to retrieval fidelity. Importantly, storing embeddings using SCR without compressing ( N = D) does not alter the perplexity landscape of the network compared to the baseline model, as shown in the inset of Fig. 3b, denoting no observable change in the quality of the results. From these studies, we observe that networks trained with SCR awareness can achieve baseline accuracy without compression on both tasks, while also providing a flexible capacity to retrieval fidelity tradeoff without any overhead cost during retrieval. Furthermore, the achievable superposition can be tuned continuously by adjusting the number of stored vectors N , rather than being limited to coarse compression factors such as 2× or 4×, common in digital systems. Finally, the performance of the method generalizes across both model types as the encoding process is distribution-agnostic, as opposed to highly specialized compression methods developed for specific network architectures, like ROBE 22 (see Extended Data Fig. 4). Besides SCR awareness, robustness to analog hardware non-idealities must also be ensured. Analog memory devices exhibit conductance fluctuations, and in-memory MVM operations introduce additional effects such as IR-drop and output discretization 11,24 . To account for these factors, we extend the training procedure to include analog hardware-aware (HA) elements. Following standard practice, we introduce Gaussian noise, clipping, and ADC quantization during training to improve robustness to hardware imperfections 11,25 . Details of the HA training procedure are described in Methods. To verify robustness, we measure the performance of HA-trained networks under varying levels of injected Gaussian noise in the elements of S during evaluation, as a proxy for the device noise 11 . Figures 3c,d show the results for DLRM at 1024 × superposition and for GPT2-large at 1× and 2× superposition. The HA simulations demonstrate that performance is sustained even in the presence of substantial noise – up to 10% variation in the stored representation.  

> IV. EXPERIMENTAL VALIDATION

We validate the proposed memory architecture through hardware experiments using the PCM‑based analog in-memory computing (AIMC) chip described in 25,26 . The chip consists of 64 memory tiles, each implementing a 5

256 × 256 crossbar array of unit cells based on PCM devices. The chip – fabricated in 14nm CMOS technology node – integrates all required peripheral circuitry to program the PCM devices to target analog conductance states and to carry out in‑memory MVM operations. To match the hardware tile dimensions, we construct a tiled representation of the network embeddings evaluated in Figures 3c,d using D = 256 . The SCR S is then mapped directly onto the PCM array. Each element of S is encoded using a differential pair of PCM devices, whose conductance difference represents the signed analog value of the corresponding matrix element (Fig. 4a). The conductance states are realized physically through different amorphous–crystalline phase configurations within the PCM material, enabling the storage of analog values in the memory array. Retrieval is performed directly on chip through in-memory MVM operations with the key vectors {ki}. During readout, the rows of the array are biased with 0.2 V read voltages according to the key vector values, producing column currents proportional to the values of the stored vectors {vi}. These currents are digitized using current‑controlled oscillator‑based ADCs and converted on‑chip into signed 8‑bit integers, which we used as the final readout values. More details about the experimental platform can be found in Methods. These hardware‑generated parameters are subsequently used to perform inference in software to evaluate model accuracy. Figure 4b summarizes the resulting performance across the evaluated networks. The measured accuracy closely matches the software baselines and aligns with the simulation results reported in the previous section for noise levels of approximately 8 − 10% . These results confirm that the proposed superposed analog storage scheme can be realized on existing PCM hardware while preserving the accuracy benefits predicted by simulation.  

> V. DISCUSSION

The proposed memory architecture addresses several key challenges in the design of memory devices and large‑scale arrays. By replacing conventional row‑by‑row readout with collective readout through in‑memory MVM, it relaxes the minimum‑conductance requirements for reliable sensing while simultaneously increasing the effective read signal. Because the readout current arises from multiple devices operating in unison rather than from a single memory cell, the architecture tolerates substantially higher device resistances. This, in turn, allows the use of smaller devices 27 , enabling further increases in array density and crossbar size. In addition, the collective read mechanism can deliver substantially faster read operations even when the underlying devices exhibit very high resistances. From a performance and energy efficiency standpoint, we provide array-level projections of latency, bandwidth, and energy per effective bit in Extended Data Table II. We do not attempt direct comparisons with SRAM or DRAM memory systems, as our projections correspond to a single array and do not include the full overhead of modern memory hierarchies. Nevertheless, the array-level performance and the key properties of the proposed memory architecture – non-volatility, on-chip integration, and superposition without decompression overhead – suggest a credible research path towards integrating many such arrays within future memory systems. Moreover, the architecture provides a path for exploiting noisy analog device states. Although reliable multi-bit storage remains challenging at the level of individual PCM devices, the relevant metric in the proposed architecture is the accuracy of the collective MVM output. In Extended Data Fig. 7, we show that, in one of the cases explored in the paper, the retrieval error lies between that of 3- and 4-bit digital reference, closer on average to the 4-bit reference. This is consistent with the effective MVM precision previously demonstrated for DNN inference 28 . This suggests that useful multilevel memory characteristics can also emerge from the collective response of devices whose individual states are noisy, opening a path towards exploiting scaled analog memories without requiring precise resolution of each device state. Beyond improving on-chip storage capacity, the proposed architecture also opens opportunities for rethinking the role of AIMC hardware. In particular, AIMC tiles could be used not only for computation but also as high-density vector storage units with minimal hardware and control overhead. For example, in multi-tile AIMC chips 29–31 , some tiles could perform in-memory computation while others store DNN vectors such as embeddings. Such a configuration could reduce the reliance of AIMC systems on external memory accesses 32 and may be particularly beneficial for cost-and energy-sensitive markets such as edge computing, where large off-chip DRAM resources may be impractical 33 .Although the primary focus of this work is to address challenges related to on‑chip storage, the proposed memory architecture can also be applied to standalone analog memories, including Flash storage. In combination with emerging 3D analog memory technologies, this architecture could potentially enable the storage of trillions of DNN vectors within an extremely compact area and with minimal energy consumption. Notably, 3D analog memory is already being investigated for use in in‑memory MVM operations 34 , suggesting a natural extension of the proposed architecture, by mapping the depicted tile groups of Fig. 2 on separate tiers of the same tiles. From an algorithmic perspective, we introduced an SCR- and analog-aware training procedure to adapt the network parameters. Although such retraining is common when deploying models on reduced-precision hardware – including 6analog or low-bit quantized platforms – it can become prohibitively expensive in the era of LLMs 12,35 . Future work could therefore explore methods to reduce this overhead. For instance, a lightweight post-training adaptation step that compensates for the approximate recovery of embeddings could significantly reduce retraining overhead. Similarly, limiting parameter updates to a small subset of layers – by freezing most of the network and updating only a few layers following the embedding stage – may allow the remaining layers to remain unchanged while preserving overall performance. In summary, we introduced a memory architecture that stores high-dimensional DNN vectors as distributed analog superpositions, providing an additional scaling dimension beyond the number of physical devices and their individually distinguishable states. We demonstrated its realization using two-dimensional analog memory arrays with the required peripheral circuitry, developed training procedures that compensate for superposition and hardware non-idealities, and experimentally validated the storage and retrieval of embedding tables from a DLRM and an LLM on a prototype PCM chip. Beyond these application-level demonstrations, the architecture offers a new perspective on nanoscale memory design. By exploiting collective readout and distributed representations, it creates opportunities to use more resistive, noisy and densely integrated devices without requiring each cell to provide the precision or readout conditions demanded by conventional memory architectures. This could relax constraints associated with device miniaturization, multilevel-state reliability and array scaling, while enabling more effective use of the intrinsic analog characteristics of emerging memory technologies. More broadly, our results suggest that information representation can become a design variable alongside device materials, geometry and array organization, opening a route towards co-optimizing nanoscale devices and memory architectures for the storage demands of future neural-network hardware. 7

> Key generation

We consider three methods to generate keys: one to generate orthogonal keys, and two to generate quasi-orthogonal keys, based on pseudo-random processes. To generate the orthogonal keys used in the analysis of Extended Data Fig. 1, we utilize Hadamard matrices. Hadamard matrices provide a deterministic and efficient way to generate orthogonal keys 36 . A Hadamard matrix 

H ∈ {− 1, +1 }D×D satisfies the equation HH ⊤ = D · I. Each row (or column) of H is orthogonal to all others, making them ideal choices for key vectors. The quasi-orthogonal keys used in Extended Data Fig. 1 are sampled from the Rademacher distribution 37 , where each element is drawn independently from {− 1, +1 } with equal probability. Given sufficiently large dimensionality 

D, these vectors are quasi-orthogonal 15 .A more hardware-friendly approach to implement random sampling to create quasi-orthogonal vectors is to use the CA Rule 30 38 . Rule 30 is a one-dimensional binary cellular automaton known for producing pseudo-random sequences. Starting from a seed vector drawn from the Rademacher distribution, we evolve it using Rule 30 to generate successive key vectors. Each ki is then mapped from binary values to ±1. The transition matrix of CA Rule 30 is included in Fig. 2. Due to its hardware-friendly nature, we use this process to generate the keys in all the neural network experiments presented in the paper. 

> SCR-aware training

To enable DNN parameter storage in the proposed memory system, the networks must be adapted to be robust to the interference ϵtpr introduced by the SCR. To achieve this, we devise a training procedure that can be applied either 8during training from scratch or fine-tuning. During this procedure, we introduce the TPR transformation during the forward pass of the model, adding on the parameters the error term ϵtpr . That way, the backpropagation modifies the parameters to find optima that both lead to good task performance and to robustness to the TPR transformation. In Extended Data Fig. 3, we demonstrate the steps to introduce TPR in the forward pass. At a first step, the parameters of the model P that are to be stored in the SCR S are collected and mapped in a set of value vectors V

of dimension D, which represents the size of the memory array in the hardware. To achieve this, the parameters are all flattened in a single one-dimensional vector and then reshaped in the shape (Nvec , D ), where Nvec is the number of all value vectors necessary to store all parameters. To achieve an integer number Nvec , we pad with zeros when necessary. Then, according to the selected superposition factor, i.e., the number of vectors stored per memory array 

Nvec/arr of dimension D, we tile the parameters in a shape (Narr , N vec/arr , D ), where Narr is the number of memory arrays required to store all parameters P.In the second step, we generate all the unique keys required to bind and unbind the value vectors. Note that we only require Nvec/arr keys, as the different memory arrays Narr can share the same keys. It is crucial that the keys generated here agree with the implementation found in hardware, as the keys used here must be used during the hardware experiments as well. For our experiments, the generation of these keys happens via the CA Rule 30, which, as mentioned in the previous Methods section, is a hardware-friendly method to generate quasi-orthogonal keys. In the third step, the value vectors V are bound with the key vectors K to produce the SCR S. Notably, since the value vectors are of shape (Narr , N vec/arr , D ), the SCR is in reality a tiled representation comprising Narr matrices of shape (D, D ). Then, on step 4, using the same keys K, we retrieve all values ˆV from the SCR matrices via an unbinding operation and finally on step 5 we map them back to the original set of parameters ˆP, reversing the tiling and padding of the first step. Due to the inaccurate retrieval process of the transformation, the retrieved vectors contain an error term, which is isolated for each parameter ϵtpr = ˆP − P. Finally, in step 6, as in a conventional noise injection-based training procedures, we perturb the parameters of the model according to the collected error terms, such that during the forward pass the model uses ˆP, while during the backwards pass the backpropagation updates P. After an update step takes place (step 7), and a new set of parameters P is found, we repeat the bind and unbind process all over. This procedure adds overhead compared to the conventional fine-tuning of the model. However, we vectorize all binding and unbinding operations using the Einstein summation notation ( einsum ) offered by the PyTorch library. This optimization leads to the overhead being on par with other noise-injection or quantization-aware training proce-dures, such as ones found in popular frameworks 39,40 . Using the delta update rule to achieve superposition, though, inflicts further overhead, as the construction of the memory matrices S happens in a serial manner. However, we overcome this by adopting a batched version of the delta update rule, which reduces the serialization overhead to an acceptable amount, trading off the effectiveness of the delta rule with training overhead according to the batch size 

B. For our implementation, we set the batch size of the delta rule update to be the full number of vectors contained in the memory matrix, as we find that we can achieve good performance while keeping the delta rule overhead to a minimum. 

> Neural network and dataset selection

For our experiments, we utilized publicly available implementations and datasets to ensure reproducibility. The GPT-2-large model 19 was obtained via the Huggingface Transformers library, and all language modeling evaluations, as well as SCR-aware training, were conducted using the WikiText dataset 23 , specifically wikitext-2-raw-v1 , also accessed through Huggingface’s datasets module. For the DLRM, we employed the official implementation released by Facebook AI 18 . Training and evaluation of the DLRM were performed on the Criteo Kaggle Display Advertising Challenge dataset, which is publicly distributed by Criteo 20 .

> Analog hardware-aware training

In addition to the SCR-aware training procedure, which makes the model parameters robust to the TPR-induced interference ϵtpr , the memory matrix S must also be made robust to the variability of analog devices. Prior works have shown both in simulation 11,12 and in hardware 25 that such robustness can be achieved through three main mechanisms during training: clipping, Gaussian noise injection, and output quantization. To that end, we extend the SCR-aware training procedure to incorporate these elements. Specifically, after con-structing S during the third step of the procedure, we apply clipping to the memory matrix using a threshold defined in terms of standard deviations. Gaussian noise is then injected into each element with a standard deviation propor-9tional to its magnitude. After these two steps, the unbinding operation is performed to retrieve the vectors ˆV, which are then quantized to emulate the effect of ADC discretization. The rest of the procedure then proceeds as outlined in the respective Methods section. Adding these analog HA elements during training causes the error term that is added to the parameters P, to include both the TPR interference ϵtpr and hardware-related perturbations such as noise and quantization. As a result, backpropagation converges to parameters that are both robust to the TPR interference and to the analog hardware non-idealities. Importantly, clipping, noise injection, and output quantization are computationally inexpensive steps, and there introduce negligible overhead during training. In the hardware experiments reported in this work, networks were trained using the hyperparameters listed in Extended Data Table I. For completeness, Extended Data Fig. 5 shows the impact of different clipping and embedding quantization settings during training and evaluation under varying levels of injected Gaussian noise. 

> Hardware Platform

The hardware platform used in this work is the IBM HERMES Project chip described in Le Gallo et al. 25 . It comprises 64 compute tiles, each with a 256 ×256 crossbar array based on PCM devices. In this work, the arrays are used to store the memory matrices S with dimensionality D = 256 . A photograph of the chip and the experimental setup is shown in Extended Data Fig. 6. To map a matrix S onto the hardware, we employ the one-device programming scheme described in 25 , resulting in only two physical devices per matrix element and a total of 131 , 072 devices per memory array. Specifically for this work, we use chips that contain the Projected PCM devices described in 26 . The maximum conductance per-device used in our experiments span from 3μS to 7μS , depending on the distribution of the SCR, such that the on-chip ADC does not saturate during integration ( Imax ≈ 110 μA )41 .Key vectors with values in {± 1} are applied to the array using voltage pulses of 0.2 V and a duration of 130 ns .The minimum pulse duration is limited by the 8-bit input interface of the hardware, which results in a minimum MVM time of approximately 127 ns . For that reason, in Section V, we include a projection of the performance of hardware that is designed to support bipolar inputs – commonplace in the literature, due to the popularity of bit-slicing 42–44 . Array outputs are sensed using current-controlled oscillator-based ADCs and converted on-chip to signed 8-bit integers, which are used as the retrieved vector values in the experiments. The retrieval accuracy using the analog hardware is depicted for one of the evaluated tasks in Extended Data Fig. 7. The hardware has an effective equivalent precision between 3- and 4-bits (i.e., storing the weights in 4-bits, reading them, and performing the SCR readout MVM in full precision). This falls in line with the demonstrated precision of the analog hardware when used to perform MVMs for DNN inference 25 .For the hardware experiments reported in Fig. 4, the number of tiled SCRs required for each application was 8 for DLRM, 1002 for GPT2-large, and 501 for its 2× compressed version. These experiments were executed by serially utilizing the 64 tiles available on the hardware platform. 10
