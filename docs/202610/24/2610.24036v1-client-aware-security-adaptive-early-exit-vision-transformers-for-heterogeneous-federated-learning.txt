Abstract —Federated learning (FL) trains a shared model across data-owning clients without centralizing raw data, but client data difficulty and compute budgets can differ. We study local early-exit Vision Transformer (ViT) inference, where an intermediate classifier may return a prediction before the final Transformer stage. The proposed method replaces one global acceptance threshold with a client-specific base threshold from label entropy and shallow-exit confidence, then adjusts each input using predictive entropy, confidence, top-two class margin, and exit depth. Aggregation uses only clients that updated a parameter. Security-aware routing reaches 88.70% CIFAR-10 accuracy with 32.0% depth saving and 73.7% ImageNet-1K top-1 accuracy with 30% saving. On matched six-client non-IID CIFAR-100, full-depth accuracy is 72.28% versus 68.20–71.80% for four heterogeneous-FL baselines; robustness-aware routing reaches 70.01% with 32.55% saving. 

Index Terms —Federated learning, Vision Transformer, early exit, adaptive inference, client heterogeneity, uncertainty estima-tion, adversarial robustness. 

I. I NTRODUCTION 

Federated learning (FL) trains a shared model by exchang-ing model updates between a central server and distributed 

clients , where each client owns local data that are not up-loaded [1]–[3]. Clients can differ in hardware, sample count, label distribution, and task difficulty. In this work, training is server-coordinated, but inference is performed locally on the client/edge device. The first gap is that heterogeneous training does not itself define a client-aware inference rule. A Vision Transformer (ViT) processes an image through sequential Transformer blocks [4], [5]. An early-exit network 

adds intermediate classifiers so an input may stop before the final block [6]. An acceptance threshold specifies the confidence required to stop; otherwise the input is deferred ,meaning it continues to the next, deeper exit. Most systems use one fixed threshold or one globally shared threshold schedule. The second gap is that such policies adapt to the input but not to the client from which it originates. Confidence alone is incomplete because neural networks can be miscalibrated [7], and adversarially perturbed inputs can remain confidently wrong [8], [9]. Selective prediction therefore ranks predictions by uncertainty so difficult inputs can be deferred [10], [11]. Confidence, predictive entropy, and top-two class margin capture different aspects of that uncertainty. The third gap is a clear connection between these sample signals, client difficulty, and when deferral to a deeper exit actually reduces error. We address the three gaps with (i) a client-difficulty score from label entropy and shallow-exit confidence, (ii) sample-adaptive routing from confidence, entropy, class margin, and exit depth with a conditional-error analysis, and (iii) coverage-aware aggregation that averages a parameter only across clients that trained it. Section II reviews related work, Section III defines the method and notation, Section IV evaluates it, and Section V concludes. II. R ELATED WORK 

HeteroFL changes neural-network width , i.e., active chan-nels [12]; DepthFL changes model depth , i.e., trainable se-quential blocks [13]; and ScaleFL combines width/depth scal-ing, exits, and self-distillation [14]. ReeFL shares a recurrent exit classifier across depths and selects a client-specific distil-lation teacher [15]. FedEE uses personalized early-exit blocks for uncertainty-aware healthcare FL [16]. Here, personaliza-tion means that client statistics change the inference threshold rather than only the trained model capacity. Early exiting stops at an intermediate classifier when an ac-ceptance condition is met [6]. Token reduction instead removes redundant ViT tokens; Byun et al. combine both mechanisms using dataset profiling and intermediate confidence [17]. Max-imum softmax confidence can be miscalibrated [7]; selective classification therefore studies prediction versus deferral using risk–coverage behavior [10], with entropy and class margin providing complementary uncertainty signals [11]. An adversarial perturbation is a small, intentionally chosen input change that increases model error. Fast Gradient Sign Method (FGSM) and Projected Gradient Descent (PGD) are gradient-based attacks [8], [9]; broader suites can include Carlini–Wagner and AutoAttack [18], [19]. The remaining intersection is a federated multi-exit system that adapts inference at both the client and sample levels while correctly aggregating unequal model-prefix coverage. III. M ETHODOLOGY

A. Datasets and Experimental Setup 

We evaluate CIFAR-10 and CIFAR-100, which contain 10 and 100 image classes respectively [20], and ImageNet-1K, which contains 1000 classes [21]. An IID partition means client data are independently and identically distributed from the same class distribution. For non-IID experiments, class-wise client proportions are sampled from a symmetric Dirich-let distribution with concentration parameter α; smaller α pro-duces stronger label skew because each class is concentrated on fewer clients. All experiments use the same six-exit ViT family. CIFAR-10 uses five local epochs, the AdamW optimizer with co-sine learning-rate scheduling, standard MixUp/CutMix and RandAugment augmentation, self-distillation, and a 200-round budget. It includes IID experiments with 3, 6, and 9 clients, plus a six-client Dirichlet sweep with α ∈ { 0.5, 0.3, 0.1, 0.05 }.CIFAR-100 uses six exits with embedding dimension 256 and four attention heads, five local epochs, batch size 64, AdamW with cosine scheduling, MixUp, RandAugment, stochastic-depth regularization of 0.1, and self-distillation weight 0.1 with 

TKD = 3 . Its client-count sweep uses 2, 4, 6, 8, 10 clients at 

α = 0 .1, and its heterogeneity sweep uses six clients with the same four α values. Adversarial routing is tested with Fast Gradient Sign Method (FGSM) and 10-step Projected Gradient Descent (PGD) [8], [9]. The symbol ϵ denotes the ℓ∞ perturbation budget, i.e., the maximum absolute element-wise input change, with ϵ ∈ { 10 −4, 10 −3, 10 −2}. These attacks are generated against the deepest exit and are used for within-run policy comparisons; no adversarial training is applied.

C. CIFAR-10 and ImageNet-1K Coverage 

With 3, 6, and 9 IID CIFAR-10 clients, global test accuracy is 90.62%, 90.17%, and 89.94%, while mean client-local accuracy is 91.78%, 91.30%, and 91.02%, respectively. Under six-client Dirichlet partitions, global test accuracy decreases from 88.90% at α = 0 .5 to 79.50% at α = 0 .05 , consistent with stronger label skew. Table II isolates the CIFAR-10 accuracy–depth trade-off. Robustness-aware routing reaches 88.70% global test accuracy with 32.0% depth saving, whereas the fixed threshold reaches 87.00% with 37.5% saving. The additional uncertainty signals therefore recover 1.70 percentage points (pp) of accuracy while using 5.5 pp more of the six-stage depth budget. ImageNet-1K tests whether the same routing design trans-fers beyond CIFAR. The six-client full-depth model reaches 75.4% top-1 and 92.3% top-5 accuracy. Fixed and global resource-aware routing reach 72.1% and 72.6% top-1 accuracy with 34% and 33% depth saving, respectively. Robustness-aware routing reaches 73.7% top-1 with 30% saving (Ta-ble III).

E. CIFAR-100 Scalability, Heterogeneity, and Efficiency 

Figure 2(a) shows that global test accuracy changes by 1.12 pp between two and ten clients, whereas worst-client accuracy reaches 58.61% at six clients, 9.83 pp below the corresponding global test accuracy. Cumulative two-way model communica-tion grows from 9.93 to 49.66 GiB (gibibytes) as the client count increases from two to ten [Fig. 2(b)], consistent with the communication definition in Section III-G. Under six-client Dirichlet partitions, reducing α from 0.50 to 0.05 lowers global accuracy by 17.85 pp and worst-client accuracy by 36.23 pp [Fig. 2(c)]. The stronger degradation of the worst client motivates replacing one global threshold with client-dependent acceptance thresholds. Table V and Fig. 2(d) compare routing policies on the same CIFAR-100 global test split. Fixed and global resource-aware routing save about 36% of stage depth but lose about 3.4 pp relative to full-depth inference. Robustness-aware rout-ing reaches 70.01% at average depth 4.05, corresponding to 32.55% depth saving. Relative to the fixed threshold, it recovers 1.21 pp of accuracy while using 3.35 pp more of the depth budget.

This paper studied local early-exit inference for heteroge-neous FL and asked whether decisions should depend on both the client and the current sample. The framework combines a client-specific base threshold from label entropy and shallow-exit confidence with sample confidence, predictive entropy, class margin, and relative exit depth; coverage-aware aggre-gation averages a parameter only across clients that trained it. The conditional-error analysis shows that deferral helps only when the deeper exit is more accurate on the deferred subset. Across CIFAR-10, CIFAR-100, and ImageNet-1K, this produces a consistent accuracy–depth trade-off: robustness-aware routing reaches 88.70% on CIFAR-10 with 32.0% depth saving; CIFAR-100 full-depth accuracy is 72.28%, 0.48 pp above the strongest matched baseline (ReeFL at 71.80%), while robustness-aware routing reaches 70.01% with 32.55% saving; and ImageNet-1K reaches 73.7% top-1 with 30% saving versus 75.4% at full depth. Under Fast Gra-dient Sign Method (FGSM) and 10-step Projected Gradient Descent (PGD), robustness-aware routing also stays above fixed-threshold routing in the tested settings. The remaining limitations are matched hardware latency/FLOP evaluation and broader adversarial suites. ACKNOWLEDGMENT
