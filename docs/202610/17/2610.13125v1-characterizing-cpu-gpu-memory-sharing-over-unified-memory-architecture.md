## 摘要
统一内存架构（UMA）使 CPU 和 GPU 能够共享同一物理内存。然而，其复杂性与不透明性常常迫使应用回退到低效的数据复制，或采用会牺牲性能甚至破坏正确性的错误直接访问方式。本文对 UMA 上的 CPU-GPU 内存共享进行了全面研究，涵盖四个平台上数据平面传输和控制平面协调的正确性与性能。研究得出四项发现，并以此指导 libumsh 的设计：该可移植库能够在跨平台场景下实现正确且高效的内存共享，并可扩展至新兴平台（如 NVIDIA DGX Spark）。在九个真实系统中的应用表明，libumsh 将数据平面时间缩短了 16%–75%，并将控制平面开销降低了 7%–90%。

## Abstract
Unified Memory Architecture (UMA) enables the CPU and GPU to share a single physical memory. However, its complexity and opacity often drive applications back to inefficient copying or to incorrect direct access that sacrifices performance or even correctness. This paper presents a comprehensive study of CPU-GPU memory sharing on UMA, covering correctness and performance across data-plane transmission and control-plane coordination on four platforms. It yields four findings that guide libumsh, a portable library that delivers correct and efficient memory sharing across platforms and extends to emerging ones (e.g., NVIDIA DGX Spark). Applied to nine real-world systems, libumsh reduces data-plane time by 16-75% and control-plane overhead by 7-90%.
