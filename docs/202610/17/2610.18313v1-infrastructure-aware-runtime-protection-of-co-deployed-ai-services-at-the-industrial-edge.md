## 摘要
在现代生产线上，单个边缘设备会同时运行多个 AI 服务，例如扭矩控制模型、视觉检测器和预测性维护程序。所有这些服务共享同一 CPU 和同一网络分段运行。当共享网络分段发生拥塞时，服务并不会崩溃，而只是产生不准确或过时的输出，无法再反映工厂的实际状况。本文聚焦于工业边缘系统中的这类静默式、部分失效场景。

我们将每个协同部署的服务视为一个自主智能体。我们提出运行时关键性评分（Runtime Criticality Score，RCS），各服务智能体利用该评分在任意时刻表达其在资源约束下的内在效用和生存紧迫性。该评分由六个归一化维度计算得出，涵盖物理后果、推理质量、输入新鲜度、近期可用性压力、执行器耦合程度，以及主机上可用的保护措施。各维度的权重通过由当前观测到的扰动类型驱动的轻量级贝叶斯更新进行在线调整，因此，同一服务在网络延迟与热节流条件下会获得不同的排序。智能体通过开放的点对点发现通道向同伴发布其 RCS，并在无需中央控制器的情况下，利用该评分协商三类事项：（i）在自身主机上执行本地阈值约束；（ii）当当前主机已无法对其提供保护时，迁移至愿意接纳它的对等节点；（iii）当现任协调者自身受损时，重新分配协调角色。除能够即时发现静默退化外，该框架还提供了一个具体实例，展示了去中心化、基于物理基础的智能体协同。隶属于不同所有者的智能体可以在开放网络中发布能力、竞标保护资源并进行重组。

## Abstract
In modern production lines, a single edge device simultaneously runs multiple AI services like a torque-control model, a vision inspector, a predictive maintenance routine. All these services run on the same CPU and same shared network segment. When the shared network segment saturates, the services do not crash. The services just produce outputs that are inaccurate or stale, and no longer reflect the plant's conditions. Our paper targets this class of silent, partial failure scenarios in Industrial Edge Systems.   We treat each co-deployed service as an autonomous agent. We introduce the Runtime Criticality Score (RCS), which each service agent uses to express at any moment, its intrinsic utility and survival urgency under resource constraints. The score is computed from six normalized dimensions covering physical consequence, inference quality, input freshness, recent availability stress, actuator coupling, and available protective actions on the host. Its dimension weights are adjusted online through a lightweight Bayesian update driven by the type of disturbance currently observed, so the same service is ranked differently under a network delay than under thermal throttling. Agents publish their RCS to peers over an open, peer-to-peer discovery channel, and use it to negotiate three things without a central controller: (i) local threshold enforcement on their own host, (ii) migration to a willing peer when the current host can no longer protect them, (iii) reassignment of the coordination role when the incumbent coordinator is itself impaired. Beyond the immediate benefit of catching silent degradation, the framework contributes a concrete instance of decentralized, physically grounded agent coordination. Agents belonging to different owners can advertise capabilities, bid for protection, and reorganize across an open network.
