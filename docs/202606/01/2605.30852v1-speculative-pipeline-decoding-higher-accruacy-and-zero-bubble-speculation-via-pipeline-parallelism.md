## 摘要
推测解码（SD）采用先起草后验证的范式来加速低并发大语言模型（LLM）的推理。然而，主流方法通常依赖于多令牌预测，这会导致预测难度不断增加和串行起草延迟。为了解决这些问题，我们提出了推测流水线解码（SPD），这是一个突破性的框架，释放了流水线并行的真正潜力。通过将目标LLM划分为n个流水线阶段，SPD允许LLM并行处理n个令牌，从而加速解码。为了在单序列解码中持续填充流水线，一个推测模块聚合来自不同流水线深度的中间特征来预测下一个令牌，与目标模型的流水线步骤严格并行执行，以实现有限的难度、更高的接受率和零延迟气泡。我们的实验表明，与主流基线相比，SPD实现了显著更高的理论加速比，为LLM解码加速提供了一个高度可扩展的解决方案。我们的代码可在https://github.com/yuyijiong/speculative_pipeline_decoding获取。

## Abstract
Speculative Decoding (SD) accelerates low-concurrency LLM inference by employing a draft-then-verify paradigm. However, mainstream methods typically rely on multi-token prediction, which introduces escalating prediction difficulty and serial drafting latency. To address these, we propose Speculative Pipeline Decoding (SPD), a groundbreaking framework that unlocks the true potential of pipeline parallelism. By partitioning the target LLM into $n$ pipeline stages, SPD allows LLM to process $n$ tokens in parallel to accelerate decoding. To continuous fill the pipeline in single sequence decoding, a speculation module aggregates intermediate features across different pipeline depths to predict the next token, executing strictly in parallel with the target model's pipeline step, to realize bounded difficulty, higher acceptance rates, and zero latency bubbles. Our experiments demonstrate that SPD achieves a significantly higher theoretical speedup compared to mainstream baselines, offering a highly scalable solution for LLM decoding acceleration. Our code is available at https://github.com/yuyijiong/speculative_pipeline_decoding

### 1. 论文的核心问题与整体含义

*   **研究动机：** 大语言模型（LLM）的自回归推理受限于内存带宽瓶颈。推测解码（Speculative Decoding, SD）通过“起草-验证”范式来缓解此问题，但其主流方法（如EAGLE系列）基于**多令牌预测范式**。该范式存在两个结构性缺陷：
    *   **预测难度累积：** 随着起草序列变长，后续令牌的预测依赖于浅层、未验证的状态，导致分布外（OOD）误差累积，接受率急剧下降，使深度推测效率低下。
    *   **串行起草延迟：** 目标模型在等待起草模型串行生成候选序列时会产生计算空闲，导致“延迟气泡”，降低了理论加速比。
*   **整体含义：** 本文旨在从根本上解决上述问题，通过引入**流水线并行**的全新范式来替代传统的多令牌预测，实现有界预测难度和零延迟气泡的推测解码。

### 2. 论文提出的方法论

*   **核心思想：推测流水线解码 (Speculative Pipeline Decoding, SPD)**
    *   将目标LLM划分为`n`个流水线阶段，使其能同时处理`n`个处于不同深度的令牌，打破串行限制。
    *   设计一个**推测模块（Speculation Module）**，在执行目标模型流水线步骤的**同时**预测下一个令牌，以持续填充流水线，消除空闲等待。

*   **关键技术细节：**
    *   **多深度特征聚合 (Multi-Depth Feature Aggregation):**
        *   为克服预测难度，推测模块不再仅依赖浅层特征。对一个经过`k`个流水线阶段的令牌，系统会从其**嵌入层、中间层和最深层**（基于其当前进度`lmax`）三个位置提取目标模型的隐藏状态`H`。
        *   这些状态被拼接后通过全连接层（FC）投影，生成一个综合特征向量`g`，数学表达为：
            `gkt = FC(Concat[H0_t, H_{lmax/2}_t, H_{lmax}_t])`
        *   由于最深可用层数被流水线阶段数`n`所固定，最大信息缺失也被数学上限定了，从而**严格限制了预测难度的增长**，解决了传统方法中误差无限累积的问题。
    *   **零等待同步执行 (Zero Mutual Waiting Overhead):**
        *   SPD将推测模块的执行窗口**前移**，使其基于流水线的**输入状态（即未经历当前步骤的状态）** 而非输出状态运行。
        *   这样一来，推测模块的计算完全与目标模型的流水线前向步骤**并行**。理论上，只要推测模块的层数`Ls`不超过单个流水线阶段的层数`L/n`，其计算延迟就能被**完全掩盖**。
    *   **流水线验证与回滚:**
        *   采用流式验证。当一个令牌走完流水线全过程后，目标模型使用其标准语言模型头（LM head）产生真实分布，并据此验证在`n`步前推测的令牌。
        *   若推测被拒绝，系统立即执行回滚协议：截断KV缓存、清空流水线、并基于验证结果重新采样正确的令牌注入流水线首个阶段。
