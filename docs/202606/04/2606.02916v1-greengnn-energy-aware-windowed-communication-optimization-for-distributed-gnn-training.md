## 摘要
大规模图神经网络（GNN）训练通常需要分布式集群，因为图结构和特征张量已无法容纳在单个节点的内存中。在基于采样的训练中，每个小批次会扩展为一个跨分区的感受野，每个周期触发数千次远程特征抓取。这会浪费能量，主要有两个原因：每次小型RPC都会产生固定的启动和协议开销，且GPU在等待远程特征时持续消耗大量基线功耗。我们提出GreenGNN，一个能量感知的分布式GNN训练系统，它通过利用邻居采样突发且短暂的时间局部性来降低通信能耗。GreenGNN将训练分组为包含W个连续小批次的窗口，将每个窗口的热点特征暂存在本地缓存中，并将来自每个分区所有者的远程请求合并为少量批量传输。这摊薄了RPC开销，同时为缓存未命中保留按需路径。由于窗口大小控制着通信摊薄与热集陈旧之间的权衡，GreenGNN使用离散事件模拟器离线选择W，该模拟器借助混合能量模型重放确定性的单周期访问轨迹。我们在DGL上实现了GreenGNN，并在4节点GPU集群上使用基准数据集进行了评估。在不同的数据集和批次大小下，GreenGNN相较于基线减少了27--43%的总系统能耗，同时将端到端吞吐量最高提升了3.9倍。GPU能耗下降36--71%，这得益于更少的RPC启动次数和更低的GPU停顿时间。

## Abstract
Large-scale graph neural network (GNN) training often requires distributed clusters because graph structure and feature tensors no longer fit in a single node's memory. In sampling-based training, each mini-batch expands into a receptive field that spans partitions and triggers thousands of remote feature fetches per epoch. This wastes energy for two main reasons: each small RPC pays a fixed initiation and protocol cost, and GPUs continue drawing substantial baseline power while waiting for remote features. We present GreenGNN, an energy-aware distributed GNN training system that reduces communication energy by exploiting the bursty, short-lived temporal locality of neighbor sampling. GreenGNN groups training into windows of W consecutive mini-batches, stages each window's hot features in a local cache, and merges remote requests from each partition owner into a small number of bulk transfers. This amortizes RPC overhead across many features while preserving an on-demand path for cache misses. Because window size controls the trade-off between communication amortization and hot-set staleness, GreenGNN selects W offline using a discrete-event simulator that replays a deterministic one-epoch access trace with a hybrid energy model. We implement GreenGNN on DGL and evaluate it on a 4-node GPU cluster with benchmark datasets. Across datasets and batch sizes, GreenGNN reduces total system energy by 27--43% relative to baseline while improving end-to-end throughput by up to 3.9x. GPU energy drops by 36--71%, driven by fewer RPC initiations and lower GPU stall time.

## 一、核心问题与研究背景

**核心问题**  
大规模图神经网络（GNN）在分布式训练时，通信能耗远高于计算能耗（数据移动占总能耗76–85%），这严重制约了训练的可持续性和成本效率。其根本原因有两个：

- **小RPC的固定启动开销**：每次远程特征抓取（通常仅几十到几百个节点）都会产生固定的CPU中断、协议处理等能量消耗，在小请求场景中该固定成本占比极高（49–99%）。
- **GPU空闲等待功耗**：GPU在等待远程特征到达时仍维持较高的基线功耗，累积形成显著能量浪费。

**研究动机**  
现有分布式GNN训练系统（如DistDGL、BGL、PaGraph等）主要面向吞吐量优化，把通信视为延迟和带宽问题，并未将能量作为首要优化目标，也未有效利用GNN采样访问的突发、短暂时间局部性。因此，急需一种能量感知的通信优化方法，在保证精度的同时大幅降低系统能量开销。

## 二、方法论

**核心思想**  
GreenGNN观察到邻居采样具有“突发且短暂的时间局部性”：在连续的若干小批次（mini-batch）内，少数远程节点被高频访问，但很快会被替换出工作集。基于此，系统采用**窗口化训练 + 批量通信合并**策略，将原本数以千计的小RPC请求在窗口边界合并为少量大规模批量传输，并按窗口周期性地刷新本地缓存。

**关键技术细节**

- **离线阶段**
  1. **收集确定性访问轨迹**：在固定随机种子和分区下，进行一次低GPU频率的单周期采样，记录每个小批次所需的远程节点ID。
  2. **硬件能量画像**：用微基准测试测量每个远程分区的RPC固定启动能耗 \(\epsilon_{\text{init}}(m)\)、单位特征传输能耗 \(\epsilon_{\text{payload}}(m, x)\)、相应延迟项以及GPU空闲功率 \(P_{\text{idle}}\)。
  3. **窗口大小自动调优**：离散事件模拟器结合混合能量模型，对每个候选窗口 \(W\) 重放访问轨迹，统计：
     - **窗口重建事件**：在窗口边界计算新热点集与上一缓存的差异，按所属分区合并为一次批量RPC。
     - **残余缺失事件**：窗口内未命中热点的节点继续按需抓取。
     - **GPU停顿时间**：综合重建和缺失的传输时间，乘以 \(P_{\text{idle}}\) 得到停顿能耗。
  
  总分析能耗为：
  \[
  E_{\text{phy}}(W) = E_{\text{rebuild}}(W) + E_{\text{miss}}(W) + E_{\text{stall}}(W)
  \]
  然后，用一个轻量级的排序校正模型 \(L(W)\) 来修正模拟器无法精确捕捉的系统效应（如计算与通信的重叠、带宽饱和等），最终得分 \(E_{\text{net}}(W)=E_{\text{phy}}(W)+L(W)\)，选择得分最低的 \(W^*\)。

- **运行时执行**
  使用流水线并行模式，后台线程在训练当前窗口的同时预取下一窗口的热点特征并构建缓存；窗口内命中的请求直接从缓存读取，缺失部分仍通过异步按需路径获取。这样将每批次多次小RPC变为每窗口几次大传输，大幅摊薄启动开销，并降低GPU停顿时间。

**公式与算法关键点**
- 窗口重建能耗（式1）：累计各窗口边界各分区所有者发起批量传输的启动开销和有效载荷能耗。
- 残余缺失能耗（式2）：累计窗口内各批次、各分区所有者按需请求的启动和载荷能耗。
- GPU停顿能耗（式3）：\(E_{\text{stall}}(W)=P_{\text{idle}}\cdot T_{\text{stall}}(W)\)，其中 \(T_{\text{stall}}\) 由所有传输事件的延迟（考虑最慢分区和带宽上限）累加得到。
- 排序校正损失（式5）：使用成对排序损失（pairwise ranking loss）训练线性模型，确保模拟器给出的窗口排序与实际测量排序一致。

## 七、优点

- **系统性能量优先**：首次将能量作为分布式GNN训练的主要优化目标，并系统量化了通信开销结构。

- **物理模型 + 学习校正的自动调优**：结合分析模型的可解释性与学习排序的修正能力，以极低离线成本获得高质量窗口选择。

## 八、不足与局限

- **硬件同质性假设**：当前能量模型和调优器假定集群内所有GPU同构，未考虑混合GPU代数或异构环境，限制了在大规模异质集群上的直接应用。
- **窗口大小静态配置**：窗口大小在训练前一次性选定，无法适应训练过程中访问模式的潜在变化（如热集漂移），可能遗留部分优化空间。
