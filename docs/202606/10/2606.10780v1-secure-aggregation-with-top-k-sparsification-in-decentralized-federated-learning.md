## 摘要
安全聚合是缓解联邦学习中梯度泄漏的关键组件，但其通信成本通常与梯度维度成正比。对于大型模型，这一问题尤为突出，而在带宽有限且节点不可靠的去中心化联邦学习中更为严重。Top-K梯度稀疏化是一种有效减少通信量的方法，仅传输整个梯度的少数条目，同时保持有竞争力的模型精度。然而，每个用户选择的Top-K条目不可预测且因用户而异，这给高效的稀疏安全聚合带来了挑战。本文研究了在用户掉线和用户共谋条件下，去中心化联邦学习中基于信息论安全聚合的Top-K稀疏化问题。我们提出了一种通信高效的稀疏安全聚合方案，该方案将维度相关的开销转移到离线阶段，并使用随机掩码和置换来保护私有梯度。实验结果表明，即使在仅1%梯度稀疏化的情况下，我们的方案也能保持与全梯度聚合相当的精度，同时大幅降低通信成本。

## Abstract
Secure aggregation is a vital component for mitigating gradient leakage in federated learning, but its communication cost conventionally scales with the gradient dimension. This becomes prohibitive for large models and even more pronounced in decentralized federated learning with limited bandwidth and unreliable nodes. Top-K gradient sparsification is an effective approach to reduce communication by transmitting only a few entries of the full gradient, while maintaining competitive model accuracy. Nevertheless, the top-K entries selected by each user are unpredictable and vary across users, which poses a challenge for efficient sparse secure aggregation. This paper studies information-theoretic secure aggregation with top-K sparsification in decentralized federated learning under user dropouts and user collusion. We propose a communication-efficient sparse secure aggregation scheme that offloads dimension-dependent overhead to an offline phase and protects private gradients using random masks and permutations. Experimental results demonstrate that our scheme preserves accuracy comparable to full-gradient aggregation even with only 1% gradient sparsification, while substantially reducing the communication cost.

### **2. 方法论**

论文提出了一种两阶段的通信高效稀疏安全聚合方案，其核心思想是**将维度相关的高开销操作转移到离线阶段**，并利用**随机排列和掩码**技术保护私有梯度。

- **核心思想**：
    - **离线阶段（Offline Phase）**：在模型训练开始前，用户之间交换加密的随机噪声和排列信息。此阶段的通信开销与梯度维度`L`相关，但因其在训练前完成，不占用训练时的关键通信资源。
    - **在线阶段（Masked-Input & Mask-Elimination）**：通过两个在线通信阶段完成聚合。在线通信量与稀疏度`K`和用户数相关，而与总维度`L`解耦。

- **关键技术细节与流程**：
    1.  **离线阶段（随机密钥与排列共享）**：
        - 每个用户`n`独立生成一个长度为`L`的随机排列`π_n`和一个随机掩码向量`r_n`。
        - 用户`n`将排列`π_n`（通过其逆排列`σ_n`的矩阵表示`P_n`）和经排列的掩码`r_n`进行**秘密共享**。具体做法是将`P_n`的行向量和`r_n`的元素分成`D = U - T`块，并利用拉格朗日多项式编码，注入`T`个随机噪声以提供抗共谋安全性。
        - 用户之间交换这些编码后的多项式求值。所有在本阶段生成和接收的信息构成了用户`n`的随机变量`Z_n`。

    2.  **掩码输入阶段（Masked-Input Phase）**：
        - 用户`n`确定其梯度`W_n`的Top-K索引集`K_n`和对应的值`{w}`。
        - **保护索引**：用本地随机排列`π_n`对索引集`K_n`进行混淆，得到`{π_n(k)}`。
        - **保护值**：用本地随机掩码`r_n`对梯度值进行盲化，得到`x_n,k = w_n,k + r_n,k`。
        - 用户`n`广播其掩码消息`X_n = {π_n(k)， x_n,k | k ∈ K_n}`。此阶段后可能发生用户掉线，定义存活的用户集为`U_1`。

    3.  **掩码消除阶段（Mask-Elimination Phase）**：
        - 每个幸存用户`n ∈ U_1`利用其离线阶段的秘密`Z_n`和接收到的`X_m`，计算并广播一条辅助消息`Y_n`。该消息本质上是所有用户掩码值`x_m,k`与其对应排列和秘密共享多项式的函数。
        - 经过可能的第二轮掉线后，任何幸存用户`n ∈ U_2`收集到足够多（至少`D + T`条）的`Y_m`消息后，即可通过拉格朗日插值恢复出一个聚合多项式。
        - 对该多项式在特定点求值，可以得到所有用户稀疏梯度值的加权和。通过利用离线阶段共享的排列矩阵知识，可以将这些加权和正确地还原到梯度向量的原始索引位置上，从而解码出最终的安全聚合结果`∑ TopK(W_n)`。

- **方案特性**：
    - **安全性**：任何至多`T`个共谋用户的视角，除最终聚合结果和自身输入外，无法获得其他用户梯度的任何信息。这由随机排列提供的“一次一密”和秘密共享中注入的噪声共同保证。
    - **容错性**：方案天然支持掉线用户，只要总存活用户数不少于`U`即可成功解码。
    - **通信率**：在线第一阶段的通信率与稀疏度`K`相关，第二阶段通信率为`1/(U-T)`，均与总维度`L`无关。
