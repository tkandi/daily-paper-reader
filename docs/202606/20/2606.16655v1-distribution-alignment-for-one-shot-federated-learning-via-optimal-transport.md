## 摘要
单次联邦学习（OSFL）解决了客户端仅与服务器交互一次的极端通信场景，这放大了客户端数据分布异质性的影响。特别是，跨客户端的领域偏移与标签偏移相互作用，导致特征表示错位，且无法通过迭代优化纠正。现有的OSFL方法依赖蒸馏、服务器端生成或基于集成的聚合，但假设表示已对齐，或分别处理领域和标签偏移。我们引入SLOT-Align（单轮、免学习的最优传输对齐），一种面向OSFL的几何感知特征协调框架。SLOT-Align使用共享的冻结编码器提取紧凑特征统计量，通过Bures-Wasserstein重心构建全局参考，并利用闭式测地最优传输映射对齐局部表示。该方法计算高效，可与依赖冻结编码器的现有OSFL流程结合，无需修改其训练过程。在多个基准、预训练骨干和OSFL方法上的大量实验表明，SLOT-Align在联合领域和标签偏移下一致地提高准确性和鲁棒性。

## Abstract
One-Shot Federated Learning (OSFL) addresses extreme communication regimes in which clients interact with the server only once, amplifying the impact of heterogeneous client data distributions. In particular, the interaction of domain shift and label shift across clients induces misaligned feature representations that cannot be corrected through iterative optimization. Existing OSFL methods rely on distillation, server-side generation or ensemble-based aggregation, but assume aligned representations or address domain and label shift separately. We introduce SLOT-Align (Single-round, Learning-free Optimal Transport Alignment), a geometry-aware feature harmonization framework for OSFL. SLOT-Align uses a shared frozen encoder to extract compact feature statistics, constructs a global reference via Bures-Wasserstein barycenters, and aligns local representations using closed-form geodesic optimal transport maps. The method is computationally efficient and can be combined with existing OSFL pipelines relying on frozen encoders without modifying their training procedures. Extensive experiments across multiple benchmarks, pretrained backbones, and OSFL methods show that SLOT-Align consistently improves accuracy and robustness under joint domain and label shift.

## 1. 核心问题与研究动机
- **OSFL 的极端通信限制**：单次联邦学习要求客户端与服务器仅交互一次，无法通过多轮迭代优化缓解数据分布差异。
- **复合数据异质性**：客户端间同时存在 **领域偏移**（输入分布 \(P_k(\mathbf{x})\) 不同）和 **标签偏移**（标签边缘分布 \(P_k(y)\) 不同），两者交互导致特征表示错位，且无法事后纠正。
- **现有方法不足**：蒸馏、生成、集成等 OSFL 方法或隐含假设特征已对齐，或将领域与标签偏移分开处理，未系统解决联合偏移下的几何错位。
- **目标**：在不修改下游 OSFL 流程的前提下，实现一种 **免学习、几何感知的特征协调机制**，提升对复合偏移的鲁棒性。

## 2. 方法论：SLOT-Align
### 2.1 核心思想
- 在 **2-Wasserstein 空间** 中，用 **高斯代理** 近似客户端特征分布，通过 **Bures-Wasserstein 重心** 构建全局参考，再以 **闭式测地最优传输映射** 将局部特征对齐到参考，从而实现轻量级、单轮的分布对齐。

### 2.2 关键技术细节
1. **共享冻结编码器**  
   所有客户端使用同一个冻结的预训练编码器 \(f_\theta: \mathcal{X} \to \mathbb{R}^m\)，确保特征处于共同度量空间。

2. **局部紧凑统计量提取**  
   - 客户端计算特征均值 \(\boldsymbol{\mu}_k\) 与样本协方差 \(\hat{\boldsymbol{\Sigma}}_k\)。
   - 为数值稳定，采用 **Ledoit-Wolf 收缩估计** 得到正定协方差 \(\boldsymbol{\Sigma}_k\)，形成高斯代理 \(\mathcal{N}(\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\)。

3. **全局参考构建**  
   - 服务器以加权平均得到全局均值 \(\boldsymbol{\mu}_b\)，权重为 \(w_k = n_k / N\)。
   - 协方差则通过 **Bures-Wasserstein 重心** 的固定点迭代最小化加权 Bures 距离：  
     \(\boldsymbol{\Sigma}^{(t+1)} = \sum_k w_k \left( (\boldsymbol{\Sigma}^{(t)})^{1/2} \boldsymbol{\Sigma}_k (\boldsymbol{\Sigma}^{(t)})^{1/2} \right)^{1/2}\)，  
     得到全局协方差 \(\boldsymbol{\Sigma}_b\)。

4. **测地最优传输对齐**  
   - 从 \(\mathcal{N}(\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\) 到 \(\mathcal{N}(\boldsymbol{\mu}_b, \boldsymbol{\Sigma}_b)\) 的 2-Wasserstein 最优传输映射为仿射变换：  
     \(\mathbf{A}_k = \boldsymbol{\Sigma}_b^{1/2} (\boldsymbol{\Sigma}_b^{1/2} \boldsymbol{\Sigma}_k \boldsymbol{\Sigma}_b^{1/2})^{-1/2} \boldsymbol{\Sigma}_b^{1/2}, \quad \mathbf{b}_k = \boldsymbol{\mu}_b - \mathbf{A}_k \boldsymbol{\mu}_k\)。
   - 引入 **插值系数** \(\tau \in [0,1]\)，定义移位插值映射 \(T_k^{(\tau)}(\mathbf{z}) = ((1-\tau)\mathbf{I} + \tau \mathbf{A}_k)\mathbf{z} + \tau(\boldsymbol{\mu}_b - \mathbf{A}_k \boldsymbol{\mu}_k)\)，\(\tau=0\) 无对齐，\(\tau=1\) 完全对齐。
   - 该映射正好使高斯代理沿 Wasserstein 测地线从 \(\mathcal{N}(\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\) 平滑演变至 \(\mathcal{N}(\boldsymbol{\mu}_b, \boldsymbol{\Sigma}_b)\)，且 \(W_2\) 距离线性缩减。

5. **集成**  
   - 客户端将变换应用于所有局部特征 \(\mathbf{z}' = T_k^{(\tau)}(\mathbf{z})\)，再输入下游 OSFL 算法（如 O-FedAvg、FedCGS、FedPFT）。
   - 整个过程于服务器和客户端各需一次通信，且仅额外传输均值与协方差。
