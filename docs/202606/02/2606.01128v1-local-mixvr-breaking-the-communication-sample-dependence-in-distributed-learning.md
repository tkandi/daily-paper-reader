## 摘要
通信开销是可扩展分布式学习中的关键瓶颈。现有方法，如Local SGD、Minibatch SGD及其加速变体，虽然旨在高效利用数据点，但其通信轮数复杂度仍与总样本数$N$成正比。本文提出Local MixVR，一种将局部更新与方差缩减技术相结合以减轻局部噪声的分布式框架。我们证明Local MixVR是首个消除通信复杂度对$N$依赖的分布式方法，其复杂度仅随工作节点数量$M$缩放。在常见情形$M<O\left(N^{1/4}\right)$下，Local MixVR优于最先进的Minibatch Accelerated SGD基线，弥合了分布式优化中长期存在的差距，并建立了通信高效训练的新范式。

## Abstract
Communication overhead is a crucial bottleneck in scalable distributed learning. While existing methods aim to efficiently utilize data points, such as Local SGD, Minibatch SGD, and their accelerated variants, they still exhibit communication-round complexity that scales with the total number of samples $N$. In this paper, we introduce Local MixVR, a distributed framework that integrates local updates with variance-reduction techniques to mitigate local noise. We show that Local MixVR is the first distributed method to eliminate the dependence of communication complexity on $N$, achieving a complexity that scales only with the number of workers $M$. In common regimes where $M<O\left(N^{1/4}\right)$, Local MixVR outperforms the state-of-the-art Minibatch Accelerated SGD baseline, bridging a long-standing gap in distributed optimization and establishing a new paradigm for communication-efficient training.

## 2. 方法论：Local MixVR 框架
Local MixVR 围绕**抑制局部漂移（worker drift）** 这一核心挑战，将三种方差缩减技术有机融合，从而在极低频通信下维持最优收敛速率。

### 2.1 三大核心组件
1. **局部双动量（Local Double-Momentum, \(\mu^2\)-SGD）**
   - **Anytime Averaging（动量平均）**：在局部迭代中维护模型参数的动量平均 \(\bar{x}_t\)，利用 \(\gamma_t = \frac{2}{t+2}\) 使得 \(\bar{x}_{t+1} - \bar{x}_t\) 缓慢变化，像“锚”一样抑制各 worker 的局部漂移。
   - **STORM 估计器（方差缩减动量）**：采用递归修正项 \((1-\beta_t)(\nabla f(\bar{x}_t;z_t) - \nabla f(\bar{x}_{t-1};z_t))\) 消除标准动量的偏差，得到无偏梯度估计 \(\mathbf{d}_t\)，方差降至 \(O(\tilde{\sigma}^2/t)\)。多 worker 聚合后进一步降至 \(O(\tilde{\sigma}^2/(Mt))\)。

2. **混合局部-小批量预算分配（Hybrid Local-Minibatching）**
   - 引入混合参数 \(\alpha \in (0,1)\)，将每轮的 \(K\) 个样本预算分为两部分：
     - \(K_{\text{loc}} = \lfloor (1-\alpha)K \rfloor\) 步局部优化（推进优化轨迹）；
     - \(K_{\text{avg}} = \lceil \alpha K \rceil\) 步小批量平均（同步前集中降噪）。
   - 同步后不直接平均动量估计器，而是通过**累积阶段**（Algorithm 2）用相同小批量在全局参数 \(\bar{x}_t\) 和上一轮局部参数 \(\bar{x}^{(i)}_{t-1}\) 上分别计算梯度，利用两者之差来抵消局部漂移，且方差被 \(K_{\text{avg}}\) 缩放。

3. **漂移修正机制（Drift Correction Mechanism）**
   - 同步时，将每个 worker 的动量估计器重新锚定到全局模型：
     \[
     \tilde{\mathbf{d}}^{(i)}_t = (1-\beta_t)\mathbf{d}^{(i)}_{t-1} + \beta_t \nabla f(\bar{x}_t;B^{(i)}_t) + (1-\beta_t)\bigl(\nabla f(\bar{x}_t;B^{(i)}_t) - \nabla f(\bar{x}^{(i)}_{t-1};B^{(i)}_t)\bigr)
     \]
   - 该修正移除了因局部路径累积的偏差，使期望始终等于 \(\nabla f(\bar{x}_t)\)。

### 2.2 算法流程（Algorithm 3）
- 每轮内 worker 先执行 \(K_{\text{loc}}\) 步局部 \(\mu^2\)-SGD；
- 同步模型参数 \(\bar{x}_t, x_t\)；
- 执行累积与漂移修正（Algorithm 2）获得 \(\tilde{\mathbf{d}}^{(i)}_t\)；
- 平均并同步修正后的估计量 \(\mathbf{d}_t = \frac{1}{M}\sum_i \tilde{\mathbf{d}}^{(i)}_t\)；
- 用同步估计量进行一步统一更新，然后进入下一轮局部阶段。

### 2.3 理论保证（Theorem 3.2）
- 取 \(\alpha=\frac12, \beta_t=\frac{1}{t}, \gamma_t=\frac{2}{t+2}, \eta_t=t\cdot\eta\)，适当设定 \(\eta\)，得收敛速率：
  \[
  \Delta_T \le O\left( \frac{L D_1^2}{KR} + \frac{\tilde{\sigma} D_1}{K^{1/2}R} + \frac{\tilde{\sigma} D_1}{\sqrt{MKR}} \right),\quad \tilde{\sigma}=\Theta(\sigma+\sigma_L D_1)
  \]
- **关键结论**：所需最小通信轮数 \(R_{\min} = \Omega(M)\)，**与样本总量 \(N\) 无关**。在 \(M \le O(N^{1/4})\) 时超越 Minibatch ASGD。
