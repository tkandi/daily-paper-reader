## 摘要
哈希学习（HL）是一种高效的表示学习方法，将实值数据映射为紧凑的二进制表示。传统的HL方法通常要求用户将个人数据上传至中央服务器，这与日益严格的数据安全法规相违背。联邦学习（FL）提供了一种去中心化的范式，用于在不集中私有数据的前提下学习全局最优模型。然而，大多数FL方法依赖传输大规模实值梯度信息，导致高昂的通信开销和潜在的隐私风险。将HL集成到FL中是一种有希望的解决方案，但现有HL方法受限于二进制码的表示能力，可能降低模型精度。为应对这一挑战，我们提出联邦哈希投影隐因子（FHPLF）模型。FHPLF引入了三项关键创新：(a) 用二进制梯度样矩阵替代实值梯度矩阵，显著降低计算、存储和通信成本，同时增强隐私保护；(b) 利用投影汉明距离进行相似度建模，捕获单个比特的重要性以提升表示能力；(c) 提出安全二进制梯度重组与隐私增强上传（SBG-PEU）策略，进一步降低传输过程中用户交互泄露的风险。在四个真实数据集上的大量实验表明，FHPLF始终优于最先进的HL和FL方法，在精度、效率和隐私保护之间实现了良好的权衡。

## Abstract
Hash Learning (HL) is an efficient representation learning approach that maps real-valued data into compact binary representations. Traditional HL methods typically require users to upload personal data to a central server, which is incompatible with increasingly stringent data security regulations. Federated Learning (FL) provides a decentralized paradigm for learning globally optimal models without centralizing private data. However, most FL methods rely on transmitting large-scale real-valued gradient information, leading to high communication overhead and potential privacy risks. Integrating HL into FL is a promising solution. Nevertheless, existing HL methods suffer from limited representational capacity of binary codes, which may degrade model accuracy. To address this challenge, we propose a Federated Hash Projected Latent Factor (FHPLF) model. FHPLF introduces three key innovations: (a) replacing real-valued gradient matrices with binary gradient-like matrices, significantly reducing computation, storage, and communication costs while enhancing privacy protection; (b) leveraging Projected Hamming Distance for similarity modeling, which captures the importance of individual binary bits to improve representation capability; and (c) proposing a Secure Binary Gradient Reassembly and Privacy-Enhanced Upload (SBG-PEU) strategy to further reduce the risk of user interaction leakage during transmission. Extensive experiments on four real-world datasets demonstrate that FHPLF consistently outperforms state-of-the-art HL and FL methods, achieving a favorable trade-off among accuracy, efficiency, and privacy preservation.

## 2. 方法论：核心思想、关键技术细节与算法流程

FHPLF 将用户与物品的表示向量约束为 `+1/-1` 的二进制码，并使用 **投影汉明距离（Projected Hamming Distance, PHD）** 度量用户与物品的相似性，从而赋予不同比特不同权重。为避免集中式训练，设计了 **离散联邦优化流程** 并辅以 **安全二进制梯度重组与隐私增强上传策略（SBG-PEU）**。

*   **基于投影汉明距离的评分预测**
    *   用户二进制码 \(w_u \in \{+1, -1\}^D\) 作为查询掩码，将物品码 \(q_i\) 投影至用户关注维度。
    *   投影汉明距离：\(\delta_{PH}(w_u, q_i) = \text{SUM}(w_u \ \text{AND}\ (\text{NOT}\ q_i))\)，仅计算用户感兴趣维度上的差异。
    *   预测评分 \(\hat{r}_{u,i}\) 由此转换为二值域中的线性公式，并引入平衡约束以避免某些比特恒为 0/1 造成的熵减。
    *   最终目标函数加入对非平衡的惩罚项，形成带二值约束与平衡正则的可优化问题。
*   **联邦离散优化流程（Discrete Coordinate Descent, DCD）**
    *   **初始化**：服务器随机初始化物品二值矩阵 \(Q\)，客户端本地生成用户二值向量 \(w_u\)。
    *   **局部更新**：客户端下载 \(Q\)，固定物品码，利用自身交互记录，逐比特更新 \(w_u\)。更新方向由「梯度样」项 \(\Delta w_{u,k} = \sum_{i \in I_u} (r_{u,i} - \tilde{r}_{u,i})(q_{i,k} - 1)\) 和平衡正则项共同决定，最终通过符号函数 `sign` 确定该比特的新值 `+1` 或 `-1`。
    *   **全局更新**：客户端为已交互物品计算比特级「梯度样」项 \(\Delta q_{u,i,k}\)，取其符号 \(\Delta\hat{q}_{u,i,k} \in \{-1,0,+1\}\) 后上传。服务器收集所有客户端的二进制梯度样值，聚合得到 \(q^*_{i,k}\)，再通过符号函数更新物品码 \(q_{i,k}\)。物品码同样逐比特迭代至收敛。
    *   **优点**：客户端上传的是二值或三元值而非实值梯度，通信量降低约 16×（与实值 FL 相比），并天然增加梯度逆向难度。
*   **SBG-PEU 策略（Secure Binary Gradient Reassembly and Privacy-Enhanced Upload）**
    *   **动机**：即使上传二值梯度，攻击者仍可通过非零位置推断用户与哪些物品交互。
    *   **做法**：客户端将本地的梯度样向量 \(\Delta Q_{u,k}\) 随机分解为 \(P\) 个片断 \(\Delta Q_{u,k}^p\)，满足 \(\sum_p \Delta Q_{u,k}^p = \Delta Q_{u,k}\)。客户端保留一个片断，其余 \(P-1\) 个片断随机交换给其他客户端。
    *   **上传**：客户端汇总收到全部片断与自身保留片断，形成虚假梯度矩阵 \(\Delta Q_{u,k}^{\text{fake}}\) 上传。
    *   **性质**：服务器端聚合后更新方向与原梯度一致，但攻击者无法从片断或虚假梯度中还原用户交互物品集合，进一步阻断交互信息泄露。

## 7. 优点：方法与实验设计的亮点

*   **三位一体优化**：同时实现低通信、高精度和强隐私，填补了联邦哈希学习在精度与隐私防御之间的空白。
*   **投影汉明距离**：突破传统汉明距离各比特平权限制，保留重要位信息，提升二进制表示的表达力。
*   **离散优化无实值梯度**：全程只上传二值/三元梯度样信号，天然削弱梯度泄露风险，且运算开销极低。
*   **SBG-PEU 机制**：通过随机分解与片段交换隐藏用户交互模式，不依赖额外加密或噪声，兼顾效率与安全。
