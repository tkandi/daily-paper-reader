## 摘要
多智能体混合（MoA）系统通过将每个查询路由到多个专家大语言模型（LLM）并聚合其输出，来提高推理准确性。在有限的GPU资源上高效执行此类工作负载存在瓶颈。基于技能的路由导致专家需求不均衡，而将指令微调LLM与长推理模型结合会带来生成长度的极端差异。因此，传统调度策略因负载不均衡而导致显著的GPU闲置和吞吐量下降。我们提出MOSAIC，一个加速MoA工作负载的调度框架。首先，我们构建了一个基于整数线性规划（ILP）的调度器，根据离线分析的成本联合优化专家放置和每个工作器的提示分配，将推理专家复制到多个工作器上，同时固定轻量级专家。其次，MOSAIC使用置信度感知的自适应聚合，利用专家间的一致性，对一致查询绕过繁重的最终聚合LLM。在我们的4-GPU系统中，MOSAIC相较于基线调度器，专家阶段加速高达2.5倍，聚合阶段加速高达4.23倍，端到端加速1.7~2.3倍，同时精度匹配在0.1个百分点以内。

## Abstract
Mixture-of-Agents (MoA) systems improve reasoning accuracy by routing each query to multiple expert LLMs and aggregating their outputs. Efficiently executing this workload on limited GPU resources has bottlenecks. Skill-based routing creates skewed expert demand, and combining instruction-tuned LLMs with long-reasoning models results in extreme variability in generation lengths. Consequently, traditional scheduling strategies suffer from significant GPU idling and throughput collapse due to load imbalances. We present MOSAIC, a scheduling framework to accelerate MoA workloads. First, we formulate an Integer Linear Program (ILP) based scheduler that jointly optimizes expert placement and per-worker prompt assignment from offline-profiled costs, replicating reasoning experts across workers while pinning lightweight ones. Second, MOSAIC uses confidence-aware adaptive aggregation, leveraging inter-expert agreement to bypass the heavy final aggregator LLM for consensus queries. In our 4-GPU system, MOSAIC achieves up to 2.5x expert-stage, 4.23x aggregator-stage and 1.7~2.3x end-to-end speedups over the baseline scheduler, while matching accuracy within 0.1pp.

## 论文核心问题与整体含义
-   **核心问题**：多智能体混合（Mixture‑of‑Agents, MoA）推理系统通过组合多个专家LLM提升精度，但在有限GPU资源上高效调度此类负载极其困难。
-   **关键瓶颈**：
    1.  **需求偏斜**：基于技能的路由导致某些专家被频繁调用，而另一些则相对空闲。
    2.  **负载不均**：指令微调LLM与长推理模型（LRM）混合，导致生成输出长度差异巨大（最高达13倍）。
-   **研究目标**：在保证MoA推理精度的前提下，设计一种针对异构、偏斜、变长LLM推理负载的高效调度框架，以最小化总完工时间（makespan）并最大化硬件利用率。

## 方法论：核心思想与关键技术细节
MOSAIC框架从两个正交的维度对MoA推理进行加速：

1.  **专家生成阶段的ILP调度器**
    -   **核心思想**：将MoA的专家分配与放置问题形式化为一个整数线性规划（Integer Linear Program, ILP），以离线分析的成本为依据，在考虑专家负载成本、生成长度及选择性复制的条件下，联合优化模型到GPU的放置以及每个GPU的提示分配。
    -   **关键机制**：
        -   **成本建模**：在离线阶段，通过校准集评估每个专家的平均/最大输出token数，并回归出不同提示数量下的会话墙钟时间，从而计算出每个提示的调度成本\(\tau_m\)。
        -   **决策变量与约束**：引入二元变量 \(Y_{m,n}\)（专家 \(m\) 是否部署在GPU \(n\)）和整数变量 \(X_{m,n}\)（GPU \(n\) 服务的专家 \(m\) 的提示数）。约束包括：所有提示必须被分配、提示只能分配给已加载相应专家的GPU、专家有复制上限\(R^{max}_m\)（由加载成本与执行成本之比\(\rho_m\)决定：长推理专家可复制到多个GPU，轻量专家则固定在一个GPU上）、每个GPU最多容纳\(K\)种不同模型。
        -   **优化目标**：最小化所有GPU中最大的总耗时\(T_n\)（加载时间与生成时间之和），从而直接降低专家生成阶段的完工时间。
    -   **算法流程**：离线分析成本\(\rightarrow\)构建ILP模型（变量、约束、目标）\(\rightarrow\)CP-SAT求解器求最优解\(\rightarrow\)运行时按该最优解进行分批、静态调度。

2.  **置信度感知的自适应聚合器**
    -   **核心思想**：在聚合阶段，避免对每个查询都调用重量级聚合器LLM。当多个专家的答案高度一致时，直接取多数票作为最终答案，跳过聚合器。
    -   **关键公式**：
        -   定义置信函数 \(C(q)\)为专家答案的多数比例。例如，3个专家的桶有3:0（C=1）、2:1（C=2/3）、1:1:1（C=1/3）。
        -   设定阈值\(\tau\)：若\(C(q) \ge \tau\)，则直接返回多数票答案；否则，调用聚合器LLM。
        -   提出了**保守**（\(\tau=1\), 仅对3:0结果跳过）和**激进**（\(\tau=2/3\), 对3:0和2:1结果均跳过）两种操作点。

## 实验设计
-   **数据集与场景**：在三个多学科、多技能的标准推理基准上进行MoA推理测试：

    -   **MedMCQA** (医学，4183题)
    -   **GPQA** (研究生级科学，198题)
-   **对比基线**：
    -   **Round‑Robin (RR)**：将备选专家依次固定地循环分配给各GPU，是一种无需校准的天然多GPU基线。
-   **实验指标**：
    -   **速度**：专家阶段加速比、聚合阶段加速比、端到端墙钟时间加速比。
    -   **精度**：相比全聚合基线的准确率变化（\(\Delta\) pp）。

-   **推理框架**：使用 vLLM 0.7.1，每个GPU一次加载一个模型，以会话形式顺序执行。

## 主要结论与发现
-   **显著加速，精度无损**：MOSAIC在4-GPU系统上，相比Round‑Robin基线，实现了端到端**1.71倍至2.34倍**的加速。其中，专家阶段最高**2.54倍**，聚合阶段最高**4.23倍**，而准确率变化保持在 \(\pm 0.1\) 个百分点以内（保守模式）甚至有所提升。
-   **负载均衡是关键**：加速主要源于ILP调度器通过将重度推理专家复制到多个GPU，并与轻量专家配对，有效地均衡了各GPU的工作负载，显著减少了闲置时间。
-   **一致性是有效信号**：专家间的答案一致性（多数比例）是一个高质量、低成本的置信度信号，可以用很小的精度代价换取极高的聚合阶段加速。

## 优点
-   **方法论与工程结合的亮点**：
    -   **形式化与优化**：将启发式的调度问题提升为数学优化（ILP），在小规模问题中可求精确最优解。
    -   **经济学启发的复制机制**：通过负载-运行比（\(\rho_m\)）自适应地决定专家的复制上限，精准且可解释。
    -   **无免费午餐的洞察**：彻底剖析单纯数据并行（DP）带来的模型加载税和小批次吞吐崩塌问题，论证了模型放置与提示分配联合优化的必要性。
    -   **自适应聚合机制**：该机制并不依赖复杂的置信度估计器，仅基于专家投票一致性，实现简单、效果显著，且观察具有普遍性。

## 不足与局限
-   **静态置信度准则**：自适应聚合的阈值\(\tau\)需要根据任务类型在推理前手动选定，缺乏动态适应性。
-   **ILP收益的任务依赖性**：论文指出，ILP调度在具有明确子类别分区的任务（如MMLU-Pro）上收益更大，而在无子类任务（如GPQA）上，收益更多来自可执行的调度决策本身，暗示其优化空间可能受任务结构影响。
-   **通用性限制**：方法与结论主要针对**LLM MoA推理**这一特定负载。作者承认，将该框架直接扩展到输入非LLM推理瓶颈的通用、异构Agentic工作负载存在挑战，有待未来研究。
