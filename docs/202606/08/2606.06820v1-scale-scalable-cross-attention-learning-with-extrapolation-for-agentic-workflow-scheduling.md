## 摘要
智能体大型语言模型（LLM）系统将复杂任务分解为工作流有向无环图（DAG），其基元需在异构集群上进行调度。现有的深度强化学习（DRL）调度器受限于固定集群规模，一旦服务器数量变化就需要重新训练。我们提出 SCALE（可扩展交叉注意力外推学习），一种无需微调即可泛化至未见集群规模的 DRL 调度器。SCALE 采用交叉注意力指针网络，其中任务特征查询服务器特征，因此该架构在构造上可接受任意数量的服务器。然而，我们观察到仅靠置换不变架构并不能保证在新规模下的良好性能——随着服务器数量增加，注意力特征会经历分布偏移。为解决这一问题，我们引入结构化表示正则化（SRR）：一个与标准正态分布之间的 KL 惩罚相结合的去相关损失，以保持特征统计量不随输入规模变化。在 16 个节点上训练并直接在 32 和 48 个节点上测试，与未使用 SRR 的相同架构相比，SCALE 在 N=48 时平均响应时间降低了 8.9%，证实了明确的正则化对于弥合规模泛化差距是必要的。

## Abstract
Agentic Large Language Model (LLM) systems decompose complex tasks into workflow Directed Acyclic Graphs (DAGs) whose primitives must be scheduled on heterogeneous clusters. Existing deep reinforcement learning (DRL) schedulers are tied to a fixed cluster size and require retraining whenever the number of servers changes. We propose SCALE (Scalable Cross-Attention Learning with Extrapolation), a DRL scheduler that generalizes to unseen cluster scales without fine-tuning. SCALE employs a cross-attention pointer network where task features query against server features, so the architecture accepts any number of servers by construction. We observe, however, that permutation-invariant architecture alone does not guarantee good performance at new scales - the attention feature undergoes distribution shift as the server count grows. To counter this, we introduce Structured Representation Regularization (SRR): a decorrelation loss combined with a KL penalty toward the standard normal, which keeps feature statistics stable regardless of input size. Trained on 16 nodes and tested directly on 32 and 48 nodes, SCALE reduces average response time by 8.9% at N=48 relative to the same architecture without SRR, confirming that explicit regularization is necessary to close the scale-generalization gap.

## 1. 核心问题与研究背景
- **问题**：智能体LLM系统将复杂目标分解为大量基元构成的工作流DAG，这些基元需要在异构集群上在线调度。现有深层强化学习（DRL）调度器（如Decima、DeepRM）的神经网络架构与集群规模绑定，一旦服务器数量发生变化就必须重新训练，无法适应弹性扩缩容场景。
- **关键挑战**：
  - 状态表示需同时包含任务特征与可变数量的服务器特征，且支持集群规模动态变化。
  - 仅依靠置换不变架构（如注意力机制）并不能自动保证规模泛化——随着服务器数增加，注意力特征的统计分布会发生偏移（方差增大、维度相关），导致策略失效。
- **目标**：设计一种DRL调度器，使其能在小规模集群（16节点）训练后，直接零样本泛化到更大集群（32、48节点），无需任何微调。

## 2. 方法论
- **两级调度框架**：
  - 第一级（确定性启发式）：从就绪任务集中按最长路径优先规则选取待调度任务 `v*`。
  - 第二级（RL智能体）：将 `v*` 分配至某个异构服务器，由所学策略决定。
- **SCALE 架构（交叉注意力指针网络）**：
  - **嵌入模块**：任务特征（5维）与每个服务器的特征（5维）分别通过独立MLP编码为 `d` 维向量。任务产生查询 `q(0)`，服务器产生键值对 `z_j`。
  - **交叉注意力骨干**：`L` 层多头交叉注意力，任务特征作为查询，服务器特征作为键和值，产生注意力特征 `f = q(L)`。该特征融合了所有服务器上下文，维度与集群大小 `N` 无关。
  - **指针演员**：利用 `f` 与每个 `z_j` 的点积计算logits并通过softmax得到对 `N` 个服务器的选择概率。输出维度自动等于当前集群节点数。
  - **评论家**：仅以 `f` 为输入，通过MLP估计状态价值，不与服务器数量产生隐式依赖。
- **结构化表示正则化（SRR）**：
  - 观察到随着 `N` 增长，`f` 的分布会偏移：维度间相关性增强，信息集中在少数主方向上，导致演员的概率分布趋于平坦。
  - **去相关损失 `L_c`**：惩罚批次内 `f` 的协方差矩阵的非对角元素绝对值，迫使特征维度统计独立。
  - **分布约束损失 `L_d`**：计算 `f` 的每维经验均值、方差与标准正态 `N(0,1)` 的KL散度，将所有维度的边际拉向标准正态。
  - **总损失**：`L = L_PPO + λ1 L_c + λ2 L_d`，通过线性预热逐渐加入SRR项，避免早期干扰策略学习。
- **训练算法**：PPO，利用广义优势估计（GAE）。模拟环境在16节点上收集样本，训练1000轮。

## 3. 实验设计
- **模拟环境**：
  - 异构集群：三类服务器（Small/Medium/Large），比例为2:5:1，不同计算、内存与功耗配置。
  - 工作流：泊松过程到达，每个工作流DAG包含3～8个基元，计算需求、内存需求、通信量随机生成。
  - 目标指标：平均响应时间（任务完成时间减去所属工作流到达时间），同时记录已完成任务数。
- **基准方法对比**：

- **SRR对非可扩展架构也有正面影响**：PPO+SRR在16节点上完成任务数略高于纯PPO，说明特征正则化带来了通用益处。

- **方法简洁有效**：SRR仅通过去相关和KL惩罚两个附加损失项约束注意力特征，不引入额外网络参数，易于实现。
- **问题形式化清晰**：将在线DAG调度建模为MDP，设计两级调度分解，降低动作空间复杂度。
