## 摘要
近似最近邻搜索（ANNS）是大语言模型和推荐系统等现代应用中的关键内核。然而，其效率从根本上受限于需要在查询与大量高维向量之间计算距离，其中绝大多数向量并非近邻。现有方法通过索引优化或提前终止来减少冗余，但仍受固定精度计算的限制，导致不必要的算术和内存带宽开销。本文提出了ANNS-AMP，这是一个自适应混合精度框架和加速器，能根据查询特性和数据分布自适应调整距离计算的精度。其核心洞察在于，向量空间的不同区域需要不同级别的精度来保持top-k准确率。ANNS-AMP利用基于乘积量化（PQ）索引的聚类结构，并引入一个轻量级预测器，在运行时根据尺度、半径和查询距离等特征确定聚类级别的精度。为高效实现可变精度执行，我们设计了一个位串行加速器，采用位交错数据布局，使吞吐量能随着精度降低而扩展，同时通过贪婪调度策略缓解内存带宽瓶颈和负载不平衡。此外，运行时预测器还可以重用位串行计算阵列进行高效的运行时预测，并无缝融入ANNS流水线，不会造成性能损失。根据我们在代表性数据集上的实验，与CPU、GPU和定制化ANNS加速器基线相比，ANNS-AMP平均性能加速分别达到163.76倍、10.57倍和2.06倍，平均能耗分别降低1100.00倍、39.41倍和6.66倍，同时保持准确率损失低于2.7%。这些结果表明，自适应混合精度计算是实现高效大规模ANNS的一个有前景的方向。

## Abstract
Approximate nearest neighbor search(ANNS) is a critical kernel in modern applications such as LLM and recommendation systems.However,its efficiency is fundamentally limited by the need to compute distances between a query and a massive number of high-dimensional vectors,most of which are non-neighbors.Existing approaches reduce redundancy via index optimization or early termination,but remain constrained by fixed-precision computation,leading to unnecessary arithmetic and memory bandwidth overhead.This paper presents ANNS-AMP,an adaptive mixed-precision framework and accelerator that adapts the precision of distance computation to the characteristics of queries and data distribution.The key insight is that different regions of the vector space require different levels of precision to preserve top-k accuracy.ANNS-AMP leverages the clustered structure of PQ-based indices and introduces a lightweight predictor to determine cluster-level precision at runtime based on features such as scale,radius,and query distance.To efficiently realize variable-precision execution,we design a bit-serial accelerator with a bit-interleaved data layout,enabling throughput to scale with reduced precision while mitigating memory bandwidth bottlenecks and load imbalance through a greedy scheduling strategy.Moreover,the runtime predictor can also reuse the bit-serial computing array for efficient runtime prediction and can be fitted to the ANNS pipeline without performance penalty.According to our experiments on representative datasets,ANNS-AMP achieves 163.76x,10.57x,and 2.06x performance speedups on average,and reduces average energy consumption by 1100.00x,39.41x,and 6.66x compared to CPU,GPU,and customized ANNS accelerator baselines,respectively,while maintaining accuracy loss below 2.7%.These results demonstrate that adaptive mixed-precision computing is a promising direction for efficient large-scale ANNS.

## 一、论文的核心问题与整体含义

- **问题背景**：近似最近邻搜索（ANNS）是大语言模型推理、推荐系统等应用的关键操作。其效率瓶颈在于，查询需要与海量高维向量计算距离，而其中绝大多数向量并非真实近邻。
- **现有方法局限**：现有索引优化（如 PQ）和早期终止技术仍基于固定精度计算，导致大量不必要的算术运算和内存带宽浪费。部分方法依赖 top-k 列表进行剪枝，在查找表（LUT）构建等阶段无法直接应用，冗余消除不彻底。
- **本文核心思路**：提出根据查询特性和数据局部分布，自适应该区域的距离计算精度——“给不同向量空间区域分配刚好足够的精度”。这需要同时解决预测何种精度和硬件如何高效支持可变精度两个问题。

## 二、方法论

### 2.1 整体框架
- 提出 **ANNS‑AMP**：一个“自适应混合精度预测”+“位串行加速器”的软硬件协同框架。
- 运行时动态预测每个聚类（或子空间）所需的计算位宽，硬件则通过位串行计算实现可变精度，并用位交错存储和贪婪调度缓解带宽与负载不均衡。

### 2.2 精度预测（软件层面）
- **向量空间划分**：先对向量维度进行切分，再在每个维度切片内做聚类划分。这样既避免高维空间中超平面分割的“邻居爆炸”问题，又能保持低维投影下的可分性。
- **特征提取**：对每个子空间提取五个特征：查询到最近子空间的距离 \(d'\)、两个子空间的半径 \(r_1,r_2\) 以及它们包含的向量数 \(n_1,n_2\)。
- **标签生成**：基于真值距离，计算“区分全局近邻与非近邻所需的最低精度位宽”，作为训练标签。
- **回归模型**：采用支持向量回归（SVR），核函数为 **RBF**（高斯核），离线训练（样本数 ≤ 1280，迭代 ≤ 50 次）。在线推理时用查找表避免指数运算。
- **预测粒度**：以子空间（聚类）为单位预测精度，而非每个向量单独预测，大幅降低开销。

### 2.3 硬件加速（架构层面）
- **位串行计算单元**：距离计算模块（DCM）由大量位串行减法器、乘法器、加法器组成。精度越低，相同面积下可并行处理的维度越多，吞吐量线性提升。
- **位交错数据布局**：将查询、质心、码本等数据按位从高到低交错存储。当预测到某一子空间只需低位宽时，内存控制器仅顺序读取对应高位的连续比特段，避免读取无用位，成倍提升带宽利用率。
- **负载均衡**：不同子空间的尺寸和位宽不同，导致位串行流水线忙闲不均。设计贪婪调度模块（LSM），允许相邻 DCM 组之间进行任务窃取，并用简单解析模型预分配任务。
- **模块复用**：精度预测模块（PPM）直接复用量化和距离计算阵列完成特征计算，不额外增加硬件开销。

### 2.4 执行流水线
- 整体 ANNS 流程分为：簇定位（CL）、残差计算（RC）、LUT 构建（LC）、距离累加（DC）、top‑k 排序（TS）。
- ANNS‑AMP 主要对 **CL** 和 **LC** 阶段进行混合精度加速，因为这两个阶段距离计算密集且不直接依赖 top‑k 表剪枝。

## 六、主要结论与发现

- 与 CPU/GPU/ANNAx12 相比，ANNS‑AMP 平均性能加速 **163.76×**、**10.57×**、**2.06×**，能耗分别降至 **1/1100**、**1/39**、**1/6.66**。
- 在 CL 阶段，最多 **87.49%** 的距离计算转为低精度；在 LC 阶段，该比例达 **93.75%**，整体准确率损失 **< 2.7%**。
- 位交错数据布局相较普通布局提升内存带宽效率 **1.18×** 以上。
- 自适应混合精度策略对索引参数变化不敏感，可普遍适用于簇基 PQ 类方法。

## 七、优点

- **软硬协同**：将精度需求抽象为回归问题，与位串行硬件天然匹配，实现“需要多少精度就用多少计算”。
- **无需 top-k 依赖**：预测仅依赖子空间几何特征，可在 LUT 构建等阶段有效工作，弥补了早期终止方法的盲区。
- **存储与计算联合优化**：位交错布局使降低精度的同时直接减少访存量，而非仅减少计算延时。
- **高能效比**：在 14 nm 工艺下，面积和功耗极低，但性能和能效显著优于 GPU 甚至同工艺的定制加速器。
- **轻量级预测器**：SVR 训练数据极少，在线推理可复用已有计算阵列，基本无性能开销。

## 八、不足与局限

- **训练样本量小、特征简化**：仅用 1280 组特征训练，且特征集仅包含距离、半径、点数等，可能对数据分布剧烈变化的场景泛化不足。
- **适用范围受限**：目前针对簇基 PQ 索引设计，未验证在图索引、哈希索引等结构上的迁移能力。
- **负载均衡收益依赖精度配置**：负载调度在默认高精度约束下收益很小（< 3.6%），只有在放宽准确率、更多位宽选项时才显著。
- **硬件实现为模拟**：基于 14 nm 工艺的周期精确仿真，实际流片可能面临噪声、工艺偏差等影响。
- **数据集覆盖有限**：仅测试了 SIFT 和 DEEP 两种典型百万级数据集，未涉及十亿级或更多样模态（如文本、基因序列）的嵌入向量。
- **预测误差传递**：精度预测错误会导致部分近邻被误分入低精度区域，虽整体损失可控，但对“硬查询”可能存在未量化的风险。
