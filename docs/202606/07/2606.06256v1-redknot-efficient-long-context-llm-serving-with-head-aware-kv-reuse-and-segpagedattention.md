## 摘要
随着大语言模型（LLM）服务的输入长度持续增长，KV缓存已成为AI基础设施中的主要瓶颈。它限制了GPU内存容量、服务并发性、缓存重用和分布式可扩展性。位置无关的KV缓存、前缀KV缓存压缩、冷热KV缓存分离以及分布式KV缓存管理等关键问题，都取决于KV缓存的表示和管理方式。然而，现有的服务系统主要依赖单一的KV缓存抽象，将KV缓存视为token级内存块的同构序列，并在不同注意力头和不同服务场景下采用相似策略进行管理。我们观察到，KV缓存的效用在不同KV头之间高度结构化：不同头表现出不同的功能角色、注意力距离和运行时重要性。因此，对于每个头、每个token范围或每种服务场景，完整的KV缓存并非总是必需的。我们提出了RedKnot，一个面向LLM服务的头感知KV缓存管理系统。RedKnot打破了传统的单一KV缓存抽象，按照KV头对KV缓存进行分解，这些头的重要性和有效注意力范围在不同服务场景下差异显著。这种头级别的分解将KV缓存从单一的张量抽象转变为结构化的内存对象，使得RedKnot能够统一支持位置无关的KV重用、前缀KV压缩、冷热KV分离和分布式KV放置，同时保持输出保真度并提高资源效率，无需模型重新训练或微调。RedKnot将KV缓存从一种单一的、被动的运行时产物转变为一种动态的、模型感知的运行时基础，为可扩展的LLM服务奠定了基础。

## Abstract
As the input length of large language model (LLM) serving continues to grow, the KV cache has become a dominant bottleneck in AI infrastructure. It limits GPU memory capacity, serving concurrency, cache reuse, and distributed scalability. Several important problems, including position-independent KV cache, prefix KV cache compression, hot/cold KV cache separation, and distributed KV cache management, all depend on how the KV cache is represented and managed. However, existing serving systems largely rely on a monolithic KV cache abstraction, where the KV cache is treated as a homogeneous sequence of token-level memory blocks and managed with similar policies across attention heads and serving scenarios. We observe that KV cache utility is highly structured across KV heads: different heads exhibit different functional roles, attention distances, and runtime importance. Therefore, a full KV cache is not always necessary for every head, token range, or serving scenario.   We present RedKnot, a head-aware KV cache management system for LLM serving. RedKnot breaks the conventional monolithic KV cache abstraction by decomposing the KV cache along KV heads, whose importance and effective attention ranges vary significantly across serving scenarios. This head-level decomposition turns the KV cache from a monolithic tensor abstraction into a structured memory object, enabling RedKnot to uniformly support position-independent KV reuse, prefix KV compression, hot/cold KV separation, and distributed KV placement while preserving output fidelity and improving resource efficiency, without requiring model retraining or fine-tuning. RedKnot establishes a new foundation for AI infrastructure by transforming the KV cache from a monolithic, passive runtime artifact into a dynamic, model-aware runtime substrate for scalable LLM serving.

### 1. 论文的核心问题与整体含义

- **核心问题（研究动机）**：随着大语言模型（LLM）服务向长上下文（如RAG、代码Agent）演进，**KV缓存已成为AI基础设施的核心瓶颈**。它急剧消耗GPU内存、限制并发量，并在位置无关缓存（PIC）重用场景下效率低下。现有系统的根本问题在于采用**单一的（Monolithic）KV缓存抽象**：将所有注意力头视为同构的token序列进行统一管理，忽略了不同注意力头在功能、注意力范围和重要性上的显著结构差异。这种粗粒度管理导致三个结构性失败：
    1.  **Token级重用失效**：位置无关缓存（PIC）方案试图在token粒度恢复重用的KV质量，但由于不同头关注不同token子集，token级选择必须取并集，导致必须重计算大部分chunk，使得重用失效。
    2.  **忽视FFN瓶颈**：PIC方案聚焦于注意力计算，但在Agent等短上下文（2K-8K）场景下，前馈网络（FFN）贡献了57%-62%的首Token时间（TTFT），这是注意力端技术无法触及的。
    3.  **掩码惩罚**：即使算法上只需保留部分KV，如仍使用密集张量存储并应用`attn_mask`，会禁用FlashAttention等快速计算路径，导致4.9-7.6倍的额外内核性能损失，使得理论上的字节节省无法转化为实际算力节省。

- **整体含义（解决方案）**：RedKnot系统通过将KV缓存的管理、恢复和计算粒度从token级**对齐到注意力头级**，将KV缓存从被动的单一运行时产物转变为**动态的、模型感知的结构化内存对象**，从而在保证输出质量的同时，成倍提升长上下文LLM服务的资源效率和可扩展性。

### 2. 论文提出的方法论

RedKnot的核心思想是**解耦并结构化KV缓存**，由三个关键机制协同设计实现：

- **核心思想：头感知的KV缓存分解与管理**
    - 对每个（层，头）进行离线分析，将其分类为**全局头（Global Head）** 或**局部头（Local Head）**。
    - **全局头**（约占12-15%）：需要全量上下文的注意力，对前缀变化敏感。
    - **局部头**（约占85-88%）：有效注意力范围有限（最近+少量注意力池token），对前缀变化鲁棒。
    - 基于此分类，系统对不同头执行差异化策略：重计算全局头，直接重用局部头KV，并针对性地应用稀疏FFN。

- **关键技术细节与算法流程**
    1.  **弹性稀疏性（Elastic Sparsity）—— 质量恢复算法**
        - **目标**：在位置无关重用KV缓存时，以最小计算代价恢复输出质量。
        - **RoPE位置对齐**：对缓存的Keys，通过应用相对旋转矩阵 `K(p_on) = R(p_on)R(p_off)^{-1}K(p_off)`，消除因chunk位置移动导致的位置编码偏差。
        - **层级弹性恢复**：
            - **浅层**：采用**局部注意力恢复 + 全量FFN**，以保护对扰动敏感的早期隐藏状态。
            - **深层**：启用**头感知注意力恢复 + 稀疏FFN**。
        - **头感知注意力恢复**：
            - **全局头**：在新前缀下全量重计算其KV状态。
            - **局部头**：仅在可见窗口内进行修复。对于token `i`，重组其`Q`与一个由**注意力池token（Sink Tokens）** 和**最近窗口token**（`[i-w, i]`）组成的局部可见集`W(i)`的KV进行计算，其余大部分本地头KV直接复用。
        - **部分稀疏FFN恢复**：利用恢复后的注意力信号评估token重要性，仅对**重要的token状态**执行完整的FFN计算，其余token直接通过残差连接传递。

    2.  **分段分页注意力（SegPagedAttention）—— 高效执行与存储基底**
        - **目标**：将算法层面的每头稀疏性在内存和计算层面物理化，消除`attn_mask`惩罚并节省内存。
        - **头分段KV布局**：打破传统的张量布局`[B, H, L, D]`，转而以**（层， 头）** 为粒度组织KV缓存。每个头独立管理其页表：全局头分配覆盖全序列的页，局部头仅分配覆盖其可见窗口（池+最近token）的页。
        - **融合的变长注意力内核**：设计一个内核，可直接消费每头不同长度的KV页列表，执行无掩码的FlashAttention快速路径，避免了因逐头调用内核导致的启动开销。这使得算力节省不再随序列增长而递减。
