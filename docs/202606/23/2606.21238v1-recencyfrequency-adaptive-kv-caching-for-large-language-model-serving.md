## 摘要
键值缓存是加速大语言模型推理与生成的强大技术。推理工作负载量大且多样，这使得高效缓存面临挑战。现有缓存管理策略采用最近最少使用策略淘汰缓存块，但LRU会导致多个不相关的工作负载相互刷新对方的缓存。为解决这一问题，我们引入了自适应缓存，动态分配缓存空间给最近和频繁出现的KV块。评估结果显示，在合成文档问答工作负载上，与朴素vLLM相比，该方法将KV缓存命中率提高最多10.8%，首token时间减少最多12.6%；在真实对话工作负载上，分别提高2.1%和2.0%。该方法能很好地推广到批量推理，并表现出清晰的可解释性，同时有效适应多样化的工作负载。

## Abstract
Key-value (KV) caching is a powerful technique for accelerating large language model inference and generation. Inference workloads are large and diverse, which makes them difficult to cache effectively. Existing cache management strategies adopt the least-recently-used policy for evicting cache blocks. However, LRU leads to multiple unrelated workloads flushing each other's caches. To address this, we integrate adaptive caching that dynamically allocates cache space between recently and frequently occurring KV blocks. Evaluations show that it improves the KV cache hit rate by up to 10.8% and reduces time to first token by up to 12.6% over naive vLLM on synthetic document question answering workloads, and 2.1% and 2.0% respectively on real-world conversation workloads. The method generalizes well to batch inference and demonstrates clear interpretability while effectively accommodating diverse workloads.

### 1. 论文的核心问题与整体含义

- **核心问题**：大语言模型（LLM）推理中的键值（KV）缓存能够避免重复计算，但其管理策略多为 LRU（最近最少使用），在面对复杂、多样且动态变化的推理负载时，容易发生“缓存污染”——即多个互不相关的工作负载相互驱逐对方的缓存块，导致命中率下降。
- **研究动机**：实际负载（如文档问答、多轮对话）常呈现“最近性”（recency）与“频度性”（frequency）混合的访问模式。纯 recency 策略（LRU）无法充分捕获频度热点，而固定比例的混合策略也难以适应负载变化。因此，需要一种能自适应地在最近块和频繁块之间动态分配缓存空间的机制。
- **整体含义**：提出将经典的自适应替换缓存算法 ARC 集成到 LLM 服务框架 vLLM 中，通过动态分区管理，在多样化负载下同时提升 KV 缓存命中率并降低首 token 时间（TTFT），为生产级 LLM 推理系统提供更高效、可解释的缓存管理方案。

### 2. 方法论

- **核心思想**：利用 Adaptive Replacement Cache (ARC) 作为 KV 缓存淘汰器，将固定大小的物理缓存逻辑上划分为关注“最近性”和“频度性”的两个队列，并通过“幽灵缓存（ghost cache）”机制根据负载变化动态调整两队列的空间比例。
- **关键技术细节**：
  - **双队列结构**：整体缓存分为低频队列 L1（记录仅被访问一次的块）和高频队列 L2（记录被多次访问的块）。L1 和 L2 又各自分为物理缓存部分（T1、T2，实际存储 KV 块）和幽灵缓存部分（B1、B2，仅存储被淘汰块的元数据，不占 GPU 显存）。
  - **晋升与淘汰**：L1 中的块若被命中，则提升到 L2；物理缓存满时，根据当前空间分配比例从 T1 或 T2 的 LRU 端淘汰。
  - **自适应分区**：若请求在幽灵缓存 B1 中命中，表明最近性队列空间不足，则增大 T1 的比例；若在 B2 中命中，表明频度队列空间不足，则增大 T2 的比例。通过这种“反馈－调整”实现无参数、自适应的工作负载适应。
  - **实现集成**：所有淘汰决策以固定大小的 KV 块（16 个 token）为单位，与 vLLM 的分页注意力机制无缝对接，仅修改 evictor 模块。

### 3. 实验设计

- **数据集与场景**：
  - **文档问答**：使用 QuALITY（长文档阅读理解）和 WikiQA（开放域问答）两个数据集，通过“窗口化 Zipf 采样”合成工作负载，以模拟文档热度的动态变化。
  - **多轮对话**：使用来自阿里云百炼平台的真实匿名 trace（Qwen-Bailian Trace A），包含约 4.3 万条请求，反映 ChatGPT 风格的多轮对话场景。
- **对比方法**：
  - **LRU**：vLLM 原生的最近最少使用策略（基线）。
  - **DBL**：固定 1:1 比例的静态双队列方案，用于剥离自适应分区带来的增益。
  - **ARC**：本文提出的自适应替换缓存方案。
- **评测指标**：KV 缓存命中率和平均首 token 时间（TTFT）。
- **实验变量**：不同缓存容量（以 token 数为单位）、不同批规模（batch size）。

### 4. 资源与算力

- 所有实验均在 **单块 NVIDIA H100 PCIe 80 GB GPU**（Lambda GPU Cloud）上完成。
- 模型为 **Qwen3-14B**。
- 推理过程采用离线推理模式，单请求生成 1 个 token，以屏蔽解码阶段的变异性。论文未提及训练过程，仅进行推理测试，因此无训练时长数据。

### 5. 实验数量与充分性

- **实验组数**：覆盖两个文档 QA 合成负载（QuALITY 和 WikiQA）和一个真实对话 trace，每个负载下又测试多个缓存容量（例如图中展示了 50k、100k、200k 等不同大小的 token 数）；此外还考察了不同批规模的影响（在 QuALITY 上，缓存固定 20k tokens，批规模 1~8），以及通过 DBL 与 ARC 的对比进行消融实验。
- **充分性与公平性**：实验设计较为全面，既包含合成负载和真实 trace，也包含消融分析和不同配置下的性能变化，能够验证方法在不同场景下的有效性和自适应特性的作用。对比基线（LRU）为 vLLM 原生策略，DBL 亦直接基于该框架实现，控制变量合理，可公平反映 ARC 的增量收益。但仍可指出，仅在单个模型、单 GPU 和离线模式下测试，且文档 QA 负载为人工合成，可能未覆盖所有真实负载特征。

### 6. 论文的主要结论与发现

- **缓存命中率与延迟改善**：在合成文档 QA 负载上，ARC 相比 LRU 的 KV 缓存命中率提升最高达 10.8%，TTFT 降低最高达 12.6%；在真实多轮对话 trace 上，命中率提升可达 2.1%，TTFT 降低 2.0%。
- **自适应分区的价值**：静态固定比例（DBL）在部分配置下性能不及 LRU，而 ARC 的自适应调整能有效跟随负载变化，特别是在较大缓存下，长期负载迁移的优势明显。
- **批量推理的泛化性**：在不同批规模下，ARC 的命中率和 TTFT 优势保持稳定甚至略有增大。
- **缓存动态行为**：通过观察 T1 比例随时间的变化，发现 ARC 能根据工作负载自动在“最近性”和“频度性”之间迁移空间分配，解释了性能提升的来源，也增强了可解释性。
- **缓存容量的影响**：随着缓存增大，ARC 的绝对提升幅度衰减，符合直觉（大缓存本身命中率已较高，置换决策影响变小）。

### 7. 优点

- **简洁有效**：将经典、无参数的 ARC 算法直接引入 LLM KV 缓存管理，不引入额外超参，易于实现和部署。
- **动态适应**：能自动捕捉负载中 recency 与 frequency 的混合模式和工作负载迁移，缓解了 LRU 的缓存污染问题。
- **可解释性强**：通过 T1/T2 比例的时间序列演化，可直观理解缓存行为与负载特征。
- **工程友好**：与 vLLM 的分页注意力机制无缝集成，且已开源实现。
- **评估相对全面**：涵盖合成负载和真实 trace，包括消融实验和不同批规模测试。

### 8. 不足与局限

- **负载覆盖有限**：文档问答负载为合成生成，仅使用 Zipf 窗口采样模拟动态；仅使用一种真实对话 trace，可能无法代表所有多轮对话模式。
- **架构假设较简单**：实验在单 GPU、离线推理设定下进行，未考虑在线服务、具有请求调度、CPU/Disk 分层卸载、多 GPU 分布式或预填充-解码分离架构等生产环境复杂情况。
- **评估模型单一**：仅测试了 Qwen3-14B 一个模型，不同模型规模和结构（如注意力机制差异）对缓存行为的影响未探索。
- **性能增益在大缓存下递减**：对于超大缓存，自适应带来的额外收益有限。
- **未考虑多维淘汰因素**：仅基于 recency 和 frequency，未融入请求长度（对延迟影响不同）或位置相关的重用概率等额外信息，存在进一步提升的空间。
