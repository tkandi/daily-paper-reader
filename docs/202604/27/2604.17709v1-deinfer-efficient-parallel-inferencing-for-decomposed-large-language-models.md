## 摘要
现有的关于大语言模型（LLM）分解的工作主要集中在提高下游任务的性能上，但它们忽略了在尝试扩大模型规模时较差的并行推理性能。为了缓解这一重要的性能问题，本文介绍了 DeInfer，这是一个专门用于分解 LLM 并行推理的高性能推理系统。它包含多项优化，旨在最大化性能并与最先进的优化技术兼容。通过广泛的实验评估了 DeInfer 的性能，结果证明了其优越性，表明它可以极大地促进分解 LLM 的并行推理。

## Abstract
Existing works on large language model (LLM) decomposition mainly focus on improving performance on downstream tasks, but they ignore the poor parallel inference performance when trying to scale up the model size. To mitigate this important performance issue, this paper introduces DeInfer, a high-performance inference system dedicated to parallel inference of decomposed LLMs. It consists of multiple optimizations to maximize performance and be compatible with state-of-the-art optimization techniques. Extensive experiments are carried out to evaluate DeInfer's performance, where the results demonstrate its superiority, suggesting it can greatly facilitate the parallel inference of decomposed LLMs.

### 1. 论文的核心问题与整体含义
*   **研究背景**：为了降低大语言模型（LLM）的显存占用，低秩分解（Low-rank Decomposition，如 SVD）成为一种流行的压缩技术。它通过将大矩阵分解为两个小矩阵来减少参数量。
*   **核心问题**：尽管分解能减少显存，但在并行推理（Tensor Parallelism）场景下，它会导致严重的性能下降。主要瓶颈包括：
    1.  **通信开销激增**：分解引入了更多的 `reduce-sum` 操作，导致通信带宽成为瓶颈。
    2.  **重复计算**：在某些层中，多个 GPU 会执行完全相同的自注意力计算。
    3.  **CUDA Graph 不兼容**：分解后的 KV Cache 重构具有动态形状，难以利用 CUDA Graph 静态图优化。
*   **研究动机**：现有的分解研究多关注下游任务精度，忽视了推理效率。DeInfer 旨在填补这一空白，使分解模型在并行环境下也能高效运行。

### 2. 论文提出的方法论
DeInfer 的核心思想是重新设计计算流水线，将通信和计算转移到低秩空间。
*   **高效低秩通信**：
    *   **核心逻辑**：不再在原始高维空间进行 `reduce-sum`，而是将计算顺序重排，在低秩潜空间（Low-rank Latent Space）进行 `all-gather` 操作。
    *   **效果**：以 LLaMA-3-70B 为例，该设计可将每 token 的通信带宽需求降低约 78%。
*   **消除重复计算**：通过重排流水线，确保每个进程只处理其分片数据，避免了分解后常见的自注意力重复计算。
*   **集成 Paged Cache 与 CUDA Graph**：
    *   **两阶段重构**：分为“准备阶段”（扫描连续物理块、生成重映射索引）和“图重放阶段”（执行捕获的算子）。
    *   **缓冲区设计**：引入固定地址的缓冲区来处理动态形状的 KV Cache 重构，从而使分解模型能够兼容 CUDA Graph，消除算子启动开销。
