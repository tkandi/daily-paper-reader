## 摘要
大语言模型（LLM）推理日益依赖多 GPU 执行，然而现有的推理并行化策略需要逐层的 rank 间同步，导致端到端性能对负载不均衡十分敏感。我们提出了 DWDP（分布式权重数据并行），这是一种推理并行化策略，它在保持数据并行执行的同时，将 MoE 权重卸载到对等 GPU 上，并根据需求获取缺失的专家权重。通过消除集合通信中的 rank 间同步，DWDP 允许每个 GPU 独立推进。我们进一步通过针对权重切分管理和异步远程权重预取的两项优化，解决了该设计的实际开销问题。我们在 TensorRT-LLM 中实现了 DWDP，并在 GB200 NVL72 上使用 DeepSeek-R1 进行了评估。在 8K 输入序列长度和 1K 输出序列长度、20-100 TPS/user 的服务范围内，DWDP 在同等 TPS/user 的情况下将端到端输出 TPS/GPU 提升了 8.8%。

## Abstract
Large language model (LLM) inference increasingly depends on multi-GPU execution, yet existing inference parallelization strategies require layer-wise inter-rank synchronization, making end-to-end performance sensitive to workload imbalance. We present DWDP (Distributed Weight Data Parallelism), an inference parallelization strategy that preserves data-parallel execution while offloading MoE weights across peer GPUs and fetching missing experts on demand. By removing collective inter-rank synchronization, DWDP allows each GPU to progress independently. We further address the practical overheads of this design with two optimizations for split-weight management and asynchronous remote-weight prefetch. Implemented in TensorRT-LLM and evaluated with DeepSeek-R1 on GB200 NVL72, DWDP improves end-to-end output TPS/GPU by 8.8% at comparable TPS/user in the 20-100 TPS/user serving range under 8K input sequence length and 1K output sequence length.

### 1. 核心问题与研究动机
*   **核心问题**：在大规模语言模型（LLM）推理中，现有的并行策略（如专家并行 EP、张量并行 TP）依赖于**层级间的集体同步**（Layer-wise Synchronization）。
*   **研究背景**：在实际生产环境中，由于请求长度不同（请求级不平衡）和 MoE 路由倾斜（权重级不平衡），各 GPU 的计算负载往往不均。传统的同步机制会导致“木桶效应”，即计算快的 GPU 必须等待最慢的 GPU，产生显著的同步开销（在 20% 负载变异下，同步开销可达 12%）。
*   **研究目标**：消除推理路径上的集体同步，使每个 GPU 能够独立执行推理任务，从而提升整体吞吐量。

### 2. 方法论：DWDP 核心思想与关键技术
DWDP（分布式权重数据并行）结合了数据并行与基于 GPU 的权重卸载（Offloading）技术：
*   **异步权重预取**：
    *   各 Rank 保持数据并行执行。Attention 权重在各 Rank 全量备份，而 MoE 专家权重分布式存储在组内对等 GPU 上。
    *   在执行当前层计算时，异步预取下一层所需的远程专家权重。
    *   **拉取模式（Pull Model）**：放弃基于 NCCL 的集体通信（如 All-to-All），改用 `cudaMemcpyAsync` 通过 Copy Engine (CE) 直接从对等 GPU 拉取权重。这种方式不占用 SM 计算资源，且无同步语义。
*   **关键优化技术**：
    1.  **消除拆分权重合并开销**：针对预取导致的权重内存不连续问题，修改了 MoE GroupedGEMM 内核，使其支持 `TensorList` 输入，直接读取本地和远程缓冲区，避免了显式的设备内内存拷贝（D2D Copy）。
    2.  **时分复用（TDM）通信调度**：为解决多个目标 Rank 同时向同一源 Rank 请求权重导致的“多对一”竞争，将传输切分为固定大小的切片（Slices），并采用轮询（Round-robin）调度，利用 Copy Engine 的流水线特性掩盖冲突。

### 5. 实验数量与充分性
*   **实验维度**：
    *   **消融实验**：分别验证了序列长度（ISL）、最大 Token 数（MNT）、负载不平衡度（STD）以及 DWDP 组大小对性能的影响。
    *   **优化验证**：专门对比了“权重合并消除”和“通信竞争缓解”前后的性能差异。
    *   **端到端测试**：在 20-200 TPS/user 的广泛范围内绘制了 Pareto 前沿曲线。
*   **充分性评价**：实验设计非常充分且具有高度的工业实战价值。通过模拟真实生产环境中的负载倾斜（ISL Ratio 0.5-0.8），客观地展示了 DWDP 在不平衡场景下的优势。

### 6. 主要结论与发现
*   **性能提升**：在典型的 8K 输入/1K 输出场景下，DWDP 在 20-100 TPS/user 范围内将**端到端输出 TPS/GPU 提升了 8.8%**。
*   **负载鲁棒性**：随着工作负载不平衡度（标准差）的增加，DWDP 相对于 DEP 的加速比从 1.09x 提升至 1.15x，证明了其消除同步开销的有效性。
*   **计算掩盖**：Roofline 模型分析表明，当计算窗口足够大（如 ISL > 16K 或 Batch Size 较大）时，远程权重预取的开销可以被完全掩盖。
*   **干扰因素**：发现通信与计算重叠时的主要干扰源是**功率诱导的频率降频（DVFS）**，而非内存带宽瓶颈。

### 7. 优点
*   **架构创新**：打破了层级同步的思维定式，将“通信等待”转化为“异步预取”，极大地释放了不平衡负载下的硬件潜力。
*   **灵活性**：支持非对称的资源分配（如 DWDP3），允许更细粒度的资源配置，这在分离式推理架构中非常有用。
*   **软硬结合**：针对 Blackwell 架构（NVL72）的高带宽特性进行了深度定制，并解决了实际工程中的内存碎片和通信竞争问题。

### 8. 不足与局限
*   **TTFT 权衡**：实验显示 DWDP 在提升吞吐量的同时，可能会导致首字延迟（TTFT）有所增加（尤其是在低 TPS/user 场景下），这主要是由于减少了上下文 GPU 数量导致的排队延迟。
*   **硬件依赖**：该策略高度依赖极高的点对点通信带宽（如 NVLink 5），在带宽较低的旧款硬件或跨节点场景下，预取开销可能无法被掩盖。
*   **适用阶段**：目前主要针对上下文（Context）阶段优化，在生成（Decoding）阶段由于计算强度低，掩盖通信开销的难度更大。
