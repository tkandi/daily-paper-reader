## 摘要
大语言模型（LLM）推理受限于 GPU 内存容量和带宽。分层内存架构通过允许 GPU 将内存卸载到远程层来缓解这一问题。然而，现有的内存卸载框架依赖于将数据预取到本地 GPU HBM 中。这种方法由于引入了 HBM 争用、浪费了内存容量并产生了流水线气泡，导致系统资源利用不足。我们证明，启用 GPU 对远程内存的直接访问显著优于预取，能够实现最优的系统聚合带宽。我们提出了 DAK，这是一个端到端的直接访问内存卸载框架，它重新利用张量内存加速器（TMA）将卸载的权重和 KV 缓存从远程内存异步获取到 GPU 共享内存（SMEM）中。为了最大化远程访问性能，DAK 引入了一种贪心算法来确定每个操作的最优卸载比例，并结合主动拥塞控制和 TMA 多播来消除互连瓶颈和读取放大。在不同架构上的评估表明，与最先进的内存卸载基准相比，DAK 实现了接近最优的带宽聚合，在 NVLink-C2C 上实现了高达 3 倍的性能提升，在 PCIe 系统上实现了 1.8 倍的性能提升。

## Abstract
LLM inference is constrained by GPU memory capacity and bandwidth. Tiered memory architectures mitigate this by allowing the GPU to offload memory to the remote tier. However, existing memory offloading frameworks rely on prefetching data into local GPU HBM. This approach underutilizes system resources by introducing HBM contention, squandering memory capacity, and creating pipeline bubbles. We show that enabling direct GPU access to remote memory significantly outperforms prefetching, achieving optimal aggregate system bandwidth. We propose DAK, an end-to-end direct-access memory offloading framework that repurposes the Tensor Memory Accelerator (TMA) to asynchronously fetch offloaded weights and KV caches directly from remote memory into GPU shared memory (SMEM). To maximize remote access performance, DAK introduces a greedy algorithm to determine optimal per-operation offloading ratios, alongside active congestion control and TMA multicast to eliminate interconnect bottlenecks and read amplification. Evaluations across diverse architectures show that DAK achieves near-optimal bandwidth aggregation, with up to 3$\times$ performance gains on NVLink-C2C and 1.8$\times$ on PCIe systems compared to state-of-the-art memory offloading baselines.

### DAK: 具有最优效率的直接访问式大语言模型推理 GPU 内存卸载

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）参数规模和上下文长度的激增，GPU 本地显存（HBM）的容量和带宽已成为推理性能的瓶颈（即“内存墙”问题）。现有的分层内存方案（如将权重卸载到 CPU 内存）主要依赖**预取（Prefetching）**机制，即在计算前将数据从远程内存拷贝到本地 HBM。
论文指出预取存在三大缺陷：
*   **带宽竞争**：预取流量与计算内核的 HBM 访问竞争带宽，导致本地性能下降。
*   **容量浪费**：需要额外的 HBM 缓冲区来暂存预取数据。
*   **流水线气泡**：粗粒度的预取难以实现计算与通信的完美重叠。
**核心动机**：探索如何让 GPU 直接访问远程内存（Direct Access），绕过 HBM 暂存，从而实现系统总带宽（HBM + 互连带宽）的聚合利用。

#### 2. 方法论：核心思想与关键技术
DAK 提出了一个端到端的直接访问框架，其核心思想是利用 NVIDIA Hopper 架构中的**张量内存加速器（TMA）**，将其从原本的“HBM 到共享内存”加速器重用为“远程内存到共享内存”的异步传输引擎。

*   **直接访问内核（Direct Access Kernel）**：开发了 Warp 特化（Warp-specialized）的 `SplitK_GEMM` 和 `SplitK_FlashAttn` 内核。通过 TMA 将卸载的权重和 KV 缓存直接从主机内存流式传输到 GPU 共享内存（SMEM），实现计算与远程读取的细粒度重叠。
*   **最优贪心卸载算法**：针对推理中不同操作（计算密集型 vs 内存密集型）对卸载比例的敏感度不同，提出三阶段贪心算法：
    1.  优先分配预算给内存密集型操作，直到达到其有效带宽峰值。
    2.  剩余预算分配给计算密集型操作，利用计算时间掩盖传输延迟。
    3.  若仍有预算，则任意分配。该算法被证明具有理论最优性。
*   **主动拥塞控制**：通过限制在途（In-flight）的 TMA 请求数量和分配给主机的 SM 数量，防止远程访问请求挤占 GPU 内部互连资源，避免 HBM 访问性能下降。
*   **TMA 多播与主机感知调度**：针对主机内存不可被 GPU L2 缓存缓冲的问题，利用 TMA 多播技术将一份远程数据同时分发给多个 SM，消除读取放大效应。
