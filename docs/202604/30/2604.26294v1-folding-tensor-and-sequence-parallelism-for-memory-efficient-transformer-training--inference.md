## 摘要
我们提出了张量与序列并行（TSP），这是一种将张量并行与序列并行折叠到单个设备轴上的并行执行策略。在传统的多维并行布局中，张量并行（TP）对模型权重进行分片，而序列并行（SP）对标记（tokens）进行分片，分别减少了每个设备的参数或激活显存。传统上，每种方案都被分配到各自的网格维度。相比之下，TSP 为每个 rank 同时分配权重分片和序列分片，从而在同一设备轴上同时减少参数和激活显存。我们通过两种运行时调度实现了这一设计。对于注意力机制，各 rank 迭代遍历广播的参数分片，并通过序列维度的键/值（key/value）交换来重建上下文。对于门控 MLP，权重分片在环中循环，而部分输出在本地累加。通过在相同设备上对权重和激活进行分片，TSP 以额外的通信量换取了更低的显存开销。我们提供了理论上的通信和显存分析，描述了 TSP 注意力机制和门控 MLP 模块的实现，并将 TSP 与 TP、SP 以及 TP+SP 进行了基准测试。这些结果表明，TSP 是长上下文和显存受限模型训练的一种硬件感知型替代方案，并且可以作为一种可行的并行轴，与流水线并行和专家并行等现有并行方案协同工作，适用于稠密模型和混合专家模型。

## Abstract
We present tensor and sequence parallelism (TSP), a parallel execution strategy that folds tensor parallelism and sequence parallelism onto a single device axis. In conventional multi-dimensional parallelism layouts, tensor parallelism (TP) shards model weights while sequence parallelism (SP) shards tokens, reducing per-device parameter or activation memory, respectively. Traditionally, each scheme is assigned its own mesh dimension. TSP instead assigns each rank both a weight shard and a sequence shard, reducing both parameter and activation memory along the same device axis. We implement this design with two runtime schedules. For attention, ranks iterate over broadcast parameter shards and reconstruct context through a sequence-wise key/value exchange. For gated MLPs, weight shards circulate in a ring while partial outputs accumulate locally. By sharding both weights and activations across the same devices, TSP trades additional communication volume for reduced memory overhead. We provide a theoretical communication and memory analysis, describe our implementation of TSP attention and gated MLP blocks, and benchmark TSP against TP, SP, and TP+SP. These results position TSP as a hardware-aware alternative for long-context and memory-constrained model training, and as a viable axis of parallelism in concert with existing parallelism schemes such as pipeline and expert parallelism for dense and mixture-of-expert models.

    *   **传统 TP+SP**：通常将两者分配在不同的设备网格轴上（如 $T \times \Sigma$），这会消耗大量设备，且往往迫使并行组跨越低带宽的节点间网络。
*   **整体含义**：提出 **TSP (Tensor and Sequence Parallelism)**，将 TP 和 SP “折叠”到同一个设备轴上，使每个设备同时分片权重和序列，从而在单一并行维度上同时获得两者的显存收益。

### 2. 方法论：张量与序列并行折叠 (TSP)
*   **核心思想**：在同一个并行组内，每个 Rank 既持有一部分模型权重，也持有一部分序列标记。通过重新设计计算调度，在运行时动态交换权重或激活。
*   **关键技术细节**：
    *   **TSP Attention（注意力机制）**：
        *   采用**广播（Broadcast）**调度：循环遍历所有 Rank，每次由一个 Rank 广播其持有的权重分片（$W_Q, W_K, W_V, W_O$）。
        *   所有 Rank 在本地序列分片上计算投影，并对 $K, V$ 进行**全收集（All-gather）**以重建全量上下文。
        *   使用 **Zigzag 分片**方案来平衡因因果掩码（Causal Mask）导致的计算负载不均。
    *   **TSP Gated MLP（门控多层感知机）**：
        *   采用**环形（Ring）**调度：权重分片在设备间通过点对点（P2P）通信循环旋转。
        *   每个 Rank 在本地序列分片上应用接收到的权重分片并累加局部结果。
        *   **优势**：消除了标准 TP 中必需的 All-reduce 操作，通信量与参数量成正比而非激活量。
*   **通信重叠**：通过多流（Multi-stream）技术，将权重的移动（Broadcast/Ring Send-Recv）与矩阵乘法（GEMM）计算重叠，以掩盖额外的通信开销。

### 6. 主要结论与发现
*   **显存最优**：TSP 在所有测试序列长度下均实现了最低的每 GPU 峰值显存占用。它结合了 TP 的参数分片和 SP 的激活分片优势。
*   **吞吐量领先**：尽管 TSP 增加了通信步骤，但由于其减小了并行组规模（更容易保持在节点内高带宽域），且通信可被计算掩盖，其吞吐量在长文本场景下优于 TP+SP。
*   **通信临界点**：理论分析表明，当 $BS > 8h$（批次大小 $\times$ 序列长度 $>$ 8倍隐层维度）时，TSP 的通信效率开始优于传统 TP。

### 7. 优点
*   **显存效率极高**：是目前唯一能在单一并行轴上同时对权重和激活进行 $1/D$ 分片的方案。
*   **拓扑感知**：通过折叠维度，使模型并行组更小，从而最大化利用节点内（如 NVLink/Infinity Fabric）的高带宽，避免跨节点瓶颈。
*   **正交性**：TSP 可以作为一种新的并行轴，与流水线并行（PP）、专家并行（EP）和数据并行（DP）无缝组合。

### 8. 不足与局限
*   **通信量增加**：在短序列或小批次场景下，权重的频繁移动可能导致通信开销占比过高。
*   **实现复杂度**：相比标准 TP/SP，TSP 需要更复杂的异步调度逻辑和显存管理，以确保通信与计算的完美重叠。
*   **硬件依赖**：该方案在具有极高节点内带宽（如 MI300X 或 H100 系统）的硬件上表现最佳，在带宽受限的旧硬件上收益可能打折扣。
