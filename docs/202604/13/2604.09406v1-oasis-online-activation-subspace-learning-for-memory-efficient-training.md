## 摘要
训练大型语言模型（LLMs）受限于内存需求，其中激活值（activations）占总内存占用的很大一部分。现有方法通过低秩权重参数化或针对优化器状态的低秩梯度子空间来减少内存，而激活值内存则通过架构修改或基于定期更新投影的压缩方案来解决。我们提出了 OASIS，一种用于高效内存训练的在线激活子空间学习算法，该算法在训练过程中跟踪并持续更新低维激活子空间。中间激活值被投影到这个演化的子空间上，在不修改前向传播计算的情况下减少了内存。演化的激活子空间诱导了低秩梯度表示，使得梯度和优化器状态都能直接在该子空间中维护，同时投影感知优化器在子空间更新过程中一致地迁移优化器状态，以确保训练的稳定性。在各种微调和预训练任务中，OASIS 的峰值内存比全量微调降低了高达 2 倍，同时保持了相当的性能，并优于先前的低秩方法。

## Abstract
Training large language models (LLMs) is constrained by memory requirements, with activations accounting for a substantial fraction of the total footprint. Existing approaches reduce memory using low-rank weight parameterizations or low-rank gradient subspaces for optimizer states, while activation memory is addressed through architectural modifications or compression schemes based on periodically updated projections. We propose OASIS, an online activation subspace learning algorithm for memory-efficient training that tracks and continuously updates a low-dimensional activation subspace during training. Intermediate activations are projected onto this evolving subspace, reducing memory without modifying forward-pass computations. The evolving activation subspace induces low-rank gradient representations, enabling both gradients and optimizer states to be maintained directly in this subspace, while a projection-aware optimizer consistently transports optimizer states across subspace updates for stable training. Across various finetuning and pretraining tasks, OASIS achieves up to $2\times$ lower peak memory than full fine-tuning while matching its performance and outperforming prior low-rank methods.

*   **研究背景**：
    *   现有的低秩方法（如 LoRA）减少了参数和优化器内存，但无法减少用于反向传播的激活值内存。
    *   激活值内存随 Batch Size 和序列长度线性增长，在大规模训练中往往占据总内存的绝大部分。

*   **核心观察**：线性层的权重梯度位于输入激活值的跨度（Span）内。因此，通过识别并跟踪一个低维的激活子空间，可以同时压缩激活值、梯度和优化器状态。

### 2. 论文提出的方法论
OASIS 的核心思想是**在线学习并动态维护一个演化的低维激活子空间**。
*   **在线子空间学习（Oja's Rule）**：由于训练过程中激活值的分布会随参数更新而漂移（Subspace Drift），OASIS 使用 Oja 规则（一种流式 PCA 方法）在每个迭代步增量式更新投影基矩阵 $U_t$。这种方法避免了昂贵的全局奇异值分解（SVD）。
*   **激活值投影**：在前向传播中，仅存储投影后的低秩激活值 $\tilde{X}_t = X_t U_t$，将内存开销从 $O(Nd)$ 降至 $O(Nr)$（其中 $r \ll d$）。
*   **低秩梯度与优化器状态**：利用投影后的激活值直接计算低秩梯度，使得优化器状态（如 Adam 的动量和方差）也直接在低秩空间中维护。
*   **投影感知优化器（Projection-Aware Optimizer）**：当子空间 $U_t$ 发生变化时，通过子空间转换矩阵 $T_t = U_t^\top U_{t-1}$ 将旧的优化器状态“平滑迁移”到新空间，确保训练稳定性。

### 6. 主要结论与发现
*   **内存大幅降低**：在 Llama-2 7B 微调中，OASIS 的峰值内存比全量微调降低了约 **2 倍**，比 LDAdam 降低了超过 **30%**。
*   **性能保持**：在减少内存的同时，OASIS 的准确率能够匹配全量微调，并显著优于 LoRA 和 GaLore 等方法（尤其是在极低秩的压缩场景下）。
*   **子空间非静态性**：实验证实激活子空间在训练过程中持续演化，静态投影或频率过低的更新会导致性能下降。

### 7. 优点
*   **全方位压缩**：不同于以往只关注优化器状态的方法，OASIS 实现了激活值、梯度、优化器状态的**统一低秩表示**。
*   **无需修改架构**：作为一种优化算法，它不需要像 CoLA 等方法那样修改模型层结构，具有更好的通用性。
*   **动态适应**：引入 Oja 规则实现了高效的在线子空间跟踪，能够适应训练过程中的分布变化。

### 8. 不足与局限
*   **超参数敏感性**：引入了额外的超参数——**子空间学习率（$\gamma$）**。实验表明该参数对最终性能有显著影响，需要针对不同任务进行调优。
*   **计算开销**：虽然减少了内存，但每步更新子空间基矩阵和进行投影操作会带来一定的额外计算开销（虽然论文声称该开销较小）。
*   **极端规模验证**：目前实验最高只到 7B 模型，在千亿级（100B+）参数模型上的表现及内存节省比例仍有待进一步验证。
