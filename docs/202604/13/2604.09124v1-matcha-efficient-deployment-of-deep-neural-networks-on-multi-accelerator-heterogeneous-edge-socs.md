## 摘要
在具有多个异构加速引擎的片上系统（SoC）上部署深度神经网络（DNN）具有挑战性，且大多数部署框架无法充分利用异构性。我们提出了 MATCHA，这是一个统一的 DNN 部署框架，它能为并行异构加速器生成高度并发的调度方案，并利用约束规划来优化 L3/L2 内存分配与调度。通过在各个硬件单元之间使用模式匹配、分块（tiling）和映射，MATCHA 实现了并行执行和高加速器利用率。在 MLPerf Tiny 基准测试中，使用包含两个异构加速器的 SoC，MATCHA 与最先进的 MATCH 编译器相比，提高了加速器利用率，并将推理延迟降低了高达 35%。

## Abstract
Deploying DNNs on System-on-Chips (SoC) with multiple heterogeneous acceleration engines is challenging, and the majority of deployment frameworks cannot fully exploit heterogeneity. We present MATCHA, a unified DNN deployment framework that generates highly concurrent schedules for parallel, heterogeneous accelerators and uses constraint programming to optimize L3/L2 memory allocation and scheduling. Using pattern matching, tiling, and mapping across individual HW units enables parallel execution and high accelerator utilization. On the MLPerf Tiny benchmark, using a SoC with two heterogeneous accelerators, MATCHA improves accelerator utilization and reduces inference latency by up to 35% with respect to the the state-of-the-art MATCH compiler.

*   **研究动机**：为了在严苛的延迟和功耗约束下提升性能，需要一种能够跨异构硬件实现**层级并行（Layer-level）**和**分块级并行（Tile-level）**的编译器，以充分榨干硬件的并发潜力。

### 2. 方法论
MATCHA 基于 TVM 和 MATCH 编译器构建，其核心思想是将 DNN 算子拆分为细粒度的分块（Tiles），并异步地分发到不同的加速器上。
*   **以分块为中心的模式匹配**：不同于传统框架将整个算子映射到单一设备，MATCHA 允许将一个算子的不同分块分配给不同的加速器（例如，卷积层的一部分行在加速器 A 运行，另一部分在加速器 B 运行）。
*   **约束规划（Constraint Programming, CP）优化**：
    *   使用 CP 求解器联合优化模式匹配、分块分配和设备映射。
    *   **成本模型**：通过线性公式估算延迟，考虑了设备速度（$\alpha$）、内核效率（$\eta$）和调用开销（$\delta$）。
*   **内存与调度规划**：
    *   将内存分配视为“时间×地址”的二维装箱问题。
    *   支持静态分配、动态交换（L2 与 L3 之间）和按需加载。
    *   集成 **ZigZag** 工具来精细化 L1/L2 内存层级的循环分块和数据移动。
*   **异步运行时**：在无操作系统（OS-less）的环境下，通过中断和邮箱（Mailbox）机制实现主机（Host）与多个加速器之间的非阻塞任务调度。

### 6. 主要结论与发现
*   **性能提升**：在 ResNet-50 块上，MATCHA 相比 MATCH 降低了 **35%** 的延迟；在 MLPerf Tiny 的 AutoEncoder 上降低了 **33.3%**。

*   **开销权衡**：对于算术强度较低的算子（如深度可分离卷积），分块带来的切片（Slice）和拼接（Concat）开销可能会抵消并行收益，因此并非所有层都适合分块。

*   **开源贡献**：代码已在 GitHub 开源，具有较高的学术和工程参考价值。

### 8. 不足与局限
*   **辅助算子开销**：目前对分块产生的 `Slice` 和 `Concat` 算子的延迟建模不够精确，可能导致在某些轻量级网络上优化效果不佳。
