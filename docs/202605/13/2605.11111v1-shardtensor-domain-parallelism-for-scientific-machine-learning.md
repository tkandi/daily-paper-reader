## 摘要
科学机器学习（SciML）在处理极高分辨率数据时面临独特挑战，现有的缓解措施往往难以扩展，或者会降低训练模型的准确性。虽然一些专门的方法通过定制技术在海量空间数据集的模型训练或推理中取得了显著成果，但目前尚缺乏一种通用的框架，能够在每个设备批量大小（batch size）小于 1 的情况下对输入数据进行并行化处理。在这项工作中，我们引入了 ShardTensor：一种新颖的领域并行范式，能够将输入数据灵活扩展到任意规模。通过将输入数据的空间维度与硬件限制解耦，ShardTensor 使科学机器学习工作负载能够达到高保真训练和推理的新水平。我们展示了训练和推理过程中工作负载的强扩展性和弱扩展性，证明了强扩展性能改善延迟，而弱扩展性则展示了处理更大规模数据的能力。此外，我们还展示了多维并行化，消除了在极端规模输入上进行 SciML 的障碍。

## Abstract
Scientific Machine Learning (SciML) faces unique challenges for extreme-resolution data, with mitigations that often fail to scale or degrade the accuracy of trained models. While some specialized methods have achieved remarkable results in training models or performing inference on massive spatial datasets with bespoke techniques, there is no generalized framework for parallelization over input data below batch size one per device. In this work we introduce ShardTensor: a novel paradigm of domain parallelism that enables flexible scaling of input data to arbitrary sizes. By decoupling the spatial dimensionality of input data from hardware constraints, ShardTensor enables scientific machine learning workloads to reach new levels of high fidelity training and inference. We demonstrate both strong and weak scaling of workloads during training and inference, showing improved latency with strong scaling and demonstrating the capacity to process higher data sizes with weak scaling. Additionally, we demonstrate multiple dimensions of parallelization, removing barriers to SciML on extreme-scale inputs.

### 1. 核心问题与整体含义（研究动机和背景）
*   **核心问题**：科学机器学习（SciML）处理的数据通常具有极高的空间分辨率（如3D/4D物理模拟）。由于“维度灾难”，分辨率翻倍会导致数据量呈指数级增长。
*   **瓶颈**：在训练过程中，GPU显存的主要消耗者是**中间激活值（Activations）**而非模型参数。现有的并行方案（如数据并行DDP）在达到“每设备批次大小为1”的极限后无法继续扩展，导致超高分辨率数据无法在单个GPU上进行训练或推理。
*   **研究背景**：虽然存在一些针对特定任务（如Ring Attention）的定制化并行方案，但缺乏一种通用的、能将输入数据在空间维度上进行切分并跨设备并行处理的框架。

### 2. 核心方法论：ShardTensor
*   **核心思想**：引入“领域并行（Domain Parallelism）”范式，将输入数据（Domain）切分到多个GPU上。ShardTensor 是对 PyTorch `DTensor` 的扩展。
*   **关键技术细节**：
    *   **动态分片描述**：不同于 `DTensor` 假设的静态均匀分布（主要用于权重），ShardTensor 增加了“分片形状（sharding shapes）”元数据，支持非均匀或动态变化的数据分布（如点云、非结构化网格）。
    *   **分发机制（Dispatch）**：利用 PyTorch 的 `__torch_dispatch__` 和 `__torch_function__` 钩子，在运行时动态拦截操作。
    *   **通信算子**：自动处理跨设备通信，例如卷积层需要的“光环交换（Halo Exchange，获取相邻分片的边缘像素）”和归一化层需要的全局统计量聚合。
    *   **编程模型**：采用非侵入式设计，用户只需通过简单的包装器（Wrapper）即可将现有模型扩展到领域并行，且能与 FSDP（完全分片数据并行）等现有技术组合使用。

### 7. 优点
*   **通用性强**：不绑定特定架构，支持卷积、Transformer、线性层等多种算子。
*   **易用性**：对用户代码侵入性极小，符合 PyTorch 生态的使用习惯。
*   **多维并行**：证明了领域并行可以与模型并行、数据并行正交组合，构建多维并行策略。

### 8. 不足与局限
*   **分发开销**：基于 Python 的命令式分发在处理小规模、计算量低的操作时，CPU 启动延迟和通信开销会抵消并行收益。
*   **编译支持不足**：目前尚未完全集成 `torch.compile`，限制了算子融合和通信/计算重叠的进一步优化。
*   **算子覆盖**：并非所有 PyTorch 算子都已实现领域并行路径，不支持的操作会退回到标准语义，可能导致性能瓶颈。
*   **硬件依赖**：性能高度依赖于 GPU 间的高速互联（如 NVLink），在低带宽环境下扩展效率会显著下降。
