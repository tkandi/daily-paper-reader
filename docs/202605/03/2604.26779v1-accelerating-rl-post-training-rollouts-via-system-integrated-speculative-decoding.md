## 摘要
前沿语言模型的强化学习（RL）后训练日益受到自回归 Rollout 生成的瓶颈限制，使得 Rollout 加速成为核心的系统挑战。许多现有的效率提升方法通过改变 Rollout 或优化方案来提高吞吐量，例如通过离策（off-policy）执行、重放或低精度生成。我们研究将投机解码（Speculative Decoding）作为 RL Rollout 的一种无损加速原语，它能保持目标模型的输出分布。我们在以 vLLM 为后端的 NeMo-RL 中实现了投机解码，支持同步和异步流水线，并在 RL Rollout 期间启用投机。这种收益可以通过多种投机机制实现，例如预训练的 MTP 头、小型外部草稿模型，甚至是传统上在 RL 阶段之后应用的 Eagle3 等技术。这为在 RL 训练中部署最先进的投机解码提供了一条路径。在 8B 规模的同步 RL 推理后训练工作负载中，投机解码将 Rollout 吞吐量提高了 1.8 倍。利用高保真性能模拟器，我们预测在 235B 规模下，将投机解码与异步 RL 相结合可实现高达 2.5 倍的端到端训练加速。

## Abstract
RL post-training of frontier language models is increasingly bottlenecked by autoregressive rollout generation, making rollout acceleration a central systems challenge. Many existing efficiency methods improve throughput by changing the rollout or optimization regime, for example, through off-policy execution, replay, or lower-precision generation. We study speculative decoding as a lossless acceleration primitive for RL rollouts that preserves the target model's output distribution. We implement speculative decoding in NeMo-RL with a vLLM backend, supporting both synchronous and asynchronous pipelines and enabling speculation during RL rollouts. This benefit is realizable across speculation mechanisms, such as pretrained MTP heads, small external draft models or even techniques such as Eagle3, which are traditionally applied after RL phase. This yields a deployment path for state-of-the-art speculative decoding inside RL training. In a reasoning post-training workload at 8B scale under synchronous RL, speculative decoding improves rollout throughput by 1.8x. Using a high-fidelity performance simulator, we project that combining speculative decoding with asynchronous RL yields up to 2.5x end-to-end training speedup at 235B scale.

*   **现有方案局限**：异步执行、离策重放或低精度生成等方法虽然能提升吞吐量，但往往会改变采样分布或引入策略滞后，影响训练的有效性。
*   **研究目标**：引入**投机解码（Speculative Decoding）**作为一种“无损”加速原语，在保证采样分布与目标策略完全一致的前提下，显著提升 Rollout 阶段的吞吐量。

### 2. 方法论
*   **核心思想**：在 RL 训练循环中集成投机采样机制。利用一个轻量级的“草稿模型”（Draft Model）预先生成多个 Token，再由“目标策略模型”（Policy Model）进行并行验证。
*   **关键技术细节**：
    *   **系统集成**：在 NeMo-RL 框架中结合 vLLM 推理后端，实现了 Learner（学习器）与 Rollout 引擎之间的**权重实时同步**。
    *   **草稿机制**：支持两种路径：一是通用的 **EAGLE-3** 路径（适用于任何预训练模型）；二是**原生 MTP**（多 Token 预测）路径（适用于自带预测头的模型）。
    *   **在线草稿适配（Online Adaptation）**：为了防止策略模型在 RL 过程中更新导致草稿模型失准，系统利用计算 GRPO 损失时的隐藏状态缓存，通过梯度分离（`.detach()`）路径在线微调草稿头，确保两者对齐。
    *   **流水线支持**：同时适配同步 RL 和异步 RL 流水线。

### 3. 实验设计
*   **数据集/场景**：专注于**数学推理**任务。使用 DAPO-Math-17K 进行训练，在 AIME-2024 验证集上评估准确率。
*   **模型规模**：主要实验基于 **Qwen3-8B**（包括 Base 和已微调版本）。
*   **Benchmark 与对比方法**：
    *   基准：标准的自回归（AR）生成。
    *   对比：n-gram 投机采样（模型无关）、EAGLE-3 投机采样（模型相关）。
*   **消融实验**：研究了草稿模型初始化（通用域 vs. 任务域）、草稿长度 $k$（3, 5, 7）、在线 vs. 离线适配的影响。

### 4. 资源与算力
*   **硬件环境**：使用了 8 个 **GB200 NVL72** 节点。
*   **GPU 配置**：每个节点包含 4 个 GPU，共 **32 个 GB200 GPU**。每个 GPU 拥有 186 GB HBM3E 显存。
*   **互联技术**：采用第五代 NVLink 连接。
*   **大规模模拟**：利用高保真性能模拟器，将实验结论扩展至 **2048 个 GB200 GPU** 规模的 235B 模型训练预测。

### 5. 实验数量与充分性
*   **实验规模**：涵盖了从 8B 实际训练到 235B 模拟预测的完整区间。
*   **充分性**：
    *   通过训练全过程的准确率曲线对比，证明了投机解码的**无损性**（准确率与自回归完全重合）。
    *   针对不同初始化策略和超参数（如 $k$ 值）进行了详细的消融实验。
    *   实验设计考虑了同步和异步两种主流 RL 架构，具有较强的工程参考价值。

### 6. 主要结论与发现
*   **加速效果**：在 8B 规模同步 RL 中，Rollout 吞吐量提升 **1.8 倍**，带动端到端单步训练速度提升 **1.41 倍**。
*   **规模效应**：模拟显示，在 235B 规模下，结合异步 RL，端到端加速可达 **2.5 倍**。
*   **草稿长度悖论**：增加草稿长度 $k$ 虽然能提高接受长度，但会增加验证开销。实验发现 $k=3$ 是 8B 规模下的最优平衡点，过大的 $k$ 反而会导致速度慢于自回归。
*   **初始化至关重要**：使用任务相关数据初始化的草稿模型比通用域模型表现显著更好。

### 7. 优点
*   **无损性**：这是该方法最大的亮点，它在不改变 RL 算法语义的情况下纯粹通过系统优化实现加速。
*   **深度集成**：解决了 RL 训练中模型权重动态变化与投机采样需要静态权重的矛盾，提供了在线适配方案。
*   **针对性强**：精准打击了当前推理模型训练中“生成长、训练短”的痛点。

### 8. 不足与局限
*   **维护成本**：EAGLE-3 等外部草稿模型需要额外的训练和维护成本，增加了系统的复杂性。
*   **加速上限**：受阿姆达尔定律限制，加速仅作用于生成阶段。如果训练阶段（如梯度计算）占比提升，该方法的边际收益会递减。
*   **任务依赖**：实验主要集中在数学推理，对于 Token 接受率较低的其他任务（如高度发散的创意写作），加速效果可能不明显。
