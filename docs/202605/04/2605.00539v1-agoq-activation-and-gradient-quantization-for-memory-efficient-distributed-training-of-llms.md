## 摘要
量化是降低大语言模型（LLM）训练过程中 GPU 显存需求的关键方法。然而，现有方法在处理 4-bit 激活和 8-bit 梯度时效果不佳，容易导致收敛缓慢或精度损失。为了解决这一问题，我们提出了 AGoQ，它包含两项新技术：1）一种层感知激活量化算法，根据不同层的类型和流水线阶段为其分配适当的位宽，以实现接近 4-bit 的激活存储；2）一种梯度量化算法，通过采用 8-bit 梯度存储和保持精度的 8-bit All-Reduce 通信，减少显存占用并缩短通信时间。我们在两个 GPU 集群（最多 64 个 GPU）上使用不同规模的 LLM 进行了广泛实验。实验结果表明，与最先进的训练系统 Megatron-LM（含或不含 ZeRO）、COAT 和 DeepSpeed 相比，AGoQ 在 8B 到 32B 的 LLaMA 模型上可减少高达 52% 的显存占用，并将训练速度提高多达 1.34 倍，同时在预训练中实现了收敛损失，并在 LLaMA 架构的下游任务中达到了相当的精度。

## Abstract
Quantization is a key method for reducing the GPU memory requirement of training large language models (LLMs). Yet, current approaches are ineffective for 4-bit activations and 8-bit gradients, which would easily cause slow convergence or accuracy loss. To address this, we introduce AGoQ, incorporating two new techniques: 1) a layer-aware activation quantization algorithm that allocates appropriate bit-widths for activations of various layers based on their types and pipeline stages to achieve near 4-bit activation storage, and 2) a gradient quantization algorithm that reduces memory usage and shortens communication time by employing 8-bit gradient storage and precision-preserving 8-bit All-Reduce communication. We conduct extensive experiments using different sizes of LLMs on two GPU clusters (up to 64 GPUs), and the experimental results show that our AGoQ reduces the memory by up to 52\% and achieves up to 1.34$\times$ improvement of training speed compared to state-of-the-art training systems Megatron-LM (w/ or w/o ZeRO), COAT and DeepSpeed with 8B to 32B LLaMA models, while achieving convergence loss on pretraining and comparable accuracy on downstream tasks with LLaMA architectures.

*   **核心问题**：LLM 训练面临巨大的显存压力，主要来自模型参数、梯度、优化器状态和中间激活值。
*   **研究动机**：
    *   现有的激活重计算（Activation Recomputation）虽然节省显存但会引入额外的计算开销，降低训练速度。
    *   现有的 8-bit 量化方法（如 INT8 或 FP8）在 4-bit 激活或 8-bit 梯度存储时容易导致模型不收敛或精度大幅下降。

*   **整体含义**：AGoQ 通过精细化的量化策略，在不牺牲模型收敛性的前提下，挑战了 4-bit 激活和 8-bit 梯度的训练极限。

### 2. 方法论：核心思想与关键技术
AGoQ 结合了三项核心技术：
*   **层感知激活量化（LAAQ）**：
    *   **误差分析驱动**：通过数学推导证明不同层对量化误差的敏感度不同。RMSNorm 和 MLP（SiLU）层可以通过“存储 4-bit 输入+反向传播时重计算中间值”的策略来降低误差；而 Attention 层的梯度误差随序列长度呈超线性增长，因此保持高精度。
    *   **动态位宽补偿（DBCA-PP）**：利用流水线并行（PP）中不同阶段显存占用不均的特性，为显存压力较小的阶段分配更高位宽（如 5-8 bit），以补偿整体精度，同时不增加峰值显存。
*   **保精度梯度量化（QuanGrad）**：
    *   **8-bit 存储**：使用 FP8 格式存储主梯度，在局部梯度累加时临时转为高精度计算以避免溢出。
    *   **8-bit 通信优化**：为了防止 All-Reduce 过程中的求和溢出，将 All-Reduce 分解为“All-to-All 通信 + 局部高精度归约 + All-Gather”，确保通信效率的同时维持数值稳定性。
*   **算子融合（Kernel Fusion）**：将量化/反量化操作与 GEMM（矩阵乘法）内核融合，利用 Tensor Core 处理计算，CUDA Core 处理量化，几乎消除了量化带来的额外时间开销。

### 7. 优点

*   **Attention 层限制**：由于误差敏感性，Attention 层仍需保持高精度，这意味着激活压缩率尚未达到理论极限。

*   **超参数敏感度**：DBCA-PP 的位宽分配公式可能需要根据不同的模型架构进行微调。
