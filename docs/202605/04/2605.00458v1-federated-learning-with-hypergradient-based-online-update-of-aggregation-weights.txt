# Federated Learning with Hypergradient-based Online Update of Aggregation Weights 

Ayano Nakai-Kasai, Member, IEEE, and Tadashi Wadayama, Member, IEEE 

Abstract —Federated learning using mobile and Internet of Things devices requires not only the ability to handle hetero-geneity of clients’ data distributions but also high adaptability to varying communication environments. We propose FedHAW (Federated Learning with Hypergradient-based update of Aggre-gation Weights) that implements online updates of aggregation weights. FedHAW updates the aggregation weights by using hypergradient, the gradient of the objective function with respect to the weights, which can be calculated with low computational overhead. Simulation results show that the proposed method possesses high generalization performance in heterogeneous en-vironments and high robustness to communication errors. 

Index Terms —Federated learning, hypergradient descent, ag-gregation weight update, heterogeneity, communication errors. 

I. I NTRODUCTION 

# INCREASING number of mobile and IoT (Internet of Things) devices encourages the provision of applications utilizing personal data stored on them. FL (Federated Learn-ing) [1] is a distributed machine learning method for such settings that achieves privacy protection and data processing load reduction: each client updates its model on local data, the server aggregates the clients’ models—primarily over wireless links—by weighted averaging, and the procedure repeats for multiple rounds without sharing raw personal data between the clients and the server. A serious problem in FL is heterogeneity of clients [2]. Clients have different computing capabilities and network environments. The data distributions are non-IID (independent and identically distributed). The heterogeneity causes bias in the learning process and degradation of the inference accuracy of the model [3]. Especially in terms of IoT devices, the communication environment is often unstable due to its lim-ited power and communication capability, and the erroneous communication link influences the FL training process [4]. To address this performance degradation due to the het-erogeneity of clients, FL algorithms that are robust to the learning environmental changes have been proposed. The majority of such methods are based on the idea that the amount of each client’s model parameter update in a round can be used to adjust each client’s learning process. Such amount is incorporated into the client update process [5], [6] or the central server’s aggregation process [7], [8], and allows

FedLAW (Federated Learning with Learnable Aggregation Weights) [9] is the method based on another perspective that achieves robustness to the learning environmental changes by learning of the FL training process itself. The update rules of FedLAW correspond to learning the aggregation weights in each round of FL training using pre-prepared data. However, this overhead can be significant relative to total FL training time and may induce unexpected changes in communication or device conditions during training. Another drawback is the need to prepare data specifically for the aggregate weight learning. It is often difficult to prepare data that reflect the true data distribution. In this letter, we improve the robustness of FedLAW to the learning environmental changes by enabling online update of the aggregation weights. We propose FedHAW (Federated Learning with Hypergradient-based update of Aggregation Weights), a method that updates the aggregation weights online using hypergradient descent [10]. The hypergradient descent is an online learning rate optimization method for gradient descent using the gradient of the objective function with respect to the learning rate, which yields high tracking ability to the environmental changes. We apply this online update idea to the aggregation weights of FedLAW to reduce learning time overhead and improve adaptability to the current environment. The main contributions of this letter are as follows:  

> •

We propose FedHAW that allows the hypergradient-based online update of the aggregation weights in each round of FL training process, which enables adaptively adjusting the learning process to the heterogeneity of data distributions and the current communication environment with low computational overhead. FedHAW does not require additional training data.  

> •

FedHAW can be combined with any client update process of FL algorithms.  

> •

Simulation results show that FedHAW possesses both high generalization performance and online capability. II. P RELIMINARIES

IV. S IMULATION RESULTS 

A. Experimental Setup 

In this section, we evaluate the image classification perfor-mance of the proposed FedHAW under heterogeneous environ-ments and communication errors. We prepared non-IID local datasets for K = 10 clients from MNIST dataset, CIFAR-10 dataset, and Stanford Dogs dataset [11], [12] by using the Dirichlet distribution [13], [14]. The concentration parameter 

Dα of the Dirichlet distribution was set to Dα ∈ { 1, 0.1}. We used a 3-layer MLP for MNIST, ResNet-18 for CIFAR-10, and a frozen ImageNet-21k-pretrained ViT [15] + FC for Stanford Dogs. Table I summarizes the dataset-specific local settings. The meta learning rates for FedHAW were set to (ηγ , η λ) = (10 −3, 10 −2) for MNIST dataset, (10 −5, 10 −2) for CIFAR-10 dataset, and (10 −7, 10 −5) for Stanford Dogs dataset. The initial parameters were set to γ(0) = 0 and λ(0)  

> k

= Nk/N .We compared performance with conventional FL algorithms in terms of the server-side aggregation process, FedAvg [1], FedAdp [7], FedHyper-G [8], FedLWS [16], and FedLAW [9]. With the exception of FedLAW, these methods are online methods that do not require separate training data or separate training in every round. For FedLAW, we used a proxy dataset of size 10 × the number of classes from each dataset’s test split, with 100 proxy epochs and learning rate = 0 .01 . No sample in the proxy subset was used in the final test subset for all methods. FedLWS is an extension of FedLAW that uses layer-dependent γ and employs online learning for it. In this experiment, we used the same weight as in FedAvg for FedLWS. We report test accuracy on held-out balanced test sets for each dataset. The experimental codes and datasets are available in a GitHub repository 1.

D. Combination with Other Client Update 

As discussed in the last paragraph in Sect. III-B, the hypergradient-based update of aggregation weights in Fed-HAW can be combined with any client update process of FL algorithms. We finally evaluate the performance of the proposed FedHAW when combined with another client update process, FedProx [5]. FedProx is a client update process that adds a proximal term to the loss function to regularize the model parameters. We set pe = 0 .5 and Dα = 0 .1 for each dataset, and the other parameter settings were the same as in Sect. IV-C. Table V summarizes the test accuracy of FedProx and FedProx+HAW in rounds ti = iT / 5 − 1 for i = 1 , 2, 3, 4, 5.FedProx+HAW shows better performance than FedProx in most rounds. The fact that FedProx+HAW achieved higher accuracy, particularly from the early rounds, indicates that the adoption of the hypergradient-based update can effectively improve the accuracy of FedProx.
