## 摘要
多头潜变量注意力（MLA）是 DeepSeek-V2/V3 所采用的注意力机制，它将键（Key）和值（Value）共同压缩为低秩潜变量，几乎完美地契合了 H100 的 roofline 性能上限。然而，其训练后的权重仅暴露了一种解码路径——即吸收后的 MQA 形式——这使得高效推理受限于 H100 级别的算力带宽比，丧失了沿头轴（head axis）的张量并行性，并且在受出口限制的 H20 等商用推理 GPU 上无法获得多标记预测（MTP）的增益。我们提出了分组查询潜变量注意力（GQLA），这是对 MLA 的一种极简修改，其训练权重在相同参数下暴露了两条代数等价的解码路径：一条是与 MLA 相同的 MQA 吸收路径，另一条是具有每组扩展缓存的 GQA 路径。运行时会根据目标硬件选择匹配的路径，无需重新训练或自定义算子，因此单套 GQLA 权重即可同时达到 H100（MQA 吸收，s_q=1）和 H20（GQA + MTP，s_q=2）的性能极限，同时在 GQA 路径上支持高达 8 路的零冗余张量并行。为了避免从头开始预训练，我们将 TransMLA 扩展为 TransGQLA，用于将预训练的 GQA 检查点转换为 GQLA 模型；在 LLaMA-3-8B 上，它在 MQA 吸收路径上将每标记 KV 缓存压缩至 GQA 基线的 28.125%，同时在每组路径上结构性地保留了 GQA 级别的流量。

## Abstract
Multi-head Latent Attention (MLA), the attention used in DeepSeek-V2/V3, jointly compresses keys and values into a low-rank latent and matches the H100 roofline almost perfectly. Its trained weights, however, expose only one decoding path - an absorbed MQA form - which ties efficient inference to H100-class compute-bandwidth ratios, forfeits tensor parallelism along the head axis, and yields no Multi-Token Prediction (MTP) gain on commodity inference GPUs such as the export-restricted H20. We propose Group-Query Latent Attention (GQLA), a minimal modification of MLA whose trained weights expose two algebraically equivalent decoding paths over the same parameters: an MQA-absorb path identical to MLA's, and a GQA path with a per-group expanded cache. The runtime picks the path that matches the target hardware - no retraining, no custom kernels - so a single set of GQLA weights pins the rooflines of both H100 (MQA-absorb, s_q=1) and H20 (GQA + MTP, s_q=2), while supporting up to 8-way zero-redundancy tensor parallelism on the GQA path. To avoid pretraining from scratch we extend TransMLA into TransGQLA, which converts a pretrained GQA checkpoint into a GQLA model; on LLaMA-3-8B it compresses the per-token KV cache to 28.125% of the GQA baseline on the MQA-absorb path while structurally preserving GQA-level traffic on the per-group path.

### GQLA：面向硬件自适应大语言模型解码的分组查询潜变量注意力

#### 1. 论文的核心问题与整体含义（研究动机和背景）
现代大语言模型（LLM）的推理瓶颈主要在于 KV 缓存（KV Cache）的内存带宽压力。DeepSeek 提出的 **MLA（多头潜变量注意力）** 通过将 KV 压缩为低秩潜变量，极大地减少了缓存体积，在 NVIDIA H100 等顶级 GPU 上表现优异。

然而，MLA 存在三个核心缺陷：
*   **硬件耦合性**：MLA 强制使用“MQA 吸收（MQA-absorb）”路径，其算力带宽比固定，仅适配 H100。在受限硬件（如 H20）上，由于算力大幅削减而带宽保留，MLA 会导致推理变成“计算受限”，无法发挥硬件潜力。
*   **张量并行（TP）不友好**：MLA 的吸收形式要求每个设备都复制一份潜变量，无法沿头轴（head axis）进行高效的张量并行。
*   **多 Token 预测（MTP）无增益**：在 H20 等算力受限的卡上，开启 MTP 会增加计算强度，导致吞吐量几乎没有提升。

**GQLA** 的提出旨在通过一种“硬件自适应”的架构设计，使同一套模型权重能够根据部署硬件自动选择最优解码路径。

#### 2. 论文提出的方法论
GQLA 是对 MLA 的极简改进，核心思想是**将 MLA 中原本按“头”复制的上投影矩阵改为按“组”索引**。

*   **核心架构**：保留了 MLA 的低秩压缩机制，但引入了分组（Group）概念。
*   **双解码路径（代数等价）**：
    1.  **MQA 吸收路径**：将上投影矩阵吸收到 Query 和 Output 投影中，直接对潜变量进行注意力计算。这与 MLA 相同，适合带宽受限、算力充裕的 H100。
    2.  **GQA 路径**：在推理时将潜变量展开为分组后的 Key 和 Value。这增加了缓存体积，但大幅降低了计算强度，适合算力受限的 H20，并天然支持张量并行。
*   **TransGQLA 转换技术**：提出了一种无需从头训练的方法，通过修改 TransMLA 的“头合并（head-merging）”步骤，将现有的 GQA 模型（如 LLaMA-3）转换为 GQLA 结构。
*   **稀疏扩展（Sparse GQLA）**：通过设置 Query 与 KV 组的比例为 16（匹配 Tensor Core 的 MMA 指令维度），使稀疏注意力在 H20 上也能高效运行。
