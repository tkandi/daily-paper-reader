## 摘要
大语言模型在单一参数集中同时编码通用能力和特定领域知识。我们探究能否重新组织这种能力：将广泛有用的计算保留在共享主干中，而将专门知识移至外部记忆模块。我们提出知识卸载（KOFF）框架，将预训练大语言模型分解为稀疏共享主干与特定领域记忆。从冻结的基座模型出发，我们联合学习结构化剪枝掩码和轻量恢复模块，这些恢复模块通过LoRA适配器和学习的键值缓存实现。在3B至8B参数的Llama和Qwen模型上，我们发现可以从共享主干中移出可观的容量而不显著损失模型能力。在约12%的全局稀疏度下，KOFF保留了未剪枝模型的大部分性能，而对同一冻结模型进行无记忆模块的剪枝则性能急剧下降。消融实验显示LoRA与学习的KV记忆是互补的，且专业化分析表明所学分解是有意义的：特定语言的神经元被优先移除，而通用语言的神经元则大多保留在主干中。这些结果表明，知识可以在共享核心与可交换的外部记忆之间重新分配。

## Abstract
LLMs encode both general capabilities and domain-specific knowledge in a single set of parameters. We ask whether this capacity can be reorganized: keeping broadly useful computation in a shared backbone, while moving specialized knowledge into external memory modules. We propose \emph{knowledge offloading} (KOFF), a framework for decomposing a pretrained LLM into a sparse shared backbone and domain-specific memories. Starting from a frozen base model, we jointly learn a structured pruning mask and lightweight recovery modules, implemented as LoRA adapters and learned key-value caches. Across Llama and Qwen models from 3B to 8B, we find that non-trivial capacity can be moved out of the shared backbone without a large loss in model ability. At around 12\% global sparsity, KOFF preserves much of the unpruned model's performance, while pruning the same frozen model without memories degrades sharply. Ablations show that LoRA and learned KV memories are complementary, and specialization analyses suggest that the learned decomposition is meaningful: language-specific neurons are preferentially removed while language-general neurons largely remain in the backbone. These results suggest that knowledge can be reallocated between a shared core and swappable external memories.

### 2. 论文提出的方法论

该框架的核心思想是**联合学习结构剪枝掩码（mask）和领域恢复模块**。整个流程基于一个冻结参数的预训练模型进行。

*   **核心思想**：通过蒸馏损失，让模型自行决定哪些容量可以被移除（剪枝）并由外部记忆恢复，哪些必须保留在主干网络中。
*   **关键技术细节与流程**：
    1.  **学习稀疏主干（Sparse Backbone）**：
        *   使用基于**硬性混凝土分布（Hard Concrete distribution）** 的L0正则化方法学习一个**结构化剪枝掩码 `z`**。
        *   该掩码作用于注意力机制的键/值投影（`WK`, `WV`）和多层感知机的三个投影（`W_gate`, `W_up`, `W_down`）的输出通道。
        *   目标是通过L0惩罚项 `Ω(z)` 来鼓励主干保持稀疏。
    2.  **构建领域记忆模块（Domain Memory Modules）**：
        *   为每个领域 `d` 创建一个模块 `M_d`，用以补偿被主干移除的领域相关容量。每个模块包含两种互补的记忆机制：
            *   **参数空间记忆——LoRA适配器（LoRA Adapters）**：在主干被剪枝的线性层旁路增加低秩分解矩阵，提供轻量级参数矫正。
            *   **激活空间记忆——可学习KV缓存（Learned KV Cache）**：在注意力层插入可训练的键-值对，作为外部存储，在推理时与文本的键-值对拼接。
    3.  **联合学习目标**：
        *   优化目标是让挂载领域模块 `M_d` 的稀疏模型 `f_{θ,z, M_d}` 的输出分布，与原始教师模型 `f_θ` 匹配，使用KL散度作为蒸馏损失 `L_distill`。
        *   **领域训练**：对于来自领域 `d` 的批次，挂载对应模块 `M_d`，同时更新掩码 `z` 和该模块的参数。
        *   **通用保留（Retention）训练**：周期性引入无领域标签的通用语料（如C4、GSM8K），随机挂载一个领域模块 `M_̃d`，但**只更新掩码 `z`**。这会惩罚移除在通用领域也重要的神经元，迫使主干保留通用能力。
    4.  **推理过程**：
        *   训练完成后，掩码 `z` 被固定，并物理移除被剪枝的神经元，得到一个紧凑的密集主干。
        *   训练一个基于RoBERTa的轻量级**路由器**来预测输入 `x` 所属的领域 `d̂`，然后挂载相应的领域记忆模块进行生成。
    5.  **数学化流程**：
        *   **总目标**：`min_{z, {M_d}} ∑_d E_{x~D_d}[L_distill(f_{θ,z,M_d}, f_θ; x)] + λΩ(z) + µL_retain(z, {M_d})`
        *   **保留损失**：`L_retain` 是从通用数据中采样，随机配对一个领域模块后计算的蒸馏损失。

### 6. 论文的主要结论与发现

*   **容量重定位可行**：在不显著损失模型能力的前提下，可以将相当比例的领域专属容量从共享主干中移入外部记忆模块。

*   **LoRA与KV缓存互补**：单个恢复机制均有帮助，但联合使用效果最好。
*   **联合学习优于两阶段训练**：在剪枝过程中让模块参与学习（“剪枝+恢复”联合优化）比先剪枝后恢复效果更好，因为前者能做出更优的容量分配决策。
*   **模块职责分离有意义**：
    *   **功能特异性**：每个领域的记忆模块在其自身领域效果最佳，跨领域使用会导致性能下降。
    *   **结构特异性**：剪枝掩码优先移除了语言特异性神经元，而保留了通用语言神经元。
