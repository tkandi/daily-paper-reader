## 摘要
联邦学习使得在不共享原始数据的情况下进行协作模型训练成为可能，但在客户端数据分布异质的情况下，其性能可能大幅下降。单一的全局模型往往无法满足多样化的客户端需求，因此个性化联邦学习被探索用于在保持全局泛化能力的同时提高客户端特定性能。现有的个性化联邦学习方法通常面临一个根本性权衡：更强的全局共享可能削弱局部特化，而更强的局部自适应则可能在数据有限、标签不平衡和缺失类别场景下导致过拟合。在这项工作中，我们提出 PGFedSplit，一种在严重客户端异质性下同时提升个性化和全局泛化能力的个性化联邦学习框架。PGFedSplit 采用拆分架构，并根据不同模型组件的角色执行自适应聚合调度，实现稳定的知识共享，同时保持客户端特定自适应。每个客户端进一步利用本地提取的表征与基于服务器端高斯统计生成的合成表征的混合，提高在标签不平衡和缺失类别条件下的鲁棒性。在 Fashion-MNIST、CIFAR-10、CIFAR-100 和 Tiny ImageNet 上的广泛实验表明，PGFedSplit 相较于最先进的个性化联邦学习方法具有一致的改进，在高度异质设置下表现出稳定的收敛性和优越的个性化能力。

## Abstract
Federated learning enables collaborative model training without sharing raw data, but its performance can degrade substantially under heterogeneous client data distributions. A single global model often cannot satisfy diverse client requirements, so personalized federated learning has therefore been explored to improve client specific performance while preserving global generalization. Existing PFL methods often face a fundamental tradeoff in which stronger global sharing can undermine local specialization, whereas stronger local adaptation can lead to overfitting under limited data, label imbalance, and missing class scenarios. In this work, we propose PGFedSplit, a personalized federated learning framework that improves both personalization and global generalization under severe client heterogeneity. PGFedSplit adopts a split architecture and performs adaptive aggregation scheduling tailored to the roles of different model components, enabling stable knowledge sharing while maintaining client specific adaptation. Each client further leverages a mixture of locally extracted representations and synthetic representations generated from server side Gaussian statistics, improving robustness under label imbalance and missing class conditions. Extensive experiments on Fashion MNIST, CIFAR 10, CIFAR 100, and Tiny ImageNet demonstrate consistent improvements over state of the art PFL methods, with stable convergence and superior personalization in highly heterogeneous settings.

- **背景与动机**：联邦学习（FL）允许多客户端在不共享原始数据的情况下协同训练模型，但在客户端数据统计异质性（non-IID）较强时，单一全局模型性能会严重退化。
- **核心矛盾**：个性化联邦学习（PFL）旨在平衡全局共享与局部适应，但现有方法面临根本权衡：
  - 更强的全局共享会损害客户端个性化特化能力；
  - 更强的局部适应则在数据稀缺、标签不平衡、类别缺失等情况下容易过拟合。
- **关键观察**：模型的不同组件（表征层与个性化层）对同步频率的需求不同：表征层适合频繁聚合以提取可迁移特征，而个性化层若同步过于频繁会偏离本地决策边界，反之则可能漂移。因此，需要为不同层设计差异化的同步机制。

### 2. 论文提出的方法论
- **整体框架：PGFedSplit**  
  采用拆分网络架构，将模型分为：
  - 表征层（θ）：负责提取可共享的特征；
  - 个性化层（ϕ）：适应客户端特定的决策边界。
- **核心策略一：分层解耦的聚合调度**  
  - 表征层：每轮通信都进行服务器聚合（加权平均）。
  - 个性化层：通过自适应周期调整（APA）进行周期性同步，周期自适应调整。
  - 自适应周期调整（APA）：根据所有客户端混合系数α的平均值变化动态增减聚合间隔τ，公式为：  
    `τ(t+1) = clip[τ_min, τ_max] (τ(t) - 1[ᾱ(t) > ᾱ_prev] + 1[ᾱ(t) < ᾱ_prev])`。  
  - 混合系数α：在接收到聚合个性化头后，客户端通过最小化一个包含交叉熵损失和KL散度（温度T_KD，同时考虑自适应间隔Δ）的优化目标，在线学习α来融合本地头与全局头：  
    `α_i ∈ argmin E[CE(ℓ_α(z), y)] + β·Δ_i·α²·D_KL(p_i(z)||p_g(z))`。
- **核心策略二：两阶段个性化与原型引导**  
  - 先通过周期性聚合得到低方差的全局个性化头，再在各客户端进行局部适应，缓解偏差并保留客户端特化。
  - 原型引导学习：
    * 表征正则化：在本地表征更新时，将样本表征拉向全局类原型（均值），损失为 `ℓ_CE + λ||θ(x) - p̄||²`。
    * 来自高斯统计的合成表征：服务器基于上传的类原型计算类条件高斯分布 `(μ, Σ)` 并广播给客户端。
    * 客户端根据本地标签分布，从高斯分布 `N(μ_l, γ²·Σ_l)` 采样生成合成嵌入，与本地真实嵌入混合构成混合训练集，用于训练个性化头，从而增强标签不平衡和类别缺失时的鲁棒性。
- **算法流程概括**：
  1. 每轮服务器广播表征层参数、全局原型和高斯统计量，若达到个性化聚合周期则广播聚合的个性化头。
  2. 客户端接收后，若收到个性化头则计算α并混合头；利用合成嵌入和真实嵌入构建混合集训练个性化头；冻结个性化头更新表征层；上传参数、原型和α到服务器。
  3. 服务器聚合表征层、原型和个性化头（周期触发），基于α更新τ。
