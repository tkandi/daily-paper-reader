## 摘要
当每个任务必须在截止时间前达到目标损失，但其所需训练工作量未知时，在并发学习任务之间分配有限计算资源十分困难。现有方法将在线损失预测与自适应资源分配相结合，但通常将计算视为连续可分的吞吐量。我们转而研究一种更实际的设定：任务随时间到达，计算由离散节点提供。该设定同时带来不确定需求和受限的序贯决策。我们提出 MARA，它利用条件流匹配预测未来损失轨迹，并通过协作多智能体自回归策略协调计算节点。基于势能的进度奖励提供中间训练反馈，同时保留无折扣的任务完成目标。在分布内、强化学习和视觉工作负载上，与加权最小二乘相比，流匹配降低了剩余资源预测误差。在调度器的训练负载下，MARA 平均完成 63.46% 的任务，比强基线自适应资源分配学习（LARA）高出 8.54 个百分点，并且在未见过的更重负载下仍保持领先。

## Abstract
Allocating limited computation among concurrent learning tasks is difficult when each task must reach a target loss before a deadline but its required training effort is unknown. Existing approaches combine online loss prediction with adaptive resource allocation, yet commonly treat computation as continuously divisible throughput. We instead study a practical setting in which tasks arrive over time and computation is provided by discrete nodes. This setting introduces both uncertain demand and constrained sequential decisions. We propose MARA, which predicts future loss trajectories with conditional flow matching and coordinates compute nodes through a cooperative multi-agent autoregressive policy. A potential-based progress reward supplies intermediate training feedback while preserving the undiscounted task-completion objective. Across in-distribution, reinforcement-learning, and vision workloads, flow matching reduces remaining-resource prediction error relative to weighted least squares. At the scheduler's training load, MARA completes 63.46% of tasks on average, 8.54 percentage points above strong baseline Learning with Adaptive Resource Allocation (LARA), and remains ahead under unseen heavier workloads.

## 1. 论文的核心问题与整体含义

- **研究背景与动机**：在共享学习服务中，多个独立训练任务（可能具有不同架构、数据、优化器配置、到达时间、截止时间和目标损失）竞争有限的计算节点。每个任务只有在截止时间前达到目标损失才算成功，但其所需训练量在任务到达时未知。
- **核心问题**：如何在离散计算节点上，面对动态到达、不确定需求和受限序贯决策，最大化成功完成任务的数量。
- **与现有工作的区别**：现有方法（如 LARA）通常将计算资源视为连续可分的吞吐量，而本文关注更实际的离散节点场景。每个节点每个时间步最多服务一个任务，每个任务最多占用一个节点，分配必须满足硬约束并随时间动态调整。

## 2. 论文提出的方法论

- **总体框架**：MARA 采用“预测—分配”闭环，分为两个核心模块：
  - 条件流匹配（Flow Matching, FM）预测器：根据已观测的损失历史，生成未来损失轨迹的分布，并解码出任务的剩余所需批次量。
  - 多智能体 Transformer（MAT）分配器：将每个计算节点视为一个智能体，通过自回归方式依次为节点选择任务，形成有效的任务—节点匹配。

- **损失轨迹预测（FM）**：
  - 使用 GRU 编码变长的观测历史（累积处理样本数和累积平均损失），并结合静态特征（批量大小、学习率、当前损失、预测范围）。
  - 将未来损失曲线离散为 32 个区间，对每个区间计算平均损失的相对对数目标值，以消除不同任务损失尺度的影响。
  - 采用条件流匹配学习从标准高斯噪声到目标损失轨迹的连续变换。速度网络为轻量 MLP，训练目标为最小化速度场与真实路径的均方误差。
  - 推理时通过少量欧拉步骤生成多条未来轨迹；对每条轨迹寻找首次达到目标阈值的交点，转换为剩余批次估计；取中位数作为稳健标量估计。若未穿越阈值，则保守地设为生成上限。

- **多智能体分配（MAT）**：
  - 将节点选择建模为协作部分观测马尔可夫博弈，所有节点共享任务完成奖励。
  - MAT 采用固定节点索引顺序的自回归解码：每个节点依次观察全局状态（任务槽、预测剩余批次、剩余截止时间、预测预热完成度等），在掩码约束下选择任务或空闲。掩码移除已被先前节点选择的任务，保证每个任务至多被一个节点选中。
  - 使用 PPO 和 GAE 优化策略，价值网络与策略共享 Transformer 编码器。

- **奖励塑形**：
  - 定义基于任务损失进度的势能函数 \(\Phi_t = \sum_{k \in \mathcal{A}_t} q_k(t)\)，其中 \(q_k(t)\) 是当前损失相对于初始损失和目标阈值的对数进度，裁剪到 [0,1]。
  - 训练奖励为任务成功奖励加上势能差 \(r_t = r_t^{\text{success}} + \beta(\Phi_{t+1} - \Phi_t)\)。在无折扣（\(\gamma=1\)）和边界条件下，该势能塑形不改变原始的无折扣任务完成目标，但提供了稠密的中间反馈。

- **训练流程**：
  - 阶段一：使用完整损失曲线训练 FM 预测器，冻结后进入阶段二。
  - 阶段二：MAT 与模拟器交互，在随机化任务流上训练，预测器保持冻结。
  - 在线使用：重复预测、掩码匹配、执行步骤，不更新参数。

- **对比方法**：
  - **MARA**：本文方法（FM + MAT + 稠密奖励）。
  - **MARA-WLS**：将 MARA 的 FM 预测器替换为加权最小二乘（WLS），其余不变。
  - **LARA**：原始自适应资源分配方法适配到离散节点，使用 WLS 预测和自适应二叉搜索。

## 6. 论文的主要结论与发现

- **预测层面**：FM 在 ID 任务上使剩余批次 MAE 降低 52.1%，预算成功准确率提升 7.66 个百分点；在 RL OOD 上 MAE 降低 41.6%，准确率提升 18.75 个百分点。ViT OOD 上提升较小（MAE 降低 3.3%，准确率提升 0.83 个百分点）。FM 的优势主要体现在早期和中期前缀，此时长程不确定性对分配影响最大。
- **分配层面**：在训练负载下，MARA 平均成功率为 63.46%，比 LARA 高 8.54 个百分点；在 ID、RL OOD、ViT OOD 上分别高出 8.30、8.96、8.35 个百分点。替换 FM 为 WLS 后 MARA 成功率下降 1.39 个百分点；将 LARA 的 WLS 替换为 FM 后成功率提升 5.71 个百分点。
- **更重负载泛化**：当到达概率从 0.04 增至 0.07 时，MARA 成功率从 63.46% 降至 50.53%，但仍比 LARA 高 8.43–8.84 个百分点。
- **压力测试**：MARA 在极端不可行任务干扰下完成全部 13 个可行任务（65% 成功率，零方差），而 FIFO 和 EDF 成功率为 0%，LARA 仅为 11%。
- **操作诊断**：MARA 与 FIFO、EDF 利用率相近（约 74%），但队列满占比更低（降低 6–7 个百分点），预测就绪时间提前约 43 步，说明其优势来自选择性使用容量而非提高原始利用率。
- **消融**：稠密奖励塑形使平均成功率从 57.87% 提升至 63.46%，其中 RL OOD 提升最大（15.72 个百分点）。

## 7. 优点

- **问题建模新颖**：首次将 CoRE-Learning 问题形式化为具有动态到达、离散节点和未知需求的多智能体决策问题，更贴近实际集群调度场景。
- **方法论创新**：将条件流匹配引入损失轨迹预测，生成未来损失分布而非单点预测，支持跨阈值解码和稳健聚合；结合自回归 MAT 处理组合匹配约束，无需枚举所有可行匹配。
- **奖励设计巧妙**：基于势能的 log-progress 奖励在不改变无折扣原始目标的前提下提供稠密反馈，显著改善稀疏完成信号下的训练效果。
- **实验设计严谨**：分离预测器质量与端到端分配效果，引入不可行任务压力测试和零样本负载泛化，并通过控制变量（MARA-WLS、LARA-FM）量化单个组件的贡献。
- **可解释性强**：操作诊断揭示性能提升并非来自更高利用率，而是更好的队列管理和预测就绪时间，增强了结论的可信度。

## 8. 不足与局限

- **假设简化**：模拟器假设节点同质、任务可无成本抢占和迁移，忽略设备异构性、切换开销、通信成本和集群实际开销。这些因素可能显著影响真实部署效果。
- **OOD 泛化有限**：FM 在 ViT 任务上相对 WLS 的提升很小（MAE 仅降 3.3%），说明流匹配预测器对未见架构的迁移能力仍有限；RL OOD 的提升虽大，但可能受益于特定损失曲线形态。
- **样本量与统计**：每负载仅 12 个 episodes，部分结果标准差较大，未进行统计显著性检验，结论的稳健性有待更大规模验证。
- **算力未透明**：训练 FM 和 MAT 所需的计算资源（GPU 型号、数量、训练时间）未在正文或附录中明确给出，难以评估方法的经济性。
- **单一优化目标**：仅最大化成功任务数，未公平性约束；可能系统性延迟困难任务族，造成资源分配偏差。论文也提到未来需考虑群体级审计和公平性约束。
- **评估范围**：任务类型覆盖图像、文本、语音和 RL，但所有任务均为单节点训练，未扩展到多 GPU 分布式训练任务，限制了在大规模集群中的适用性。
