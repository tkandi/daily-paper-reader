## 摘要
查询-键归一化（QK-Norm）可提高现代大语言模型（LLM）的训练稳定性和质量。然而，在张量并行（TP）下，逐层 QK-Norm 会引入额外的跨 GPU 通信，因为归一化因子依赖于完整的隐藏向量。我们提出 SwiftQK，这是一种多 GPU RMSNorm 内核，它仅交换标量归一化统计量，并在一个无死锁的持久内核中将剩余的 Peer-to-Peer 归约与独立的逐元素计算重叠。在近期 LLM 上的评估表明，与使用全向量 All-Gather 的标准 TP QK-Norm 相比，SwiftQK 将 QK-Norm 延迟降低了 81.4%–93.9%。在端到端服务中，与基于 All-Gather 的基线相比，SwiftQK 将 TPOT 平均降低 29.5%，与优化的标量聚合实现相比降低 14.3%。

## Abstract
Query-Key Normalization (QK-Norm) improves the training stability and quality of modern Large Language Models (LLMs). However, under Tensor Parallelism (TP), layerwise QK-Norm introduces additional cross-GPU communication because the normalization factor depends on the full hidden vector. We present SwiftQK, a multi-GPU RMSNorm kernel that exchanges only scalar normalization statistics and overlaps the remaining Peer-to-Peer reduction with independent element-wise computation in a deadlock-safe persistent kernel. Evaluations on recent LLMs show that SwiftQK reduces QK-Norm latency by 81.4--93.9% relative to the standard TP QK-Norm using full-vector All-Gather. In end-to-end serving, SwiftQK reduces TPOT on average by 29.5% over the All-Gather-based baseline and by 14.3% over an optimized scalar-aggregation implementation.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）推理服务广泛采用张量并行（TP）以降低单请求延迟；与此同时，现代 LLM 越来越多地使用查询-键归一化（QK-Norm）来稳定注意力训练与推理质量。
- **核心问题**：在 TP 下，逐层（layerwise）QK-Norm 的归一化因子依赖完整的 Q/K 隐藏向量，但该向量在 TP 中跨 GPU 分片存储，因此每个 GPU 必须先进行跨 GPU 同步（通常为 All-Gather）才能计算归一化因子。这带来了显著的通信开销。
- **动机与含义**：QK-Norm 的计算本身较轻（仅平方求和、逐元素乘法和缩放），但在 TP 下其跨 GPU 同步成本较高，且随 TP 度增加而上升，成为限制 TP 推理效率的主要瓶颈。仅依靠“通信-计算重叠”不足以解决问题，因为计算量不足以隐藏通信延迟。因此，论文提出将“通信量最小化”与“通信-计算重叠”相结合，从算子层面优化该瓶颈。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：将全向量 Q/K 激活的 All-Gather 替换为仅交换标量平方和统计量，并在一个无死锁的持久融合内核中，将标量 Peer-to-Peer（P2P）归约与独立的逐元素权重乘法重叠执行，从而同时降低通信量和隐藏剩余同步延迟。

- **公式基础**：RMSNorm 定义为

  \text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{H}\sum_{j=1}^{H} x_j^2 + \epsilon}} \odot \gamma

  其中归一化因子只依赖隐藏向量的平方和 \(\sum_{j=1}^{H} x_j^2\)，而不是完整的隐藏向量。这为通信量最小化提供了理论依据。
