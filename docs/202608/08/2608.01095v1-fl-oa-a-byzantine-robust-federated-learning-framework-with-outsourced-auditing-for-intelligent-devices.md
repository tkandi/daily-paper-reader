## 摘要
联邦学习允许多个智能设备在不共享原始数据的情况下协作训练高精度模型。然而，由于其分布式特性，联邦学习容易受到拜占庭攻击。现有的防御方法依赖于强假设，例如恶意设备的比例不超过50%，或者服务器拥有与训练任务匹配的额外根数据集。此外，它们忽略了(i)良性更新之间的差异以及(ii)比较两个高维更新时涉及的维度灾难，因此效果有限。为解决这些问题，我们提出了FL-OA，一个利用外包审计的拜占庭鲁棒联邦学习框架。在FL-OA中，服务器与持有额外根数据集的第三方组织合作执行外包审计，从而使服务器能够在无需强假设的情况下实现鲁棒聚合。此外，FL-OA在本地训练过程中引入梯度上升步骤和修正项以缓解良性更新之间的差异，并设计参数重要性指标提取关键参数进行审计，缓解维度灾难。我们进一步提供了FL-OA的详细理论分析。大量实验表明，FL-OA在抵御拜占庭攻击方面优于现有的防御方法。

## Abstract
Federated learning (FL) enables multiple intelligent devices to collaboratively train a high-accuracy model without sharing raw data. However, due to its distributed nature, FL is vulnerable to Byzantine attacks. Existing defense methods rely on strong assumptions, such as the proportion of malicious devices not exceeding 50\%, or the server having an additional root dataset that matches the training task. Moreover, they show limited efficacy as they overlook $(i)$ the divergence among benign updates and $(ii)$ the curse of dimensionality involved in comparing two high-dimensional updates. To solve these concerns, we propose FL-OA, a Byzantine-robust federated learning framework utilizing outsourced auditing. In FL-OA, the server collaborates with third-party organization that holds an additional root dataset to perform outsourced auditing, thereby enabling the server to achieve robust aggregation without strong assumptions. Additionally, FL-OA introduces a gradient ascent step and a correction term during local training to mitigate the divergence among benign updates, and designs a parameter importance indicator to extract critical parameters for auditing, alleviating the curse of dimensionality. We further provide a detailed theoretical analysis of FL-OA. Extensive experiments demonstrate that FL-OA outperforms existing defense methods against Byzantine attacks.

### 2. 方法论
FL‑OA 由任务服务器（TS）、外包服务器（OS）和智能设备三方协作完成。每轮迭代包含四个步骤。

- **系统架构与角色**
  - **Task Server (TS)**：发布训练任务，最终执行鲁棒聚合。
  - **Outsourced Server (OS)**：持有与任务统计同分布的根数据集，负责审计设备更新并返回信任分数和归一化更新。
  - **智能设备**：基于私有数据执行本地训练，上传模型更新。

- **关键技术细节**
  1. **本地训练（增强一致性）**：
     - **梯度上升步骤**：首先计算随机梯度 $g_{1}$，沿梯度上升方向得到中间参数 $\tilde{w}$，引导优化趋向平坦局部极小值，从而减少更新不一致。
     - **偏差修正项**：更新公式中引入 $\frac{1}{\alpha}(w_t - W_t)$ 作为近端项以对齐本地与全局模型，并用动量式修正项 $\hat{g}$ 累积历史局部偏移，消除因数据异质性导致的系统性偏移。最终模型更新为 $u_k = w_k^{(E)} - \alpha \hat{g}_k - w_k^{(0)}$。
  2. **审计更新（缓解维度灾难）**：
     - **参数重要性指标（PII）**：为每个参数坐标计算 $PII_k[j] = |u_k[j]| + \frac{|u_k[j]| - \text{med}(\{|u_i[j]|\})}{\text{med}(\{|u_i[j]|\}) + \epsilon}$，结合参数的绝对大小和偏离中位数的程度，用以衡量被恶意操纵的可能性。
     - **关键参数提取**：根据 PII 向量选出前 $\kappa$ 比例的坐标，生成二进制掩码 $M_k$，仅在该坐标子集上计算余弦相似度，避免在高维全空间上遭受维度灾难。
     - **信任分数与归一化**：计算设备更新与 OS 根更新在关键参数上的余弦相似度，并通过 ReLU 截断为 $s_k$；同时将所有更新的范数强制对齐到根更新范数，防止恶意更新通过幅度放大攻击。
  3. **鲁棒聚合**：
     - TS 根据 OS 返回的 $\{s_k\}$ 和 $\{\tilde{u}_k\}$ 加权聚合：$u_g = \frac{1}{\sum s_k} \sum s_k \tilde{u}_k$，更新全局模型 $W_{t+1} = W_t + \mu u_g$。

- **理论分析**：
  - **收敛性**（定理1）：在强凸与Lipschitz连续等假设下，FL‑OA 的全局模型与最优解的距离被严格界住，即使存在拜占庭攻击也能收敛到一个有限误差范围内。
  - **修正项机理**（定理2）：局部偏移可表达为历史梯度的指数移动平均减去修正项，证明修正项能有效估计并抵消局部偏移，提升更新一致性。

### 6. 主要结论与发现
- FL‑OA 在不依赖“根数据集由服务器持有”或“良性设备占多数”的强假设下，成功实现了拜占庭鲁棒聚合。

- **基于 PII 的关键参数提取**有效缓解了维度灾难，使得在低维子空间上的相似度计算能清晰区分良性和恶意更新。

- 即使恶意设备占比高达 70%，FL‑OA 仍能保持相当的模型准确率。
- 框架额外引入的通信延迟（TS‑OS 间）和内存开销在可接受范围内，且设备端计算开销增加有限。

### 8. 不足与局限
- **外包服务器完全可信的假设**：框架安全性建立在 OS 诚实且未被攻陷的前提下。论文虽指出可通过引入多个独立 OS 平均信任分数来缓解，但未进行实验验证。
