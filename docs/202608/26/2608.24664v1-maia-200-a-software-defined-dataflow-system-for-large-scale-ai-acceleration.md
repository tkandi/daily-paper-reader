## 摘要
我们介绍了Maia 200，一款先进的AI加速器，在750 W TDP和7 TB/s HBM带宽下可提供高性能——10 145 Tflop/s FP4和5072 Tflop/s FP8。Maia代表了一类新型的软件定义本地访问数据流架构（SDLA），该类架构显式编程数据流引擎以协调高度专用的存储器和数据移动引擎。这一方法将重点从当今以线程为中心的架构转向以数据移动为中心的架构，从而提升效率和可扩展性。我们受Flynn分类法启发的数据管理分类法，突显了SDLA如何应对现代AI计算中的挑战。Maia 200在支持AI推理工作负载的大规模并行性的同时实现了显著的成本和能耗节省，使其成为下一代高性能计算系统极具吸引力的解决方案。

## Abstract
We introduce Maia 200, an advanced AI accelerator delivering high performance-10 145 Tflop/s FP4 and 5072 Tflop/s FP8 within a 750W TDP and 7 TB/s HBM bandwidth. Maia exemplifies a new class of Software Defined Locally Accessed Dataflow Architectures (SDLA), which explicitly program dataflow engines to orchestrate highly specialized memories and data movement engines. This approach shifts the focus from today's thread-centric to data-movement-centric architecture, improving efficiency and scalability. Our taxonomy of data management, inspired by Flynn's classification, highlights how SDLA addresses challenges in modern AI computing. Maia 200 achieves significant cost and energy savings while supporting massive parallelism for AI inference workloads, making it a compelling solution for next-generation high-performance computing systems.

## 2. 论文提出的方法论

### 2.1 SDLA 架构定位与分类法

- 论文提出一种类似 Flynn 分类法的**数据管理分类法**，两个维度分别是：
  - 数据访问方式：**本地访问（Local）** vs **全局访问（Global）**。
  - 数据移动定义方式：**隐式 Load/Store** vs **软件定义数据流（Software Defined Dataflow）**。
- 由此得到四个象限：LSGA、LSLA、SDGA、SDLA。Maia 200 属于 SDLA，即本地存储 + 显式数据流编排。
- 相比 SIMT（单指令多线程），SDLA 更强调独立、并行的控制和数据指令流，不再强制 warp 级同步，而是面向空间架构，把数据局部性和数据管理作为一等公民。

### 2.2 SDLA 的三条基本原则

1. **暴露并行的低级控制编程接口**：允许程序员、编译器、软件栈直接控制加速数据移动、格式转换和同步引擎。
2. **提供分布式、专业化存储器系统**：片上与 pod 级存储器可编程管理，利用专用引擎加速数据移动。
3. **尽量提供确定性性能**：便于静态调度，对注意力机制等 kernel 特别有利。

### 2.3 抽象机器模型

- 控制路径由控制处理器（Control Processor, CP）运行，可使用 C/C++ 等系统语言编程。
- 数据路径由 DMA、处理单元（PE）等执行**数据流指令**。
- 每条数据流指令包含：
  - **前置条件（precondition）**：最多等待两个信号量；
  - **宏指令（macro-instruction）**：例如 DMA 命令、kernel 调用、网络发送/接收；
  - **后置条件（postcondition）**：完成后最多触发两个信号量。
- 硬件队列按序执行数据流指令，通过信号量完成显式同步，可实现计算与数据移动的深度异步重叠。
