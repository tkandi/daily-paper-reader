## 摘要
在动态移动去中心化联邦学习（DFL）中，攻击者可以同时毒化模型更新和设备用于选择协作者的拓扑信息。我们提出 DMTT（带有信任拓扑的动态 MURMURA），一种建立在 MURMURA 上的去中心化个性化联邦学习协议，利用证据深度学习来降低分布不匹配的节点的权重，并在此扩展至拓扑操纵攻击下的时变图。每个设备通过链路可靠性估计、签名拓扑声明、见证印证和 Beta 分布的信源信任模型维护一个置信度加权的局部拓扑视图，然后仅在一个经过信任筛选的协作者集合上进行聚合，使用融合模型兼容性、拓扑信任和链路可靠性的综合评分。我们证明筛选后的混合矩阵将拜占庭影响限制在有限残差 $δ_{max}$ 内，在完美筛选下该残差消失，并将 DMTT 实现为一个无协调器的分布式系统，每个客户端作为独立的 ZeroMQ 进程运行，由共享的挂钟时间同步。在 UCI HAR 和 PAMAP2 数据集上，每个数据集通过狄利克雷异质性分布到 100 个移动客户端，DMTT 在所有测试的攻击者比例（10% 到 80%）下均维持诚实节点准确率高于 0.862（UCI HAR）和 0.829（PAMAP2），在低比例时几乎匹配无攻击准确率，在极高比例时逐渐降至仅本地性能；静态和动态 FedAvg 在所有比例下均降至随机水平，鲁棒聚合器（Krum、BALANCE、UBAR）未能持续优于仅本地基线，而 DMTT 是唯一在两个数据集的所有比例下均超过这一基线的方法，且幸存的拜占庭聚合权重全程经验为零，与 $δ_{max}=0$ 一致。该协议通过墨尔本研究云上的无协调器 ZeroMQ 后端在真实节点上端到端运行。

## Abstract
In dynamic mobile decentralized federated learning (DFL), adversaries can poison both model updates and the topology information devices use to choose collaborators. We present DMTT (Dynamic MURMURA with Trusted Topology), a decentralized personalized FL protocol built on MURMURA, which uses evidential deep learning to down-weight distribution-mismatched peers, extended here to time-varying graphs under topology-manipulation attacks. Each device maintains a confidence-weighted local topology view from link-reliability estimates, signed topology claims, witness corroboration, and a Beta-distributed source-trust model, then aggregates only over a trust-screened collaborator set using a composite score fusing model compatibility, topology trust, and link reliability. We prove the screened mixing matrices confine Byzantine influence to a bounded residual $δ_{max}$ that vanishes under perfect screening, and implement DMTT as a coordinator-free distributed system with each client running as an independent ZeroMQ process synchronized by a shared wall-clock epoch. On UCI HAR and PAMAP2, each partitioned across 100 mobile clients with Dirichlet heterogeneity, DMTT sustains honest-node accuracy above 0.862 (UCI HAR) and 0.829 (PAMAP2) across all tested adversary fractions (10 to 80%), nearly matching no-attack accuracy at low fractions and degrading gracefully toward local-only performance at extremes; static and dynamic FedAvg collapse to chance at every fraction, and robust aggregators (Krum, BALANCE, UBAR) fail to consistently beat a local-only baseline, while DMTT is the only method that clears this bar across both datasets at all fractions, with surviving Byzantine aggregation weight empirically zero throughout, consistent with $δ_{max}$=0. The protocol runs end-to-end on real nodes via a coordinator-free ZeroMQ backend on the Melbourne Research Cloud.

### 2. 论文提出的方法论

核心思想是在MURMURA（基于证据深度学习评估同伴模型兼容性并降权不匹配者）的基础上，引入三层信任体系：**直接可达性、拓扑信任、协作信任**，并通过四算法模块在无协调器分布式环境中运行。

- **核心机制与算法流程**：
  - **链路可靠性估计**：每个设备通过 Hello Beacon 与传输确认，用指数移动平均更新直接链路可靠性 $\hat{p}_{ij}^t$，捕捉物理通信质量而非拓扑信任。
  - **签名拓扑声明与见证证据**：设备在观察本地拓扑变化时生成签名、版本化的声明；接收声明后，基于声明的跳数、信源信任评分 $T_{ij}^{\text{topo},t}$ 等计算见证权重 $\psi_{ij}^t(e) = T_{ij}^{\text{topo},t} \exp(-\xi h_{ij}^t(e))$，累加到对每条边 $e$ 的支持池/反对池，计算边置信度 $\chi_i^t(e)$，仅当置信度达到阈值且满足独立见证等条件才接受边增加或删除。
  - **Beta分布信源信任**：为每个拓扑报备来源 $j$，维护阳性证据（确认、印证、一致）和阴性证据（矛盾、刷屏、冲突），用Beta分布模型更新声誉均值和认知不确定度 $U_{ij}^t$，最终拓扑信任得分 $T_{ij}^{\text{topo},t}=R_{ij}^t \exp(-\eta\max(0,U_{ij}^t-\tau_U))$，使高不确定度来源即使偶然正确也影响小。
  - **受控转发**：仅当信源信任超阈值、跳数未越限、转发预算未耗尽时才转发声明，抑制恶意泛洪。
  - **信任感知协作选择**：节点先完成局部训练并交换模型，再用MURMURA方式计算模型兼容性得分 $s_{ij}^{\text{model},t}$，综合模型兼容性、拓扑信任、链路可靠性和通信代价得到复合得分 $q_{ij}^t$，并挑选Top-B同伴形成协作集 $C_i^t$，仅在信任筛选后的集合内加权聚合。此外，通过轻量范数检查拒绝异常大模长的模型更新。
- **理论保证**：证明在完美筛选（拜占庭节点完全剔除）时，平均局部梯度以 $O(1/\sqrt{NT}+1/T)$ 速率收敛，且数据异构度 $\tau_{\text{scr}}^2$ 因筛选而降低，加速收敛。在非完美筛选下，拜占庭影响被限制在 $\rho^2=( \Delta_{\text{scr}}(R+\eta G)+\delta_{\max}\Theta_B)^2$ 的附加拖尾项中，在完美筛选下 $(\Delta_{\text{scr}}=0,\delta_{\max}=0)$ 该项消失，直观对应实验中拜占庭聚合权重始终为零。
- **分布式系统实现**：每个设备作为独立 ZeroMQ 进程运行，通过共享挂钟时刻（$t_k = t_{\text{start}}+k\cdot\Delta$）同步回合，使用 PUSH/PULL 套接字交换模型状态与拓扑声明，无中心协调器；被动监控器仅收集指标，不发消息；采用确定性共享种子生成一致动态图；通过传输层“自我包含”检查（若 $j$ 向 $i$ 交付消息，则 $j$ 的拓扑声明必须包含 $i$）无甲骨地检测拓扑谎言。
