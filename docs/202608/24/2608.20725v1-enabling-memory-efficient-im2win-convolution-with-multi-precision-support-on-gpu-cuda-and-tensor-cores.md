## 摘要
卷积是深度神经网络中的主要计算瓶颈，其效率依赖于算法与 GPU 硬件之间的紧密集成。现有 GPU 卷积方法存在内存开销大、缓存利用率低、对不同卷积核尺寸的适用性有限或数值不稳定等问题。本工作扩展了 im2win 范式——一种通用的内存高效卷积方法，对所有卷积核尺寸均具有连续内存访问特性——使其能够在 CUDA 核上以全精度高效运行，并在 Tensor Core 上以半精度高效运行。通过引入锯齿形内存访问和异步数据搬运等新内核设计与优化，im2win 高效利用了硬件加速的半精度矩阵乘加运算。在十二个 CNN 基准测试中，im2win 的 TFLOPS 比其 CUDA 核实现最高提升 2.8 倍，比 cuDNN 最高提升 1.4 倍，比基于 GEMM 的 cuBLAS 卷积最高提升 6.4 倍，同时分别仅使用它们 53% 和 35% 的内存。这些结果确立了 im2win 作为面向现代 GPU 架构的统一高性能卷积框架的地位。

## Abstract
Convolution is a principal computational bottleneck in deep neural networks, and its efficiency depends on tight integration between algorithms and GPU hardware. Existing GPU convolution methods suffer from large memory overhead, poor cache utilization, limited effectiveness across kernel sizes, or numerical instability. This work extends the im2win paradigm -- a universal, memory-efficient convolution method with contiguous memory access for all kernel sizes -- to run efficiently in full precision on CUDA cores and half precision on tensor cores. By introducing new kernel designs and optimizations such as zig-zag memory access and asynchronous data movement, im2win efficiently exploits hardware-accelerated half-precision matrix multiply-accumulate operations. Across twelve CNN benchmarks, im2win achieves up to 2.8x higher TFLOPS than its CUDA core implementation, 1.4x higher than cuDNN, and 6.4x higher than GEMM-based convolution with cuBLAS, while using as little as 53% and 35% of their memory, respectively. These results establish im2win as a unified, high-performance convolution framework for modern GPU architectures.

## 2. 论文提出的方法论

- **核心思想**：  
  im2win 通过数据重排，使每个滑动窗口内的输入元素在内存中跨通道连续排列，避免 im2col 的冗余复制，同时保留连续内存访问和良好的数据复用。

- **数据变换公式**：  
  输入的 im2win 变换定义为：
  \[
  \hat{I}(i, r, m, k \times H_f + u) = I(i, r, m \times s + u, k)
  \]
  其中 \(s\) 为步长，\(H_f\) 为滤波器高度。该变换相比 im2col 省去约  
  \(N_o \times C_o \times H_o \times W_o \times C_i \times H_f \times (W_f - s)\) 的冗余存储。

- **卷积计算方式**：  
  对于每个输出元素，对应窗口元素与滤波器逐元素相乘累加，可在数学上写作：
  \[
  \hat{I}(i, r, m, (n \times s) \times W_f + v \times W_f + u) \times F(j, r, u, v)
  \]
  计算复杂度与 direct convolution 相同，但通过窗口间缓存复用提升效率。

- **GPU/Tensor Core 实现（Algorithm 1）**：
  - 使用 NHWC 布局增强卷积窗口的内存连续性。
  - 将输出映射为逻辑矩阵乘法维度：\(M = C_o\)，\(N = N_o \times H_o \times W_o\)，\(K = C_f \times H_f \times W_f\)。
  - 线程块分块大小采用 32×128 或 64×128，保证为 WMMA 16×16 粒度整数倍。
  - 利用 WMMA API 在 Tensor Core 上执行半精度矩阵乘加。
  - 采用共享内存双缓冲、寄存器双缓冲、向量化异步加载（PTX）隐藏数据搬运延迟。
  - 对于 N 维度采用 Zig-Zag 访问顺序，减少不同线程块同时访问共享内存时的 bank conflict。

- **关键优化技术**：
  - **索引预计算**：将固定索引偏移在主机端预先计算并存入 GPU 常量内存，避免设备端重复索引计算。
  - **异步数据搬运**：通过 PTX 指令实现全局内存到共享内存的异步 vec load，结合双缓冲形成生产者-消费者流水线，隐藏数据移动延迟。
  - **Zig-Zag 访问**：给线程块划分增加访问维度，按维度奇偶交替改变访问方向，缓解共享内存 bank conflict。

- **多精度支持**：
  - FP32 版本在 CUDA 核上执行；
  - FP16 版本利用 Tensor Core 原生 WMMA 指令执行，避免 CUDA 核上 FP16 内部转 FP32 的性能损失。
