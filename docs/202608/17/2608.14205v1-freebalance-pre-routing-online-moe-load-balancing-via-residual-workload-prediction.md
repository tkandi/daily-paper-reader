## 摘要
负载不均衡是混合专家（MoE）模型分布式推理中专家并行效率的主要瓶颈。由于路由分布偏斜，负载最重的 rank 会拖慢全局执行，直接增加延迟。虽然离线专家放置可以缓解持续性的不均衡，但实际的多任务服务负载表现出依赖层和批次的路由动态性，使得在线负载均衡不可或缺。现有方法依赖于在每个 MoE 路由器之后收集的路由统计信息，要求只有在路由决策可用后才能开始专家权重加载或迁移，从而将迁移开销置于推理关键路径上。在本工作中，我们观察到如果能够提前准确预测路由分布，在线均衡可以很大程度上与目标路由（如注意力）之前的计算重叠。因此，我们提出 FreeBalance，一个通过残差工作负载预测将专家迁移与前置计算阶段重叠的无损在线负载均衡框架。FreeBalance 利用残差网络内隐藏表示的跨层相似性来构建轻量级工作负载预测器。这使得在路由决策可用之前就能进行主动的专家迁移规划，在权重传输与计算密集的路由前阶段之间创造了大量重叠。此外，成本模型约束交换次数，以在可用窗口内完全隐藏同步开销。跨模型和数据集的实验表明，FreeBalance 将最大与平均 rank 负载比降低了 32.8%，端到端预填充延迟降低了 13.1%。具体来说，我们的方法每层平均隐藏了 5.1 个专家的均衡开销，否则这些开销将占关键路径延迟的约 8.5%。

## Abstract
Load imbalance poses a major bottleneck to the efficiency of expert parallelism in distributed inference of Mixture-of-Experts (MoE) models. The most heavily loaded rank stalls global execution due to skewed routing distributions, directly increasing latency. While offline expert placement can alleviate persistent imbalance, practical multi-task serving workloads exhibit layer- and batch-dependent routing dynamics, making online load balancing indispensable. Existing approaches rely on routing statistics collected after each MoE router, requiring expert weight load or migration to begin only after routing decisions are available, consequently placing migration overhead on the inference critical path. In this work, we observe that online balancing can instead be largely overlapped with computation before target routing (e.g., attention), if routing distributions can be predicted accurately in advance. Therefore, we propose FreeBalance, a lossless online load-balancing framework that overlaps expert migration with preceding computation stages via residual workload prediction. FreeBalance leverages cross-layer similarities in hidden representations within the residual network to build a lightweight workload predictor. This enables proactive expert migration planning before routing decisions are available, creating substantial overlap between weight transfer and computation-heavy pre-routing stages. Furthermore, a cost model constrains the number of swaps to fully hide the synchronization overhead within the available window. Experiments across models and datasets show that FreeBalance reduces the max-to-mean rank load ratio by 32.8% and end-to-end prefill latency by 13.1%. Specifically, our method hides balancing overhead of an average of 5.1 experts per layer, which would otherwise account for about 8.5% of the critical-path latency.

## 1. 论文的核心问题与整体含义

- **研究背景**：在 Mixture-of-Experts（MoE）模型的分布式推理中，专家并行（Expert Parallelism, EP）被广泛采用，但路由分布偏斜会导致不同 rank 上的负载严重不均衡。最繁忙的 rank 成为 straggler，决定全局延迟，其他 rank 空闲等待。
- **问题痛点**：现有在线负载均衡方法依赖路由后的统计信息，只有在路由决策完成后才能开始专家权重迁移。这使得迁移开销直接落在推理关键路径上，削弱负载均衡带来的收益。离线专家放置无法适应多任务服务中层级和批次相关的动态路由变化。
- **核心想法**：如果能提前准确预测路由分布，就能把专家迁移与路由前的计算（如注意力计算）重叠，从而将均衡开销移出关键路径。
- **整体含义**：FreeBalance 提出一种无损的在线负载均衡框架，通过残差工作负载预测实现路由前迁移，在不改变模型输出和语义的前提下，提高分布式 MoE 推理效率。

## 2. 论文提出的方法论

- **核心思想**：利用残差网络中相邻层隐藏表示的高相似性，在目标 MoE 层的路由执行之前，使用上一层的输出隐藏状态 \( h_{\ell-1} \) 输入同一个路由器，提前预测当前层的专家工作负载。
- **残差工作负载预测**：
  - 不引入独立预测器，直接复用目标层冻结的路由器 \( g_\ell \)，对 \( h_{\ell-1} \) 计算 logits，得到早期路由 logits \( \hat{G}_\ell = g_\ell(h_{\ell-1}) \)。
  - 对早期 logits 施加原始 top-k 规则，估计每个 token 的专家分配，再聚合得到预测的专家工作量 \( \hat{n}_{\ell,e} \)。
  - 最终路由决策仍由正常输入 \( H_\ell \) 经过同一路由器决定，预测结果只用于物理专家放置，不改变模型输出，因此无损。
- **预算化专家交换规划**：
  - 采用成对专家交换（pairwise swaps）保持每个 rank 上的专家数量不变，避免复制和额外内存占用。
  - 优化目标：\( \Phi(L) = \max_r L_r + \gamma \sum_r (L_r - \bar{L})^2 \)，同时最小化最大 rank 负载，并避免将瓶颈转移到其他 rank。
  - 候选交换的收益为 \( \Delta(e_a, e_b) = \Phi(L) - \Phi(L') \)，丢弃非正收益候选。
- **成本模型与预算约束**：
  - 交换成本 \( C(s) = \alpha_{a,b} + \frac{S(e_a) + S(e_b)}{\beta_{a,b}} \)，其中 \( S(e) \) 为专家表示体量，\( \beta_{a,b} \) 为点对点带宽，\( \alpha_{a,b} \) 为启动和协议开销。
  - 可用迁移预算 \( B_\ell = \max(0, T_{\text{attn}}^{r(\ell)} - \delta) \)，其中 \( T_{\text{attn}} \) 为同类注意力层的测量时间，\( \delta \) 为安全裕量；预算按链路和 rank 分别强制，避免超额订阅。
- **确定性贪心规划流程**：
  - 每个 rank 收到相同的全局负载统计和相同的放置映射，独立枚举候选对、去除冲突、按收益/成本比排序，接受满足预算的交换，最终产生相同的交换序列，无需广播计划。
  - 算法伪代码对应：预测负载 → 聚合 rank 负载 → 迭代选择有益交换 → 在注意力阶段迁移权重 → 提交放置 → 执行正常路由和 MoE 计算。

## 6. 论文的主要结论与发现

- **负载均衡效果**：FreeBalance 将 max-to-mean rank 负载比从最高 2.01 降至 1.35，改善幅度最高 32.8%；在所有 19 个 LongBench 子集上平均降低 Qwen3-30B 的 prefill 延迟 13.1%。

## 7. 优点

- **创新性地打破顺序依赖**：通过残差表示预测路由前负载，将专家迁移与注意力计算重叠，解决了在线负载均衡中迁移开销落在关键路径的问题。
- **无损且轻量**：预测仅用于专家放置，不改变最终路由决策；复用已有路由器参数，不引入额外模型权重或训练过程。
- **确定性和可扩展性**：所有 rank 本地重现相同的交换计划，避免广播通信；成对交换保持每个 rank 专家数量不变，简化内存管理。
- **预算成本模型**：根据实测注意力和带宽约束限制迁移数量，防止过度迁移带来额外延迟。
- **实验覆盖较好**：在两个模型、多个数据集、多个序列长度下验证，结果具有一般性参考价值。
