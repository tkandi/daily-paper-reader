## 摘要
小型 NLP 模型，尤其是 BERT 家族编码器，在大语言模型时代依然在分类、排序和检索等工业工作负载中具有重要意义。在服务器 CPU 上，INT8 量化提供了具有吸引力的延迟-吞吐量-成本权衡，但用户越来越期望此类加速能够直接在 PyTorch 原生栈中使用。我们将 SmoothQuant 集成到 TorchAO 中，并通过 TorchInductor 中的图级融合以及跨 oneDNN、AVX512_VNNI 和 AMX 实现的高效 INT8 GEMM 内核选择，为 Intel Xeon CPU 优化了所得的推理路径。在 BERT、DistilBERT 和 XLM-RoBERTa 基准测试中，该方法实现了高达 5.8 倍的端到端吞吐量加速，并且相对于 FP32 基线，准确率损失可忽略不计——在某些情况下甚至没有可测量的损失。我们还通过 roofline 模型进行了详细的性能分析来验证我们的工作。该实现已上游合入 PyTorch 和 TorchAO，支持使用 PyTorch 原生工具开箱即用部署。

## Abstract
Small NLP models, especially BERT-family encoders, remain important in industrial workloads such as classification, ranking, and retrieval even in the era of large language models. On server CPUs, INT8 quantization offers an attractive latency-throughput-cost trade-off, but users increasingly expect such acceleration to be available directly in the native PyTorch stack. We integrate SmoothQuant into TorchAO and optimize the resulting inference path for Intel Xeon CPUs through graph-level fusion in TorchInductor and efficient INT8 GEMM kernel selection across oneDNN-, AVX512_VNNI-, and AMX-based implementations. Across BERT, DistilBERT, and XLM-RoBERTa benchmarks, the approach delivers up to 5.8x end-to-end throughput speedup with negligible---and in some cases no measurable---accuracy loss relative to the FP32 baseline. We also validated our work by detailed performance analysis with roofline models. The implementation has been upstreamed to PyTorch and TorchAO, enabling out-of-the-box deployment with native PyTorch tooling

## 1. 论文的核心问题与整体含义

- **研究背景**：尽管大语言模型受到广泛关注，BERT 族小型编码器模型在分类、排序、检索等工业任务中仍被大量部署。服务器 CPU 推理因其成本优势和基础设施普及度而保持核心地位。
- **核心问题**：用户希望直接在 PyTorch 原生栈中获得服务器 CPU 上的 INT8 量化加速，而无需依赖第三方工具或非原生路径。然而，仅将量化模型置于 eager 模式执行，性能往往不够理想。
- **整体含义**：本文将 SmoothQuant 集成到 TorchAO，并通过 TorchInductor 图级融合、INT8 GEMM 内核选择以及针对 Intel Xeon 平台（AVX512_VNNI / AMX）的底层优化，打通了一条开箱即用的 PyTorch 原生 INT8 推理路径，最高实现 5.8 倍端到端吞吐提升，且精度损失可忽略甚至为零。

## 2. 论文提出的方法论

- **核心思想**：
  - 采用 SmoothQuant 后训练量化方法，通过平滑因子将激活异常值难度“迁移”到权重，使标准 INT8 算术在通用 CPU 硬件上可用。
  - 将量化后的模型交由 TorchInductor 编译，利用图级融合消除运行时权重布局转换、独立缩放和后处理开销。
- **关键流程**：
  1. 使用 TorchAO 前端完成 SmoothQuant 量化：插入观测器、在校准数据上搜索平滑因子、将 `nn.Linear` 替换为 INT8 GEMM（`torch._int_mm`）及后续缩放。
  2. 在 TorchInductor 中扩展图融合：匹配 `input_reshape -> int_mm -> dtype_convert -> mul -> mul -> output_reshape -> add_bias` 等模式，将其替换为单个 `torch.ops.onednn.qlinear_pointwise` 融合算子。
  3. 权重布局转换（plain → blocked）在常量折叠阶段预先完成，避免运行时转换。
  4. 扩展 TorchInductor 的 CPP 后端模板 GEMM 内核，加入 AMX 与 AVX512_VNNI 微内核；内核选择机制在编译后对候选内核进行微基准测试，选择最快实现。
- **Ice Lake 适配（s8s8 → u8s8）**：
  - 第 3 代 Xeon（Ice Lake）不支持原生 s8×s8，需将激活张量偏移为无符号：  
    `X_u8 = uint8(int32(X_s8) + 128)`
  - 补偿项为权重各列求和乘以 128：  
    `c = (Σ_k W_{:,k}) · 128`
  - 最终 GEMM：  
    `Y = X_u8 · W^T − c`
  - 偏移和补偿项在推理前预计算，据此扩展融合模式。
