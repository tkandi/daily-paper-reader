## 摘要
时变的云工作负载经常导致非高峰期的资源利用不足和高峰期的资源争用。现有的预测后优化框架存在两阶段解耦的问题，阻碍了违例率、用户满意度和资源利用率之间的平衡。我们将异构作业调度形式化为不确定约束下的多目标组合优化问题，并提出了用于云编排的闭环决策聚焦学习框架（CL-DFL）。CL-DFL 集成了基于多元时间序列图神经网络（MTGNN）的时空预测器和基于树形结构Parzen估计器（TPE）的零阶决策聚焦学习机制。这种集成建立了资源感知和调度决策之间的端到端反馈路径。此外，我们通过将组相对策略优化（GRPO）融入协作局部搜索，开发了 GNeuro-PLS 策略，以提高异构工作负载下的鲁棒性。在四个真实世界数据集上的大量实验表明，CL-DFL 在违例率、用户满意度和资源利用率之间实现了优异的权衡。与最先进的基线相比，它在常规工作负载下有效控制过载风险，并在高度饱和的场景下保持弹性。

## Abstract
Time-varying cloud workloads often cause resource under-utilization during off-peak periods and resource contention during peak periods. Existing prediction-then-optimization (PTO) frameworks suffer from two-stage decoupling, hindering the balance among violation rate, user satisfaction, and resource utilization. We formulate heterogeneous job scheduling as a multi-objective combinatorial optimization problem (MOCOP) under uncertain constraints and propose a closed-loop decision-focused learning (CL-DFL) framework for cloud orchestration. CL-DFL integrates a Multivariate Time-series Graph Neural Network (MTGNN)-based spatio-temporal predictor with a zeroth-order decision-focused learning (DFL) mechanism based on the tree-structured Parzen estimator (TPE). This integration establishes an end-to-end (E2E) feedback pathway between resource perception and scheduling decisions. Furthermore, we develop the GNeuro-PLS strategy by incorporating group relative policy optimization (GRPO) into cooperative local search to improve robustness under heterogeneous workloads. Extensive experiments on four real-world datasets demonstrate that CL-DFL achieves superior trade-offs among violation rate, user satisfaction, and resource utilization. It effectively controls overload risks under regular workloads and maintains resilience under highly saturated scenarios compared with state-of-the-art baselines.

### 2. 方法论
论文提出 **闭环决策聚焦学习 (CL-DFL)** 框架，建立从资源感知到调度决策的端到端反馈通路，主要由三个模块构成：

- **时空容量预测**
  - 使用 **MTGNN（多元时间序列图神经网络）** 同时捕获服务器之间的动态空间依赖和每个服务器容量的时序演变。
  - 通过自适应图学习从数据中推断服务器间的隐含连接关系，无需先验拓扑。
  - 预测残差用 **高斯混合模型（GMM）** 拟合，再利用逆CDF将预测置信度参数 `p` 映射为“不确定性‑感知”的容量边界 `ā(p)`，作为后续优化问题的约束。

- **多目标调度优化：GNeuro‑PLS**
  - 以 **Neuro‑PLS**（神经网络引导的 Pareto 局部搜索）为基本框架，通过切比雪夫标量化将多目标问题分解成多个子问题，并用神经网络给候选解打分，选择种子解并自适应控制局部搜索的截断半径 `K`。
  - 为适应云端黑箱、非凸特性，引入 **组相对策略优化（GRPO）** 进行零阶合作策略进化：
    - 对策略参数施加对偶镜像扰动（`θ+σϵ` 和 `θ−σϵ`）。
    - 收集扰动策略生成的调度方案的 **SPO 决策损失 `L_SPO`**（由违规率、用户体验、资源利用率的线性组合定义）作为奖励信号。
    - 进行组内相对优势归一化，估计零阶梯度方向，在不依赖反向传播的情况下更新策略参数。

- **闭环零阶 DFL（基于 TPE）**
  - 由于调度器不可微，无法对预测器参数求梯度，因此固定预训练的 MTGNN 预测器参数。
  - 采用 **树形结构 Parzen 估计器（TPE）** 这种贝叶斯优化器，在验证集上直接调优决策‑面向参数 `(p, Ŵ)`（置信度边界和多目标权重）。
  - 每次试参数都运行完整的 GNeuro‑PLS 调度，并用真实物理容量评估产生 `L_SPO`，再反馈给 TPE 模型引导下一轮建议。
  - 最终选出的 `(p*, Ŵ*)` 在测试集上固定使用，形成“预测‑调度‑反馈‑校准”的闭环。

算法关键步骤：
1. TPE 采样 `(p, Ŵ)`。
2. MTGNN 预测容量并用 `p` 校准约束边界。
3. GNeuro‑PLS 调度，得到 Pareto 解。
4. 在真实容量下回测解的质量，计算 `L_SPO`。
5. 用 `(p, Ŵ, L_SPO)` 更新 TPE 模型，循环至结束。

### 6. 主要结论与发现
- **更优的多目标权衡**：CL‑DFL 一致地在违规率、用户满意度、资源利用率上实现均衡优化。轻度负载下违规率低至 0% 且用户满意度接近 100%；中度负载下违规率控制在 3‑4% 以内，远超其他方法；重负载下也能将违规率压至 20‑28%，同时利用率高出基线（如 NSGA‑II）约 20‑40%。
- **强鲁棒性**：在 Alibaba 混部数据等异质负载下，闭环参数的自动校准使其违规率远低于 PLS 等，且用户满意度保持在 99.9% 以上，显示出应对复杂未知模式的韧性。
- **决策效率**：得益于 GNN 引导和自适应搜索，CL‑DFL 在线推理延迟极端轻量（300 任务下 <1 秒至 20 秒），远优于需要分钟级搜索的进化算法（NSGA‑II、SEMO）和 CUC。
- **GRPO 合作进化的有效性**：GNeuro‑PLS 相比 Neuro‑PLS 在 HV 上获得更快收敛和更高的最终值，且训练更稳定。

### 7. 优点
- **端到端闭环设计**：打破预测‑优化的传统隔离，利用调度反馈直接调整约束边界和偏好权重，是解决非稳态云环境的创新思路。
- **零阶 DFL 的巧妙应用**：用 TPE 处理不可微调度器，避免了梯度近似难题，既能在验证集上自动寻优，又不增加在线推理负担。
- **GRPO 增强的多目标搜索**：将对偶扰动和组内相对优势用于离散 MOCOP 的策略进化，无需价值网络，算法简洁且稳定。
- **工业级数据集与多尺度验证**：使用 2023‑2025 最新 Azure 推理追踪和经典 Alibaba 混部数据，涵盖轻度到高度饱和负载，覆盖了实际云计算的典型场景。
- **低推理时延**：通过 C++ 加速和智能搜索控制，保证了方法在动态调度中的实时可用性。

### 8. 不足与局限
- **实验边界较窄**：任务请求的 CPU 需求、时长和灵活性窗口是根据追踪统计估计的，可能与真实作业不完全一致；只测试了同一种 10‑server 集群配置，未验证异构硬件（如 GPU、内存带宽）和多集群跨域场景。
