## 摘要
基于记忆的时序图神经网络（M-TGNN）通过递归更新节点状态来捕获细粒度时序交互。然而，现有分布式框架缺乏有效的机制来管理这些模型固有的时序数据依赖。因此，它们必须强制执行严格的时间顺序更新，产生大量远程同步开销，并在时序事件流倾斜时出现严重的负载不均衡。我们提出 DepTGL，一个可扩展的分布式训练框架，从以数据为中心的视角重构 M-TGNN 的时序依赖管理。首先，DepTGL 引入一种混合时序依赖管理方案，通过时序事件缓存显式平衡通信与缓存开销，并辅以选择性依赖驱动的通信。其次，DepTGL 引入梯度感知的缓存同步策略，在模型优化趋于稳定时自适应抑制边界更新，从而减少冗余同步。最后，DepTGL 集成负载感知的时序剪枝策略，在倾斜引起的负载峰值下消除辅助重放事件，减少冗余数据处理并缓解滞后效应。在六个真实世界时序图上的实验表明，DepTGL 相较于最先进基线平均实现 4.99 倍加速，同时保持相当的准确率。

## Abstract
Memory-based Temporal Graph Neural Networks (M-TGNNs) maintain recursively updated node states to capture fine-grained temporal interactions. However, existing distributed frameworks lack effective mechanisms for managing the temporal data dependencies inherent in these models. As a result, they must enforce strict chronological updates, incur substantial remote synchronization overhead, and experience severe load imbalance when temporal event streams are skewed. We propose DepTGL, a scalable distributed training framework that restructures temporal-dependency management for M-TGNNs from a data-centric perspective. First, DepTGL introduces a hybrid temporal-dependency management scheme that explicitly balances communication and caching overhead via temporal-event caching, supplemented by selective dependency-driven communication. Next, DepTGL incorporates a gradient-aware cache-synchronization policy that adaptively suppresses boundary updates as model optimization stabilizes, thereby reducing redundant synchronization. Finally, DepTGL integrates a load-aware temporal-pruning strategy that eliminates auxiliary replay events under skew-induced load spikes, reducing redundant data processing and mitigating straggler effects. Experiments on six real-world temporal graphs show that DepTGL achieves an average speedup of 4.99x over state-of-the-art baselines, while maintaining comparable accuracy.

## 1. 论文的核心问题与整体含义

论文针对**基于记忆的时序图神经网络（Memory-based Temporal Graph Neural Networks, M-TGNNs）** 在分布式训练中的效率瓶颈展开研究。

- **研究背景**：M-TGNN（如 JODIE、DyRep、TGN）通过递归更新节点级时序状态来建模连续时间交互事件，在动态图学习任务中表现优异。然而，其节点状态沿时间顺序演化，导致事件之间存在严格的跨批次、跨工作者时序数据依赖。
- **核心问题**：
  - **挑战一**：跨工作者时序数据依赖难以高效服务。处理一个事件可能依赖其他工作者维护的远程节点历史状态，简单空间缓存无法弥补同步边界之间的时序演化缺失。
  - **挑战二**：严格的缓存一致性与同步带来巨大通信开销。现有系统通常采用周期性或高频同步边界，忽略后期训练收敛特性，产生大量冗余数据状态同步。
  - **挑战三**：时序流数据倾斜导致严重计算瓶颈。输入事件量和依赖诱导的重放负载在不同批次间剧烈波动，在全局同步屏障下造成滞后工作者（straggler）问题，降低集群利用率。
- **整体含义**：论文提出 **DepTGL**，一个**可扩展的分布式训练框架**，从**数据为中心**视角重塑时序依赖管理，通过混合缓存、自适应同步和负载感知剪枝，在保持模型准确率的同时显著降低训练时间。

## 2. 论文提出的方法论

DepTGL 的核心思想是：**将大部分时序依赖展开从运行时关键路径移到离线阶段，并在运行时自适应控制缓存同步和辅助重放计算量**。具体包括三大技术组件。

### 2.1 混合时序依赖管理（Hybrid Temporal-Dependency Management）

- **同步窗口**：将时序流划分为长度为 \(K\) 的连续批次组，窗口起点作为候选缓存刷新边界。
- **离线依赖扫描与混合批次构建**：
  - 对于每个工作者 \(p\)，按**逆时间顺序**扫描窗口内事件，识别其目标事件（源节点归该工作者所有）以及这些目标事件依赖的远程历史事件。
  - 将远程依赖事件标记为**辅助重放事件（auxiliary replay events）**，与目标事件合并，并按时间戳排序形成**混合批次（mixed batch）**。
  - 辅助重放事件不参与监督损失，仅用于在本地重建远程节点状态演化。
  - 生成候选边界刷新集 \(N_{p,\text{sync}}^q\)，即窗口边界需要从远程所有者获取的节点状态集合。
- **优点**：将依赖扩展和远程状态请求从在线关键路径转移到离线预处理阶段，减少运行时的细粒度远程请求，同时控制缓存增长。

### 2.2 梯度感知动态缓存同步（Gradient-Aware Dynamic Cache Synchronization）

- 动机：在训练后期，模型参数和节点记忆趋于稳定，频繁刷新远程缓存收益有限，却带来高通信和屏障等待成本。
- **实现方式**：
  - 维护梯度范数 \(g_r\) 的指数移动平均（EMA）\(\bar{g}_r\)。
  - 在候选刷新边界 \(r\)，若最近梯度范数低于阈值 \(\tau_g\) 乘以其 EMA，即 \(g_{r-1} < \tau_g \bar{g}_{r-1}\)，则**跳过本次刷新**（\(S_r=0\)）；否则执行刷新（\(S_r=1\)）。
  - 跳过刷新时，工作者继续使用本地缓存状态，依靠时间戳排序的混合批次执行来本地推进远程状态。
- **效果**：降低通信频率而不改变目标事件监督目标。

### 2.3 负载感知时序数据剪枝（Load-Aware Temporal Data Pruning）

- 动机：辅助重放事件虽减少远程通信，但增加热点批次的计算量，可能加剧滞后。
- **实现方式**：
  - 维护每个工作者本地批次执行时间 \(c_r^p\) 的 EMA \(\bar{c}_r^p\)。
  - 若上一批次时间超过阈值 \(\tau_c\) 乘以其 EMA，则进入**高负载模式**（\(H_r^p=1\)）。
  - 在高负载模式下，剪除混合批次中的**纯辅助重放事件**（即源节点不属于该工作者的事件），保留所有目标事件。
  - 损失函数使用源节点掩码，仅对目标事件计算监督损失，与剪枝操作相互独立。
- **效果**：减少重负载工作者的冗余计算，缓解同步屏障下的滞后效应，同时不损害监督学习目标。

### 2.4 理论分析

- **通信代价**：DepTGL 的边界通信量不超过刚性同步方案，通信比 \(\rho_{\text{comm}} \le 1\)。
- **计算与滞后效应**：负载感知剪枝可减少约 \(H_r^p c_{\text{aux}} |B_{p,\text{aux}}^r|\) 的辅助计算，若剪枝对象为瓶颈工作者，可降低全局迭代时间。
- **目标保持性**：剪枝仅移除掩码为 0 的纯辅助事件，不删除任何目标事件，因此不改变监督损失项集合。
