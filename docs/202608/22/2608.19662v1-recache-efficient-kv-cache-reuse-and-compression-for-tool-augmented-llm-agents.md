## 摘要
智能体语言模型会反复编码在请求中以不同组合和顺序重复出现的工具与技能模式，这导致标准前缀缓存无法复用其键值（KV）状态。我们提出 ReCache，一个独立缓存资源表示并降低其推理时计算与内存开销的框架。资源级注意力消除了跨资源交互并分配资源局部位置，从而生成与组合方式无关的 KV 块。随后，ReCache 通过贡献筛选的层–KV 头组路径限制资源可见性，并通过结构剪枝和语义剪枝仅保留对调用至关重要的字段。我们在由七个公开工具与技能使用数据集组成的基准上评估 ReCache，其中包含资源不相交测试。资源级注意力达到了与稠密调用相当的性能（82.3% 对 82.4% Inv-F1），同时将首 token 时间加速了 3.655 倍。完整框架将分配的 KV 张量内存减少了 92.43%，并将注意力计算加速了 1.423 倍。这些结果表明，将可复用的模式编码与选择性资源访问分离，可在效果损失有限的情况下大幅降低智能体推理成本。代码可在 https://github.com/EIT-NLP/ReCache 获取。

## Abstract
Agentic language models repeatedly encode tool and skill schemas that recur across requests in different combinations and orders, preventing standard prefix caching from reusing their key--value (KV) states. We introduce \textbf{ReCache}, a framework for independently caching resource representations while reducing their inference-time computational and memory overhead. Resource-wise attention removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks. ReCache then restricts resource visibility to contribution-selected layer--KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. We evaluate ReCache on a benchmark assembled from seven public tool- and skill-use datasets, including resource-disjoint tests. Resource-wise attention matches dense invocation performance (82.3\% versus 82.4\% Inv-F1) while providing a 3.655$\times$ time-to-first-token speedup. The complete framework reduces allocated KV-tensor memory by 92.43\% and accelerates attention by 1.423$\times$. These results show that separating reusable schema encoding from selective resource access substantially reduces agentic inference costs with limited effectiveness loss. The code is available at https://github.com/EIT-NLP/ReCache.

## 1. 论文的核心问题与整体含义

- **研究背景**：工具增强型大语言模型（LLM）智能体在推理过程中需要反复编码工具与技能的模式（schema）。这些模式虽然会在不同请求中重复出现，但其组合与顺序往往不同，导致标准前缀缓存（prefix caching）无法复用其 KV 状态，带来大量重复的预填充计算。
- **核心问题**：如何在动态组合、不同排序的工具/技能上下文下，实现资源级别（resource-level）的 KV 缓存复用与压缩，从而降低推理时的计算和内存开销。
- **整体含义**：将可复用的模式编码与选择性资源访问分离开来，能够在不显著损失调用效果的前提下，大幅降低智能体推理成本，为大规模工具/技能池的 LLM 推理提供实用方案。

## 2. 论文提出的方法论

ReCache 框架包含三个渐进阶段：

- **资源级注意力（Resource-wise Attention）**
  - 移除不同资源块之间的注意力交互，并为每个资源内部重置位置索引（从 0 开始）。
  - 得到的资源 KV 表示与邻近资源及其绝对位置无关，因此可以实现资源块的独立构建与复用。
  - 将资源间注意力的复杂度从 \(O(D_R^2)\) 降至 \(O(\sum_i D_i^2)\)，其中 \(D_i\) 为第 \(i\) 个资源的 token 长度。

- **结构剪枝（Structural Pruning）**
  - 利用 Transformer 层和 KV 头组的冗余性，只在贡献最大的层–头组路径上暴露资源 KV 状态。
  - 采用“leave-one-in”贡献评价：对于每个层 \(l\)，计算激活该层全部头组相对于空配置 \(\Omega=\emptyset\) 的调用损失下降 \(s_l = J(\emptyset) - J(\Omega_l)\)；头组贡献 \(s_g\) 同理。
  - 将正贡献归一化为权重 \(w_i = \frac{\max(s_i,0)}{\sum_j \max(s_j,0)}\)，选择 Top-K 层和 Top-K 头组，最终路由配置为 \(\Omega^\star = L^\star \times G^\star\)。
  - 只有 \(\Omega^\star\) 中的路径使用 \(M_{resource}\) 关注资源 token，其余路径使用 \(M_{context}\) 仅保留普通因果注意力。

- **语义剪枝（Semantic Pruning）**
  - 基于工具/技能调用失败的常见原因（无效名称、错误参数），保留对调用至关重要的字段：资源名称、参数名称、参数描述，以及最后一个后缀 token（其隐藏状态自然聚合了前面的信息）。
  - 最后得到的紧凑资源子序列 \( \tilde{R}_i \) 长度 \( \tilde{D}_i \le D_i \)，进一步减少资源–上下文注意力开销。

## 7. 优点

- **方法创新性**：提出资源级注意力实现组合不变的 KV 块，解决了动态资源组合下的缓存复用难题。
- **多维度压缩**：结合结构剪枝（层–头组路径）和语义剪枝（字段级保留），从冗余的多个来源进行削减。

- **字段感知语义剪枝**：针对工具/技能调用特点保留关键字段，优于通用文本摘要压缩方法。
- **基准构建严谨**：通过多样性优先采样和资源不相交 OOD 划分，减少了频率偏差和记忆捷径的影响。
