## 摘要
视觉-语言-动作（VLA）模型在具身AI中展现出强大潜力，但其在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）提高了效率，却将VLA模型视为全精度工作负载，未充分挖掘内存和计算中的冗余。本文提出VQVLA，一种算法-硬件协同设计框架，通过利用权重相似性和执行动态来加速VLA推理。我们首先引入MotionVQ，一种运动感知向量量化方案，根据机器人执行状态动态调整量化精度，在保持任务成功率的同时减少内存访问。随后，我们提出一种合并质心向量化GEMM范式，在码本索引表示上操作，通过质心的空间聚合和时间重用消除冗余乘法。为实现这些优化，我们设计了一种加速器，高效支持动态精度选择和质心重用计算。实验结果表明，VQVLA较A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM分别实现6.5倍、2.8倍、1.9倍、3.3倍和4.3倍加速，且精度下降可忽略。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

- **现有方法的不足**：
  - GPU 加速器（如 Dadu‑Corki）只从“减少模型调用次数”角度优化，仍将 VLA 模型视为全精度黑盒，未挖掘模型内部的权重冗余和计算冗余。
  - 向量量化（VQ）能高效压缩模型，但现有 VQ 方法采用静态精度策略，忽略了**机器人在不同执行阶段对量化的敏感度不同**。
- **关键洞察**：
  - 机器人动作幅度（motion magnitude）与距目标物体距离高度相关。**执行态**（小幅度精细动作）对量化敏感，**过渡态**（大幅度移动）对扰动更鲁棒。
  - VQ 压缩后的权重矩阵存在**质心重复使用**的高频模式（热索引），提供了消除冗余计算的机会。
- **整体含义**：利用机器人执行动态自适应调整 VQ 精度，同时从压缩表示中直接消除重复乘法，并通过专用硬件实现算法‑硬件协同加速，从而大幅降低 VLA 推理延迟，且精度损失可忽略。

### 2. 论文提出的方法论
- **总体框架 VQVLA**：算法‑硬件协同设计，包含三个阶段：
  1. 基于运动状态的动态向量量化（MotionVQ）
  2. 合并质心向量化 GEMM 计算范式（Merged‑Centroid Vectorized GEMM）
  3. 支持上述优化的专用加速器硬件
- **关键技术细节**：
  - **MotionVQ 算法**：
    - **状态预测**：利用上一次 VLA 输出的 3D 动作 (𝐴𝑥, 𝐴𝑦, 𝐴𝑧) 计算运动幅度 𝐷 = √(𝐴𝑥²+𝐴𝑦²+𝐴𝑧²) ，与阈值 𝑇𝑑 比较。𝐷 ≤ 𝑇𝑑 归为执行态，否则为过渡态。
    - **精度自适应**：离线准备两套 VQ 配置。执行态使用高精度集（VQ[256,2,256]，平均 4.125 bits），过渡态使用低精度集（VQ[128,2,64]，平均 3.125 bits），动态切换码本与索引，降低内存带宽需求。
  - **合并质心向量化 GEMM**：
    - **空间合并（Spatial Merging）**：识别同一权重列中重复的质心索引，先将对应激活相加，再与质心做一次乘法，即 ∑(𝐼_𝑖 × Centroid) → (∑𝐼_𝑖) × Centroid。
    - **时间重用（Temporal Reusing）**：跨列重用已计算的“激活‑质心”乘积结果。离线选定 Top‑k 高频质心，运行时用缓存（tag：质心ID+权重向量ID）存储中间结果，若索引匹配则直接读取缓存，避免重复计算。
  - **硬件架构**：
    - **状态预测器**：轻量级单元，计算运动幅值并比较阈值。
    - **索引处理引擎**：多 IPU 并行，从索引矩阵构建质心位置表（空间表与时间表）。
    - **矩阵乘法引擎**：
      - 空间合并 PE 阵列 + 3 级流水加法树，将最多 8 个激活输入累加后再送入 PE 做乘法。
      - 时间重用 PE 阵列 + 1.5 MB 结果缓存，PE 查询缓存命中则跳过乘法，直接累加。
    - 两个 PE 阵列以 1:1 比例并行，流水线执行。
