## 摘要
去中心化训练在不受信任且地理分布的节点上执行时会引入关键的安全风险。虽然现有的拜占庭容错研究通过鲁棒聚合方法解决了数据并行（DP）训练的问题，但流水线并行（PP）面临着根本不同的挑战。在 PP 中，模型层分布在工作节点上，激活值及其梯度在各阶段之间流动而非进行聚合，这使得传统的 DP 方法不再适用。我们提出了 SENTINEL，一种无需计算重复的 PP 训练验证机制。SENTINEL 采用基于指数移动平均（EMA）的轻量级动量监测来检测受损的阶段间通信。与现有的针对 DP 的拜占庭容错方法（在副本间聚合参数梯度）不同，我们的方法验证了层与层之间的顺序激活/梯度传输。我们为这种新设置提供了理论收敛保证，在放宽到标准训练时可恢复经典的收敛速率。实验表明，在包含多达 176 个工作节点的非受信任分布式环境中，该方法成功训练了参数量高达 40 亿（4B）的大语言模型（LLM），同时保持了模型的收敛性和性能。

## Abstract
Decentralized training introduces critical security risks when executed across untrusted, geographically distributed nodes. While existing Byzantine-tolerant literature addresses data parallel (DP) training through robust aggregation methods, pipeline parallelism (PP) presents fundamentally distinct challenges. In PP, model layers are distributed across workers where the activations and their gradients flow between stages rather than being aggregated, making traditional DP approaches inapplicable. We propose SENTINEL, a verification mechanism for PP training without computation duplication. SENTINEL employs lightweight momentum-based monitoring using exponential moving averages (EMAs) to detect corrupted inter-stage communication. Unlike existing Byzantine-tolerant approaches for DP that aggregate parameter gradients across replicas, our approach verifies sequential activation/gradient transmission between layers. We provide theoretical convergence guarantees for this new setting that recovers classical convergence rates when relaxed to standard training. Experiments demonstrate successful training of up to 4B-parameter LLMs across untrusted distributed environments with up to 176 workers while maintaining model convergence and performance.

### 2. 方法论：SENTINEL 核心思想与技术细节
*   **核心思想**：利用统计一致性进行监测。正常训练中，各节点的输出在统计上应保持稳定。SENTINEL 通过维护激活值和梯度的**指数移动平均（EMA）**作为参考基准，检测偏离基准的异常行为。
*   **关键技术细节**：
    *   **验证节点（Verifier Nodes）**：在流水线各阶段之间设置轻量级的验证节点（通常为 CPU 节点），拦截并校验通信信号。
    *   **多维距离度量**：使用 L1 距离、归一化 L2 距离、符号翻转率（SFR）和切片 Wasserstein 距离（SWD）等多种指标来捕捉不同类型的攻击。
    *   **自适应阈值（Adaptive Thresholds）**：利用四分位距（IQR）和 Tukey's fences 算法，根据训练动态自动调整检测阈值，以平衡检出率和误报率。
    *   **级联效应处理**：当检测到上游节点异常时，标记该批次为“受污染（tainted）”，并使用 EMA 动量值替换损坏的梯度，防止错误向全网扩散。
    *   **惩罚机制**：设置违规计数器和“宽恕”机制，多次违规者将被永久封禁。

### 6. 主要结论与发现
*   **高效检测**：SENTINEL 在大多数攻击场景下实现了 **>90% 的 F1 分数**。
*   **收敛保证**：理论证明并实验验证了，即使有少量弱攻击逃避了检测，其对最终模型收敛的影响也是微乎其微的（误差在可控范围内）。
*   **零冗余开销**：与需要双倍算力的冗余验证法相比，SENTINEL 几乎不损失训练吞吐量（TPS 提升一倍）。
*   **架构通用性**：该方法在 Dense 模型和 MoE 模型上均表现良好，且能无缝集成到现有的去中心化框架（如 SWARM）中。

### 7. 优点
*   **轻量化**：无需重复计算，验证过程对计算和带宽的额外消耗极低。
*   **自适应性**：通过 IQR 动态调整阈值，能够应对训练过程中的自然分布偏移。
*   **理论完备**：提供了非凸优化下的收敛性证明，填补了 PP 拜占庭容错的理论空白。
*   **实战化**：在真实的 AWS 地理分布环境下进行了验证，而非仅在单机模拟。

### 8. 不足与局限
*   **验证节点信任假设**：虽然验证节点很轻量，但仍假设这些中间协调节点是可信的。如果验证节点本身被攻破，系统将失效。
*   **超参数敏感性**：尽管有自适应机制，但 EMA 的衰减率（Beta）等参数在不同模型间仍可能需要微调。
*   **对抗性攻击进化**：虽然测试了隐蔽噪声攻击，但未来可能出现专门针对 EMA 统计特性的更高级伪装攻击。
*   **首尾层保护**：目前假设模型的第一层和最后一层由诚实节点运行（以保护输入数据和损失计算），这在完全去中心化的极端场景下可能难以保证。
