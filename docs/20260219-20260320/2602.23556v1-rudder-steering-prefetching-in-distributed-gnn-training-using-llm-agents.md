## 摘要
大规模图神经网络 (GNN) 通常通过将顶点的邻居采样到固定距离来进行训练。由于大型输入图是分布式的，训练需要频繁的非规则通信，这会阻碍前向计算的进度。此外，获取的数据会随着图、图分布、采样和批处理参数以及缓存策略的变化而改变。因此，任何静态预取方法都会错失适应不同动态条件的关键机会。在本文中，我们介绍了 Rudder，这是一个嵌入在最先进的 AWS DistDGL 框架中的软件模块，用于自主预取远程节点并最小化通信。Rudder 的自适应能力与标准启发式方法和传统机器学习分类器截然不同。我们观察到，当代大语言模型 (LLM) 中的生成式人工智能表现出诸如针对零样本任务的上下文学习 (ICL) 等涌现属性，并具有逻辑多步推理能力。我们发现这种行为非常适合自适应控制，即使在训练严重不足的情况下也是如此。在 NERSC Perlmutter 超级计算机上使用标准数据集和未见配置进行的评估显示，与基准 DistDGL（无预取）相比，端到端训练性能提升高达 91%，与静态预取相比提升了 82%，并将通信减少了 50% 以上。我们的代码可在 https://github.com/aishwaryyasarkar/rudder-llm-agent 获取。

## Abstract
Large-scale Graph Neural Networks (GNNs) are typically trained by sampling a vertex's neighbors to a fixed distance. Because large input graphs are distributed, training requires frequent irregular communication that stalls forward progress. Moreover, fetched data changes with graph, graph distribution, sample and batch parameters, and caching polices. Consequently, any static prefetching method will miss crucial opportunities to adapt to different dynamic conditions. In this paper, we introduce Rudder, a software module embedded in the state-of-the-art AWS DistDGL framework, to autonomously prefetch remote nodes and minimize communication. Rudder's adaptation contrasts with both standard heuristics and traditional ML classifiers. We observe that the generative AI found in contemporary Large Language Models (LLMs) exhibits emergent properties like In-Context Learning (ICL) for zero-shot tasks, with logical multi-step reasoning. We find this behavior well-suited for adaptive control even with substantial undertraining. Evaluations using standard datasets and unseen configurations on the NERSC Perlmutter supercomputer show up to 91% improvement in end-to-end training performance over baseline DistDGL (no prefetching), and an 82% improvement over static prefetching, reducing communication by over 50%. Our code is available at https://github.com/aishwaryyasarkar/rudder-llm-agent.

*   **核心问题**：现有的预取（Prefetching）或缓存策略大多是静态的或基于简单启发式规则的，难以适应动态变化的图分布、采样参数和硬件配置。
*   **整体含义**：本文提出了 **Rudder**，这是首个利用 **大语言模型（LLM）智能体** 动态引导分布式 GNN 预取策略的系统。它利用 LLM 的上下文学习（ICL）和推理能力，自主决定何时以及如何更新本地缓存（Persistent Buffer），从而最小化通信开销。

### 2. 方法论
*   **核心思想**：将预取决策建模为一个自适应控制问题，由 LLM 智能体根据实时运行指标（如缓存命中率、通信量、训练进度）做出决策。
*   **关键技术细节**：
    *   **评分策略（Scoring Policy）**：对缓存内的节点进行频率跟踪。访问时加分，未访问时按 0.95 倍率惩罚。分数低于阈值的节点被视为“陈旧”，优先被新采样的远程节点替换。
    *   **LLM 智能体工作流**：
        *   **指标收集器**：实时监控 `%-Hits`（命中率）、通信量和 Minibatch 进度。
        *   **上下文构建器**：记录历史决策及其对系统性能的实际影响，为 LLM 提供反馈闭环。
        *   **决策者**：LLM 接收结构化 Prompt（包含系统状态和历史），输出“替换”或“跳过”指令。
    *   **异步执行架构**：Rudder 在后台守护线程中运行 LLM 推理，与前台的 GNN 训练和采样任务重叠（Overlap），以隐藏推理延迟。
*   **算法流程**：训练开始后，预取线程在处理当前 Minibatch 的同时，将运行指标推入队列；LLM 智能体异步处理请求并返回决策；预取线程根据决策更新本地持久缓冲区。

### 6. 主要结论与发现
*   **性能飞跃**：Rudder 相比无预取基准提升了高达 **91%** 的端到端性能，相比静态预取提升了 **82%**。
*   **通信优化**：成功减少了超过 **50%** 的远程数据通信量。
*   **LLM 优势**：小型 LLM（如 Gemma3-4B）在零样本（Zero-shot）任务中表现优于经过离线训练的传统 ML 分类器，尤其是在复杂、多变的训练配置下。
*   **推理开销**：通过异步重叠技术，LLM 的推理延迟几乎可以被完全隐藏，不会阻塞训练主循环。

### 7. 优点
*   **自适应性强**：无需针对每个数据集进行繁琐的手动参数调优。
*   **零样本学习**：利用 ICL 避免了收集海量训练轨迹来训练专用 ML 模型的昂贵成本。
*   **系统集成度高**：直接嵌入工业级框架 DistDGL，具有很强的实用价值。
*   **轻量化尝试**：证明了量化后的小型语言模型（SLM）足以胜任复杂的系统优化任务。

### 8. 不足与局限
*   **推理延迟风险**：在极高性能的计算环境下，如果训练步长极短，LLM 的推理速度可能跟不上 Minibatch 的产生速度，导致决策滞后。
*   **Prompt 依赖**：系统性能高度依赖于 Prompt 的设计质量。
*   **模型选择**：并非所有 LLM 都适用，实验显示某些模型（如 Qwen-1.5B）在遵循指令和逻辑推理方面表现较差，导致决策失效。
*   **显存占用**：尽管使用了量化技术，LLM 仍需占用一定的 GPU 显存，在显存极度紧张的 GNN 任务中可能存在竞争。
