## 摘要
随着大语言模型（LLM）规模的增加和上下文长度的扩展，注意力计算已成为 LLM 推理服务中的关键性能瓶颈。为了实现快速的注意力计算，近期的实践通常在多个 GPU 上并行化注意力头，并广泛采用注意力稀疏化来减少计算量——即在预设的稀疏度预算下选择性地计算注意力对的子集。在本文中，我们注意到 LLM 模型的注意力头通常表现出异构且稳定的稀疏弹性，这促使我们实施头自适应（head-adaptive）的稀疏度预算，以在保持高推理质量的同时获得更好的效率。然而，从系统层面来看，由于稀疏程度不同，不同头上的注意力计算时间会不一致，从而在多头并行部署下产生跨 GPU 的资源气泡（resource bubbles）。为了进一步减少此类气泡，我们提出了一种名为“稀疏感知多头并行负载均衡”（S-HPLB）的新型注意力部署策略。在长上下文基准测试上的实验表明，S-HPLB 在不降低质量的情况下，可实现 2.88 倍的平均注意力计算延迟改进。

## Abstract
With the increasing volumes of Large Language Models (LLMs) and the expanding context lengths, attention computation has become a key performance bottleneck in LLM serving. For fast attention computation, recent practices often parallelize the attention heads on multiple GPUs, and also widely adopt attention sparsification to reduce the computation amount -- which selectively computes a subset of attention pairs under a preset sparsity budget. In this paper, we notice that attention heads of an LLM model often exhibit heterogeneous-yet-stable sparsity elasticities, which motivates us to enforce head-adaptive sparsity budgets to attain better efficiency while preserving high inference quality. Yet, from the system aspect, with heterogeneous sparsity levels, attention computation time on different heads would be inconsistent, yielding cross-GPU resource bubbles under head-parallel deployment. To further minimize such bubbles, we propose a novel attention deployment strategy called Sparsity-aware Head-Parallel Load Balance (S-HPLB). Experiments on long-context benchmark show that, S-HPLB can achieve a $2.88\times$ improvement in average attention computation latency without quality degradation.

### S-HPLB：通过稀疏感知多头并行负载均衡实现高效的大语言模型推理服务

#### 1. 核心问题与整体含义（研究动机和背景）
随着大语言模型（LLM）上下文长度的增加，注意力机制（Attention）的计算开销呈平方级增长，成为推理服务的核心瓶颈。虽然现有的“稀疏注意力”技术（如 Top-k 策略）能减少计算量，但通常对所有注意力头采用统一的稀疏预算。
**研究动机：** 作者发现不同注意力头对稀疏性的敏感度（即“稀疏弹性”）具有显著的**异构性**（有的头只需少量 Token 即可恢复大部分权重，有的则需要更多），且这种特性在不同任务间表现**稳定**。然而，若为不同头分配不同的计算预算，会导致在多 GPU 并行部署时出现严重的负载不均衡（Load Imbalance），产生资源气泡。

#### 2. 论文提出的方法论
论文提出了 **S-HPLB**，一种系统与算法协同设计的框架，包含两个核心组件：
*   **自适应头预算分配（Adaptive Head Budget Allocation）：**
    *   **离线分析：** 利用注意力头稀疏特性的稳定性，通过少量样本离线分析每个头的稀疏模式。
    *   **Max-Min 预算转移：** 在总计算预算不变的前提下，采用迭代策略将高稀疏度（容易压缩）头的预算转移给低稀疏度（难以压缩）的头，以在相同计算量下最大化模型精度。
*   **多头并行负载均衡（Head Parallel Load Balance）：**
    *   **问题建模：** 将注意力头到 GPU 的分配建模为“多路划分问题”（Multiway Partitioning），目标是最小化各 GPU 间的负载差异比。
    *   **贪心启发式算法：** 将注意力头按预算降序排列，依次将其分配给当前负载最小的 GPU。该算法复杂度低（$O(N \log N)$），适合实际部署。

    *   全量注意力（Full Attention / FlashAttention）。

#### 6. 主要结论与发现
*   **精度提升：** 在 RULER 基准上，S-HPLB 的平均精度优于所有稀疏注意力基准，且与全量注意力相当（差距仅在 0.5%~3.1% 之间）。
*   **延迟降低：** 相比全量注意力，S-HPLB 实现了 3.3x~4.2x 的加速；相比最先进的动态稀疏方法（XAttention），延迟降低了 **2.88 倍**。

#### 7. 优点
*   **系统-算法协同：** 不仅优化了算法层面的预算分配，还解决了系统层面的并行负载不均问题。
*   **高效性：** 避免了 Top-p 方法中昂贵的在线注意力图分析开销。
*   **Pareto 优越性：** 在相同的延迟水平下，S-HPLB 能够提供更高的模型精度，始终处于性能前沿面。
